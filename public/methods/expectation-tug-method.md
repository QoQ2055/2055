# 预期拉扯法 · 主线宏观蓝图 + 客观尺子

> **来源**：墨香阁柒爷网文创作课《预期管理的魔法》第四课「第二部分 · 设计故事主线的宏观蓝图」。
> **定位**：craft 层 · **主线设计型模块**（与 information-asymmetry / 9-pleasure / expectation-cycle 强协同）。
> **核心命题**：故事的根本矛盾 = 主角的"现实状态"与"期望状态"之间一场漫长的拉锯战。所有事件设计的客观尺子 = **是否清晰移动了这两个指针**。
> **核心价值**：把"凭感觉创作"升级为"精确施工" · 提供**客观可衡量的事件评估标准**。

---

## 适用边界

✅ **强推荐启用**（几乎全部叙事项目）：
- 都市爽文 / 玄幻升级 / 系统流 / 重生流
- 言情甜宠 / 大女主 / 战神文
- 悬疑推理 / 灾难科幻 / 反乌托邦
- 短剧 / 动态漫
- 武侠 / 仙侠 / 古风权谋

⚠ **可选启用**：
- 散文式 / 意识流叙事（部分采用）
- 群像小说（每个主角独立画指针）

❌ **不要启用**：
- 完全的非叙事内容（诗集 / 散文集）
- 实验性反主流叙事（故意打破期待）

---

## 核心心法 · 故事 = 指针拉锯

```
现实指针：主角"当前客观的"身份/地位/处境
期望指针：主角"内心深渊渴望"的身份/地位/处境

故事的全部内容 = 主角让两个指针重合所付出的努力
                = 现实 ↔ 期望 之间的反复拉扯
```

→ 写故事前问：**主角的现实是什么？期望是什么？两者鸿沟有多大？**

---

## 第一部分 · 预期拉扯 4 步法（主线设计）

### 步骤 1 · 制造鸿沟（确立目标 + 看点）

**作用**：确立故事的核心目标和主要看点。

**操作**：故事开端 → 让主角的"现实"与"期望"产生**巨大、几乎不可调和的差距**。

**鸿沟越大 = 看点越足**。

#### 经典模板

| 题材 | 现实指针 | 期望指针 | 鸿沟看点 |
|---|---|---|---|
| 先婚后爱 | 已经是法律夫妻 | 互相讨厌 · 想离婚 | 如何从恨变爱？ |
| 战神归来 | 看似废物 / 上门女婿 | 隐藏的真实身份是兵王 | 何时揭露身份？|
| 重生爽文 | 重生回 18 岁 | 改变前世悲剧 | 能否阻止厄运？|
| 个人成长 | 街头小混混 | 受人尊敬的人民教师 | 能否真正逆袭？|
| 复仇黑化 | 失去一切 / 悲惨 | 让仇人付出代价 | 能否实现复仇？|
| 悬疑推理 | 主角不知凶手 | 凶手藏在身边 | 能否找到真相？|

**LLM 注入**（novel.0 / novel.1）：
```
立项时强制完成 4 字段：
- 主角现实指针（一句话 · 具体可量化）
- 主角期望指针（一句话 · 具体可量化）
- 鸿沟描述（差距维度 · 物理 / 情感 / 地位 / 知识 / 关系）
- 长线看点（观众长期期待的核心问题）
```

### 步骤 2 · 反复拉扯（主体 · 事件链）

**作用**：故事主体部分 · 填充情节 · 持续调动观众情绪。

**操作**：设计**一连串事件** · 让两个指针像拔河一样**来回拉扯** · 时而靠近 · 时而远离。

**这一步告诉我们 → 需要设计哪些事件**。

#### 事件分类（设计客观标准）

| 事件类型 | 作用 | 例子（先婚后爱）|
|---|---|---|
| **靠近事件** | 让"期望"向"现实"挪近 | 男主救了女主 → 女主心软（-100 → 0）|
| **远离事件** | 让"期望"远离"现实" | 白月光出现 → 女主误会（0 → -200）|
| **再靠近事件** | 拉回靠近 | 男主公开和白月光划清界限（-200 → -50）|
| **再远离事件** | 再次拉开 | 男主家族秘密暴露 |
| ... | 反复直到归零 | |

**关键原则**：
- 不是凭感觉"我觉得这样好玩" · 而是有目的设计
- 每个事件都问：**这个事件让指针向哪个方向移动了多少？**
- 靠近 / 远离事件**交错排列** · 不能连续靠近（无张力）也不能连续远离（无希望）

#### 节奏控制（事件密度）

```
长篇（30+ 章）：
- 每卷 5-8 个核心事件（3 靠近 + 2-3 远离 + 1 归零候选）
- 每章 1-2 个微事件 · 5 章一次重大事件

短剧（10-30 集）：
- 每集 1-2 个核心事件
- 第 5 集左右第一次归零 · 第 8 集第二次

短篇爽文：
- 每章 1 个核心事件
- 总计 30-100 个事件 · 间隔交错
```

**LLM 注入**（novel.2.1 / novel.2.2）：
```
分卷规划时强制：
- 标注每个事件类型（靠近 / 远离 / 归零）
- 标注事件对指针移动的影响幅度（轻微/中度/重度）
- 全卷靠近 vs 远离事件比例（约 1:1 · 不偏极端）
- 卷高潮 = 远离事件（归零候选）
```

### 步骤 3 · 归零（高潮前最低谷）

**作用**：制造**最大危机和转折点** · 将情绪推向**最低谷** · 为最高潮做铺垫。

**操作**：当反复拉扯接近"达成"时 → 设计**毁灭性打击事件** → 现实和期望**双双归零**。

#### 经典归零设计

| 题材 | 归零事件 |
|---|---|
| 先婚后爱 | 女主发现男主家族是导致自己家破人亡的元凶 → 递离婚协议 |
| 战神归来 | 兵团身份被仇敌曝光 → 国家通缉 → 战友被害 |
| 重生爽文 | 关键人物再次死亡 → 重生似乎也不能改变命运 |
| 个人成长 | 黑历史曝光 → 被开除 + 教育系统拉黑 |
| 复仇黑化 | 主角发现自己亲生父母才是真凶 |
| 悬疑推理 | 真相揭露 → 主角发现凶手是最亲的人 |

**关键**：归零必须**毁灭主角到目前为止的所有积累** · 不能"假危机"。

**LLM 注入**（novel.2.1 高潮设计）：
```
归零事件强制：
- 摧毁主角已积累 ≥ 80% 的成果（关系 / 地位 / 资源）
- 来源必须"足够强大"（不是命运恶作剧 · 是真实威胁）
- 时机：故事 70-85% 处（不能太早也不能太晚）
- 主角"绝望"描写（≥ 一段心理描写 + 1 个关键决定）
```

### 步骤 4 · 达成新平衡（结局）

**作用**：解决最终矛盾 · 实现主角成长 · 给予观众最终情感满足。

**操作**：积蓄力量 → 爆发"决战"和"救赎"事件 → 现实和期望**在更高层面完美重合**。

#### 关键差异 · 不是回到起点 · 是螺旋上升

```
原始起点：主角 [现实 A] · 期望 [B]
原始期望：变成 B 状态
归零后：失去一切
新平衡：主角达成 [B+] 状态（比 B 更高）
       且对 [B] 本身的理解发生了升华
```

#### 经典结局模板

| 题材 | 新平衡 |
|---|---|
| 先婚后爱 | 男主弥补女主 + 用行动证明爱 → 真心相爱（不只是"原谅" · 是更深的羁绊）|
| 战神归来 | 不仅复仇 · 还守护更多人 |
| 重生爽文 | 不仅修正前世遗憾 · 还创造新的可能 |
| 个人成长 | 没得到官方教师身份 · 但赢得真正"老师"的尊敬（更高层面） |
| 复仇黑化 | 选择宽恕（更高的胜利）|

**LLM 注入**（novel.2.1 结局设计）：
```
结局事件强制：
- 不是"回到起点 + 1" · 是"质变跃升"
- 主角"成长"必须可见（性格 / 价值观 / 能力维度任一）
- 结局画面与开场画面押韵（参考 truby-22-steps 押韵法则）
- 长线期待"终于实现"的情感满足感（不能开放结局给爽文 / 短剧）
```

## 第二部分 · 客观尺子（事件评估标准）

### 核心问题：我们设计事件的"尺子"是什么？

**绝不能是创作者主观感觉**（"今天心情好就让他们甜一下"）· 商业创作最忌"看心情"。

**客观尺子 = 预期管理模型本身**。

### 事件评估 4 问

每设计一个事件 · 强制问以下 4 个问题：

```
1. 这个事件让"期望指针"朝哪个方向移动？（靠近 / 远离 / 不变）
2. 移动的幅度是多少？（轻微 +10 / 中度 +30 / 重度 +60 / 归零 -∞）
3. 这是当前阶段需要的方向吗？（看主线蓝图）
4. 移动是否对观众清晰可见？（不能模糊 · 必须有明确事件触发）
```

→ **如果 4 问任一回答"不"= 事件设计失败 → 重写**。

### 真实案例对照

#### ❌ 失败设计
- "我觉得这章可以让主角和女主一起去吃饭" → 4 问失败：指针没移动 / 没明确方向 / 观众无感 → 重写
- "这章设计反派出现挑衅一下" → 4 问失败：远离了多少？为什么是这个时机？

#### ✅ 成功设计
- "这章设计男主公开支持女主反对家族 → 期望指针 +50（靠近）→ 当前阶段需要靠近铺垫归零事件 → 男主当众发声让所有人看见 → 观众清晰可见"
- "这章设计反派揭露男主家族真相 → 期望指针 -200（强远离 · 归零候选）→ 当前阶段需要归零 → 直接对话揭露 + 女主表情特写 → 观众清晰可见"

## 第三部分 · 从主观到客观的创作流程

```
[传统创作 · 凭感觉]
   ├─ 想到什么写什么
   ├─ 写到哪算哪
   └─ 卡文了 = 创作枯竭

[预期拉扯 · 工程学]
   ├─ Step 1：画两个指针 + 鸿沟
   ├─ Step 2：列事件清单（靠近 + 远离 交错）
   ├─ Step 3：每事件用客观尺子评估
   ├─ Step 4：归零时机选定
   └─ Step 5：新平衡押韵开场
```

→ 创作 = "有图纸、有公式、有升级路径的工程学"。

## 第四部分 · 与信息差魔术法的协作

```
预期拉扯 = 导航（长线主线）
信息差魔术 = 路况（瞬间冲突）

预期拉扯告诉你：
- "这章是靠近事件 · 男主救女主"
- "这章指针 +50"
↓
信息差告诉你：
- "用什么牌局玩法实现救人？"
- "观众应该知道什么？主角不知道什么？反派不知道什么？"
- "用台词 / 动作 / 道具 / 旁白哪种方式安插信息？"
```

→ **预期管理负责搭台 · 信息差负责唱戏**。

参考 `information-asymmetry-method.md` § 第三部分。

## 检验清单（dogfood 时人工抽检）

- [ ] 项目立项含**清晰的两个指针 + 鸿沟描述**

- [ ] 靠近事件 vs 远离事件**比例约 1:1**（不偏极端）
- [ ] **归零事件**位于 70-85% 处（不能太早或太晚）

- [ ] 每章事件能用**客观尺子 4 问**通过

## 范例 · 一句话激活公式

```
{ 主角 } 是 [现实状态] · 内心渴望 [期望状态]
两者之间的鸿沟是 [鸿沟描述]
故事通过 [N 个靠近 + N 个远离 + 1 个归零] 反复拉扯
最终在 [新平衡描述] 实现两指针的更高层级重合
```
