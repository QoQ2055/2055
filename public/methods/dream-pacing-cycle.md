# 梦境高效满足感 · 爽点 4 段循环（事件级情绪体操）

> **来源**：墨香阁柒爷网文创作课《观众心理学与梦境关系》第二课「梦境三大指标 · 指标二」。
> **定位**：dream 层 · **守梦型模块**。爽文 / 短剧 / 网文项目**强烈推荐启用**。
> **核心命题**：观众生活在碎片化时间里 · 精神疲惫 · 缺乏耐心。打开内容像饥饿者走进餐厅 · 需要**立刻吃到最美味的食物** · 任何多余的等待都会烦躁离开。
> **核心价值**：用**事件级 4 段循环**（压力 → 引燃 → 爆发 → 展示发酵）标准化情绪释放流程，确保**每一次情绪释放的强度都达到最大化**。

---

|---|---|---|

→ **不冲突，互补**：一章可包含 1-3 个本模块的 4 段循环（嵌套使用）。

## 适用边界

✅ **强推荐启用**：
- 都市爽文 / 赘婿逆袭 / 战神归来
- 玄幻升级流 / 系统流 / 修真爽文
- 短剧（霸总 / 复仇 / 装逼）
- 任何含"打脸 / 装逼 / 碾压 / 反转"的项目

⚠ **可选启用**：
- 言情甜宠（爽点更柔和 · 部分采用）
- 大女主 / 大男主成长剧（部分采用 · 弱化"展示发酵"段）

❌ **不要启用**：
- 严肃文学（节奏不应 mechanized）
- 慢热成长向（爽点稀缺更有力）
- 推理悬疑（节奏靠揭谜而非情绪体操）

## 核心心法 · 情绪体操

```
不是在讲故事 · 是在做"情绪体操"
通过 [先抑后扬] 标准化流程 · 确保每次情绪释放的强度最大化
```

→ 我们不创造情绪 · 我们**精确制造**情绪。

## 4 段循环 · 实操指引（LLM 提示词）

### 段 1 · 压力阶段（憋）

**核心**：**快速积蓄观众的愤怒和期待**。

**做法**：
- 反派 / 路人 / 既得利益者**嚣张跋扈** / **冷嘲热讽** / **欺凌弱者**
- 主角处于**弱势**（伪装弱 / 被低估 / 被孤立）· 必须强压住手段
- 反派的"作恶"必须**清晰指向受害者**（不能是抽象的恶 · 必须有具体的人受害）

**字数控制**：
- 短剧：100-200 字
- 短篇爽文：300-500 字
- 长篇章节：500-1000 字

**反例**（压力不够 → 爆发不爽）：
- ❌ 反派只是嘴上挑衅（没有实际恶行）→ 观众："好吧，反正没人受伤"
- ❌ 主角根本没受影响（无关旁观）→ 观众："这关主角什么事？"
- ❌ 压力描写太长太细（铺垫超 1000 字）→ 观众："还没爆发？我要弃书了"

**正例**：
- ✅ 反派当众羞辱主角的女友 + 砸毁主角心爱物品 + 嘲笑主角无能
- ✅ 反派强抢主角公司 + 解雇全部老员工 + 让主角断财路
- ✅ 反派欺凌主角的妹妹 + 嘲笑主角"穷光蛋哥哥不在"

**LLM 注入**：
```
压力段必含：
- 反派具体恶行（≥ 1 件具体的、对主角阵营有伤害的事）
- 主角"被迫忍耐"的描写（憋住 · 蓄力）
- 旁观者反应（围观者畏惧 / 议论 / 助纣为虐）
```

### 段 2 · 引燃阶段（导火索）

**核心**：**一个关键的台词或事件** · 成为主角行动的**导火索**。

**做法**：
- 引燃必须有**具体明显的触发点**（不是主角"突然觉得受够了"）
- 引燃通常是反派**踩到主角底线**（伤害至亲 / 侮辱信仰 / 触犯尊严）
- 引燃**节奏极快**（200 字内完成 · 不能拖）

**字数控制**：
- 短剧：50-100 字
- 短篇爽文：100-200 字
- 长篇：200-400 字

**经典模板**：
```
反派：「你这种 [贬义词]，凭什么 [挑战我的资格]！」
主角：（眼神一冷 / 嘴角微扬）
```

**反例**（引燃不到位 → 爆发突兀）：
- ❌ 没有明确触发点（主角突然爆发 → 观众："为什么是这一刻？"）
- ❌ 反派挑衅过于温和（不足以让主角出手 → 观众："至于吗"）
- ❌ 引燃后主角又拖延（500 字才出手 → 观众："你倒是动手啊"）

**正例**：
- ✅ 反派："你妈以前求我办事时，跪着舔我的鞋。" → 主角眼神彻底冰封
- ✅ 反派当面撕毁主角已故父亲的画像 → 主角拍案而起
- ✅ 反派朝主角女儿吐口水 → 主角空气瞬间凝固

**LLM 注入**：
```
引燃段必含：
- 一句反派挑衅台词或一个反派恶行（具体、有冲击力）
- 主角微表情 / 微动作变化（眼神冷 / 拳头握紧 / 嘴角扬）
- 字数严格控制（不能超过压力段的 1/3）
```

### 段 3 · 爆发阶段（爽 · 核心）

**核心**：主角以**雷霆万钧之势** · 用实力或计谋 · **彻底粉碎反派的挑衅**。这是**情绪释放的核心**。

**做法**：
- 主角**展示压倒性力量**（能力 / 资源 / 智慧 / 关系）
- 反派被**全方位碾压**（物理 / 精神 / 财富 / 地位）
- **慢镜头化**（用 200-500 字详细描写打脸瞬间 · 哪怕现实中只有 1 秒）
- **多角度描写**（主角动作 / 反派表情 / 围观反应交替）

**字数控制**：
- 短剧：300-500 字
- 短篇爽文：500-1000 字
- 长篇：1000-2000 字（占章节最大块）

**反例**（爆发不爽）：
- ❌ 主角力量 ≤ 反派（碾压感不够）→ 观众："勉强赢的不爽"
- ❌ 爆发太快（300 字搞定一切）→ 观众："这就完了？回味不够"
- ❌ 主角心慈手软（留情 · 让反派"长记性"）→ 观众："彻底打死啊！"

**正例**：
- ✅ 主角随手一指 · 反派整栋楼倒塌 · 反派当场跪地求饶 · 围观者全部跪下
- ✅ 主角用 1 张银行卡碾压反派全部财富 · 反派看到余额当场吐血
- ✅ 主角秀出真实身份（神秘世家继承人）· 反派父亲亲自上门赔罪

**LLM 注入**：
```
爆发段必含：
- 主角力量 ≥ 反派 10 倍以上（绝对碾压感）
- 慢镜头描写（拆解动作 / 表情 / 反应 · 200-500 字）
- 反派"无法反抗"的细节（全方位被碾压）
```

### 段 4 · 展示发酵阶段（回味 · ★ 关键）

**核心**：**这一段尤其重要** · 用大量笔墨描绘 **3 件事**：
1. **反派失败后的惨状**（跪地求饶 / 失去一切 / 当众丢人）
2. **围观群众的震惊与崇拜**（氛围组催眠 · 见 dream-reality-anchor）
3. **主角获得的实质性奖励**（地位 / 财富 / 美女 / 资源）

**目的**：**延长和巩固胜利的快感** · 让观众**充分回味**。

**字数控制**：
- 短剧：200-400 字
- 短篇爽文：500-1000 字（占章节大块）
- 长篇：1000-2000 字

**反例**（发酵不够 → 爽点稀释）：
- ❌ 反派被打就消失（没有惨状描写）→ 观众："不够爽 · 没看够"
- ❌ 围观者无反应（没有氛围组催眠）→ 观众："这一切真的发生了吗？"
- ❌ 主角没有奖励（爆发后无收益）→ 观众："然后呢？"

**正例**：
- ✅ 反派当众丢人 + 失去全部财产 + 父亲断绝关系 + 美女女友离他而去
- ✅ 围观者 5 类不同身份反复夸赞主角（小妹崇拜 / 老板震惊 / 路人膜拜 / 朋友自豪 / 反派阵营恐惧）
- ✅ 主角当场获得：晋升 + 资源 + 美女青睐 + 反派遗孀求合作

**LLM 注入**：
```
展示发酵段必含：
- 反派失败惨状（≥ 3 个具体细节 · 跪 / 哭 / 失去 / 丢人）
- 氛围组反馈（≥ 3 个不同身份角色 · 见 dream-reality-anchor 协同）
- 主角实质奖励（≥ 1 个 · 地位 / 财富 / 美女 / 资源）
- 字数 ≥ 爆发段（不能比爆发短 · 否则发酵不够）
```

## 4 段比例 · 黄金配比

```
                字数占比
                ────────────────────
压力（憋）     25-30%   ━━━━━━
引燃（导火索） 5-10%    ━
爆发（爽核心） 30-35%   ━━━━━━━━
展示发酵       30-40%   ━━━━━━━━━ ★ 关键
```

→ **展示发酵 = 4 段中最长（或与爆发齐长）**。新手最容易犯错：爆发完就匆匆收尾。

## 高频轰炸 · 章节级使用

**单章爽点循环数**：
- 短剧：1-2 个完整循环
- 短篇爽文：2-3 个完整循环
- 长篇章节：1 个主循环 + 2-3 个微循环（小冲突 · 短压力 + 短爆发 + 短发酵）

**循环嵌套**：
```
章节开始
  ├─ 微循环 1：路人挑衅 → 主角秒杀（5 段 + 段落级）
  ├─ 主循环：反派 BOSS 出场 → 全套 4 段（章节主体）
  ├─ 微循环 2：女主登场 → 主角魅力展示（5 段 + 段落级）
  └─ 章节钩子：下一个憋点引子
```

**LLM 注入**：
```
章节生成时显式标注：
- 第 N 段：[压力 / 引燃 / 爆发 / 展示发酵 / 钩子]
- 字数占比检查（按黄金配比）
- 至少 1 个完整 4 段循环（短篇）/ 1 主循环 + 2 微循环（长篇）
```

## 检验清单（dogfood 时人工抽检）

- [ ] 每章**至少 1 个完整 4 段循环**（章节核心爽点）
- [ ] **展示发酵段** ≥ 爆发段长度（不能匆匆收尾）
- [ ] 压力段反派恶行**具体化**（不是抽象的"嚣张"）
- [ ] 引燃段**节奏极快**（≤ 压力段 1/3）
- [ ] 爆发段**慢镜头描写**（拆解 / 多角度 / 200+ 字）
- [ ] 展示发酵段含 3 件事（惨状 + 氛围 + 奖励）

## 范例 · 4 段循环模板（爽文）

```markdown
## 第 N 章 · 反派挑衅

### 段 1 · 压力（30%）
[反派当众羞辱主角女友] + [反派强抢主角公司] + [主角强压怒火]
旁观者：议论 / 嘲笑 / 助纣

### 段 2 · 引燃（5%）
反派："你这穷光蛋，凭什么管我的事！"
主角眼神一冷 → 嘴角扬起冷笑

### 段 3 · 爆发（30%）★ 慢镜头
[主角秀出真实身份：神秘世家继承人] +
[反派父亲亲自上门赔罪] + [反派当场跪地]
- 主角动作描写
- 反派表情拆解
- 围观者震惊瞬间

### 段 4 · 展示发酵（35%）★ 关键
- 反派惨状：失去公司 / 父亲断绝关系 / 女友离开
- 氛围组反馈：5 类身份角色全部惊呼 / 崇拜 / 议论
- 主角奖励：女友更爱 / 公司被赎回 / 反派阵营资源易主

### 段 5 · 钩子
新反派阴影出现（更强的对手 · 下一个 4 段循环憋点引子）
```
