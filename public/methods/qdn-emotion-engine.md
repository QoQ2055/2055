# QDN 神经动力学情绪引擎 · 情绪化学式 + 8 基础情绪

> **来源**：墨香阁柒爷网文创作课《情绪篇 · 实战技巧》第九课「情绪编程 · QDN 模型」。
> **定位**：craft 层 · **情绪驱动最核心黄金资产**（与所有情绪模块强协同）。
> **核心命题**：情绪不是"感觉"出来的 · 是**化学合成**的。3 种核心神经递质（Q 血清素 / D 多巴胺 / N 去甲肾上腺素）的浓度变化 · 决定我们感受到的情绪。我们不需要"描写"情绪 · 只需要设计能精准影响 Q/D/N 的"外部环境"。
> **核心价值**：从"艺术"到"工程"的飞跃 · 让情绪可计算、可预测、可编程。

---

## 适用边界

✅ **强推荐启用**（**几乎所有情绪驱动项目**）：
- 短剧 / 网文爽文（精准制造爽感）
- 言情 / 虐文（精准制造虐点）
- 任何需要"情绪定量设计"的项目
- 关键章节情绪爆发段落

⚠ **可选启用**：
- 文学严肃（淡化用 · 仅做情感设计参考）

❌ **不要启用**：
- 工具书 / 说明文（无情绪设计需求）

## 核心心法 · 情绪的化学本质

### 革命性认知

```
我们平时说的"开心""难过""生气" · 只是文化标签
拨开标签深入大脑底层 · 情绪本质 = 一连串化学反应

世间万物色彩斑斓 · 根源是红/绿/蓝三基色
情绪千变万化 · 根源是 Q/D/N 三神经递质
```

### 关键认知转变

```
旧思路：直接"描写"情绪 · "她很难过 · 哭得很伤心"
新思路：设计影响 Q/D/N 的"外部环境" · 观众身体自动合成情绪

→ 调酒师不需凭空变出"莫吉托"
   只需按配方混合朗姆酒/青柠/薄荷/苏打水
   这杯酒自然就是莫吉托
```

→ **QDN 模型不是让你"感觉"情绪 · 是让你"设计"情绪化学配方**。

## 三大神经递质详解

### Q · 血清素 · 决定"自我价值感"

> **掌控感** / **自信** / **当下满意度**

```
+Q 高血清素：感觉"我能行""一切尽在掌握"
-Q 低血清素：感觉"我要完了""彻底失控"
```

#### Q 扳机事件库

| 方向 | 触发方式 | 事件库 |
|---|---|---|
| **+Q 提升自我价值** | 描写成功 / 安全 / 被尊重 / 亲密关系 | 主角打赢了 / 回到安全的家 / 获得崇拜和爱人拥抱 / 财富地位提升 |
| **-Q 打击自我价值** | 描写失败 / 危险 / 被孤立 / 地位下降 | 主角被打败 / 被追杀 / 被朋友背叛 / 当众出丑 / 破产 / 被羞辱 |

---

### D · 多巴胺 · 决定"未来预期"

> **希望** / **期待** / **正向 vs 负向预期**

```
+D 高多巴胺：产生"正向期待"·"马上就要有好事发生了！"
-D 低多巴胺：产生"负向期待"·"感觉要有坏事发生。"
```

#### D 扳机事件库

| 方向 | 触发方式 | 事件库 |
|---|---|---|
| **+D 给予希望** | 描写新希望 / 奖励线索 / 即将到来的好事 | 发现藏宝图 / 收到约会短信 / 大决战前获得神兵利器 / 得知翻盘秘密 |
| **-D 剥夺希望** | 描写希望破灭 / 坏事预兆 / 陷入两难 | 计划被识破 / 出现不祥血月 / 救妈妈还是救老婆两难 / 得知绝症 |

---

### N · 去甲肾上腺素 · 决定"注意力警觉度"

> **意外** / **警觉** / **专注 vs 麻木**

```
+N 高去甲肾上腺素：感觉"兴奋/专注"·"卧槽！什么情况？"
-N 低去甲肾上腺素：感觉"常规/麻木"·"哦 · 知道了。"
```

#### N 扳机事件库

| 方向 | 触发方式 | 事件库 |
|---|---|---|
| **+N 打破常规** | 描写突发事件 / 反转 / 意外消息 / 反常行为 | 平静婚礼上突然杀手闯入 / 最信任兄弟背后捅刀 / 死人突然发短信 / 主角做出反常决定 |
| **-N 维持常规** | 描写日常 / 重复 / 符合预期的结果 | 主角按部就班练功 / 太阳照常升起 / 反派如预料般被打败 / 生活平淡如水 |

## 8 基础情绪化学式 ★ 核心实操

### 工作流程

```
目标情绪 → 拆解成 QDN 化学式 → 查找对应事件扳机 → 组合成具体情节
```

### 产品 1 · 乐 = [+Q, +D, +N]

#### 化学式拆解

```
中了大奖式狂喜 = 三高
  +Q：我感觉自己牛逼爆了 · 是世界的主角！
  +D：我感觉未来一片光明 · 天大好事砸到我头上！
  +N：而且这件好事完全出乎我意料！
```

#### 实战合成

```
+N（意外）：主角在所有人都嘲笑他时 ·
            抱着玩玩心态刮开了一张彩票
+D（巨大奖励）：他发现自己中了头奖
+Q（被尊重 + 掌控感）：他拿着彩票 · 在全场震惊目光中 ·
                       向一直支持他的女友求婚 ·
                       感觉自己掌控了全世界
```

### 产品 2 · 悲 = [-Q, -D, -N]

#### 化学式拆解

```
生离死别式沉痛 = 三低
  -Q：我感觉自己渺小又无力 · 什么都改变不了
  -D：我珍视的东西永远失去了 · 未来一片灰暗
  -N：虽然痛苦 · 却又在我的预料之中 · 我无力反抗
```

#### 实战合成

```
-N（符合预期的坏结果）：主角病重的爱人 ·
                       在花了一辈子积蓄治疗后 ·
                       还是在一个平静的午后 ·
                       如医生预言的那样 ·
                       各项生命体征开始平稳下降
-D（希望彻底破灭）：主角握着她渐渐冰冷的手 ·
                   知道这一次再也不会有奇迹了
-Q（彻底失控失败）：当心电图拉成一条直线时 ·
                   主角感觉被全世界抛弃 ·
                   之前所有努力都失败了
```

### 产品 3 · 怒 = [-Q, +D, +N]

#### 化学式拆解

```
尊严被践踏式暴怒
  -Q：我的价值被否定 · 我被羞辱了 · 感觉自己很失败
  +D：不能就这么算了 · 我必须报复 · 我必须夺回尊严！
  +N：这个羞辱如此突然 · 点燃了我心中从未有过的怒火！
```

#### 实战合成

```
+N + -Q（突然强烈的价值打击）：
  主角在众目睽睽之下 ·
  被反派毫无征兆地、狠狠地打了一巴掌

+D（强烈反击欲望）：
  全场死寂的屈辱瞬间 · 主角没有哭 · 而是抬起头 ·
  看到对方眼神中那种极致的轻蔑 ·
  内心涌起一股"我今天一定要让你加倍奉还"的不可遏制的渴望
```

### 产品 4 · 惧 = [-Q, -D, +N]

#### 化学式拆解

```
面对未知不可控危险式恐惧
  -Q：我感觉自己要死了 · 完全没有反抗能力
  -D：未来充满危险和不确定 · 下一秒会发生更可怕的事
  +N：因为一个可怕的东西突然出现了 · 打破了原有的平静！
```

#### 实战合成

```
+N（打破常规）：
  主角一个人走在漆黑的、本应空无一人的医院走廊 ·
  突然听到背后传来"嘀嗒、嘀嗒"的脚步声 · 而且越来越近

-Q（打击自我价值）：
  他想跑 · 但发现双腿像灌了铅一样不听使唤 ·
  感觉自己被未知强大的东西盯上了 · 像砧板上的肉

-D（剥夺希望）：
  唯一的希望——走廊尽头的出口大门 ·
  突然"砰"的一声自己关上了
  他被彻底困在了这里 · 未来只有无尽的危险
```

### 产品 5 · 惊 = [+Q, -D, +N]

#### 化学式拆解

```
注意：惊 ≠ 惧
惧是负面的 · 惊是中性的（"世界观被刷新"的震惊）

  +Q：我当下的状态还行 · 甚至有点得意 · 感觉自己正常
  -D：我对未来没什么特别想法 · 一切都在按部就班
  +N：但卧槽？！这是什么鬼？！发生的事超出了我的认知！
```

#### 实战合成

```
+Q + -D（维持常规）：
  主角（普通上班族）正在自己家里 ·
  悠闲地看电视吃薯片 · 对生活很满意

+N（打破常规）：
  突然窗外传来巨大轰鸣声
  他拉开窗帘一看 · 他最好的朋友——
  一个他以为一直很穷和他一样天天挤地铁的普通同事——
  正开着一架私人直升机 · 悬停在他家窗外
  对他招手说："兄弟 · 上机 · 带你去兜风！"
```

### 产品 6 · 怡 = [+Q, +D, -N]

#### 化学式拆解

```
注意：怡 ≠ 乐
乐是爆发式狂喜 · 怡是"一切尽在掌握"的从容愉悦

  +Q：我很牛逼 · 我对自己的能力和判断力充满自信
  +D：我知道接下来会有好事发生 · 而且这是我应得的
  -N：这一切都在我的计划之内 · 没有任何意外
```

#### 实战合成

```
-N（维持常规）：故事发生在重要考试结果公布之前

+Q + +D（自信与正向期待）：
  主角（次次考第一的学霸）考完试后 · 根本不和别人对答案
  当朋友紧张地问他考得怎么样时 ·
  他只是淡定地推了推眼镜 · 说了一句：
  "这次的第一名 · 应该还是我。"
  然后就去图书馆看下一本课外书了
  胸有成竹 · 对即将到来的荣誉毫不怀疑
```

### 产品 7 · 怯 = [-Q, +D, -N]

#### 化学式拆解

```
"想爱又不敢爱"的胆怯/自卑

  -Q：我感觉自己不行 · 我配不上这么好的东西/人
  +D：前面有个好东西（奖励）在向我招手 · 真的很诱人
  -N：过程太平静了让我不安 · 怕其中有诈、怕自己出丑
```

#### 实战合成

```
+D（给予希望）：
  主角（家境贫寒、性格内向的穷小子）
  意外收到了全校公认的校花的毕业舞会邀请函

-Q + -N（打击自我价值 + 维持常规）：
  他拿着那封精美的邀请函 ·
  看着镜子里自己那件洗得发白的旧衬衫 ·
  和自己空空如也的钱包
  他想象着舞会上那些穿着华服、谈吐优雅的富家子弟 ·
  再看看自己 · 内心充满自卑
  觉得这一定是个恶作剧 · 或就算去了也只会让她和自己一起丢脸
  他犹豫着 · 迟迟不敢回复
```

### 产品 8 · 安 = [+Q, -D, -N]

#### 化学式拆解

```
风波过后的宁静与平和（故事大结局的"软着陆"）

  +Q：我现在很安全 · 一切尽在掌握 · 我对当下状态很满意
  -D：未来没有特别值得期待的惊喜 · 也不会再有坏事发生
  -N：生活平静如水 · 波澜不惊
```

#### 实战合成

```
+Q + -D + -N 稳定状态：
  主角在经历了一系列惊心动魄的冒险 · 打败大魔王之后 ·
  放弃了王位和财富 · 回到了阔别已久的家乡
  在一个阳光明媚的下午 · 他什么也不做 ·
  只是躺在院子里那棵老槐树下的摇椅上 ·
  喝着妻子泡的茶 ·
  看着自己的孩子在不远处追逐蝴蝶
  岁月静好 · 现世安稳
```

| 情绪 | Q | D | N | 描述 |
|---|:---:|:---:|:---:|---|
| **乐** | + | + | + | 中奖式狂喜 |
| **悲** | - | - | - | 生离死别式沉痛 |
| **怒** | - | + | + | 尊严被践踏式暴怒 |
| **惧** | - | - | + | 未知不可控式恐惧 |
| **惊** | + | - | + | 世界观被刷新式震惊（中性）|
| **怡** | + | + | - | 一切在掌握式愉悦 |
| **怯** | - | + | - | 想要又不敢式胆怯 |
| **安** | + | - | - | 风波过后式平和 |

### 速记口诀

```
QDN 三符号：
  + + + = 乐    - - - = 悲
  + + - = 怡    - - + = 惧
  + - + = 惊    - + + = 怒
  + - - = 安    - + - = 怯

→ 8 种基础情绪 = 2³ = 8 种 QDN 组合（覆盖所有可能）
```

## 高阶进阶 · 复合情感（手术刀类比）

### 关键认知

```
QDN 模型只是"新手村装备" · 不是世界的全部
真实人生体验远比 8 种基础情绪复杂得多
我们感受到的往往是"五味杂陈""百感交集"的复合情感
```

### 复合情感的本质

```
复合情感 = 多种基础情绪的快速交织 + 相互影响 + 个人经历调制
```

### 复合情感分析示例

| 复合情感 | 基础情绪组合 | 触发场景 |
|---|---|---|
| **激动** | 乐 [+Q+D+N] + 惧 [-Q-D+N] | 上台领奖前 · 既开心又怕说错话 |
| **酸楚** | 悲 [-Q-D-N] + 怡 [+Q+D-N] | 看到前任过得幸福 · 替她高兴又为自己难过 |
| **释然** | 悲 [-Q-D-N] + 安 [+Q-D-N] | 折磨一生的仇人死了 · 大仇得报又内心空虚 |

### QDN 模型的真正意义

```
我们无法直接合成"五味杂陈"
但我们可以通过精准控制构成它的"基础情绪"的类别和强度
来间接但更深刻地引导观众的情绪走向

→ 顶级大厨没有"佛跳墙"调味料
   但他能精准控制火腿咸度、鲍鱼鲜度、花胶醇厚度
   最终为你呈现一道层次丰富的佛跳墙

→ QDN 是你手中的盐、糖、醋
   掌握它 · 你才能调配独一无二的"人生百味"
```

## 常见错误 · 化学式失败案例

### 错误 1 · 浓度不够

```
❌ 单写 +Q 想做"乐"
   主角打赢了反派 · 很开心
   → 缺 +D 和 +N · 只是"满意" · 不是"狂喜"

✅ 三高合成
   主角打赢了反派（+Q）
   还获得意外财富（+N + +D）
   → 真正的"乐"
```

### 错误 2 · 方向错误

```
❌ 想写"怒" · 但全是 -Q
   主角被打败 · 被羞辱 · 失去尊严 · 跪在地上哭
   → 这是"悲"不是"怒"

✅ 怒 = -Q + 强 +D + 强 +N
   主角被打败（-Q）· 但抬头看到反派轻蔑眼神（+N）
   涌起强烈复仇欲望（+D）
   → 这才是"怒"
```

### 错误 3 · 复合情感全部基础情绪都直白写出

```
❌ 写"释然"·  分别用大段写"悲"和"安"
   → 读起来割裂 · 不是复合 · 是切换

✅ 释然 = 在同一场景中同时激发悲和安的扳机
   仇人死了（+Q · 安）
   但主角看着尸体 · 想起自己被仇人毁掉的青春（-Q -D · 悲）
   → 真正的"释然"是同时存在
```
