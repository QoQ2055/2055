# 超自然网文综合包（ATU 编码 + 三大类型本土化）

> **来源**：用户上传《超自然网络小说 AI 创作方法论（提炼版）》。架构实现部分（AAPT 提示模板 / HCC 上下文管理 / 一致性三工具）已归档到 `docs/architecture-refs/supernatural-webfiction-v1.md`，本模块只保留创作层规则。
> **定位**：工艺层题材增强模块，**与任意结构骨架正交**（Save the Cat / 英雄之旅 / ATU 301 / 三幕式 / 起承转合）。
> **价值**：给超自然题材网文提供**编码系统 + 元素赋值公式 + 三大子题材落地映射**，让 LLM 写修仙 / 魔法 / 都市异能时有可抄的骨架。

---

## 适用边界

✅ **推荐启用**（超自然题材）：
- 修仙 / 玄幻 / 仙侠 / 东方神魔
- 西方奇幻 / 魔法学院 / 剑与魔法
- 都市异能 / 都市超能力 / 灵异 / 克苏鲁
- 异世界穿越（含超自然元素）
- 无限流（含异常 / 规则怪谈）

❌ **不要启用**：
- 都市现实主义 / 职场 / 校园（无超自然）
- 纯硬科幻（靠科学设定撑世界，不是超自然）
- 历史 / 穿越但无异能设定
- 纯言情 / 甜宠

## 二、超自然元素三维编码库（写世界观设定时硬律）

### 2.1 魔法物品三维赋值（D 类硬律）

**每一件魔法物品必须同时设定三维，缺一不合格**：

| 维度 | 可选值 |
|---|---|
| **功能** | 攻击 / 防御 / 辅助 / 移动 / 信息 / 控制 |
| **形态** | 物品 / 生物 / 能力 / 空间 / 时间 / 契约 |
| **限制** | 次数 / 条件 / 代价 / 副作用 / 冷却 |

**示例**：「不死剑」= 功能（攻击+信息）+ 形态（物品）+ 限制（每次出鞘需献血 1 滴 + 使用者寿命 -1 年）

**硬律**：限制维度**必须实际制约剧情**（契诃夫规则），不能只是摆设。限制被突破时应成为剧情转折点。

### 2.2 契约系统 C 类三元结构（C900–C999）

超自然契约**必须**满足三元结构：

```
条款（Contract Terms）
  ↓
代价（Cost）
  ├─ 即时代价（签约瞬间付出）
  ├─ 持续代价（每次动用付出）
  └─ 终极代价（违约或到期付出）
  ↓
违约（Breach）
  ├─ 警告（轻度违反）
  ├─ 制裁（中度违反）
  └─ 追索（严重违反，追至极限）
```

**写作硬律**：主角与恶魔 / 神灵 / 系统的契约必须明示**三重代价**，其中**终极代价**应在全书 60–80% 位置显化，成为主线终极抉择。

### 2.3 变形 D 类四种触发

| 触发类型 | 叙事功能 | 典型场景 |
|---|---|---|
| **自愿变形** | 选择与代价主题 | 为救人主动接受异化 |
| **强制变形** | 身份认同危机 | 被诅咒 / 被系统绑定 |
| **条件触发** | 自我控制 vs 释放张力 | 情绪爆发时变身 |
| **渐进变形** | 成长与蜕变史诗感 | 境界突破 / 身体异化 |

### 2.4 生死母题（H 类）情感权重

写死亡 / 复活场景时按下表估量情感冲击：

| 类型 | 情感指数 | 写法要点 |
|---|---|---|
| **真实死亡** | **10** | 永久消失不可逆，需有替代性收尾（他人继承遗志） |
| **条件复活** | 8 | 真爱 / 心愿 / 献祭条件明示，**条件必须前置埋好** |
| **象征死亡** | 6–7 | 能力 / 身份丧失，可逆，需设计重生仪式 |
| **代价复活** | 复杂 | 带来**希望 + 愧疚 + 恐惧**三重情绪，最难写 |
| **假死** | 3–4 | **前文必须有至少一处不合理细节**让警觉读者提前怀疑 |

**硬律**：全书「真实死亡」数量 ≤ 主要角色总数的 30%，否则读者疲劳。

## 三、三大子题材 × 结构骨架本土化映射

超自然题材下，**结构骨架（英雄之旅 / ATU 301 等）需要按子题材做具体落地映射**。下面三张表让 LLM 知道"骨架的每一阶段在你这种题材里对应什么具体事件"。

### 3.1 东方玄幻 / 修仙体系映射

| 修仙境界 | 英雄之旅阶段 | 典型事件 |
|---|---|---|
| 炼气 → 筑基 | 冒险召唤 + 超自然援助 | 主角获得功法 / 遇到第一位师父 |
| **金丹** | 越过门槛 | 告别凡俗世界，正式踏入修真界 |
| **元婴** | 试炼之路 | 秘境闯关 / 宗门任务 / 打怪升级主战场 |
| **化神** | 遇见女神 | **心魔劫**：认知突破 / 面对内在阴影 |
| **渡劫** | 终极恩赐 | **天劫洗礼**：获得核心能力 / 神器 |
| **大乘** | 回归门槛 + 生活的自由 | 带着力量返回改变世界 / 成为两界主人 |

**志怪母题扩展**（东方特色）：
- ATU-EX 300.2-CN-01：**山中遇仙**（偶得仙缘）
- ATU-EX 301.2-CN-01：**闭关修炼**（时间跳跃叙事）
- ATU-EX 301.4-CN-01：**前世记忆觉醒**（身世揭露）

### 3.2 西方奇幻 / 魔法学院映射

| 年级阶段 | 英雄之旅阶段 | 典型事件 |
|---|---|---|
| **入学** | 冒险召唤 | 收到入学通知 / 身份揭露 |
| **基础学年** | 超自然援助 | 遇到导师 / 学习基础课程 / 结识伙伴 |
| **中级学年** | 越过门槛 | 进入禁忌区域 / 第一次实战 |
| **高级学年** | 试炼之路 | 学院竞赛 / 团队任务 / 面对派系斗争 |
| **毕业危机** | 终极恩赐 | 面对终极威胁 / 学院沦陷 |
| **毕业后** | 回归门槛 | 带着习得能力走向更广阔世界 |

### 3.3 都市异能 · 渐进渗透五层级

都市异能特有的**世界观渗透节奏**：

```
感知层（偶尔看到异常，以为自己幻觉）
    ↓
接触层（直接与异常接触，无法否认）
    ↓
卷入层（被迫参与异能事件）
    ↓
认同层（接受自己的异能身份）
    ↓
融合层（自由穿梭两个世界）
```

**硬律**：每层停留章数建议 8–15 章，总占比约 30–50%（剩余篇幅做大冒险）。过快跳层会让"都市感"崩塌，过慢会让爽感延迟。

## 四、冲突升级模型

### 4.1 三维挑战

每次重大冲突必须**至少覆盖两维**，否则过于单薄：

| 挑战类型 | 内容 |
|---|---|
| **能力挑战** | 超自然能力强度 / 技巧 / 创新应用 |
| **资源挑战** | 信息获取 / 物资筹备 / 人脉调动 |
| **道德挑战** | 价值取舍 / 底线坚守 / 代价承受 |

### 4.2 冲突强度曲线

- **常规提升**：幂律增长 S(t) = S₀ × (1+r)^t，r ≈ 0.05–0.15（每章强度微增）
- **战力跃迁**：获得关键元素后提升 50%–200%（对应"终极恩赐"节点）
- **硬律**：相邻两章强度差不超过 30%，跃迁必须有剧情触发事件（非凭空成长）

## 五、元素调用频率（斐波那契间隔）

超自然元素的出现频率按斐波那契数列：

| 元素等级 | 出现频率 | 示例 |
|---|---|---|
| **核心元素**（主角神器 / 金手指） | 每章 | 如系统 / 灵根 |
| **重要辅助**（关键援助者） | 每 2–3 章 | 如师父 / 伴生灵宠 |
| **次要元素**（一次性道具） | 每 5–8 章 | 如补给丹药 |
| **稀有元素**（世界规则揭示） | 每 13–21 章 | 如突破境界的本质 |

**波浪式分布**（每 10–15 章一个节奏单元）：
- 上升期（3–5 章）→ 高潮期（2–3 章）→ 下降期（3–5 章）→ 蓄力期（2–4 章）

## 六、质量控制 5 指标（全书 / 卷末自检）

| 指标 | 合格标准 |
|---|---|
| 原型母题覆盖率 | 英雄之旅每阶段至少 1 次核心场景 |
| 功能母题均衡 | 每 FSM 簇至少 2 次出现，相邻重复 ≤ 3 次 |
| 情感载荷平衡 | 正面 / 负面母题比例 4:6 到 6:4 |
| 元素密度 | 开篇 5–8 次 / 万字，高潮 12–18 次 / 万字 |
| 新鲜感指数 | 首次出现元素占比 > 30% |

## 七、十大核心原则

1. **类型是骨架，ATU 是肌肉，FSM 是血液** —— 三层缺一不可
2. **母题链式触发**：因果驱动，**绝不允许事件堆砌**
3. **密度控制节奏**：高潮密集，铺垫稀疏
4. **契约系统 = 条款 + 代价 + 违约三元结构** —— 缺一不合格
5. **冲突升级 = 幂律提升 + 阶梯跃迁**
6. **每章必须有钩子，超级钩子贯穿半部作品**
7. **超自然元素渐进揭示**：前期单一 → 中期组合 → 后期联动
8. **平凡世界压缩，冲突前置，倒叙式启程**（第一章就呈现核心冲突）
9. **主角成长 = 功能整合**，不等于类型转换
10. **女性英雄之旅**需要主动赋予**完整的行动空间**（不能让她只是被救）

## 八、与其他模块协同

- **与 `heros-journey-12stages` / `atu-301-rescue-quest`**：强协同。本模块的三大子题材映射表（修仙 / 魔法学校 / 都市异能）是**英雄之旅 / ATU 301 骨架在超自然题材下的落地蓝本**。
- **与 `save-the-cat-15beats` / `three-act-structure`**：可叠加，但失去映射表的精确对齐价值。
- **与 `起承转合`**：较弱。起承转合偏东方散文化，与超自然网文爽文节奏不太契合。
- **与 `mbti-*` 角色层**：正交。角色 MBTI 与超自然契约 / 变形触发可交叉设计（如 ENTP 更可能签下"代价是自由"的契约）。
- **与 `plot-coherence-scaffold`**：强协同。本模块的"元素调用频率"+"契约三元结构"+"生死母题"可直接作为 `plot-coherence-scaffold` 的一致性校验依据。
- **与 `seven-emotion-peaks`**：协同。七情节奏点管"每章情绪锚点"，本模块管"每章超自然元素强度"，共同决定章节节奏。
- **与 `visual-dehydration`**：弱冲突。超自然网文大多需要较厚的内心戏描写（灵力感受、境界感悟），不适合开脱水法。
