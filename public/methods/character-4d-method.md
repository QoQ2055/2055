# 4 维穿衣法则 · 人物魅力核动力

> **来源**：墨香阁柒爷网文创作课《人物篇 · 实战技巧》第七课「灵魂构建」。
> **定位**：character 层 · **人物灵魂构建型模块**（与 character-810-blueprint / character-three-elements-method 强协同）。
> **核心命题**：人物魅力 ≠ 完美 / 鲜明。**完美是无聊的**。魅力的核动力 = **外显与内含之间的矛盾**。
> **核心价值**：用"选衣服 4 维"打造让观众**愿意走上去（吸引）+ 走得稳（逻辑）+ 舍不得下来（共情）**的桥梁。

---

## 适用边界

✅ **强推荐启用**：
- 长篇小说（人物驱动主场）
- 大女主 / 大男主成长剧
- 古风权谋 / 武侠仙侠
- 言情甜宠（虐心型）
- 任何要求人物有"反差感"的项目

⚠ **可选启用**：
- 中短篇（部分采用 · 弱化和谐机制）
- 短剧（4 维需精简到 2 维：外显 + 矛盾）

❌ **不要启用**：
- 纯爽文系统流（人物是工具人 · 不需要立体）
- 沙雕反讽（故意打破 4 维）

---

## 核心心法 · 选衣服理论

```
观众 = 商场买衣服的顾客
人物 = 一件衣服

要被买走（被观众喜欢并代入）必须满足 4 维度：
  1. 款式好看（外显 · 设计感 · 符合大众身份）
  2. 尺寸合身（内含 · 强调自我不同）
  3. 独特不撞衫（矛盾 · 独特魅力）
  4. 材质舒服（和谐 · 真实感）
```

→ 现实生活中 · 我们既要安全感（不另类）· 也要个性（与众不同）。观众选主角同理。

---

## 第一维 · 外显（设计感）

### 定义

观众**第一眼看到的、最直观的标签**。也是主角希望向世界展示的样子。

### 评分标准 · 清晰度

观众能不能在 **3 秒钟内**用一个词概括出主角是谁？

| 评级 | 示例 | 评价 |
|:---:|---|---|
| 🟢 高分 | "霸道总裁" / "落魄皇子" / "搞笑男" / "高智商疯子" | 标签鲜明 · 设计感强 · 一眼吸引 |
| 🔴 低分 | "一个普通的、有点小帅的、正在找工作的大学生" | 标签模糊 · 设计平庸 · 毫无购买欲 |

### 设计原则

**外显要"脸谱化"但不能"俗套化"**。

- ✅ 脸谱化：用最鲜明的标签抓眼球（霸道总裁是脸谱化的好）
- ❌ 俗套化：千篇一律没新意（"又一个"穷小子被欺负开局）

### LLM 注入

```
角色 bible (novel.1.2) 必填：
- 一句话外显标签（≤ 8 字 · 必含身份 + 1 个特质）
- 第一次出场 200 字内观众能否提取此标签
- 与已有同题材作品的差异化点（防止撞衫）
```

## 第二维 · 内含（合身度）

### 定义

主角脱下伪装后**赤裸的灵魂**。是他想掩饰的软肋 · 或者**区别于同类角色的独特印记**。

### 评分标准 · 代入感与独特性

这件衣服穿在观众身上（代入）· 观众会觉得"这说的就是我"或"我理解这种感觉"吗？

### 高分案例

| 外显 | 内含 | 效果 |
|---|---|---|
| 无敌战神 | 是个路痴 + 怕老婆 | 神变成人 · 亲切合身 |
| 斯文败类 | 真的渴望家庭温暖 | 共情产生 · 想看救赎 |
| 冷酷杀手 | 偷偷喜欢可爱玩偶 | 反差萌 · 记忆点强 |

### 设计原则

**内含负责"吸粉"** · 外显吸引观众来看 · **内含让观众留下来**。

### LLM 注入

```
角色 bible 必填：
- 内含真我（≤ 30 字 · 与外显有显著反差）
- 内含的"软肋"或"创伤源"（与下面"和谐机制"链接）
- 与同类角色的差异印记（一句话）
```

---

## 第三维 · 矛盾（核动力）★ 魅力的发动机

### 核心定义

**外显标签**与**内含标签**之间那个**不可调和的冲突点**。

> **矛盾越尖锐 · 角色魅力潜力越高**。
> 这也是信息差的应用（外显已知 vs 内含未知）。

### 为什么矛盾是魅力？

**完美是无聊的**。
- 表里如一的好人 = 一眼望到底 · 没看头
- 表里如一的坏人 = 一眼望到底 · 没看头
- **外显 vs 内含打架** = **反常识 → 好奇 → 独特记忆点**

→ 同时产生**戏剧性**（不同信息差碰撞）。

### 经典矛盾配对

| 外显 | 内含 | 矛盾驱动看点 |
|---|---|---|
| 杀手 | 晕血 | "他怎么活下来的？杀人时多痛苦？" |
| 渣男 | 深情 | "他什么时候翻车？什么时候动真心？" |
| 冷面阎王 | 内心戏丰富 | "他每天到底在想什么？" |
| 神医 | 穷得揭不开锅 | "为什么有手艺却赚不到钱？" |
| 宗师 | 怕老鼠 | "在徒弟面前露馅怎么办？" |

→ **观众会立刻好奇 + 主角会在万千同质中独树一帜**。

### LLM 注入

```
角色 bible 强制：
- 显式标注外显 vs 内含的矛盾点（一句话）
- 矛盾尖锐度自评（1-10）· < 5 → 重新设计
- 矛盾如何在事件中触发（参考"矛盾驱动事件"段）
```

## 第四维 · 和谐（合理性 · 质感）

### 定义

既然外显和内含矛盾 · **这个人为什么还没精神分裂**？必须有一个合理的解释机制。

### 评分标准 · 可信度

| 评级 | 示例 | 评价 |
|:---:|---|---|
| 🟢 高分 | 外冷内热的人 = 童年被父母抛弃过（创伤源 → 自我保护） | 让矛盾合理 · 有血有肉有质感 |
| 🔴 低分 | "他就是这么个人 · 没有理由"（作者硬设定） | **人设崩塌** · 衣服扎人 |

### 常用和谐机制

| 矛盾 | 和谐机制（创伤源 / 历练 / 习惯）|
|---|---|
| 外冷内热 | 童年被亲人抛弃 → 自我保护机制 |
| 表面坏内心善 | 父母被冤枉害死 → 用"恶"对抗虚伪 |
| 看似软弱实则强大 | 师父早死 + 担心暴露 → 韬光养晦 |
| 装傻充愣实则聪明 | 出身世家 + 厌恶斗争 → 主动选择平庸 |

### LLM 注入

```
角色 bible 必填：
- 矛盾的"和谐解释机制"（1 个核心童年/经历事件）
- 此机制必须在前 30 章某处揭露给观众
- 揭露时机配合人物弧光（不能太早/太晚）
```

## 矛盾驱动事件设计 ★ 故事自动生成器

### 命题

**人物的矛盾 = 故事的发动机**。

不需要硬编情节 · 只需要把主角扔进**"必须在外显和内含之间做选择"**的场景里 · **情节自然诞生**。

### 事件生成器（3 类场景）

设定示例：
- 外显：高冷学霸 · 生人勿近
- 内含：极度社恐 · 内心戏丰富

#### 场景 A · 逼迫外显（喜剧/爽点）

强迫主角戴好面具但内心很痛苦。

**事件**：老师让他上台演讲（逼迫外显）。
- 表面：云淡风轻（维持外显）
- 内心：腿在桌子底下疯狂发抖（暴露内含）

**效果**：反差喜剧 · 观众会笑。

#### 场景 B · 逼迫内含（虐点/纠结）

强迫主角暴露真相但他恐惧被发现。

**事件**：他喜欢的女孩向他搭话。
- 心里想说："我好喜欢你"（内含）
- 嘴上冷冷说："借过"（外显）

**效果**：纠结虐点 · 观众想喊"快说出来啊！"。

#### 场景 C · 面具破碎（高潮/人物弧光）

极致场景让面具彻底戴不住。

**事件**：女孩被小混混欺负。
- 他再也装不了高冷了
- 冲上去打架 · 打得毫无章法但像个疯狗（内含冲破外显）

**效果**：人物弧光显现 · 观众震撼共情。

### 实操步骤（写给 LLM）

```
1. 列出主角的 [外显 + 内含 + 矛盾]
2. 为本章选择场景类型：A 逼迫外显 / B 逼迫内含 / C 面具破碎
3. 设计具体事件触发器（什么外部压力让主角必须做选择）
4. 描写"维持面具"vs"真心暴露"的拉扯过程
5. 标注本事件的人物弧光位置（铺垫期 / 试探期 / 爆发期）
```

→ **故事就永远有动力 · 观众就永远挪不开眼**。

## 4 种人物命运（结局类型）

根据"外显 vs 内含"这场战争的最终结果 · 所有人物驱动故事可归纳为 4 种结局：

### 结局 1 · 成长型（内含代替外显）

**故事走向**：主角一开始戴面具 · 经历一系列事件后获得勇气 · **打碎面具 · 活出真实的自己**。

**适用**：传统王道热血漫 / 励志剧 / 大女主成长剧

**经典案例**：哈利·波特（从胆怯走向救世主）

### 结局 2 · 现实型（势均力敌的摇摆）

**故事走向**：主角终其一生都在欲望（外显）和良知（内含）之间挣扎 · **永远无法彻底倒向哪一边**。

**适用**：深度权谋剧 / 黑色幽默剧 / 写实主义小说

**经典案例**：唐吉柯德（理想 vs 现实的永恒摇摆）

### 结局 3 · 和解型（外显与内含融合）

**故事走向**：主角不再对抗 · **接受了自己的复杂性**。变得豁达通透。

**适用**：宗师题材 / 治愈系故事 / 大结局状态

**经典案例**：星爷晚期作品（接纳自己的不完美）

### 结局 4 · 悲剧型（外显吞噬内含）

**故事走向**：主角为了获得力量或地位 · **彻底扼杀了内心的善良和软肋** · 变成了外显的那个人（彻底黑化）。

**适用**：枭雄传 / 反派前传 / 赛博朋克等暗黑题材

**经典案例**：《教父》迈克（从善良青年到冷血教父）

### 选型决策

| 项目类型 | 推荐结局 |
|---|---|
| 商业爽文 / 短剧 | 1 成长型（最爽）|
| 言情 / 大女主 | 1 成长型 + 部分 3 和解 |
| 严肃文学 | 2 现实型 / 3 和解型 |
| 悲剧 / 暗黑 | 4 悲剧型 |

## 检验清单（dogfood 时人工抽检）

- [ ] 主角**4 维全部填写**（外显 / 内含 / 矛盾 / 和谐）
- [ ] 外显标签**3 秒可识别**（清晰度高分）
- [ ] 内含与外显**有显著反差**（差异印记明显）
- [ ] 矛盾尖锐度 ≥ 5/10
- [ ] 和谐机制**前 30 章揭露**（不能太早/太晚）
- [ ] 每章至少含 1 个 A/B/C 场景（人物驱动项目）
- [ ] 结局类型与项目题材匹配
