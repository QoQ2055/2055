# ATU 301 · 救援奇幻骨架（七功能簇）

> **来源**：Aarne-Thompson-Uther 民俗故事类型索引 301 型 *The Three Stolen Princesses*，并融合 Vladimir Propp 31 功能论。
> **定位**：结构层方法论，与 Save the Cat / 英雄之旅 / 三幕式 / 起承转合 **互斥**（同一项目只选一个结构骨架）。

---

## 适用边界（**先看清楚再启用**）

✅ **推荐启用**：
- 西幻屠龙 / 神话重述 / 东方神魔 / 仙侠救师门
- 救援型系统文（"拯救被困 NPC / 另一个世界的某人"）
- 寻回任务型（找回丢失的神器 / 族人 / 爱人）
- 童话 / 民间故事改写 / 克苏鲁式"深渊探入 + 归来"

❌ **不要启用**：
- 都市 / 现实主义 / 职场 / 校园 / 甜宠 / 种田
- 硬科幻 / 赛博朋克 / 无限流（除非明确走"拯救某人"主线）
- 多主角群像 / 非线性叙事 / 散文化网文

> 这是**特定故事类型**的骨架，不是通用结构。强上到都市文 / 日常文会把故事**扭曲为"救公主"范式**，反而僵化。

---

## 七功能簇 · 强制骨架

长篇按下面七个簇**顺序推进**，每簇对应一段卷/多章。必备 = 主线必须出现；常见 = 可选但强烈推荐。

### 簇 A · 王国的破局（必备 · 开篇 5–10% 篇幅）

设置**失衡**：
- **A1 · 被盗**：关键对象（公主 / 爱人 / 神器 / 族人 / 记忆）被偷走或陷入困境
- **A2 · 悬赏 / 内驱**：发布悬赏 OR 主角自发出发（内驱 > 外驱更现代）
- **A3 · 出发**：踏上寻找之路

> 此簇结束时，**读者必须明确知道：主角要找回什么 + 为什么非要他**。

### 簇 B · 试炼之路（必备 · 占大篇幅，30–40%）

**三重试炼硬律**（ATU 301 最核心的"三"法则）：

```
第一重试炼 · 身体力量型
  → 穿越火海 / 击败守卫 / 跨过刀桥
  → 考验：体力 / 反应 / 勇气

第二重试炼 · 智力解谜型
  → 猜谜 / 分类 / 完成看似不可能的任务
  → 考验：智力 / 观察 / 创造力

第三重试炼 · 道德抉择型
  → 抵抗诱惑 / 帮助弱者 / 遵守诺言
  → 考验：人格 / 牺牲 / 价值观
```

**B1–B2 · 遇见赠礼者 + 获得魔法物品**（在三试炼之前 OR 之间，不可省略）：
- 老人 / 巫婆 / 精灵 / 动物帮手 赠予关键物品
- 魔法物品必须在后面的剧情中**实际用上**（契诃夫枪原则）

### 簇 C · 深渊探入（常见 · 高潮前）

**下降到"另一个世界"**——这是 ATU 301 与普通冒险故事的分水岭：
- **C1 · 下降**：进入山洞 / 地底王国 / 海底 / 云端 / 梦境 / 精神世界
- **C2 · 发现**：找到被囚禁者
- **C3 · 获知弱点**：从被困者 / 俘虏 / 老人处得知打败反派的方法
- **C4 · 信物交接**：被救者给主角**唯一信物**（头巾 / 戒指 / 一绺头发 / 龙牙）

> **信物在簇 F 会决定真假英雄的辩识**，此处必须埋好。

### 簇 D · 终极对决（必备 · 高潮段 10–15%）

- **D1 · 对抗守卫者**：击败看门的次级 BOSS
- **D2 · 对抗主敌**：决定性战斗 / 智取 / 利用弱点（C3 埋的伏笔）
- **D3 · 反派被击败**：物理击倒 / 魔法破除
- **D4 · 被救者解放**：打破魔法 / 解开锁链

### 簇 E · 归来之路（常见 · 8–12%）

**逃脱也必须遵守"三"法则**：
- **E1** 踏上归途
- **E2** 追兵来袭（残余势力 / 魔法师 / 怪物同类）
- **E3** 三重障碍（河流 / 山脉 / 火海）依次设置
- **E4** 用途中获得的魔法物品逐个破解

### 簇 F · 归来与确认（必备 · 8–12%）

**ATU 301 最独特的段落，不可省略**：
- **F1** 英雄归来，但**以伪装身份**或身受重伤，外人不识
- **F2** **假冒者出现**（真正的对立面升级！ 不是最终反派，而是冒领功劳的"自己人"）
- **F3** 信物（C4 埋下）作为证据
- **F4** 国王 / 权威设下**最终考验**
- **F5** 英雄身份被揭露
- **F6** 假冒者受罚

> **假冒者这条线必须在前文埋足伏笔**——兄弟 / 长官 / 路上相识的同伴都是候选。这是 ATU 301 区别于英雄之旅的关键差异点。

### 簇 G · 圆满结局（必备 · 结尾 3–8%）

- **G1** 婚礼 / 加冕 / 身份升格
- **G2** 余敌肃清
- **G3**（可选）多重婚姻 / 姐妹同嫁 / 多份奖赏（适合多公主设定）
- **G4** 王国 / 世界恢复秩序

## 角色功能表（所有关键角色必须能被分类到下表其一）

### 主角方

| 功能定位 | 必须做什么 | 典型 |
|---|---|---|
| 英雄 Hero | 主动行动者 | 士兵 / 小儿子 / 流浪汉 / 系统携带者 |
| 赠礼者 Donor | 一次性赠予关键物品 | 老人 / 巫婆 / 精灵 / 动物 |
| 被救者 Princess | 被动受害者 + 信物给予者 + 情报源 | **不能只是奖品**——必须至少给一次关键信息 |
| 假英雄 False Hero | 冒领功劳者 | 大哥 / 长官 / 同行者 |

### 反派方

| 功能定位 | 必须做什么 | 典型 |
|---|---|---|
| 偷盗者 Abductor | 制造初始失衡 | 龙 / 巨人 / 恶魔 / 魔法师 |
| 守卫者 Guardian | 次级 BOSS | 怪犬 / 卫兵 / 陷阱 |
| 幕后操控者 Mastermind | 可选最终 BOSS | 黑暗魔法师 / 魔王（不必出场） |

### 辅助角色

- **国王 / 权威**：发布任务、设下最终考验、最后做身份裁决
- **母亲 / 师父**：在主角出发前给暗中忠告或信物
- **兄弟 / 同行者**：对照组，**大概率是假英雄候选**
- **动物帮手**：关键时刻送情报或协助逃脱

## 魔法物品功能清单（每个必须有剧情用途）

| 类型 | 剧情功能 |
|---|---|
| 魔马 / 载具 | 快速到达目的地 + 逃脱追兵 |
| 魔剑 / 核心武器 | 击败主敌（弱点由 C3 揭示） |
| 隐身帽 / 披风 | 潜入反派巢穴 |
| 飞行物 | 跨越 E3 的障碍 |
| 变形戒指 | 通过 F1 的伪装归来 |
| 防火 / 防XX 护符 | 穿越 B3 试炼 |
| 被救者信物 | **证明身份（F3 唯一证据）** |

**硬律**：每件魔法物品**都必须在后续用上**，否则是契诃夫枪失灵。不要堆没用的设定。

## 三个变体（选一种做骨架子形态）

### 变体 α · 龙穴型（最经典）

重心放在 D（对决），反派是明显的怪物。适合：西幻屠龙 / 动作爽文 / 玄幻打怪升级。

### 变体 β · 地下王国型

重心放在 C（探入），强调"进入另一个世界"的奇幻感。适合：克苏鲁式探险 / 精神世界旅行 / 真实与虚幻交错 / 意识流向。

### 变体 γ · 巨人国型

重心放在 B（智斗）+ 弱点情报。反派不是死物，是会说话的对手。适合：需要智斗戏份 / 需要反派有人格魅力 / 双雄对话风。

## 与其他方法论模块的协同

- **与 MBTI 五步法**：正交，必须同用。英雄 / 被救者 / 假英雄 / 偷盗者四人 MBTI 建议至少三种不同。
- **与 Pixar 22 法则**：正交。特别借"角色的欲望 vs 真正需要"来做 F 段身份揭露。
- **与 七情节奏点**：正交。每一簇内部的章节仍要有情绪锚点。
- **与 视听语言脱水法**：可叠加。ATU 301 管"故事走向"，脱水法管"镜头怎么拍"。

## 分卷 / 分章映射建议（注入 novel.2.1 / 2.2 时给 LLM 的指引）

**长篇默认切法（50–80 万字 / 约 300 章）**：

| 卷 | 功能簇 | 章节占比 |
|---|---|---|
| 第一卷 | A 全部 + B1–B2 | 8–12% |
| 第二卷 | B3 + B4（前两重试炼） | 20–25% |
| 第三卷 | B5 + C 全部（第三试炼 + 深渊探入） | 25–30% |
| 第四卷 | D 全部 + E 大部分（对决 + 归来） | 18–22% |
| 第五卷 | E 尾 + F 全部 + G（假英雄线 + 圆满） | 15–20% |

**短中篇（5–15 万字 / 30–60 章）**：压缩 C 和 E，合并到 B 和 D；F 段可缩短但**不要删**——假冒者反转是 ATU 301 的 DNA。

---

## 伏笔埋点硬律（注入 novel.3 伏笔节点时必用）

1. **假英雄伏笔**：至少在簇 A 或 B 就出现候选人（不必明说他会背叛）
2. **信物伏笔**：C4 交接的信物必须有**唯一不可复制特征**（独特花纹 / 专属字符），F3 才能成立
3. **反派弱点伏笔**：C3 的弱点信息最好**提前在 B 或甚至 A 埋微小线索**，让后期揭示不突兀
4. **魔法物品伏笔**：B2 获得时就暗示它未来派什么用场（不必点破，但留钩子）

## 不合格的反例

- ❌ 删掉簇 F 的假英雄反转，直接凯旋成婚（变成普通冒险故事，失去 301 骨架特征）
- ❌ 三试炼全用身体力量型（失去"三试炼分别考察力、智、德"的结构美感）
- ❌ 魔法物品只用一次就弃（变成道具堆）
- ❌ 被救者全程不开口（退化为奖品，违反 C3 / C4 的功能要求）
- ❌ 假英雄与最终反派是同一个（两个独立反派层才有 301 韵味）
