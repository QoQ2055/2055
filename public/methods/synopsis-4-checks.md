# 故事梗概 4 步检测法 · 立项质量门 ★ 项目种子审查

> **来源**：墨香阁柒爷网文创作课《掌控心跳的艺术 · 故事节奏控制》第五课「工具一 · 故事梗概是项目的生死判决书」。
> **定位**：craft 层 · **立项门槛型模块**（项目质量第一关 · 任一步不合格立刻停止创作）。
> **核心命题**：故事梗概是创意阶段的"种子" · 一个故事未来 70% 的样貌（质量 / 商业价值 / 吸引力）在写完几百字梗概的那一刻就已注定。**梗概是你对自己创意的"第一次大考"**。
> **核心价值**：用 **4 步检测**强制审查梗概 · 在浪费时间写大纲 / 章节前过滤掉**注定失败**的项目。

---

## 适用边界

✅ **强推荐启用**（**所有叙事项目立项必启**）：
- 所有商业写作项目（爽文 / 短剧 / 言情 / 玄幻 / 推理 / ...）
- 长篇 / 中篇 / 短篇均适用
- 改编项目立项（评估原作梗概是否值得改）

⚠ **可选启用**：
- 实验性 / 个人写作（不追求商业 → 可弱化使用）
- 命题作文 / 同人创作（部分检测项不适用）

❌ **不要启用**：
- 散文 / 诗歌 / 非叙事内容
- 已写完正文的项目（事后评估意义不大）

---

## 核心心法 · 不要用战术勤奋掩盖战略懒惰

```
错误模式：写不好梗概 → 拼命写正文 → 遮羞 / 自欺欺人
   结果：100 万字垃圾代码 · 没人愿看

正确模式：梗概 4 步检测 → 任一不合格 → 立刻停止 → 重写或放弃
   结果：写出来的每个项目都是"好种子"长出的好庄稼
```

→ **梗概不是"概括" · 是种子 / 投影 / 大考**。

## 第一步 · 关系链检测（凝聚力 + 体量上限）

### 操作

以主角为核心视角 · 浏览整个梗概 · 把所有人物**与主角发生的关系变化**圈出来。

**关系变化类型**：
- 结识 / 相遇
- 靠近 / 信任 / 友好
- 疏远 / 冷淡 / 误解
- 相爱 / 暧昧
- 背叛 / 决裂 / 仇恨
- 复合 / 和解 / 复婚
- 牺牲 / 死亡 / 永别
- ...

### 检测标准 1 · 凝聚力

**问**：这些关系变化 · **是不是都紧紧围绕着主角展开**？

❌ **失败**（缺凝聚力）：配角 A 与配角 B 之间发生一堆关系变化 · 但跟主角没啥关系 → **故事散了**

✅ **通过**（有凝聚力）：所有关系变化都通过主角的视角发生 · 主角是关系网的核心节点

### 检测标准 2 · 体量上限

**问**：关系变化的节点有多少？

| 关系变化数量 | 适合体量 |
|:---:|---|
| 1 次 | 短篇（撑死短篇 · 比如"认识 → 结婚"）|
| 3-5 次 | 中篇 |
| 6-10 次 | 长篇骨架（认识 A → 被 A 背叛 → 结识 B → 与 B 联手反击 A → ...） |
| 10+ 次 | 长篇连载（多线复杂关系网） |

→ **关系变化越多 · 体量上限越高**。

### 这一步决定了

- 故事**能不能写长**（体量上限）
- 故事**会不会写散**（凝聚力）

### LLM 注入

```
立项强制问：
1. 列出梗概中主角参与的所有关系变化（清单）
2. 是否所有变化都围绕主角？
3. 关系变化数量与计划体量是否匹配？

任一答 "否" → 重写梗概
```

## 第二步 · 事件有效性检测（废戏率 + 体量下限）

### 操作

看着第一步圈出的"关系链" · 再去检查梗概里写到的**所有事件**。

### 灵魂拷问

每个事件强制问：
- 这个事件**是不是引发了某种关系的改变**？
- 或者这个事件**是不是因为某种关系改变而导致的后果**？

### 检测标准

#### 删废戏

❌ **无效事件（废戏）**：事件发生后 · **人和人的关系没变**（例如：主角打了一架 · 打完大家各回各家 · 关系既没更铁也没结仇）

→ **果断删掉**！

#### 定下限

**问**：剩下的有效事件有多少？这就是故事的**体量下限**。

| 有效事件数量 | 体量下限 |
|:---:|---|
| < 5 个 | 干瘪短篇 · 全是注水 |
| 5-15 个 | 中篇骨架 |
| 15-30 个 | 长篇骨架 |
| 30+ 个 | 长篇连载 |

### 这一步帮你

- **挤干水分** · 确保每个情节都是"干货"
- 锁定**体量下限**

### LLM 注入

```
立项强制问：
1. 列出梗概中所有事件（含小冲突 / 大转折）
2. 每事件标注是否引发关系改变（Y/N）
3. 移除所有 N 的事件
4. 剩余事件数量与计划体量是否匹配？

废戏占比 > 30% → 重写梗概
有效事件数 < 计划体量下限 → 重写或缩减体量
```

## 第三步 · 核心驱动检测（商业价值 + 吸引力）

### 操作

1. 找到故事的**核心驱动力**（参考 `character-driven-method` / `event-driven-method` / `emotion-driven-method`）
2. 拿着这个驱动力 · 去比对第二步筛选剩下的所有事件

### 检测标准

#### 一致性

**问**：这些事件 · **是不是都在塑造、强化、扩展这个核心情绪**？

❌ **失败**：核心驱动是"复仇的爽感" · 但梗概中插一段温吞的谈恋爱 → **稀释核心驱动**

✅ **通过**：所有事件都铺垫"压抑"或"释放爆发" · 朝核心驱动收敛

#### 吸引力（商业价值）

**问**：把这些事件串起来 · 能不能**满足观众的心理需求**？能不能**让观众产生好奇**？

❌ **失败**：核心驱动是"悬疑" · 但事件全是家长里短 → **没有商业价值 · 观众不买单**

✅ **通过**：核心驱动 + 事件链 = 直接命中目标读者的心理诉求（参考 `audience-personas.md`）

### 这一步决定

故事**好不好看 · 能不能卖钱**。

**主题越集中 · 驱动力越强 · 商业价值越高**。

### LLM 注入

```
立项强制问：
1. 这个故事的核心驱动力是什么？（character / event / emotion 驱动 + 具体核心情绪）
2. 列出第二步筛选后的所有事件
3. 每事件评估是否服务核心驱动（强 / 中 / 弱 / 反向）
4. 反向 + 弱事件占比 > 20% → 重写

5. 串联事件链 → 命中目标人群（B1 / B2 / B3）的哪个心理诉求？
6. 完全不命中 → 重新选择目标人群或修改梗概
```

## 第四步 · 底层逻辑检测（合理性 + 致命 BUG）

### 操作

像一个**杠精**一样 · 审视梗概里的**因果关系、人物动机、行动逻辑**。

### 检测标准 · 三问法

每个关键事件 / 关键决定强制问：

#### 动机合理吗？

**示例**：女主抗旨拒婚 · 突然把皇帝杀了称帝。

**杠精三问**：
- 她**为什么**要杀皇帝？（动机：仅仅因为拒婚就杀人 · **动机不足**）
- 她**敢**杀吗？（性格：她受的教育支持她这么叛逆吗？）
- 她**能**杀吗？（能力：她一介弱女子 · 凭什么能杀进皇宫？）

#### 逻辑通顺吗？

如果 3 问任一无法**合理解释** → **致命的逻辑 BUG**。

### 这一步决定

故事**能不能立得住**。**逻辑崩了 · 故事就塌了**。

### 常见致命 BUG 模式

| 模式 | 示例 | 修复 |
|---|---|---|
| 动机不足 | 主角因为小事大开杀戒 | 加深背景仇恨 / 阶段性升级 |
| 性格 OOC | 懦弱主角突然超级勇敢 | 触发事件铺垫 / 性格弧线 |
| 能力悬殊 | 普通人秒杀职业杀手 | 添加金手指来源 / 或者降低对手 |
| 巧合滥用 | 关键时刻总有救兵出现 | 限制次数 / 增加伏笔 |
| 信息不一致 | 角色前后行为矛盾 | 时间线 / 性格 chronological 检查 |

### LLM 注入

```
立项强制问：
1. 列出梗概中主角的所有"重大决定"和"关键转折"
2. 每个决定 / 转折用三问法检验：
   - 动机：为什么？充分吗？
   - 性格：他敢吗？合性格吗？
   - 能力：他能吗？合实力吗？
3. 任一回答 "否" 或 "不充分" → 致命 BUG → 重写

4. 列出 ≤ 3 个最大的逻辑漏洞 + 修复方案
5. 修复后重新过 4 步检测
```

## 4 步连环效应

```
Step 1 关系链 ✓        →  故事不散 + 体量上限合适
   ↓ 任一失败立刻停
Step 2 事件有效性 ✓    →  没有废戏 + 体量下限合适
   ↓ 任一失败立刻停
Step 3 核心驱动 ✓      →  商业价值高 + 命中读者心理
   ↓ 任一失败立刻停
Step 4 底层逻辑 ✓      →  立得住 + 没致命 BUG

全 4 步通过 → 这是颗好种子 → 可以进 810 大纲阶段
```

→ **不要试图用战术上的勤奋（拼命写正文）· 去掩盖战略上的懒惰（写不好梗概）**。

## 检验清单（dogfood 时人工抽检）

- [ ] 项目立项有**显式梗概**（不是脑海中的设想）
- [ ] 梗概通过**4 步全部检测**（缺一不可）
- [ ] **关系变化数量** ≥ 计划体量下限
- [ ] **废戏占比** ≤ 30%
- [ ] **核心驱动一致性** ≥ 80%
- [ ] **0 致命逻辑 BUG**
- [ ] 任何后续阶段（大纲 / 章节）发现新问题 → 回到梗概重写
