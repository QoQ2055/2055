# 人物驱动法（Character-Driven · 由内向外 · 先造人后造事）

> **来源**：墨香阁柒爷网文创作课《故事三驱动》第七课。
> **定位**：driver 层 · **故事引擎选择型模块**（与 event-driven / emotion-driven 互斥 · 一个项目同时只选一种主驱动）。
> **核心价值**：当主线故事的看点是**人物魅力 + 共情成长**而不是"惊天大案"或"极致爽点"时，启用本模块让 LLM 在角色塑造、剧情推进、矛盾设置上**全部围绕主角性格弧线展开**。

---

## 适用边界

✅ **强推荐启用**：
- 长篇小说（≥ 30 章 / ≥ 50 万字）
- 大女主 / 大男主成长剧
- 正剧 / 严肃文学
- 慢热向 · 后劲粘性优先

⚠ **可选启用**（次优）：
- 短篇 / 中篇（1 万-30 万字）· 但要小心节奏拖
- 群像小说（多主角时人物驱动比单主角更难）

❌ **不要启用**（错配）：
- 付费短剧（应选 emotion-driven）
- 悬疑推理 / 灾难科幻（应选 event-driven）
- 系统流爽文（角色是工具人，不需要立体）

---

## 核心心法

### 第一原则 · 先造人后造事

**不要先想"发生了什么惊天大案"**，先想"我要写一个什么样的人，才会让观众对他好奇 / 爱上他？"

剧情是**人物性格撞击现实后的回声**。你不需要硬编故事 · 你只需要把这个鲜活的人扔进困境，问自己：

> "他这种性格，下一步会怎么做？"

故事自然流淌出来。

### 第二原则 · 由内向外

```
灵魂  →  弱点  →  设障碍  →  人物在压力下的选择  →  剧情自动展开
↑                                                ↓
└──── 性格弧线 / 成长 / 蜕变 ──────────────────────┘
```

## 三步实操（LLM 提示词指引）

### 步骤 1 · 挖灵魂（Soul-First）

为主角写一份**人物小传**，必须含 4 个字段：

| 字段 | 一句话 | 示例（古风） |
|---|---|---|
| **欲望** | 他最想要什么？为之愿意付出一切？ | "夺回家族流亡海外的家产 + 杀母之仇" |
| **致命弱点** | 他害怕 / 厌恶 / 抗拒什么？逻辑上不可承受的代价？ | "信任 → 被亲哥哥利用举报母亲" |
| **童年创伤** | 他怕什么 / 他的脆弱底色源自何处？ | "亲眼目睹母亲被拖走，无能为力" |
| **与众不同的魅力** | 他不同于 99% 路人的特质？观众第一眼记住他的钩子？ | "在朋友面前永远笑，独处时一夜白发" |

→ 4 字段缺一不可。LLM 生成角色 bible 时**先填表 · 再写描写**。

### 步骤 2 · 设障碍（让弱点流血）

根据角色"致命弱点"**专门设计让他难受的事件**：

| 主角弱点 | 障碍设计 |
|---|---|
| 主角是个洁癖 | 把他扔进垃圾场 / 必须穿别人的旧衣 |
| 主角是个懦夫 | 逼他单挑 / 上战场 |
| 主角不信任任何人 | 设局让他必须把性命交给陌生人 |
| 主角童年被父亲抛弃 | 让他在最关键时刻必须扮演父亲 |

**只有这么做** · 角色魅力才能从事件中**绽放出人性之花**。读者不是在看"事件"，是在看主角"如何在事件中挣扎不断"。

### 步骤 3 · 性格撞击现实（让故事自动生长）

把"鲜活的人"扔进"残酷的世界"。每章问自己：

```
当前章节冲突 = ?
主角性格 / 弱点 / 当前心理状态 = ?
那么基于他的性格，他会怎么做？  ← 这就是下一段剧情
```

**核心规则**：
- 主角不应"为了剧情服务"行动 · 应**为自己行动**
- 主角的选择应该 80% 来自性格 + 20% 来自外部胁迫
- 当外部胁迫 > 性格选择时，故事就"工具化"了 → 退回 emotion-driven

## 注入指引（fili-web 内部用）

本模块通过 `injectsTo` 在以下节点注入：

- `novel.1.2`（角色 bible）：强制要求填 4 字段（欲望 / 弱点 / 童年 / 钩子）
- `novel.2.1`（分卷规划）：每卷的"卷末转折"必须撞击主角弱点
- `novel.3.1`（章节草稿）：章节结尾必须显示主角性格变化或弱点暴露
- `novel.3.2`（章节润色）：检查"主角行动是否来自性格而非剧情"

## 检验清单（dogfood 时人工抽检）

- [ ] 主角第一次出场，读者能记住他**1 个独特的标签**（不是"少年"/"修士"等通用）
- [ ] 主角至少有 1 次因为弱点犯下**重大错误**（不是因为外部 bug）
- [ ] 主角至少有 1 次**违背直接利益的选择**（因为性格高于诱惑）
- [ ] 章节结尾段比章节开头段，主角心理状态有可见变化（哪怕微小）
- [ ] 配角的存在让主角弱点更鲜明（不是为剧情功能而存在）

## 范例 · 一句话激活公式

```
{ 主角名 } 是一个 { 一句话身份 }，最想 { 欲望 }，
但因为 { 弱点 / 童年创伤 } 而难以达成，
当他遇到 { 外部障碍 } 时，他会本能地 { 性格反应 } —
而这个反应，恰好把他推向 { 卷末转折 }。
```

把这段填空给 LLM · 角色弧线自动出来。

---

## 与"信息差 / 预期管理 / 节奏控制"3 大理论的关系

人物驱动法 = "由人物属性发起信息差 + 由人物欲望制造预期 + 由人物挣扎控制节奏"。

```
人物驱动 = 信息差 × 预期管理 × 节奏控制 的人物坐标系
```

→ 选了人物驱动 = 三大理论自动从"人物视角"展开。
