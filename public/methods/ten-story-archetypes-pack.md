# 10 故事原型完整图鉴 · 事件驱动元素周期表

> **来源**：墨香阁柒爷网文创作课《事件篇 · 实战技巧》第八课「故事的罗盘 · 10 个故事原型」。
> **定位**：structure 层 · **事件驱动框架选型型模块**（与 driver-blueprint / event-driven-method 强协同）。
> **核心命题**：人类讲了几千年的故事 · 能驱动故事跑起来的"有效事件模型"**只有这 10 种**。每一种都是一套经过验证的"事件设定图纸"。
> **核心价值**：10 框架 + 每框架"3 必备零件" + 烂大街公式 + 选型决策树 = 立项时直接选定故事种类。

---

## 适用边界

✅ **强推荐启用**（**所有事件驱动项目立项必读**）：
- 任何商业写作项目（爽文/短剧/言情/玄幻/推理...）
- 立项阶段尚未确定故事框架时
- 写到一半"故事很散推不动"时反查

⚠ **可选启用**：
- 已确定框架 + 实操 → 阅读对应 method module
- 实验性 / 反类型作品

❌ **不要启用**：
- 散文 / 诗歌 / 意识流

---

## 核心心法 · 框架选型铁律

```
故事原型 = 故事的基因
动笔前必须先确定故事属于哪种"物种"
一旦选定 · 核心驱动力 / 终极目标 / 情感体验就锁死了
→ 防止写偏

每种原型必有 3 必备零件 → 缺一不可
零件齐了 · 故事就稳了
```

## 原型 1 · 鬼屋型 · 生存游戏

**一句话定义**："努力活下来！"

**为什么写**：人类最原始的本能是恐惧 · 肾上腺素飙升的"吓得半死又很想看"。

**核心爽点**：紧张感（能不能活）+ 宣泄感（作死的人终于死了）。

### 3 必备零件

#### 零件 1 · 一个无法摆脱的空间（焊死的笼子门）

**为什么**：主角能跑的话故事 5 分钟就结束了。

**怎么造屋子**：
- **方法 A 物理封锁**（最常用）：孤岛 / 暴风雪山庄 / 深海潜水艇 / 太空船
- **方法 B 概念封锁**（更高级）：诅咒（《午夜凶铃》七天后鬼会来）

#### 零件 2 · 一个无法解释的力量（不可沟通的怪物）

**恐惧来源于未知**。

**3 属性**：
- **强大且邪恶**：碾压级实力 · 主角如蚂蚁
- **无法沟通**：杀戮机器 · 不能坐下喝茶讲道理
- **神出鬼没**：先看影子 / 听声音 / 看撕碎的尸体 → 未知最恐怖

#### 零件 3 · 一种原罪（为什么把怪物放进来）

**为什么**：单纯倒霉是"虐杀"没意思 · 需要道德审判意味。

**4 类原罪**：
- **贪婪**：挖古墓（僵尸）/ 研究生物兵器（异形）
- **傲慢**：复活恐龙（《侏罗纪公园》）
- **色欲 / 愚蠢**：恐怖片"打野战"的年轻人

→ 通常**不是主角犯的错**（主角是无辜背锅侠）· 而是配角 / 反派 / 贪婪资本家。

### 烂大街公式

```
1. 犯错（原罪）：贪心老板带主角团队来荒岛挖宝
2. 锁门（屋子）：突然台风 · 船开不走 · 通讯断了
3. 现身（怪物）：贪心人失踪 · 找到惨不忍睹尸体
4. 绝望（对抗）：怪物刀枪不入 · 死人越来越多
5. 幸存（结局）：主角发现怪物弱点 / 运气好 · 九死一生逃出
```

## 原型 2 · 金羊毛型 · 成长游戏

**一句话定义**："出门寻宝 · 找回自我。"

**为什么写**：人生是旅途 · "远方有更好的东西"是普世投射。

**核心爽点**：公路片风景 + 团队羁绊 + 最后升华（不需要宝藏也能活得很好）。

### 3 必备零件

#### 零件 1 · 一条明确的路径（藏宝图）

**为什么**：主角必须**离开舒适区** · 故事才能像串糖葫芦一样串起来。

**类型**：
- **物理路径**：东土去西天 / 夏尔去末日火山
- **抽象路径**：穷小子打败所有对手成为冠军（夺冠之路）

→ 设置关卡：第一站强盗 / 第二站美女 / 第三站大雪。**让路途充满波折**。

#### 零件 2 · 一个互补的团队（搭档配置）

**为什么**：一个人走路太无聊 · 配角展示主角缺点 / 弥补不足。

**配对法**：
- **能力互补**：战士 + 法师 / 唐僧（理想）+ 孙悟空（能力）
- **性格冲突**：严肃 + 搞笑 / 胆小 + 鲁莽 → 越吵感情越深

#### 零件 3 · 一个成长的终点（宝藏只是幌子）

**核心金羊毛**：宝藏拿没拿到不重要 · **主角变成了更好的人**才是真正的金羊毛。

**结局两写法**：
- **写法 A**：拿到宝藏 · 但发现没用 / 送人了
- **写法 B**：没拿到宝藏 · 但收获爱情 / 友情

→ **始于欲望 · 终于成长**。

## 原型 3 · 如愿以偿型 · 代价游戏

**一句话定义**："小心你许的愿望 · 它可能会实现。"

**为什么写**：每个人都做白日梦（超能力 / 中彩票 / 和明星谈恋爱）。

**核心爽点**：极度意淫（前期爽翻天）+ 失控混乱（中期手忙脚乱）+ 回归平凡（还是做自己最好）。

### 3 必备零件

#### 零件 1 · 一个极致的愿望（天上掉馅饼）

**为什么**：必须是主角做梦都想要、但靠自己绝对得不到的东西。

**怎么许愿**：
- 主角必须是 Loser（受尽欺负）
- 愿望简单粗暴：变有钱 / 变美 / 听到心声 / 变明星

#### 零件 2 · 一个带有副作用的咒语（馅饼里有毒）

**为什么**：愿望实现后幸福快乐故事就结束了。

**3 类副作用**：
- **规则限制**：《西虹市首富》给十亿但必须一月花光
- **身份错位**：变明星但要面对狗仔 / 失去隐私
- **不可控**：能听到心声 → 听到女朋友骂你 / 老板想炒你 → 崩溃

#### 零件 3 · 一个深刻的教训（把馅饼吐出来）

**为什么**：寓言性 · 告诉观众"捷径不好走 · 做自己最踏实"。

**怎么收尾**：主角发现失去真爱 / 快乐 → 主动放弃能力 / 魔法失效 → 找回初心 → 平凡幸福。

## 原型 4 · 家伙遇到麻烦型 · 勇气游戏

**一句话定义**："倒霉蛋拯救世界。"

**为什么写**：普通人喜欢看普通人被逼到绝境时爆发出惊人力量 · 让我们相信自己也有潜力。

**核心爽点**：以弱胜强（反差萌）+ 绝地求生（紧张刺激）。

### 3 必备零件

#### 零件 1 · 一个无辜的普通人（穿拖鞋的主角）

**为什么**：主角越普通 · 反差越大。
- 特种兵打赢恐怖分子 = 应该
- **修水管的打赢恐怖分子 = 牛逼**

**怎么设定**：最普通职业（司机 / 厨师 / 失恋倒霉蛋）+ 强调无辜（只是去上厕所 / 接孩子）。

#### 零件 2 · 一个从天而降的巨大麻烦（大楼进恐怖分子）

**为什么**：必须大到离谱 · 完全超出主角能力。

**2 特征**：
- **不对等**：恐怖分子有枪有炮 · 主角只有快没电的手机
- **突发性**：没预兆 · 突然发生（《虎胆龙威》派对变劫持）

#### 零件 3 · 一场生死攸关的考验（不拼命就得死）

**为什么**：普通人遇大麻烦肯定先躲 · 必须给"不得不战"的理由。

**逼主角出手**：
- **涉及至亲**：老婆 / 孩子被抓
- **无路可逃**：整个区域被封锁

→ 主角被迫**利用身边普通道具**（灭火器 / 玻璃碴）对抗全副武装敌人。

## 原型 5 · 变迁仪式型 · 接纳游戏

**一句话定义**："成长的阵痛。"

**为什么写**：人生有很多坎（青春期 / 失恋 / 中年危机 / 丧亲）· 每过一道坎都要脱一层皮。

**核心爽点**：共鸣感（我也经历过）+ 治愈感（生活还得继续）。

### 3 必备零件

#### 零件 1 · 一个普世的生命难题（那道坎）

**3 类难题**：
- **青春期**：没人理解我 · 想离家出走
- **中年危机**：工作不顺 / 老婆不爱 / 觉得自己老了
- **丧亲**：最爱的人死了 · 不知道怎么活下去

#### 零件 2 · 一种过激的对抗方式（瞎折腾）

**为什么**：人遇痛苦第一反应是**逃避或发疯** · 这才是戏。

**3 类折腾**：
- **逃避**：中年男和年轻姑娘鬼混 / 买跑车装嫩
- **发疯**：失恋酗酒 / 报复社会 / 《宿醉》荒唐事
- **幻想**：《爱丽丝梦游仙境》躲幻想世界

#### 零件 3 · 一种成熟的回归 / 自我放逐（认命并前行）

**怎么写结局**：
- 主角不再逃避 · 接受变老 / 单身 / 失去亲人
- 带着伤疤 · 学会笑对生活
- 或选择自我流放 · 相信宿命无法战胜

## 原型 6 · 伙伴之情型 · 互补游戏

**一句话定义**："没头脑和不高兴。"

> ⚠ **冷知识**：爱情事件**也算**伙伴之情。底层逻辑（互补）相同 · 只是情感和性别有些区别。
> 这种"看本质不看现象"的能力 · 是商业写作高手的标志。

**核心爽点**：化学反应（吵架拌嘴）+ 情感升华（为你牺牲）。

### 3 必备零件

#### 零件 1 · 一个残缺的主角（半个圆）

**为什么**：主角必须有明显缺陷 · 一个人搞不定事情。

**怎么设定**：刻板工作狂 / 循规蹈矩警察 / 生活乏味孤单。

#### 零件 2 · 一个完美契合的零件（另外半个圆）

**为什么**：另一个人必须拥有主角缺失的东西 · 但性格南辕北辙。

**怎么配对**：
- **性格反差**：严肃警察 vs 话痨小偷 / 高冷学霸 vs 活泼学渣 / 人类 vs 外星人
- **冲突**：刚见面互相看不顺眼 · 被迫绑在一起（手铐 / 必须合作破案）

#### 零件 3 · 一条巨大的鸿沟（能不能在一起？）

**为什么**：一拍即合就没戏 · 必须有阻力让他们分分合合。

**鸿沟类型**：
- **误会**：第三者 / 理念分手时刻
- **外部压力**：罗密欧朱丽叶（家族世仇）/ 人鬼情未了（阴阳两隔）

**结局**：跨越鸿沟 / 一方为跨越鸿沟而牺牲（证明感情伟大）。

## 原型 7 · 侦探型 · 人性游戏

**一句话定义**："真相往往是黑色的。"

**为什么写**：观众想知道"谁杀的（Who）" + "为什么杀（Why）"。

**核心爽点**：烧脑（猜谜）+ 震撼（人性这么黑）。

### 3 必备零件

#### 零件 1 · 一个必须知道真相的人（咬住不放的狗）

**为什么**：查案危险 · 正常人早跑了 · 主角必须有死磕到底的理由。

**怎么给理由**：
- **职业道德**：警察 / 侦探（身份必须）
- **切身利益**：被冤枉不查清要坐牢 / 爱人死了不查清死不瞑目

#### 零件 2 · 一个足够吸引人的秘密（不可能的犯罪）

**3 类秘密**：
- **不可能**：密室杀人 / 门窗紧闭人死了
- **不在场证明**：嫌疑人当时在几百公里外
- **反常识**：最善良的老好人死了 / 凶手最不可能杀人

#### 零件 3 · 一次为了真相的牺牲（凝视深渊）

**侦探故事的灵魂**：真相不仅是抓凶手 · 还牵扯巨大阴谋 / 人性丑陋。

**升华**：
- 凶手是主角最敬重的人
- 主角为揭真相牺牲职业 / 生命 / 爱人 / 朋友 / 良知
- **主角越在意 · 牺牲越值钱！真相是昂贵的**

> ⚠ 底层逻辑：恐怖片解密 / 阴谋片背后黑暗势力 = **本质都是侦探型**（包含秘密需破解）。学东西要看本质 · 灵活应用。

## 原型 8 · 愚者成功型 · 智慧降维游戏

**一句话定义**："当所有人都以为他在第一层时 · 他其实在第五层 · 或他根本不在这个楼里玩。"

**为什么写**：现代社会复杂规则 + 聪明人博弈让人疲惫 · 渴望看到**纯粹本质的力量击穿虚伪**。

**核心爽点**：认知颠覆 + 价值认同。

### 3 必备零件

#### 零件 1 · 一个不被理解的"愚者"（局外人 / 破局者）

**4 种"愚"**（不是缺陷 · 是破局武器）：
- **价值观的愚**：绝望监狱里坚信希望（安迪《肖申克救赎》）
- **规则上的愚**：人情官场只认死理和法律（包龙星《九品芝麻官》前期）
- **智力上的愚**（表象）：纯粹赤子之心（阿甘《阿甘正传》）
- **身份上的愚**：土包子用农村实在对抗都市浮华（王宝强《人在囧途》）

#### 零件 2 · 一个僵化自洽的"聪明"体制（傲慢的既得利益者）

**为什么**：对手必须强大 · 对自己规则极度自信 · 这种**傲慢是失败的根源**。

**4 类体制**：
- **规则至上权力机构**：肖申克监狱
- **精于算计商业帝国**：华尔街
- **虚伪封闭上流社会**：礼仪潜规则
- **逻辑严密犯罪团伙**：自信天衣无缝

#### 零件 3 · 一种降维打击的智慧（用 OS 对抗 App 的 bug）

**核心爽点**：主角胜利**不能因为他学会了聪明人规则**并玩得更好。

**4 类降维打击**：
- **坚持胜过算计**：二十年笨办法挖隧道（肖申克）
- **真诚胜过伪善**：真诚获得关键信任 · 粉碎阴谋
- **简单胜过复杂**：直接掀桌子 / 捅破窗户纸
- **专注胜过投机**：阿甘只跑步 / 捕虾 / 打乒乓球

## 原型 9 · 被制度化型 · 个体 vs 集体游戏

**一句话定义**："当'我们'试图吞噬'我'时 · '我'该如何存在？"

**为什么写**：每个人都生活在集体中 · 既渴望归属又害怕失去自我。

**核心爽点**：选择的张力 + 价值观的碰撞。

### 3 必备零件

#### 零件 1 · 一个强大的同化力场（铁屋子 / The System）

**4 类力场**：
- **物理牢笼**：疯人院（《飞越疯人院》）/ 监狱（《肖申克救赎》）/ 军队（《全金属外壳》）
- **精神牢笼**：精英学校（《死亡诗社》）/ 大公司 / 邪教
- **文化牢笼**：黑帮家族（《教父》）/ 保守小镇
- **权力化身**：护士长 / 典狱长 / 教父 / 校长

#### 零件 2 · 一个根本性的价值权衡（牺牲个体还是牺牲群体？）

**核心冲突**：必须将选择提升到对**整个集体产生实质性影响**的高度。

**选项 A · 牺牲个体保全群体**：
- 同流合污：腐败警局新警察睁一只眼闭一只眼
- 自我审查：孩子隐瞒性取向不破坏家庭和睦
- 成为一部分：迈克接管家族（《教父》）

**选项 B · 牺牲群体保全个体**：
- 公然反抗：麦克墨菲组织看世界杯（《飞越疯人院》）
- 揭露真相：吹哨人不惜公司倒闭
- 颠覆传统：新教师挑战僵化教育（《死亡诗社》）

#### 零件 3 · 一次决定命运的最终碰撞

**4 种结局**：
- **个体被集体清除/压制**：身体被毁但精神延续（《飞越疯人院》麦克墨菲）
- **个体被集体同化**：放弃对抗 · 成系统齿轮（《教父》迈克）
- **个体改变/战胜集体**：旧规则崩溃（《肖申克救赎》安迪）
- **个体与集体和解**：找到共存新方式 · 主动回归

## 原型 10 · 超级英雄型 · 特权碾压游戏

**一句话定义**："我不吃牛肉。"

**为什么写**：现实憋屈（被骂 / 房贷压）· 想看绝对特权"想干嘛就干嘛 · 谁不服干谁"。

**核心爽点**：降维打击（满级打一级）+ 扮猪吃虎（你以为青铜其实王者）。

### 3 必备零件

#### 零件 1 · 绝对的"外挂"（不讲道理的强）

**网文逻辑**：能力不需"平衡" · 只需"溢出" · **越强越爽**。

**3 类外挂**：
- **系统流**：走路捡钱 · 呼吸变强
- **重生流**：知道未来 50 年彩票号码和股票走势
- **身份流**：表面送外卖 / 其实全球首富 / 龙王 / 修罗战神

**关键点**：用一次爽一次 · 一直用一直爽。

#### 零件 2 · 源源不断的"挑衅者"（排队送脸的）

**为什么**：主角强但没人惹他就在家睡觉 · 必须有"有眼无珠"的人不断跳出来嘲讽。

**怎么设计反派**：
- **不需要势均力敌**：反派越嚣张越看不起主角越好
- **经典嘴脸**："臭送外卖的你也配？" / "小子你知道我是谁吗？"
- 他们是**爽感垫脚石** · 跳得越高摔得越惨

#### 零件 3 · 一层"伪装"或"限制"（蓄水的大坝）

**最关键技术活**：必须让主角暂时不能暴露实力 / 让反派误以为主角很弱 · 形成**信息差** · 积蓄爽感。

**3 类伪装**：
- **身份伪装**：龙王报恩当赘婿 · 隐藏身份三年
- **扮猪吃虎**：明明满级但穿破衣服骑电瓶车
- **规则限制**：系统规定必须被打一巴掌才能激活神力

**爆发时刻**：反派嚣张到极点 / 触碰主角底线（动了老婆孩子）→ 伪装撕碎 · 大坝决堤 · 爽感爆发！
