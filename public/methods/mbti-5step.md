# MBTI 五步法 · 人物角色卡（注入到 N1.2）

> 抽自《小婳生成小说 SKILL 6.0》第三步「角色先按 MBTI 五步法生成」。
> 不允许 MBTI 只是装饰词；必须直接服务剧情。

## 适用对象

下列角色**全部**必须按本法生成完整角色卡：
- 主角
- 主要配角
- 反派
- 关键助攻角色
- 关键见证人

## 五步法标准结构

### 1. MBTI 类型 + 类型标签
- 必须明确四字母（INTJ / ESFP / INFJ 等）
- **同时**给出类型定位标签（不能省略）
  - 例：INTJ → 洞察谋略型
  - 例：ESFP → 表演社交型
  - 例：ISTJ → 秩序执行型
  - 例：ENFJ → 守护压迫型

### 2. 主导功能表现
- 写出该角色最核心的认知方式 / 行动方式 / 表达方式
- **必须**说明这个功能如何影响他的决策

### 3. 辅助功能表现
- 写出他的补充能力
- **必须**说明这个能力如何帮助推进剧情

### 4. 第三功能 + 劣势功能表现
- 写出他在压力下会暴露的软肋 / 偏执 / 误判 / 失控
- **必须**说明这个弱点如何成为剧情转折点

### 5. 剧情落点 + 功能定位
- 这个角色在故事里的作用是什么？
- 是推动冲突 / 制造误会 / 递交底牌 / 放大压迫 / 提供反转 / 还是承担清算？
- **必须**说明他在前 / 中 / 后段分别起什么作用

## 角色卡输出格式（YAML，每个角色一份）

```
- 角色名：
- MBTI 类型：（如 INTJ · 洞察谋略型）
- 类型标签：
- 主导功能：
- 辅助功能：
- 第三功能：
- 劣势功能：
- 角色欲望：
- 核心恐惧：
- 行动逻辑：
- 剧情功能：（推动冲突 / 制造误会 / 递交底牌 / 放大压迫 / 提供反转 / 承担清算）
- 与主角关系：
- 关键转折点：（哪一卷 / 哪一章是这个角色的高光 / 失控 / 退场）
- 前段任务：
- 中段任务：
- 后段任务：
```

## MBTI 选型硬律（不可违反）

1. **主角的 MBTI** 必须能解释他「看世界 / 选择反击 / 承受打击 / 完成成长」的方式
2. **配角的 MBTI** 必须与主角形成「对照 / 互补 / 冲突」三选一（每个配角至少一个）
3. **反派的 MBTI** 必须能解释「压迫方式 + 控制方式 + 失控方式」三件套
4. **助攻角色的 MBTI** 必须能解释「为什么提供帮助 + 帮助的边界在哪里」
5. **不允许 MBTI 只是装饰词**：每个 MBTI 都必须直接对应剧情中的具体行为
6. **不允许全员同 MBTI**：主要角色（≥4 人）的 MBTI 至少 3 种不同，避免人物声纹同质化
7. **不允许把 MBTI 写成性格测试结果**：不要写"INTJ 喜欢思考"，要写"他在 X 章选择 Y 而不是 Z 是因为 INTJ 主导功能 Ni 优先把 ..."

## 反例（这样写不合格）

- ❌ "主角是 INTJ，性格冷静"（没说具体怎么影响剧情）
- ❌ "反派 ESTJ，控制欲强"（没说他怎么失控）
- ❌ "全员都很有意思"（没用 MBTI 区分声纹）
