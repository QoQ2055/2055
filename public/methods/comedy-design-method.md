# 喜剧设计法 · 种子培育 + 3 玩法 + 三番升级

> **来源**：墨香阁柒爷网文创作课《事件篇 · 实战技巧》第八课「事件设计 · 喜剧篇 + 喜剧的种子」。
> **定位**：craft 层 · **题材级别设计型模块**（最大块 · 喜剧最难）。
> **核心命题**：喜剧的内核是悲剧。**我们笑的不是主角好笑 · 是从上帝视角看到他的"倒霉"和"徒劳"**。喜剧种子不是笑点 · 是痛点。
> **核心价值**：(1) 喜剧 5 大笑点底层逻辑；(2) 结构喜剧 3 玩法（信息差操控）；(3) 种子培育 5 步法（抱怨→筛选→选模型→三番→合理性催眠）。

## 适用边界

✅ **强推荐启用**：
- 喜剧 / 沙雕 / 解压文
- 短剧 / 喜剧电影 / 情景剧
- 含喜剧副线的任何类型（言情甜宠 / 都市轻喜剧）

- 严肃历史 / 哲学

## 核心心法 · 喜剧的三大真相

### 真相 1 · 笑的本质 = 小小的悲剧

```
我们为什么会笑？

笑 = 优越感（我没摔）+ 预期违背（他不该摔）+ 压力解除（他没死）

→ 三个源头都指向"小小的悲剧"
→ 别人的倒霉 / 尴尬 / 失控 / 出糗 = 我们快乐的源泉
```

⚠ **关键原则**：是**小小的**悲剧 · 别弄大！弄大就变虐了。

### 真相 2 · 喜剧种子 = 痛点不是笑点

```
喜剧种子 ≠ 开心果
喜剧种子 = 一粒砂子（硌得你我生疼 · 让人忍不住吐槽的"生活中的砂子"）

你的任务：找到这粒砂 · 放大 · 变成一颗让所有人都笑出声的珍珠
```

### 真相 3 · 戏剧性 = 信息差操控

```
观众笑 = 因为我们知道（上帝视角）
主角不笑 = 因为他不知道（凡人视角）

→ 喜剧的引擎 = 信息差
```

## 第一部分 · 喜剧 3 大基本形态

### 形态 1 · 语言喜剧（不深入教 · 但必须懂）

依赖作者**语言天赋和知识储备**。文字效果极佳 · 对演员要求不高。

#### 5 个底层逻辑（笑点的来源）

##### 逻辑 1 · 信息错位（鸡同鸭讲）

两个人说的不是一回事 · 但都以为对方听懂了。

```
A："你车上怎么有根长头发？"
B（心虚）："哦……可能是我妈的。"
A："你妈不是短发吗？"
B（更虚）："她……可能戴了假发。"
A："我 TM 问的是我掉在你车上的那根！"
```

##### 逻辑 2 · 逻辑滑坡（一本正经地胡说八道）

从看似正常的起点 · 通过看似合理的推导 · 滑向极其荒谬的结论。

```
"如果我今天上班迟到 · 就会被扣钱。
被扣了钱 · 就没钱吃饭。
没钱吃饭 · 就会饿死。
所以 · 迟到等于自杀。"
```

##### 逻辑 3 · 预期违背（反转梗）

建立一个常见预期 · 在最后一刻用意想不到的答案打破它。

```
"我这辈子最佩服四个人：
第一个是发明了电的爱迪生 ·
第二个是发明了飞机的莱特兄弟……"
"那第三个呢？"
"……还有我爸。"
```

##### 逻辑 4 · 概念偷换（文字游戏）

故意曲解一个词语的常规含义。

```
老师："小明 · 你的梦想是什么？"
小明："我的梦想是不用再有梦想。"
```

##### 逻辑 5 · 鲜活比喻（神吐槽）

用极其生动、形象 · 但又有点不搭边的比喻形容一件事。

```
"他唱歌跑调 · 跑得比我那被拖走的共享单车还远。"
```

### 形态 2 · 动作喜剧（不深入）

主要靠**演员的肢体语言**（摔跤 / 追逐 / 挨打）· 文字难体现 · 不做深入探讨。

### 形态 3 · 结构喜剧 ★ 文字创作核心

通过设计"事件结构"系统性制造喜剧效果。**本质 = 信息差的精妙操控**。

→ 后续所有内容围绕这个展开。

## 第二部分 · 结构喜剧 3 玩法

### 玩法 1 · 信息优势 · "雪球效应"

#### 核心原理

```
主角为了解决危机 A · 采取过激办法 1
但我们（观众）已经提前知道：办法 1 会引发更严重危机 B

主角的每一次"努力" · 都在把事情搞得更糟
他的行为在自己看来是"救火" · 在我们看来是"浇油"

→ 雪球越滚越大 · 直到彻底失控
```

#### 实战示例 · "打碎花瓶"

**危机 A**：主角不小心把老板最心爱的花瓶打碎了 · 老板半小时后回来。

**过激办法 1**：主角决定用强力胶把花瓶粘起来。

**信息优势（观众知道）**：通过特写镜头 · 我们看到强力胶的说明书写着 **"警告：遇热会爆炸"**。

**危机 B（爆发）**：
> 主角粘好花瓶 · 为了让胶水快点干 · 拿吹风机对着花瓶吹。
> "砰！" 花瓶炸成了碎片。

**更过激办法 2**：现在连碎片都没了 · 主角灵机一动 · 决定去古玩市场买个一模一样的假货。

**信息优势（观众知道）**：我们知道 · 老板的那个花瓶其实**也是个假货** · 但他自己不知道。而主角现在要去买的 · **是个真古董**……

**更强危机 C（爆发）**：
> 主角花光积蓄买了个真古董放回原位。
> 老板回来后 · 没看出区别 · 但因为心情不好 · **随手把那个价值连城的真古董扔进了垃圾桶**……

→ **雪球效应公式**：
```
A 危机 → 解决方案 1 → B 危机（更大）→ 解决方案 2 → C 危机（更大）→ ...
观众每一步都比主角早知道结果 · 笑点持续爆发
```

### 玩法 2 · 信息屏障与假饵 · "多米诺骨牌"

#### 核心原理

```
几个角色或势力 · 各自掌握片面、错误的信息（信息屏障）
都采取自认为正确的行动
但因为"假饵"（误会、假线索）的存在 · 行动互相冲突 / 碰撞
最终引发一场啼笑皆非的混乱

→ 每个人都在认真地搞事情
→ 他们越努力 · 场面越失控
```

#### 实战示例 · "丈夫妻子小偷警察"

##### Step 1 · 设置多方势力与信息屏障

```
A 方（丈夫）：以为妻子要给自己一个生日惊喜
B 方（妻子）：其实在秘密筹备和丈夫离婚
C 方（小偷）：以为这家里没人 · 准备今晚来行窃
D 方（警察）：接到邻居举报说可能有家暴 · 正在门口蹲守
```

##### Step 2 · 投放"假饵"（误会制造机）

```
假饵 1：妻子买了一个巨大的行李箱（准备离家出走用）
        丈夫看见了 · 以为是送给自己的生日礼物
假饵 2：妻子在网上订购了"分手蜡烛"和仪式用品
        丈夫看见了 · 以为是浪漫晚餐的道具
假饵 3：小偷看见妻子在搬箱子 · 以为她在搬运贵重财物
```

##### Step 3 · 行动冲突与事件升级

```
晚上：
  丈夫为了配合"惊喜" · 假装提前出门
    其实躲在衣柜里想给妻子一个反向惊喜
  同时：小偷从窗户爬进来 · 准备偷"装满财物"的行李箱
  同时：妻子点燃"分手蜡烛" · 布置"分手现场"
        准备等丈夫回来摊牌

此时：躲在衣柜里的丈夫 + 撬锁的小偷 + 布置现场的妻子
        三方在屋内形成"恐怖平衡"
```

##### Step 4 · 引爆

```
门外的警察以为屋里动静太大 · 破门而入！
四方人马面面相觑 · 乱作一团
```

→ **多米诺公式**：
```
设定 N 方势力 + 各自信息屏障 + 投放共同假饵 → 行动同时发生 → 灾难性爆发
```

### 玩法 3 · 信息误导 · "扮猪被当成真猪"

#### 核心原理

```
主角的信息被其他角色错误解读
他们对主角产生错误判断（通常是高估或低估）
做出错误行为 · 反而把主角推向他根本不想去的离奇境地

→ 主角被命运（其实是别人的误会）推着走
→ 越解释越乱 · 越反抗越糟
```

#### 实战示例 · "龙套演员变杀手"

##### 主角设定 + 信息误导源

```
主角：胆小如鼠的龙套演员
今天演一个黑帮杀手
穿着戏服（风衣 + 墨镜）+ 拿着假枪
正在揣摩台词

误导源（巧合）：他走错了房间 · 闯进了一个真正的黑帮交易现场
```

##### 错误判断与行为

```
黑帮老大看到主角的打扮 + "沉着冷静"（其实是吓傻了）
  误以为他是对家派来的顶级杀手

为了保命 · 黑帮老大立刻把一个装满毒品的箱子推给主角
  说："大哥 · 货都在这儿了 · 您高抬贵手！"
```

##### 事件升级与无法脱身

```
主角稀里糊涂地提着一箱毒品跑了

真正的杀手来了 · 发现货没了 · 以为是主角黑吃黑 · 开始追杀主角
黑帮老大也反应过来 · 以为主角是警察派来的卧底 · 也开始追杀主角
警察也盯上了这个提着毒品到处跑的"杀手"
```

##### 结局

```
一个只想拿盒饭的龙套演员
莫名其妙地被黑白两道同时追杀
百口莫辩
```

→ **扮猪公式**：
```
[主角真实身份] × [误导源（巧合 / 表象）]
  → [错误判断] × [错误行为]
  → 主角被推向荒诞境地
```

## 第三部分 · 喜剧种子培育法 · 5 步流程

> 在你不知道写什么前 · 先学这套**生成喜剧素材**的工业化方法。

### 第 1 步 · 寻找种子 · 在生活中"捡砂子"

#### 万能"抱怨公式"

```
我对 [一个具体的东西] 感到 [一种负面情绪] ·
因为 [一个荒谬的理由] 。
```

#### 公式拆解

| 部分 | 要求 |
|---|---|
| **[具体的东西]** | 必须具体（"广场舞音响" 不是"生活"）|
| **[负面情绪]** | 愤怒/讨厌/害怕/尴尬/奇怪/困难（越具体越好）|
| **[荒谬的理由]** | 种子的 DNA · 揭示一种"反常"的逻辑 |

#### 实战示例

```
砂子 1（关于客服）：
  我对 [电话客服] 感到 [很生气] ·
  因为 [他们说话永远那么礼貌 · 态度永远那么好 ·
        但就是死活不给你解决问题]
  → 荒谬点："礼貌的攻击性"

砂子 2（关于理发）：
  我对 [理发店的 Tony 老师] 感到 [很害怕] ·
  因为 [他明明只是个剪头的 ·
        却总想当你的"人生导师"和"财务规划师"]
  → 荒谬点："身份的错位"

砂子 3（关于开会）：
  我对 [公司的 PPT 汇报] 感到 [很奇怪] ·
  因为 [一件 5 分钟能说清的事 · 非要做成 50 页 PPT ·
        配上动画和背景音乐 · 搞得像申办奥运会]
  → 荒谬点："形式远大于内容的内卷"
```

→ 当你用这个公式抱怨时 · 你不再是发泄情绪 · 你是在**喜剧分析** · 从情绪垃圾中筛选闪光的"荒谬 DNA"。

---

### 第 2 步 · 筛选种子 · 两道"安检门"

#### 安检门 1 · 共鸣门

> "这事儿别人也烦吗？"

**检测**：把抱怨念给朋友 · 看他会不会说："卧槽 · 我也是！"

| 类型 | 示例 |
|---|---|
| ✅ 通过 | "客服不解决问题" / "开会形式主义" |
| ❌ 不通过 | "我家的猫总在凌晨三点舔我的脚"（太个人化）|

#### 安检门 2 · 画面门

> "这事儿能演出来吗？"

**检测**：闭眼想象 · 能不能像看电影一样清晰看到人物 / 环境 / 动作？

| 类型 | 示例 |
|---|---|
| ✅ 通过 | "理发店 Tony 老师"（紧身裤 Tony · 围布 · 语重心长）|
| ❌ 不通过 | "我讨厌别人在网上跟我抬杠"（画面感弱）|

→ **同时通过两道门** = 金种子。

---

### 第 3 步 · 培育种子 · 给它一个"身体"（前提）

#### 什么是前提

**一句话故事梗概**：用最精练语言告诉所有人——
> 我的故事 · 演一个什么样的人 · 在一个什么样的场景里 · 干了一件什么样的荒唐事。

#### 公式

```
前提 = 基础现实（场景）+ 反常点（游戏）
```

---

### 第 4 步 · 选模型 · 角色游戏 vs 设定游戏

#### 模型 A · 角色游戏 · "怪人入正常环境"

**一句话定义**：在一个大家都很正常的环境里 · 突然出现一个思想或行为极其不正常的"怪人"。

**适用**：种子的"荒诞"主要体现在某种"人"的奇葩行为或逻辑上。

**为什么有效**：
- 正常环境是白色背景板 · 怪人这个黑点格外突出
- 观众代入"直人"（被逼疯的正常人）通过他的视角感受
- 直人的崩溃 / 吐槽 = 替观众发声 = 强烈共鸣

##### 三步搭建（以"客服礼貌不解决问题"为例）

###### Step 1 · 定义怪人和直人

```
怪人（荒诞化身）：客服小王
  核心信念："公司规定 = 宇宙真理 · 客户情绪一文不值"
  他不是坏 · 是纯粹的"规则卫士"

直人（观众嘴替）：客户张三
  需求："手机坏了 · 快给我换！"
  代表所有被客服折磨过的我们
```

###### Step 2 · 设计游戏（怪 vs 正常反复碰撞）

游戏点：无论张三如何咆哮 / 哀求 / 讲道理 · 小王永远只用同一招——
**微笑着说对不起 · 然后引用一条公司规定来拒绝你**。

写**三番**（三轮交锋）：

**第一番（试探）**：
- 张三："我手机坏了 · 要换！"
- 小王（微笑）："先生您好 · 根据公司规定第 108 条 · 换货需要出示原始发票。"

**第二番（升级）**：
- 张三（找到发票）："发票在这！"
- 小王（微笑）："非常抱歉先生 · 根据规定附则第 37 条 · 发票复印件无效 · 必须是原件。"

**第三番（爆炸）**：
- 张三（回家拿来原件 · 气喘吁吁）："原件！给你！"
- 小王（微笑）："好的先生 · 我核对一下…… 嗯 · 非常抱歉 · 根据公司最新规定 · 今天下午五点之后 · 所有售后业务暂停办理 · 请您明天再来。"

###### Step 3 · 设计结局

| 结局 | 描述 |
|---|---|
| **A · 怪人胜利**（荒诞到底）| 张三彻底崩溃 · 也开始对小王背公司规定 · 变成了和小王一样的"怪人"|
| **B · 直人胜利**（回归现实）| 公司老板出现 · 一巴掌把小王开除 · 亲自给张三换手机（喜剧效果较弱）|

→ **角色游戏总结**：核心是"人"。先塑造极致"怪人" · 再扔进人群里 · 看他作妖。

---

#### 模型 B · 设定游戏 · "正常人入怪环境"

**一句话定义**：把一个三观正常、行为普通的人 · 扔进一个规则极其荒诞、逻辑完全颠倒的"怪环境"里。

**适用**：种子的"荒诞"主要体现在某种"现象"或"规则"的奇葩上。

**为什么有效**：
- 观众和主角一样对"怪世界"充满好奇
- 主角 = 观众。他在怪世界的每一次碰壁 / 不解 / 被整蛊 = 我们感同身受
- 主角目标卑微（吃顿饭 / 下班）→ 我们发自内心同情他

##### 三步搭建（以"扫码点餐像上晚自习"为例）

###### Step 1 · 定义正常人和怪环境

```
正常人：
  路人甲 · 饿了一天的游客 · 第一次来这个城市
  对这家餐厅规矩一无所知 · 而且手机刚好没电
  ⚠"没电"设定至关重要——它是主角与怪环境冲突的导火索

怪环境："默剧餐厅"
  核心规则：绝对静音
  规则 1：点餐 / 催菜 / 买单一切交流必须通过手机 App
  规则 2：服务员都戴降噪耳机 · 听不见任何声音
  规则 3：发出声音会被扣"社交积分" · 扣完会被机器人保安请出去
```

###### Step 2 · 设计游戏（三番挣扎）

**第一番（试探性犯规）**：
- 主角走进餐厅 · 对服务员说："你好 · 一位。" 服务员毫无反应
- 主角提高声音："一位！" 一个机器人滑过来 · 红灯闪烁："警告 · 您已发出噪音 · 扣除 10 点社交积分。"

**第二番（理解规则后的挣扎）**：
- 主角明白不能说话 · 想借充电宝
- 走到隔壁桌 · 对一个吃饭的女孩 · 疯狂比画"手机"+"充电"的手势
- 女孩面无表情打开手机 App · 在"邻桌交流"界面打字：
  "请不要用原始的肢体语言骚扰我 · 有事请在 App 里申请'对话'。"

**第三番（彻底放弃正常逻辑）**：
- 主角崩溃 · 为了吃上饭 · 开始模仿服务员的机器人舞步引起注意
- 甚至开始用敲莫尔斯电码的方式敲桌子……
- 他**逐渐被这个怪环境同化了**

###### Step 3 · 设计结局

| 结局 | 描述 |
|---|---|
| **A · 融入或被驱逐**（悲喜剧）| 主角因犯规太多被机器人保安抬出去 · 没吃上饭（讽刺科技异化）|
| **B · 打破规则**（爽点）| 主角忍无可忍掀翻桌子大吼："老子要吃饭！" 全餐厅人摘下耳机鼓掌 · 原来大家早受不了这破规矩 · 他成了打破规则的英雄 |

→ **设定游戏总结**：核心是"环境"。先构建规则荒诞的"疯人院" · 再把正常人扔进去 · 看他如何被逼疯 / 拆掉疯人院。

---

#### 模型选择决策

```
拿到喜剧种子时 · 问自己：
  这颗种子的"荒诞" · 是更集中在"某个人"身上 · 还是更集中在"某个环境/现象"上？

如果荒诞的是"人"（奇葩室友 / 爱吹牛领导）→ 角色游戏
  让这个怪人去祸害世界

如果荒诞的是"事"（社会风气 / 公司制度）→ 设定游戏
  让一个正常人去体验这个怪事有多离谱
```

### 第 5 步 · 节拍器 · "三番升级"与"合理性催眠"

#### 核心命题

```
喜剧的重复 ≠ 复制粘贴
喜剧的重复 = 有节奏 / 有铺垫的"升级"

目的不只是搞笑 · 更是完成"合理性催眠"——
通过前两次"小剂量"铺垫 · 拉高观众对"荒诞"的接受阈值
当第三次最夸张事件发生时 · 观众已被催眠 · 觉得"挺合理的"
```

#### 节拍模板：小 · 小 · 大 / 弱 · 弱 · 强

#### 案例 1 · 角色游戏 · 《功夫》包租婆

**最终目标**：包租婆将斧头帮二当家打得嵌进墙里。

❌ **错误写法**（直接上）：
> 斧头帮欺压众人。包租婆突然冲出来 · 大喊"我忍你很久了！"· 一套降龙十八掌打飞所有人。
> → 观众反应：太突兀了！没铺垫！

✅ **正确写法**（三番升级 · 小小大）：

**第一番 · 小试探**（建立"她不简单"的规则）：
> 斧头帮二当家点烟 · 火苗燎到包租婆头发。
> 包租婆没回头 · 反手一巴掌 · 看似随意却快如闪电 · 瞬间打灭火苗 · 还把二当家的脸扇得红肿。
> → 观众反应：咦？这个女人反应好快 · 力气也不小。

**第二番 · 再确认**（强化规则 · 略升级）：
> 二当家想报复 · 一斧头砍向包租婆。
> 包租婆一边叼烟 · 一边用两根手指轻描淡写夹住斧刃 · 手指一搓 · 木柄寸寸断裂。
> → 观众反应：卧槽！两根手指夹住斧头？高手！我懂了 · 她在隐藏实力。

**第三番 · 大爆发**（观众已有心理准备 · 玩大的）：
> 二当家激怒 · 召集所有人围攻。
> 包租婆不再隐藏 · 展现出与肥胖身材完全不符的惊人速度 · 在人群中穿梭 · 拳拳到肉。
> 最后抓住二当家的头 · 像拧毛巾一样左右开弓 · 一记重拳将他打得飞起 · **深深嵌进墙壁**。
> → 观众反应：来了来了！果然是高手！既在意料之外 · 又在情理之中！

#### 案例 2 · 设定游戏 · 《让子弹飞》六爷之死

**最终目标**：六爷剖腹证明自己只吃了一碗粉。

❌ **错误写法**（直接上）：
> 武状元诬陷六爷吃了两碗粉。六爷二话不说 · 直接拔刀剖腹。
> → 观众反应：这人有病吧？无法共情。

✅ **正确写法**（三番升级 · 弱弱强）：

**第一番 · 弱升级**（建立"讲理行不通"的规则）：
> 武状元和胡万一口咬定六爷吃了两碗粉 · 拒不付钱。
> 六爷讲道理："我随身钱就够一碗 · 怎么可能吃两碗？"
> 但胡万和众人根本不听 · 用起哄 / 嘲笑 / 鼓噪 · 用"人多势众"压制他。
> → 观众反应：哦 · 这地方不讲道理 · 只看谁横。

**第二番 · 弱升级**（强化规则 · 堵死所有退路）：
> 六爷拔出枪想威慑对方。
> 胡万不仅不怕 · 反而进一步挑衅："枪 · 是用来干这个的？"（指着自己脑袋）
> 并煽动众人指责张麻子的人"吃粉不给钱还欺负人"。
> 把简单经济纠纷成功上升到"土匪欺压百姓"的道德困境。
> → 观众反应：完了 · 六爷退路全被堵死了。讲理没人听 · 动武又会落入对方道德陷阱。

**第三番 · 强爆发**（讲理和动武都被堵死 · 放大招）：
> 六爷这个"一根筋"理想主义者 · 为了"公平"和张麻子的"名声" · 选择唯一剩下的最惨烈方式。
> 把刀递给胡万 · 让他当见证。
> 在众人惊愕目光中 · 缓缓地、决绝地将刀捅进自己肚子 · 划开 · 亲手捞出里面的凉粉 · 高高举起 · 嘶吼道："**看见了吗！是不是只有一碗！**"
> → 观众反应：天啊！但在那种被逼到绝境的情况下 · 以他的性格 · 这似乎是他唯一能做的选择了。**既荒诞又无比合理**。

## 喜剧创作的信任游戏

```
喜剧创作 · 本质上是你和观众之间的一场"信任游戏"
你的任务 · 通过"三番升级"工具一步步引导观众
让他们放下戒备 · 暂时忘记现实逻辑 · 相信你为他们构建的荒诞世界

第一次重复：朋友 · 我这儿有个好玩的东西 · 你瞅瞅
第二次重复：你看 · 我没骗你吧 · 这东西就是这么玩的
第三次重复：既然你信了 · 那咱俩就一起 · 把这事儿玩到飞起！

→ 当你掌握"小小大 / 弱弱强"节拍器 · 你就掌握了通往高级喜剧的钥匙
```
