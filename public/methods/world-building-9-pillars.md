# 世界观九柱法（World Building 9 Pillars）

> **来源**：番茄小说 16 门写作课程体系 v2.0 提炼 + 《天眼女相师》实例验证。
> **定位**：craft 工艺层 · **世界观构建骨架模块**。与结构骨架、角色层、节奏层**全正交**。填补 `novel.1.1`（世界观节点）此前的方法论空白。
> **核心价值**：9 个标准化章节 + 渐进揭示节奏 + 世界级悬念表 + 7 条反常见错误禁忌。让 LLM 写世界观时**不做开篇说明书、不临时加设定、不自相矛盾**。

---

## 适用边界

✅ **强推荐**（世界观复杂度高）：
- 玄幻 / 仙侠 / 修真 / 异世界
- 都市异能 / 灵异 / 克苏鲁
- 科幻 / 末世 / 赛博朋克
- 奇幻 / 剑与魔法 / 克里苏

✅ **推荐**（世界观中等复杂度）：
- 悬疑 / 推理（规则怪谈型）
- 权谋 / 宫斗 / 架空历史
- 言情 / 古言（需阶层与规则）

⚠ **可选**（简化使用）：
- 现代都市 / 现代言情（只需填 1–3 / 6 / 9 三柱）
- 校园 / 职场（同上）

❌ **不推荐**：
- 纯日常 / 治愈 / 散文化作品
- 微小说 / 短篇（开销 > 收益）

## 一、九柱结构总览

世界观必填 **9 柱**（长度可缩放，但柱数不能减）：

| # | 柱名 | 核心功能 | 推荐篇幅 |
|---|---|---|---|
| 1 | **故事类型与基调** | 定位题材 + 篇幅 + 核心标签 + 感情线占比 | 小 |
| 2 | **世界观顶层设计** | 表/里世界二分 + 核心设定 + **硬规则三条** | 中 |
| 3 | **势力格局** | 势力表 + 冲突图谱 | 中 |
| 4 | **社会/阶层结构** | 表层社会 + 里层权力结构 | 小–中 |
| 5 | **力量/能力体系** | 等级 + 能力详解 + 限制 | 中 |
| 6 | **世界观揭示节奏规范** | 前 10 / 10–30 / 30–60 / 60+ 章渐进揭示 | 小 |
| 7 | **未解悬念** | 世界级谜题表（5 条以内） | 小 |
| 8 | **金手指详细设定** | 标准化 7 字段 | 中 |
| 9 | **世界观禁忌清单** | 反常见错误硬律 | 小 |

## 二、九柱详解 + 硬律

### 柱 1 · 故事类型与基调

**必填字段**：
- 类型（如：现代都市 + 玄学捉鬼）
- 篇幅（如：300 章 × 3000–4000 字 ≈ 90–120 万字）
- 核心标签（3–5 个）
- 主要卖点（2–3 条）
- 时间线类型（顺叙 / 倒叙 / 插叙）
- 感情线占比（百分比）

### 柱 2 · 世界观顶层设计

**2.1 表世界 vs 里世界**（必做）

| 世界层 | 主角表面身份 | 真实身份 | 读者认知方式 |
|---|---|---|---|
| 表世界（日常层） | ... | ... | 第 1 章即知 |
| 里世界（真实层） | ... | ... | 随剧情逐步揭示 |

**硬律**：即使纯现实题材也应有**"表里二分"**——主角的**公开身份** vs **真实处境/动机**。没有二分 = 世界观塌陷。

**2.2 核心设定（开篇即亮的强设定）**

| 项目 | 内容 |
|---|---|
| 设定名称 | （1 个关键词） |
| 核心能力 / 规则 | ... |
| 限制 / 代价 | ... |
| 成长路径 | ... |

**硬律**：**限制必须实际制约剧情**（契诃夫规则），不能只是摆设。

**2.3 世界运转的硬规则（三条）**

| 规则 | 内容 | 违背后果 |
|---|---|---|
| 铁律一 | ... | ... |
| 铁律二 | ... | ... |
| 铁律三 | ... | ... |

**硬律**：至少 **3 条**硬规则 + 每条必须明确**违背后果**。后果越具体，剧情冲突越有爆发力。违背事件应成为某章的核心冲突点。

### 柱 3 · 势力格局

**3.1 主要势力一览**（至少 3 势力，不超过 7）

| 势力名称 | 性质 | 代表人物 | 核心利益 | 与主角关系 |
|---|---|---|---|---|

**3.2 势力冲突图谱**（ASCII 图）

```
符号说明：→ 敌对  ⇆ 对抗中合作  ↔ 合作

[势力A] ──→ [势力B]    ← 死敌
[势力A] ⇆── [势力C]    ← 隔阂但可合作
```

**硬律**：势力关系图必须**图示化**（不用文字段落），LLM 可扫读一次记住。

### 柱 4 · 社会/阶层结构

**4.1 表层社会结构**（ASCII 分层）

```
顶层：...
中层：...
底层：...
最底层：→ 主角表面身份
```

**4.2 里层权力结构**（等级表 + 主角当前位置标记 ✅）

**硬律**：**主角当前位置必须明确标注**。爽文的"碾压感"来源于明确的等级差。

### 柱 5 · 力量/能力体系

**等级表**（6–8 级为佳）：

| 等级 | 能力描述 | 代表人物 |
|---|---|---|
| 入门 | ... | |
| 小成 | ... | |
| 大成 | ... | |
| 宗师 | ... | |
| 天师 / 飞升 | ... | ✅ 主角终局 |
| 传说级 | 仅提及不出场 | |

**主要能力详解**：
- 能力来源
- 可见 / 可做什么
- **特殊用法（高消耗）**
- **局限 / 代价**

**硬律**：能力体系必须**每一级都有代表人物**，否则是空中楼阁。**传说级通常仅提及不出场**，为续集或大结局留空间。

### 柱 6 · 世界观揭示节奏规范（**最核心硬律**）

> **世界观随剧情揭示，不是开篇说明书。**

**四段渐进揭示模型**（按章节位置）：

| 揭示时机 | 内容 | 揭示方式 |
|---|---|---|
| **前 10 章** | 基本设定（核心金手指存在 / 主角表面身份 / 主业） | **融入第 1 章冲突场景**，自然带出 |
| **10–30 章** | 势力版图（主要势力对立） | 通过角色互动 / 冲突自然带出 |
| **30–60 章** | 反派组织详情 / 主角家族历史 | 随主线推进逐步揭示 |
| **60 章以后** | 深层次设定（世纪恩怨 / 核心金手指全部能力） | 随感情升温和主线高潮逐步揭示 |

**三大禁忌**：
- ❌ 开篇用大段旁白介绍体系
- ❌ 一次性抛出超过 **3 个新设定**
- ❌ 同一能力在不同章节表现矛盾（需建立能力表现档案）

### 柱 7 · 未解悬念（世界级谜题）

| 悬念 | 埋入章节 | 揭示时机 | 与主线关系 |
|---|---|---|---|
| 悬念 A：核心冲突根源 | 第 1 章 | 第 60–80 章 | 核心主线驱动 |
| 悬念 B：关键配角真实身份 | 前 3 章 | 第 40–50 章 | 感情 / 悬疑线交汇 |
| 悬念 C：世纪恩怨 | 第 5–10 章 | 第 100 章附近 | 大型揭秘 |
| 悬念 D：最终反派真身 | 前 3 章 | 第 80–100 章 | 反派终极揭秘 |
| 悬念 E：金手指真正来源 | 第 1 章 | **大结局附近** | 收束所有伏笔 |

**硬律**：
- 悬念总数 **3–7 条**（少于 3 支撑不住，多于 7 读者记不住）
- **悬念 A 必须第 1 章就埋下钩子**（成为读者追文的根本动力）
- **悬念 E（金手指本源）必须大结局才揭示**，中间不得泄露
- 每条悬念必须**明确标注**「埋入章节 / 揭示时机 / 与主线关系」三字段

**与 `plot-coherence-scaffold` 的区别**：本柱管**世界级宏观悬念**（跨 100 章），plot-coherence 管**章节级因果伏笔**（局部回响）。两层正交叠加。

### 柱 8 · 金手指详细设定

**标准化 7 字段**（金手指是爽文命脉，必须严谨）：

| 字段 | 内容 |
|---|---|
| 名称 | 1 个关键词 |
| 来源 | 天生 / 获得 / 觉醒 / 穿越带来 |
| 核心能力 1 | ... |
| 核心能力 2 | ... |
| 核心能力 3 | ... |
| **限制条件** | **必须有** |
| 成长方式 | 实战积累 / 解锁新能力 |
| 与其他能力的关系 | 辅助 / 互补 / 制约 |

**硬律**：
- 核心能力 **3–5 条**，每条都要明确
- **限制条件必写**（否则金手指无限强，故事崩盘）
- **成长方式必写**（爽文核心是"不断变强"，每次变强都应有明确依据）

### 柱 9 · 世界观禁忌清单

必含的 7 条禁忌（可按题材微调）：

- ❌ **不要告诉读者的事情**：金手指终极秘密 / 主角血脉真正来源，大结局前不揭示
- ❌ **不要自相矛盾的设定**：金手指在不同场景的表现必须有统一限制规则
- ❌ **不要临时加入新势力 / 规则**：反派组织设定必须在大纲阶段确定，不临时增加
- ❌ **不要让配角知道主角的全部能力**：保留隐藏身份 / 隐藏马甲给读者独享
- ❌ **主角绝不圣母 / 软弱 / 被动挨打**（爽文核心，绝不违背；文学向可弱化此条）
- ❌ **不写真正恐怖**（悬疑/灵异题材）：以"诡异 + 刺激"替代"吓人 + 恶心"，读者感受是"好刺激"不是"好害怕"
- ❌ **反派 / 鬼怪 / 异常不能有完整人类情感**：保持神秘感，动机单纯化，不做复杂情感演绎

## 四、与其他模块协同

- **与 `supernatural-webfiction-pack`**：**极强协同**。本模块管世界观骨架，超自然包管元素编码（ATU / 魔法物品三维 / 契约 / 变形 / 生死）。柱 5 能力体系 + 柱 8 金手指 的填法可直接调用超自然包的 D/H/C/N 类母题。
- **与 `plot-coherence-scaffold`**：**互补协同**。本模块柱 7 管**世界级宏观悬念**（跨 100 章），plot-coherence 管**章节级因果伏笔**（局部回响）。两层正交叠加，长篇项目建议双开。
- **与结构骨架**：正交。9 柱定世界观，结构骨架定情节节拍。
- **与 `mbti-*` / `character-three-elements-method`**：正交但强相关。柱 4 阶层结构 + 柱 7 悬念中"关键配角身份"等应与角色层设计对齐。
- **与 `anti-ai-flavor`**：正交。本模块在世界观注入，anti-ai 在章节润色注入，作用层不同。
- **与 `seven-emotion-peaks`**：弱相关。柱 6 渐进揭示节奏影响单章情绪曲线（爆点前要蓄势）。

## 五、一句话原则

> **世界观不是背景板，是一台会按规则运转的机器。你写的不是设定，是这台机器"按规则运转会发生什么"。**
