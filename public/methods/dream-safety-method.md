# 梦境绝对安全感 · 道德焦虑守护 4 手法

> **来源**：墨香阁柒爷网文创作课《观众心理学与梦境关系》第二课「梦境三大指标 · 指标一」。
> **定位**：dream 层 · **守梦型模块**。爽文 / 网文 / 短剧项目**强烈推荐启用**。
> **核心命题**：观众在梦里宣泄的，很多是现实中被压抑的负面欲望（贪婪 / 报复 / 权力欲）。如果一个梦让观众觉得"自己是个坏人"，理性脑会启动**心理防御**，本能抗拒并惊醒。
> **核心价值**：用 4 个**包装手法**为观众提供"道德安全区"，让他们心安理得地享受爽点，而不会产生罪恶感。

---

## 适用边界

✅ **强推荐启用**：
- 都市爽文 / 赘婿逆袭 / 战神归来 / 重生流
- 玄幻升级流 / 系统流 / 修真爽文
- 短剧（霸总 / 复仇 / 装逼）
- 任何含有"主角复仇 / 装逼 / 碾压"主线的项目

⚠ **可选启用**（部分采用即可）：
- 大女主 / 大男主成长剧（弱化使用）
- 言情甜宠（仅"反派非人化"一项）

❌ **不要启用**：
- 严肃文学 / 现实主义（道德灰度反而是卖点）
- 心理悬疑（人物复杂度是卖点）
- 反英雄题材（反英雄就是要打破道德安全区）

---

## 核心心法 · 道德焦虑守护

```
观众想 报复 → 但报复在现实中违法 → 罪恶感 → 弃书
我们的工作：把"报复"包装成"伸张正义" → 罪恶感消解 → 沉浸继续
```

→ 我们不创造道德 · 我们**重新包装**让观众的现实欲望变得"道德可接受"。

---

## 4 大手法 · 实操指引（LLM 提示词）

### 手法 1 · 主角的完美圣人化

**核心**：主角是**道德完美的容器** · 善良 / 孝顺 / 重情义 · 几乎 0 性格缺陷。

**做法**：
- 主角的所有行动，**即便本质是夺取利益，也必须被包装成"为保护亲人 / 伸张正义"**
- 主角不能有**真正的道德污点**（不能贪小便宜 / 不能伤害无辜 / 不能背叛承诺）
- 主角即使"杀人"，也是被逼无奈或为他人 · 不是为自己

**反例**（破坏安全感）：
- ❌ 主角抢了一个无辜小贩的生意（即使小贩很弱）
- ❌ 主角因为情绪冲动伤害了好人（哪怕之后道歉）
- ❌ 主角说谎欺骗朋友（哪怕是善意的谎言）

**正例**（守护安全感）：
- ✅ 主角抢了首富的生意（首富是反派，是恶人）
- ✅ 主角伤害"好人"原来发现是反派伪装（反派非人化协同）
- ✅ 主角说谎是为了保护朋友的家人

**LLM 注入**：
```
角色 bible 生成 (novel.1.2) 必填：
- 主角道德底线（≥ 5 条 · 包含 "不伤害无辜" / "信守承诺" / "保护弱者" 等）
- 主角"被迫做坏事"时必须有第三方声音（OS / 配角）解释正当性
```

### 手法 2 · 动机的正义合理化

**核心**：为主角设计**足够凄惨的背景** · 让后续所有复仇 / 掠夺 = "拿回本该属于我的"+"替天行道"。

**做法**：
- 起点章必须铺垫**主角受害背景**（被背叛 / 被羞辱 / 被剥夺一切 / 童年悲剧）
- 凄惨程度 ≥ 主角后续要做的"恶"程度（复仇杀人 = 受害情节必须包含至亲被害）
- 受害情节必须**明确归罪到反派阵营**（不能模糊到"命运" / "社会"）

**经典模板**：
```
起点：主角 [身份] 被 [反派] 害得 [家破人亡 / 一无所有 / 名誉扫地]
冲突：主角发现 [反派] 还在嚣张 / 还在害更多无辜者
合理化：主角的复仇 = 拿回属于自己的 + 阻止反派继续作恶
观众感：大快人心 / 替天行道（不是"心胸狭隘"）
```

**LLM 注入**：
```
立项阶段 (novel.0/novel.1) 必含：
- 主角受害历史 chronological 时间线（≥ 3 个事件）
- 反派罪行清单（每条对应主角受害事件）
- 复仇正义性自检：主角行动 vs 反派罪行 = 1:1 或 1:n（绝不能反过来）
```

### 手法 3 · 反派的极端非人化

**核心**：反派是**纯粹的、无道德的、集所有负面标签于一身的"恶"的符号**。

**做法**：
- 反派**又蠢又坏**（智商可降但绝不能降到搞笑 · 必须有威胁感的"坏"）
- 反派**傲慢自大** / **双重标准** / **欺软怕硬**
- 反派**对主角阵营的人毫无怜悯**（杀人不眨眼 / 折磨弱者）
- 反派的存在**就是为了作恶** · 没有"反派也有苦衷"的复杂性

**反例**（破坏安全感 → 让观众产生同情）：
- ❌ 反派也有悲惨童年（观众："其实他也挺可怜的…"）
- ❌ 反派对家人很好（观众："至少他不是纯恶…"）
- ❌ 反派有合理动机（观众："站在他的立场也能理解…"）

**正例**（强化安全感）：
- ✅ 反派对自己的下属也是工具人态度
- ✅ 反派欺凌弱者时露出享受表情
- ✅ 反派的"动机"是纯粹的贪婪 / 嫉妒 / 报复（不是被迫）

**例外**：
- 反派 BOSS 可以有"复杂动机"（增加深度）· 但小反派必须扁平
- 反派"洗白"必须放在**很后期**（前 80% 都是非人化）

**LLM 注入**：
```
反派塑造 (novel.1.2 反派 bible) 必含：
- 反派罪行清单（≥ 5 条 · 每条都有受害者具体描写）
- 反派"非人化"特征（≥ 3 条 · 如"虐待动物" / "欺辱老人" / "享受他人痛苦"）
- 反派"复杂动机"禁用（除非主反派且仅在最后 20% 揭示）
```

### 手法 4 · 金手指的天命所归化

**核心**：主角强大的金手指（系统 / 老爷爷 / 神级天赋）**不能仅是运气好** · 必须被描绘成**天命所归 / 苦尽甘来的必然**。

**做法**：
- 金手指来源 = **天选 / 报恩 / 因果**（不是"中彩票" / "意外捡到"）
- 主角善良在先 → 天命补偿在后（因果链清晰）
- 金手指的力量与主角"承受的苦难"成正比（受苦越多 → 金手指越强）

**反例**（破坏安全感 → 让观众觉得"凭什么"）：
- ❌ 主角早上起床就发现自己是天选之人（凭什么？）
- ❌ 主角随便捡到神器就变强（运气这么好？）
- ❌ 没有铺垫的金手指（观众："这不就是开挂吗"）

**正例**（守护安全感 → 让观众觉得"应得的"）：
- ✅ 主角小时候救了一个老乞丐 → 多年后老乞丐是大宗师传授功法
- ✅ 主角无辜被害身死 → 系统因主角"善心+冤魂"激活
- ✅ 主角守护母亲遗物 → 遗物原来是上古宝物认主

**LLM 注入**：
```
金手指设计 (novel.1.1 世界观 / novel.1.2 角色) 必含：
- 金手指获得契机 = 主角善行 / 牺牲 / 苦难（不能是"凭空获得"）
- 金手指等级 ↔ 主角苦难程度（受苦越多 → 力量越强 · 因果链清晰）
- 强金手指的"代价"（避免"过分外挂"破坏可信度）
```

## 4 手法协同 · 道德安全区构建

```
                ┌─ 主角圣人化（观众代入 = 自己是好人）
                │
观众情绪沉浸 ──→ ┼─ 动机正义化（主角行动 = 替天行道）
                │
                ├─ 反派非人化（打的对象 = 该死的）
                │
                └─ 金手指天命化（拥有的力量 = 应得的）

                          ↓
                   道德安全区完整 → 观众心安理得享受爽点
```

**4 手法缺一**：
- 缺主角圣人化 → 观众代入"自己是坏人"→ 罪恶感
- 缺动机正义化 → 主角行为变"私欲"→ 心胸狭隘感
- 缺反派非人化 → 观众同情反派 → 主角变"霸凌者"
- 缺金手指天命化 → 观众感觉"凭什么是他"→ 不公平感

## 检验清单（dogfood 时人工抽检）

- [ ] 主角第 1 章亮相 5000 字内，**受害背景已铺垫完整**（被害事件 + 反派归属）
- [ ] 主角整本书**未做过一件"违反道德底线"的事**（除非被反派伪装欺骗）
- [ ] 反派**前 80% 没有获得读者同情**（无悲惨童年描写 / 无家庭温情）
- [ ] 主角金手指**首次激活时有明确"应得"铺垫**（救人 / 牺牲 / 因果）
- [ ] 主角"复仇 / 掠夺"行为时，必有**第三方声音**（OS / 配角）确认其正当性

## 范例 · 一句话激活公式

```
{ 主角 } 因 { 反派 } 的 { 罪行 } 失去 { 至亲 / 一切 }，
此时 { 天命 / 因果 } 让主角获得 { 金手指 }，
主角必须对抗 { 反派 + 反派阵营 }，
每打败一个反派 = 拿回 { 属于自己的 / 弱者的公道 }。
```

把这段填空给 LLM · 道德安全区骨架自动出来。
