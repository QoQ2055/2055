# 双线叙事模板 · 平行 / 对比 / 交叉 6 段结构

> **来源**：Jaygo Creativity v28 概念提取（视频分镜模板 9 抽象为通用故事结构 · 与平台无关）。
> **定位**：structure 层 · **双线叙事专用结构**（与 kishotenketsu / heros-journey / save-the-cat 等单线结构互补）。
> **核心命题**：fili-web 现有所有结构 modules（kishotenketsu / heros-journey / save-the-cat / atu-301 / seven-points-romance / twelve-step-mystery / truby-22-steps）**全部是单线**结构。**双线 / 平行 / 对比 / 交叉**叙事结构完全空白。本模块填补该盲区。
> **核心价值**：(1) 双线设定（线 A vs 线 B 的 4 维差异）；(2) 6 段时间轴（上线建立 → 下线建立 → 上线发展 → 下线发展 → 交叉点 → 落版）；(3) 3 类交叉模式（合流 / 对比 / 冲突）；(4) 4 维视觉对比设计。

---

## 适用边界

✅ **强推荐启用**：
- 平行时空（重生流双时空 · 古今对照）
- 双男主 / 双女主 / 双视角
- 对比叙事（前世今生 / AB 面 / 善恶双面）
- 双线悬疑（凶手 + 侦探 双视角）
- 古言 + 现代双线穿越
- 双男主 / 双女主同人

⚠ **可选启用**：
- 群像戏（3-5 主角 · 双线为主）
- 武侠（正派 + 反派 双线）

❌ **不要启用**：
- 单视角第一人称小说
- 短篇 / 单元剧（不够空间展开双线）
- 速食爽文（双线降低爽感节奏）

## 核心心法 · 双线 ≠ 简单切换

### 痛点

```
新手写双线常犯错误：
  Bug 1：两条线毫无关联 · 读者觉得"两本书拼一起"
  Bug 2：A 线 → B 线 → A 线 → B 线 · 机械切换
  Bug 3：B 线只是 A 线的注脚 · 不独立
  Bug 4：交叉点突兀 · 没有铺垫
  Bug 5：结尾只收一条线 · 另一条悬空

→ 这些 bug 让双线变成"双线+"
→ 失去对比 / 交叉 / 揭示的核心价值
```

### 解决方案 · 4 维差异 + 6 段结构 + 3 类交叉

```
真正的双线 = 设定差异化 + 节奏交错 + 主题呼应

→ 双线必须有"差异"（不是分身术）
→ 双线必须有"呼应"（不是分书）
→ 双线必须有"交叉"（不是平行不交）
```

## 一 · 双线设定 · 4 维差异化 ★ 必备

### 维度 1 · 主体差异

```
线 A 主体 与 线 B 主体 必须不同：
  ├─ 角色不同：林深 vs 沈砚
  ├─ 视角不同：第一人称 vs 第三人称
  ├─ 时间不同：现代 vs 古代
  └─ 空间不同：北京 vs 江南古镇

→ 两条线**不是同一个人**（除非平行时空版本）
→ 让读者一眼分辨"现在在 A 还是 B"
```

### 维度 2 · 场景 / 调性差异

```
线 A：清冷 / 都市 / 钢铁灰
线 B：温暖 / 古镇 / 暖黄绿

→ 视觉上一秒分辨
→ 调性上不重复
```

### 维度 3 · 节奏差异

```
线 A：快节奏（每章 1-2 个场景）
线 B：慢节奏（每章 1 个场景 + 长描写）

→ 节奏对位（A 紧时 B 松 · A 松时 B 紧）
→ 防止双高潮压垮读者
```

### 维度 4 · 情绪 / 色彩差异

```
线 A：紧张 / 冷酷 / 蓝灰
线 B：温柔 / 平和 / 米黄

→ 情绪互补（A 暗时 B 亮）
→ 色彩对比（视觉化为画面）
```

### 4 维差异速查表

| 维度 | 线 A | 线 B |
|---|---|---|
| 主体 | [角色 / 视角] | [角色 / 视角] |
| 场景 | [时空 / 地点] | [时空 / 地点] |
| 节奏 | [快 / 慢] | [快 / 慢] |
| 情绪 / 色彩 | [情绪 / 色彩] | [情绪 / 色彩] |

## 二 · 6 段时间轴 ★ 章节版

```
按全书 100% 进度划分（章节数自适应）：
```

### 段 1 · 上线建立（0% → 15%）

```
任务：
  ├─ 立 A 线主角 / 主场景
  ├─ 给 A 线核心冲突（一句话）
  └─ 让读者**爱上 A 线主角**

写法：
  ├─ 开场放 A 线（强吸引力）
  ├─ 不提 B 线（保留意外感）
  └─ A 线第一个钩子（章末 / 段末）

时长：1-3 章
```

### 段 2 · 下线建立 + 对比关系（15% → 30%）

```
任务：
  ├─ 立 B 线主角 / 主场景
  ├─ 给 B 线核心冲突（与 A 线**有差异**）
  └─ 暗示 A 与 B 的关联（**不揭示**）

关键：
  ├─ B 线一上来就**对比 A 线**（视觉/情绪/节奏）
  ├─ 不要简单复述 A 线模式
  └─ B 线要让读者**惊喜**："原来还有另一条线！"

时长：2-3 章
```

### 段 3 · 上线发展 · A 关键节点（30% → 50%）

```
任务：
  ├─ A 线推进核心冲突
  ├─ A 线主角解决一个挑战
  └─ A 线埋下中段伏笔

关键：
  ├─ B 线在这段**几乎不出现**（保持注意力）
  ├─ 章末或段末 A 线高潮
  └─ A 线高潮需要 B 线"接力"
```

### 段 4 · 下线发展 · B 关键节点（50% → 65%）

```
任务：
  ├─ B 线推进核心冲突
  ├─ B 线主角解决一个挑战（**节奏匹配 A 线段 3**）
  └─ B 线埋下中段伏笔

关键：
  ├─ B 线高潮 = A 线高潮的"对位"
  ├─ 暗示 A 与 B 的关联（**部分揭示**）
  └─ 读者开始猜"两条线怎么交"
```

### 段 5 · 交叉点 · 双线合流（65% → 85%）

```
任务：
  ├─ A 线 与 B 线 在某个事件 / 地点 / 时间**汇合**
  ├─ 主题揭示
  └─ 双线合流后的化学反应

关键（最难写）：
  ├─ 交叉**不能突兀**（前面要充分铺垫）
  ├─ 交叉**要有意义**（揭示主题 / 解决冲突 / 制造冲突）
  └─ 交叉后双线**继续 OR 收为单线**

3 种交叉模式（详 §三）
```

### 段 6 · 落版 · 收尾（85% → 100%）

```
任务：
  ├─ 解决主冲突
  ├─ 双线主题统一
  └─ 留给读者一个余味

3 种结尾方式：
  ├─ 单线收尾：交叉后只走 A 或 B（另一线已完成使命）
  ├─ 双线叠加：A 与 B 都收 · 但呈现统一画面（如倒叙）
  └─ 主题揭示：交叉点本身就是结尾（开放式）
```

## 三 · 3 类交叉模式 ★ 段 5 核心

### 模式 1 · 合流（汇合 · 同一目标）

```
A 线主角 + B 线主角 → 同一事件
  例：林深（侦探）+ 沈砚（凶手）→ 同一案发现场

适合：
  ├─ 双男主 / 双女主同框
  ├─ 双视角悬疑（揭穿真相）
  └─ 平行时空合流

关键：
  ├─ 合流前不知对方身份
  ├─ 合流时**第一次互动**要冲击力
  └─ 合流后**矛盾或化学反应**
```

### 模式 2 · 对比（同一时间 · 不同空间）

```
A 线 与 B 线 在**同一时刻发生不同事件**
  例：林深求婚 vs 沈砚被分手 · 同一秒同城两端

适合：
  ├─ 古今对照
  ├─ 人生 AB 面
  └─ 命运对比

关键：
  ├─ 时间锚点对得上（"同一晚"/"同一秒"）
  ├─ 情绪对比拉满（喜 vs 悲 / 得 vs 失）
  └─ 读者感受"双倍冲击"
```

### 模式 3 · 冲突（A 与 B 是对手）

```
A 线主角 vs B 线主角 → 直接对决
  例：哥哥（A 线）vs 弟弟（B 线）→ 兄弟反目

适合：
  ├─ 善恶双线
  ├─ 兄弟 / 姐妹反目
  └─ 师徒对决

关键：
  ├─ 双方都"自己有理"（不是非黑即白）
  ├─ 对决前**双方都被读者爱**
  └─ 对决后**至少一方破碎**（读者也心碎）
```

## 四 · 视觉对比设计 · 4 维 ★ 文笔层

```
双线一定要"看上去就不同"
```

### 4 维视觉对比

| 维度 | 线 A | 线 B | 对比效果 |
|---|---|---|---|
| **色调** | 冷蓝 / 钢灰 | 暖黄 / 米色 | 一秒分辨 |
| **视角** | 俯视 / 仰视 | 平视 / 远景 | 镜头语言不同 |
| **景别** | 特写 / 中景 | 远景 / 全景 | 节奏差异 |
| **运镜** | 快推 / 跟镜 | 缓拉 / 静镜 | 节奏差异 |

### 4 维视觉对比写在小说里

```
小说不是视频 · 但可以用文字模拟视觉对比：

色调（文字描写偏色）：
  线 A："冰冷的钢铁与水泥" · "钢蓝色暮霭"
  线 B："温暖的木质与亚麻" · "蜂蜜色的午后"

视角（叙述视角）：
  线 A：第一人称（紧张代入）
  线 B：第三人称全知（缓慢全景）

景别（场景颗粒度）：
  线 A：1 个场景 / 章 · 描写细致
  线 B：3 个场景 / 章 · 描写疏放

运镜（叙述节奏）：
  线 A：短句 + 高频换段
  线 B：长句 + 大段叙述
```

## 章节级双线分配模板（连载小说版）

```
3 种 A:B 章节配比（按全书 30 章为例）：

模板 1 · 经典 1:1（推荐 ★）
  Ch.1-3：A 线建立（3 章纯 A）
  Ch.4-6：B 线建立（3 章纯 B）
  Ch.7-12：A B 交替（A B A B A B）
  Ch.13-18：A 线发展为主（B 线 1-2 章插入）
  Ch.19-24：B 线发展为主（A 线 1-2 章插入）
  Ch.25-27：交叉点（A B 同章）
  Ch.28-30：落版（单线或双线收）

模板 2 · A 主 B 辅 2:1
  A 线 20 章 · B 线 10 章
  适合：B 线只是注解 / 镜像
  风险：B 线弱化为附庸

模板 3 · 交错平衡 1:1 严格
  奇数章 A · 偶数章 B
  适合：双男主 / 双女主同等戏份
  风险：节奏单调
```

## 实战检验法

### 双线项目立项时 · 4 项自检

#### 自检 1 · 4 维差异化

- [ ] 线 A 与线 B 的**主体**不同？
- [ ] 线 A 与线 B 的**场景**不同？
- [ ] 线 A 与线 B 的**节奏**不同？
- [ ] 线 A 与线 B 的**情绪 / 色彩**不同？

#### 自检 2 · 6 段结构

- [ ] 段 1 上线建立 = 0-15%？
- [ ] 段 2 下线建立 + 对比 = 15-30%？
- [ ] 段 3 A 关键节点 = 30-50%？
- [ ] 段 4 B 关键节点 = 50-65%？
- [ ] 段 5 交叉点 = 65-85%？
- [ ] 段 6 落版 = 85-100%？

#### 自检 3 · 交叉模式

- [ ] 选定了 3 类交叉模式之一？
- [ ] 交叉点**有铺垫**（不突兀）？
- [ ] 交叉点**有意义**（推主题）？

#### 自检 4 · 视觉对比

- [ ] 4 维视觉对比设计齐全？
- [ ] 读者能"一秒分辨"现在是 A 还是 B？

## 章节级自检（每写一章后）

```
□ 这章是 A 线还是 B 线？（明确）
□ 这章符合 6 段位置吗？（不超前 / 不滞后）
□ 这章的视觉对比与对面线区分明显？
□ 这章是否有暗示 A B 关联？（中后段）
□ 章末钩子与对面线**节奏对位**？
```

## 双线 vs 单线 · 何时选

```
选双线的信号：
  ✅ 故事有"对比 / 平行 / 镜像"主题
  ✅ 主角设计是"双男主 / 双女主"
  ✅ 故事是"穿越 + 现实"双时空
  ✅ 故事是"侦探 + 凶手"双视角
  ✅ 故事是"前世今生"对比

选单线的信号：
  ❌ 只有 1 个核心主角
  ❌ 速食爽文（追求节奏不要复杂）
  ❌ 短篇（不够空间展开）
  ❌ 第一人称叙事（视角受限）
```

## 常见错误

```
❌ 两条线毫无关联（读者不知道为什么放一起）
❌ B 线只是 A 线的镜像 / 注脚（不独立）
❌ 机械 A B A B A B 切换（无节奏）
❌ 交叉点突兀（无铺垫 · 突然汇合）
❌ 交叉点无意义（汇合就汇合 · 不推主题）
❌ 4 维差异化只做 1-2 个（视觉混淆）
❌ 6 段结构错位（A 线 50% 时 B 线还在建立）
❌ 双线没有视觉对比（文字写法相同）
❌ 双线高潮重叠（同一章 / 同一段双高潮 · 压垮读者）
❌ 收尾只收一条线（另一条悬空）
```

## 范例 · 一句话激活公式

```
本项目双线设计：

线 A：[主体] [场景] [节奏] [情绪 / 色彩]
线 B：[主体] [场景] [节奏] [情绪 / 色彩]

6 段位置（按 30 章为例）：
  Ch.1-4   段 1 · 上线建立
  Ch.5-9   段 2 · 下线建立 + 对比
  Ch.10-15 段 3 · A 关键节点
  Ch.16-20 段 4 · B 关键节点
  Ch.21-26 段 5 · 交叉点（[合流 / 对比 / 冲突]）
  Ch.27-30 段 6 · 落版（[单线收 / 双线叠加 / 主题揭示]）

视觉对比：
  色调：A [冷] vs B [暖]
  视角：A [一人称] vs B [三人称]
  景别：A [紧] vs B [疏]
  运镜：A [快] vs B [慢]

交叉点设计：
  时间：第 X 章
  地点：[场景]
  事件：[A vs B 的相遇 / 对决 / 同时事件]
  主题揭示：[一句话]
```

把这段填空给 LLM · 双线设计自动产出。
