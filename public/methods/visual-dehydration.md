# 视听语言脱水法 · 镜头化写作（注入到 N3.1 / N3.2）

> 来源：用户上传 prompt「影视剧本"洗稿"专家」的正向化改写。
> 原 prompt 是事后压缩工具；本模块把其规则转为「生成期约束」，让 LLM 在写章节时就按视听语言下笔。

---

## 适用边界（先看清楚再启用）

✅ **推荐启用**：
- 冷硬悬疑 / 短篇科幻 / 都市冷峻 / 高概念无限流
- 项目目标包含「影视改编潜力」「电影感」
- 用户明确想脱离传统网文笔调（少废话 / 节奏快 / 对话推进剧情）

❌ **不要启用**：
- 心流向 / 后宫向 / 治愈日常 / 校园甜宠 / 系统爽文
- 第一人称深度内心戏 / 意识流 / 散文化网文
- 读者期待大段心理独白与细腻情绪铺陈的题材

> 本模块**会主动牺牲心理描写厚度**换取镜头感。误启用会让作品失去网文读者熟悉的「沉浸感」。

---

## 五条生成期硬律（写章节时必须遵守）

### 1. 心理戏只走两条合法通道
- ✅ **可视化外化**：把「他很紧张」改写为「他下意识攥紧手指，指节泛白」
- ✅ **画外音 V.O.**：必要时用 `（V.O.）` 显式标注一段内心独白，每章 ≤ 2 处，每处 ≤ 60 字
- ❌ **禁止**长段第三人称心理上帝视角（"她感到一阵悲伤""他想起多年前……"等无 V.O. 标注的内心戏一概不写）

### 2. 情绪 → 肢体 / 微表情双通道
每个情绪点必须落到至少一个**可被镜头拍到的具体动作或微表情**：

| 情绪 | ❌ 抽象 | ✅ 镜头化 |
|---|---|---|
| 紧张 | 她很紧张 | 她舌尖抵住上颚，呼吸放慢半拍 |
| 愤怒 | 他怒火中烧 | 他喉结上下滚动一次，指节抵在桌沿泛白 |
| 失落 | 她内心崩塌 | 她的肩线塌下去 1 厘米，目光从对方脸上滑到地板 |
| 警觉 | 他突然警觉 | 他停下咀嚼，眼神斜向门口而头未转 |

### 3. 空间动线必须可演
角色之间的位置关系、走动方向、距离变化要明确写出来：
- 「他走过来」→ 不够；改为「他从沙发起身，绕过茶几，在她面前停下三步距离」
- 强调**逼近 / 后撤 / 转身 / 错位**等导演级走位语言

### 4. 环境白描：名词 + 方位 + 一种感官
环境描写用「名词 + 方位词 + 一种主导感官」三要素勾勒，**不堆形容词**：
- ❌ 「这是一个温馨而精致的卫生间」
- ✅ 「米色大理石卫生间，镜前灯暖黄；水龙头滴答声」（视觉 + 听觉各一）

每段环境描写 ≤ 50 字，留白给读者脑补。

### 5. 对话承担 60% 以上的剧情推进
- 章节里**对话量目标 ≥ 总字数 50%**（散文化章节可放宽到 35%）
- 对话不堆寒暄；每句台词必须做下列至少一件事：**推进剧情 / 暴露人物 / 制造冲突 / 埋伏笔**
- 必要时用台词后括注**轻量提示**：`（垂下眼眸）` / `（语速放慢）` / `（指节敲了下桌面）`，单次 ≤ 12 字

## 单段写作模板（可选采用，不强制覆盖原 prompt 输出格式）

当章节的某些场景适合走极致镜头化笔法时，可参考这种段落组织：

```
【场景定位】凌晨 2:47，李远家次卧。
【出场人物】李远、苏晚

[李远坐在床沿，一只手扶着膝盖，另一只手攥着手机屏幕亮着的一角。]
[他没看那条消息，目光停在窗帘缝里漏进的橘色路灯光上。]

苏晚（V.O.）：
——你说要等的那个人，是不是其实一直没出现过？

[他终于把手机翻过来扣在床垫上，发出闷响。]

李远："你今晚不该来。"
（喉结动了一下，没看她）

苏晚："那你为什么开门？"
（停在门框边，没进来）
```

> ⚠ 这只是**可借鉴的段落骨架**，不要让整章变成纯剧本格式 —— 章节产物仍是小说而非剧本。建议每章 1–3 个关键场景采用此密度，其余场景用普通叙事衔接。

## 与其他模块的协同

- 与 **MBTI 五步法**：完全正交。MBTI 决定角色「为什么这样动」，本模块决定「怎样把这个动作拍出来」。
- 与 **七情节奏点**：协同增强。七情节奏点要求每章至少 2 个情绪锚点，本模块负责把每个锚点**落到具体肢体动作**。
- 与 **三幕式 / Save the Cat / 起承转合 / 英雄之旅**：完全正交。结构层管"何时发生什么"，本模块管"发生时镜头怎么拍"。
- 与 **Pixar 22 法则**：协同。Pixar 法则中「show, don't tell」与本模块同源同向。

---

## 反例（这样写不合格）

- ❌ 「她内心五味杂陈，回忆起多年前那个雨夜……」（纯上帝视角心理回溯，无 V.O.）
- ❌ 「房间里的氛围变得十分尴尬」（不可拍的抽象形容）
- ❌ 「他走过来，看着她」（动线 + 情绪双双缺失，等于没写）
- ❌ 整章 80% 是叙述，对话 < 20%（违反对话占比硬律）
