# 9 大爽感类型 × 信息差模型映射 + 2 类虐心拉扯

> **来源**：墨香阁柒爷网文创作课《让观众上瘾的秘密 · 信息差魔术》第三课「第四部分 · 高级应用」。
> **定位**：craft 层 · **爽点分类速查型模块**。爽文 / 短剧 / 网文项目**必启**。
> **核心命题**：所有"爽感"和"虐心"本质都是**特定的信息差碰撞模式**。理解每种爽感的信息结构 = 可逆向工程精准引爆。
> **核心价值**：把模糊的"爽" / "虐"细分为 **9 + 2 = 11 类信息差模型**，每类含触发公式、典型示例、LLM 提示模板。

## 第一部分 · 9 大爽感类型详解

### D1 · 打脸爽（最经典）

```
信息差模型：主角(知真相) vs 反派(不知真相)
碰撞原理：反派基于错误/过时信息嘲讽贬低主角 → 势能积蓄
        → 主角亮真相牌彻底颠覆反派认知 → 势能引爆
关键节奏：反派傲慢度↑ → 观众愤怒度↑ → 主角揭穿 → 爽感强度 = ∫ 愤怒度
```

**典型示例**：
- 反派："你这穷光蛋也敢追我女儿！"
- 主角默不作声任其挑衅 → 第 N 次挑衅时主角揭穿真实身份（神秘世家继承人）
- 反派父亲亲自上门道歉 → 反派傻眼

**LLM 提示模板**：
```
打脸场景生成必含：
- 反派挑衅 ≥ 2 次（势能积蓄）· 每次明确表达"主角无能 / 卑微"
- 反派挑衅必须基于"错误信息"（主角的"真实身份" / "金手指" 反派不知）
- 主角忍耐到反派踩到底线 → 一击揭穿
- 反派当场态度 180 度反转（求饶 / 跪地 / 求加入）
- 字数控制：势能 30% + 揭穿 30% + 反派惨状 40%
```

### D2 · 扮猪吃虎爽（渐进爽）

```
信息差模型：主角(全知) vs 观众(半知) vs 反派(完全不知)
碰撞原理：主角隐藏真实实力 / 反派完全不知 / 观众"知道主角很牛但不知多牛"
        → 观众与主角形成"共谋"关系 · 优越感 + 期待感
        → 欣赏反派如何在无知中一步步走向作死深渊
        → 每次反派挑衅 = 为最终引爆积蓄能量
```

**典型示例**：
- 主角伪装外卖小哥进公司 → 公司员工嘲笑欺凌
- 观众知道主角是首富但不知道主角"打算怎么处理"
- 反派一步步加码挑衅（嘲笑 / 推搡 / 毁掉主角"外卖") 
- 最终主角召开股东会议宣布"我是真老板"→ 反派全部跪地

**LLM 提示模板**：
```
扮猪吃虎场景生成必含：
- 主角伪装设定（明确隐藏什么 · 隐藏多深）
- 早期暗示主角不简单（给观众"半知"信号 · 但主角拒绝展示）
- 反派挑衅至少 3 轮（递进式 · 每轮升级）
- 观众与主角的"共谋感"（OS 透露主角的内心想法）
- 终局揭穿时多角度反派震惊描写
```

### D3 · 逆袭爽（修正命运）

```
信息差模型：过去主角(不知) vs 现在主角(知)
碰撞原理：常见于重生 / 穿越题材 · "未来知识"vs"过去时空"
        → 主角利用先知 · 修正过去无知导致的错误和遗憾
        → 每次成功改变命运 / 救人 / 抓机遇 = "已知" vs "未知"的胜利
        → 观众获得"掌控和修正命运"的巨大满足感
```

**典型示例**：
- 主角重生回 18 岁 · 知道父母会在某事故中遇难
- 主角提前布局 · 改变事件 · 父母得救
- 主角阻止前世背叛者 · 抓住前世错过的机遇

**LLM 提示模板**：
```
逆袭场景生成必含：
- 起始设定：明确"前世遗憾"（≥ 3 件 · 死人 / 错失 / 误信）
- 重生触发：主角获得"未来信息"作为金手指
- 修正机会：每章 1-2 件"前世错事"被改变
- 修正成功 = 信息差胜利的描写（前世失败 vs 现世成功对比）
- 观众情感：从"惋惜"转"释然" → 从"愤怒"转"快意"
```

### D4 · 团宠爽（集体爽）

```
信息差模型：主角团(内部信息共享) vs 外部世界(不知)
碰撞原理：主角被强大无条件支持的角色（家人/师门/朋友）包围
        → 内部共享核心信息："主角是宝贝 · 谁都不能欺负"
        → 外部反派"不知" · 用普通人方式挑衅
        → 反派一挑衅 = 整个"宠爱圈"降维打击
        → 观众感受 = 强大集体无条件保护和认可的安全感 + 幸福感
```

**典型示例**：
- 主角看似柔弱小姑娘 → 实则是某宗门弟子 / 某世家千金 / 某神级大佬养女
- 反派欺凌主角 → 几小时后宗门长老 / 家族继承人 / 神级大佬上门
- 反派全家被株连

**LLM 提示模板**：
```
团宠场景生成必含：
- 主角"靠山"配置（≥ 3 个不同领域的强者 · 全部宠主角）
- 主角"被欺凌"段（让反派出手 · 不能太弱否则没爽点）
- 靠山团逐次出场（一个比一个强 · 阶梯式碾压）
- 反派"被株连"细节（家族 / 公司 / 个人全方位 ruined）
- 观众情感锚点：旁观者震惊 / 反派后悔 / 主角娇羞
```

### D5 · 降维打击爽（智识爽）

```
信息差模型：主角(高维信息) vs 全世界(低维信息)
碰撞原理：主角掌握远超当前世界认知水平的知识或技能
        → 用现代常识碾压古代科技 / 用未来科技碾压现代认知
        → 巨大的认知鸿沟 + 碾压效果 = 智识爽
        → 观众获得"绝对智力优越感"
```

**典型示例**：
- 现代化学家穿越古代 → 肥皂 / 玻璃 / 火药"神术"碾压
- 未来 AI 重生现代 → 区块链 / 量子计算 / 神经网络降维
- 高维生物降临低维 → 三体级碾压

**LLM 提示模板**：
```
降维打击场景生成必含：
- 主角"高维知识"明确化（来自哪个时代 / 维度 / 文明）
- 当地"低维认知"对照展示（让读者对比）
- 主角"随手一用"现代常识 → 当地人 "神迹" 反应
- 多次降维事件累积（不是单次 · 是持续展示）
- 智识优越感渲染：当地权威专家面前主角的从容
```

### D6 · 养成爽（长线爽）

```
信息差模型：现在的状态(信息少) vs 未来的状态(信息多)
碰撞原理：动态变化的过程 · 不追求单次爆发 · 追求长线持续满足
        → 主角从信息匮乏（修仙菜鸟）→ 不断学习探索升级
        → 每次升级 / 学新技能 / 解锁地图 = 信息差填补 + 能力扩张
        → 观众与主角共同成长的"虚拟成就感"
```

**典型示例**：
- 修仙小说从一阶 → 飞升 · 每个境界都解锁新地图 / 新功法
- RPG 风格升级流：每章打怪升级 / 解锁装备
- 经营养成（庄园 / 公司 / 帮派从小到大）

**LLM 提示模板**：
```
养成爽生成必含：
- 起始：主角"信息匮乏"（明确不知什么）
- 升级路径：清晰的等级体系 + 每级解锁内容
- 每章微升级（不一定是境界 · 可以是"学会一招" / "认识一个人"）
- 长线大目标（30 章后达成什么 · 100 章后达成什么）
- 与读者建立"陪伴感"（主角进步 = 读者陪伴的回报）
```

### D7 · 破局爽（烧脑爽）

```
信息差模型：困局/谜题(信息被封锁) vs 主角(信息探索者)
碰撞原理：主角陷入看似无解的困局或复杂阴谋 · 关键信息被反派/环境刻意隐藏
        → 观众和主角一样信息不足 · 焦虑状态
        → 主角通过逻辑推理 / 抽丝剥茧 / 找到隐藏的关键线索
        → 一举打破僵局 / 反败为胜
        → 那种从压抑到释放、豁然开朗的快感 = 智力高峰体验
```

**典型示例**：
- 推理小说凶手揭露
- 谍战剧主角识破阴谋
- 商战逆转：主角识破对手布局后反将一军

**LLM 提示模板**：
```
破局爽生成必含：
- 起始压抑（明确"无解"的困局描述 + 主角焦虑）
- 线索铺设（前期已埋 ≥ 3 条线索 · 主角和观众都没注意到）
- 关键发现（主角灵光一闪 · 串联所有线索）
- 破局过程（一步步反败为胜 · 不能 1 句话搞定）
- 终局豁然开朗（之前压抑情绪释放 · 旁观者震惊）
```

### D8 · 忠犬爽（情感爽）

```
信息差模型：主角(被误解/不知情) vs 忠犬型角色(知晓真相/坚定不移)
碰撞原理：全世界都误解 / 背叛主角 · 总有 1+ 个强大的"忠犬"角色
        → 因掌握不为人知的真相（主角曾救过他）或纯粹信任 → 坚定站在主角这边
        → "全世界不信任" vs "绝对信任"的强烈对比
        → 观众情感慰藉 + 安全感 + 为不离不弃的忠诚而深深动容
```

**典型示例**：
- 大女主被全家误解 · 唯独某哥哥 / 师傅 / 暗恋者无条件相信
- 战神被栽赃 · 当年救过的小兄弟跨越千里来作证
- 主角失忆被陷害 · 失忆前救过的某神秘人挺身而出

**LLM 提示模板**：
```
忠犬爽生成必含：
- 主角被群体误解 / 抛弃 / 背叛的描写（让读者心疼）
- 忠犬角色出场（前期可能是路人 / 配角）
- 忠犬"信任主角"的具体行动（不是嘴上说 · 是行为）
- 忠犬"知道真相"的来源揭露（主角曾救过他 / 帮过他）
- 忠犬牺牲 / 付出的描写（强化情感震撼）
```

### D9 · 集体荣誉爽（民族爽）

```
信息差模型：我方(知真正实力/底牌) vs 敌方(不知/轻视)
碰撞原理：个人爽感的放大版 · 国家 / 民族层面
        → 敌国基于错误信息挑衅、封锁、嘲讽
        → 我方主角 / 团队代表集体 · 关键时刻亮"杀手锏"
        → 一举扭转乾坤、捍卫集体荣誉
        → 点燃集体归属感 + 民族自豪感
        → 比个人爽感更宏大、更强烈的情感共鸣
```

**典型示例**：
- 大国博弈：他国封锁芯片 → 我国突然亮出自研芯片 → 反封锁
- 国际比赛：被裁判压制 → 主角逆转夺冠 → 国旗升起
- 异世界：地球文明被低估 → 主角带来人类智慧逆袭

**LLM 提示模板**：
```
集体荣誉爽生成必含：
- 集体被轻视 / 封锁的描写（具体场景 · 不要抽象的"被欺负"）
- 主角作为集体代表（个人 vs 个人，但代表了一个集体）
- 杀手锏 / 黑科技 / 秘密武器揭露（必须有"知识/技术"硬核内核）
- 敌方"震惊 / 后悔"的群体反应（不是单个反派）
- 集体象征性场景（升旗 / 国歌 / 旗帜 / 庆祝）
```

## 第二部分 · 2 类情绪拉扯（虐心 + 大悲大喜）

### E1 · 误会与错过（虐心）

```
信息差模型：观众(全知) vs 主角 A(不知 B 真相) vs 主角 B(不知 A 真相)
碰撞原理：观众知道全部真相（A 是为了保护 B 才假装冷漠）
        → 但 A 和 B 彼此都不知道对方的真实想法
        → 他们说的每一句伤人的话 · 在自己看来是"事实"
        → 但在观众听来 · 都因这层信息差变成"刺向自己的刀子"
```

**经典台词放大**：
- 女主含泪："你根本没有爱过我！"（女主的"不知"）
- 男主忍痛冷漠："是 · 我从来没爱过。"（男主隐藏的"真相"）
- → 观众内心知道男主深爱女主 · 这两句台词在"全知"观众心中**瞬间引爆巨大虐心感**

**LLM 提示模板**：
```
误会虐心场景生成必含：
- 观众明确知道双方真心（OS / 闪回 / 旁白透露）
- 双方主角彼此误会（基于错误信息 · 每次对话都是误读）
- 关键虐心台词（双方各 1 句 · 形成"刀子互刺"）
- 字数控制：核心 2 句台词 + 100-200 字情绪描写
- 不要让任何一方"突然懂了"（持续误会 · 加大虐心）
```

### E2 · 真相大白（先虐后爽 · 大悲大喜）

```
信息差模型：之前 → 观众(知) vs 主角(不知) vs 反派(知)
          之后 → 主角(知) = 观众(知) = 真相揭露
碰撞原理：背负巨大误会的主角 · 终于通过关键台词或信物得知全部真相
        → 长期存在的"信息壁垒"瞬间被击碎
        → 之前所有委屈、痛苦、不解 → 找到出口
        → 形成最强烈的情感宣泄
```

**经典台词模板**：
- 奄奄一息的配角拿出信物："当年…是我骗了你 · 他为了救你…才…"
- 这句台词 = 钥匙 · 瞬间打开尘封的信息黑箱
- 主角的震惊 / 悔恨 / 痛苦 + 观众"终于真相大白"的释然
- 交织在一起 · 推情绪到最高潮

**LLM 提示模板**：
```
真相大白场景生成必含：
- 前期累积（≥ 30% 篇幅是"主角误解"的虐心铺垫）
- 关键揭露载体（信物 / 遗言 / 闪回 / 关键证人）
- 揭露瞬间（≤ 200 字 · 不能展开 · 速度快）
- 主角崩溃描写（震惊 → 悔恨 → 痛苦 → 释然 / 决心）
- 观众情绪共振（之前所有"虐"在此刻一次性宣泄）
```

## 爽感组合策略 · 复合爽点设计

### 高频组合（实战推荐）

| 组合 | 适用题材 | 效果 |
|---|---|---|
| **D1 + D4**（打脸 + 团宠）| 都市爽文 / 大女主 | 个人爽 + 集体爽双重 |
| **D2 + D5**（扮猪吃虎 + 降维打击）| 重生 / 穿越 | 期待 + 智识双引爆 |
| **D3 + D8**（逆袭 + 忠犬）| 重生言情 | 修正命运 + 情感慰藉 |
| **D7 + D9**（破局 + 集体荣誉）| 国家叙事 / 主旋律 | 智力 + 民族自豪 |
| **E1 + E2**（误会 + 真相大白）| 言情虐文 | 极致虐心 → 大悲大喜 |

### 一章爽点密度

- 短篇（< 5000 字）：1 个核心爽点 · 完整描写
- 中篇（5000-10000）：1-2 个爽点 · 主次明确
- 长篇章节：1 个主爽点 + 2-3 个微爽点（递进引爆）
- 短剧 / 动漫：每段 1 个爽点 · 高频轰炸

## 注入指引（fili-web 内部用）

- `novel.2.1` 分卷规划：每卷主线选定主爽感类型（卷高潮 = 该类爽感引爆）
- `novel.2.2` 单卷分章：每章选定爽感子类型 + 信息差模型
- `novel.3.1` 章节草稿：按选定爽感类型生成 + 显式标注
- `novel.3.2` 章节润色：检查爽感是否到位 / 是否选错类型

## 检验清单（dogfood 时人工抽检）

- [ ] 项目主爽感类型**清晰**（不是 9 种混杂）
- [ ] 每章**至少 1 个爽点**且**类型明确**
- [ ] 爽点引爆前**势能积蓄充分**（反派挑衅 / 困局压抑 / 群体误解）
- [ ] 爽点引爆后**反派 / 困局 / 误解者反应到位**（震惊 / 跪求 / 后悔）
- [ ] 长篇必含**长线爽点**（D6 养成 + D3 逆袭 + 信物伏笔）

## 范例 · 9 大爽感一句话激活公式

```
D1 打脸：     反派依据[错误信息]挑衅主角 → 主角揭穿[真相牌]碾压
D2 扮猪吃虎： 主角隐藏[真实力] · 反派多次挑衅 · 观众与主角共谋 · 终局揭穿
D3 逆袭：     主角重生回过去 → 利用[未来知识]修正[前世遗憾]
D4 团宠：     主角拥有[强大靠山团] → 反派挑衅 → 靠山团降维打击
D5 降维打击： 主角持[高维知识] → 用常识碾压低维科技 / 认知
D6 养成：     主角从[菜鸟] → 长线升级解锁[新地图 / 新技能]
D7 破局：     主角陷[无解困局] → 抽丝剥茧找到[隐藏线索] → 反败为胜
D8 忠犬：     主角被群体[误解 / 背叛] → 唯有[忠犬]知真相坚定支持
D9 集体荣誉： 我方被敌方[轻视封锁] → 主角代表集体亮[杀手锏]逆转

E1 误会虐心： 观众知双方真心 · 双方互不知 · 关键台词刀子互刺
E2 真相大白： 长期误解 → 关键载体（信物 / 遗言）瞬间击碎信息壁垒
```

把对应公式填空给 LLM · 爽感骨架自动出来。
