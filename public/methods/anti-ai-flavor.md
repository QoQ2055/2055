# 祛 AI 味 · 人类叙事黄金法则

> **来源**：用户上传《祛 AI 味 · 人类叙事黄金法则》。
> **定位**：craft 工艺层 · **章节生成期的反 AI 文风硬律**。与 `visual-dehydration`（镜头化/减法）互为**加减两路**，可共存互补。
> **核心主张**：AI 生成的文本最致命问题是**"太正确"**——每句都完整、每段都推进、每个情绪都干净、每个词都精确。**人类写作需要毛刺**。

---

## 适用边界

✅ **推荐启用**（AI 味是通用问题，几乎所有小说都该启用）：
- 网文 / 长篇小说 / 短篇
- 严肃文学（文笔要求最高）
- 言情 / 古风 / 悬疑等各类题材
- 特别推荐：**AI 一次性生成 ≥ 3000 字的章节草稿**

⚠ **谨慎启用**：
- 剧本格式作品（剧本本身就是精确体裁，加毛刺会破坏格式）
- 以"精确说明"为功能的科普文 / 技术说明

❌ **不要启用**：
- 诗 / 散文（这类文体的"毛刺"规则完全不同，不能套用本模块）

## 一、AI 文本的 9 大特征（先认清问题）

| # | AI 特征 | 人类版 | 问题等级 |
|:-:|---|---|:-:|
| 1 | 每个句子都承载信息/推进剧情 | 会有废话、过渡、赘余 | ★★★ |
| 2 | 句式结构规整（主谓宾完整） | 短句、破句、省略句、倒装 | ★★★ |
| 3 | 情绪线干净利落（不反复） | 情绪会矛盾、会犹豫 | ★★ |
| 4 | 词汇精确（不用模糊词） | 用"大概""好像""有点" | ★★ |
| 5 | 对话每个角色都字正腔圆 | 有语气词、结巴、吞字 | ★★★ |
| 6 | 思维链完整，前后逻辑严密 | 有断点、跳跃、不连贯 | ★★★ |
| 7 | 感官描写标准化（见/听/闻） | 有与叙事无关的无意识感官 | ★★ |
| 8 | 叙述距离稳定锁定 | 自然拉近拉远，偶尔抽离 | ★★ |
| 9 | 文化引用来自训练语料（通用感） | 使用地域性 / 时代性特定梗 | ★★ |

## 二、八大反 AI 技法

### 2.1 句式破壁（最重要的技法，★★★）

**问题**：AI 每句话都结构完整、语义都在推进。

**三法**：

#### A · 断句法

```
AI 版：   他在黑暗中摸索着墙壁，试图找到电灯开关。
人类版： 他在黑暗中摸索着墙壁。
          开关。
          就在指尖前面。
```

#### B · 插入打断

```
AI 版：   她看着窗外下了一整夜的雨，想着昨天发生的事情。
人类版： 她看着窗外的雨。
          下了一整夜了。
          等等——那只猫怎么还在外面？
          猫是昨天想到的。
```

#### C · 语法缺口

- 故意省略主语：「不想去。很冷。算了。」
- 故意用不完整句：「车窗。雨刷。雨水模糊的街灯。」
- 故意重复：「他坐在那里坐了很久。很久很久。」

**硬律**：**连续 ≥ 3 句完整主谓宾 = 必须打断**。每千字至少 3–5 处断句。

---

### 2.2 对话真实化（★★★）

**问题**：AI 对话里每个人都像在宣读剧本。

#### A · 加语气粒子

```
AI 版：  "你确定要这么做？这是一个危险的计划。"
人类版："你确定？这……啧，太冒险了。"
```

#### B · 对话中的空白

- 不说话比说话更多信息
- 「嗯」「唔」「……」比完整句子真实
- **叉开话题**（人类真实对话的特征）

#### C · 信息不对称

```
AI 对话：
"你昨天见到老黄了吗？"
"见到了，他已经把文件签了。"
"那就好。"
"嗯。"

人类对话：
"老黄的东西弄完了？"
"签了，不过——你说他是不是故意的？拖了那么久，偏偏昨天……"
"他那人就那样。算了，签了就行。"
"也是。诶对了你吃饭没？"
```

**硬律**：每段对话至少 **1 处语气粒子 / 空白 / 跑题**。

---

### 2.3 无意义细节 · 黄金调味料（★★）

AI 只写"推进剧情"的细节。人类会写与主线无关但让世界鲜活的细节。

```
AI 版：
他走进办公室，桌上放着一份文件。

人类版：
他走进办公室。
桌上放着一份文件。
角落里那盆绿萝的叶子耷拉下来——上次浇水是什么时候来着？好像是周一？
他把文件翻开。
```

**三种无意义细节**：
1. **感官漂移**：突然注意到与叙事无关的气味 / 温度 / 触感
2. **回忆碎片**：看到某物触发一个短暂的无关回忆
3. **内心吐槽**：角色对当前场景的情绪反应（"这椅子真不舒服"）

**硬律**：每千字 **2–3 个**无意义细节。过多会失去节奏，过少则失去"真人感"。

---

### 2.4 模糊语言与不确定性（★★）

**问题**：AI 什么都确定。人类什么都不确定。

**对照表**：

| AI 用词 | 人类用词 |
|---|---|
| 他决定 | 他大概觉得 |
| 这是 | 这像是 |
| 一定是 | 可能是 |
| 完全 | 还算 |
| 绝对 | 基本上 |
| 三个选择 | 要么这样要么那样 |
| 他开始思考 | 他也不知道自己在想什么 |

**关键洞察**：**叙述者不需要全知**。尤其是限制视角下，主角不知道的事就是"可能""好像""说不清"。

**硬律**：每千字至少 **4–6 处**模糊语言；全章**禁用** "决定"/"意识到"/"感到" 这三个词作为心理动词（必改为"大概觉得"/"好像"/"有点")。

---

### 2.5 情绪不一致 · 情绪回旋法（★★）

**问题**：AI 情绪线是 A→B→C 单向；人类情绪是 A→B→A'→B→C 反复。

```
AI 版：
她感到非常失望，决定不再和他说话。

人类版：
她感到非常失望。
不想和他说话了。真不说了。
走到门口的时候想，算了，给他一次机会。
打开门又想，凭什么？
最后摔门走了。
```

**硬律**：每场**重要冲突戏**至少 **1 次情绪回旋**（至少一个"又想" / "算了" / "不对" 的反复）。

---

### 2.6 叙述距离的呼吸（★★）

AI 倾向锁定一个距离叙事，要么全在人物内心，要么全程上帝视角。

**四档距离**：
- **近**：身体感受 / 第一人称心理
- **中**：第三人称限知视角
- **远**：客观环境 / 时间流逝
- **视角漂移**：跳到配角内心（偶尔使用）

**示例**：
```
他的手指在扳机上微微颤抖。（近——身体感受）

雨一直下。三个小时了。（中——客观环境）

老杨躲在墙后面，正在想自己的女儿。（远——视角漂移到配角）

他不知道自己能不能扣下扳机。（回近）
```

**节奏公式**：**近 → 远 → 近 → 中 → 远 → 近**（保持变化）

**硬律**：每章至少 **3–4 次**叙述距离切换。

---

### 2.7 避开 AI 高频句式（★★★ · 全章禁用）

以下句式是 AI 的标志性语言，**全章禁用**：

- ❌ 「这不仅仅是一个……更是一个……」
- ❌ 「在……的同时，也……」
- ❌ 「从……角度来看……」
- ❌ 「无论……还是……」
- ❌ 「如果说……那么……」
- ❌ 「与其……不如……」
- ❌ 「不但……而且……」
- ❌ 「随着……的……」
- ❌ 「在这一刻，他意识到……」
- ❌ 「他深吸一口气，说……」

**替换策略**：把上述句式**全部打碎成 2–3 个短句**。

```
AI 版：   在这一刻，他意识到，这不仅仅是一场战斗，更是一次救赎。
人类版： 这不是战斗。
          或者说，不止是战斗。
          他知道这一次是为了什么。
```

---

### 2.8 地域性与时代性细节（★★）

AI 的知识来自语料库，输出都带"通用感"。

**破法**：加入无法被训练数据预测的**细微差异**。
- 用**特定本地菜名**（"葱烧海参"）而非通用描述（"一道海鲜菜"）
- 用**特定年份的时代特征**（"那台搪瓷缸子"）而非泛泛的"那个年代"
- 用**角色的特定习惯**（"他总爱把烟灰弹进左手掌心"）而非通用行为

**硬律**：每章至少 **1–2 个**地域性 / 时代性 / 角色专属的独有细节。

## 三、技法使用频率速查表

| 技法 | 每千字使用频率 | 等级 |
|---|:-:|---|
| 断句法（句式破壁） | **3–5 次** | ★★★ 最重要 |
| 对话真实化（语气粒子） | 每段对话至少 1 处 | ★★★ |
| 无意义细节 | **2–3 个** | ★★ |
| 模糊语言 | **4–6 处** | ★★ |
| 情绪回旋 | 每场重要冲突 **1 次** | ★★ |
| 叙述距离变化 | 每章 **3–4 次** | ★★ |
| 避开 AI 句式 | **全章禁用** 10 种高频句式 | ★★★ |
| 地域细节 | 每章 **1–2 个** | ★★ |

## 四、快速自检清单（章节生成后检查）

写完一段 / 一章后，LLM 需自问：

1. ☐ 有没有**连续 ≥ 3 句完整主谓宾**？→ 有则打断
2. ☐ 对话中每个人是否说话都"正确"？→ 是则加语气词 / 空白 / 跑题
3. ☐ 每段是否都在推进剧情？→ 是则插入 1 个无意义细节
4. ☐ 情绪线是否太干净？→ 是则加一次反复 / 矛盾
5. ☐ 是否出现 **10 条 AI 高频句式**？→ 必须打碎
6. ☐ 叙述距离是否一直不变？→ 是则做一次拉远或拉近
7. ☐ 是否用了太多「他意识到」「她感到」「他决定」？→ 改为"大概""好像""说不清"

**硬律**：以上 7 条**任一不合格 → 强制重写对应段落**。

## 五、与其他模块协同

### 与 `visual-dehydration`（镜头化/减法）——**加减两路组合**

| 维度 | `visual-dehydration` | `anti-ai-flavor`（本模块） |
|---|---|---|
| 路线 | 减法（削心理戏，强化镜头） | 加法（加毛刺，强化人味） |
| 适合 | 冷峻 / 影视感 / 硬科幻 | 通用 / 生活化 / 口语感 |
| 风格效果 | 严峻、利落、像剧本 | 真实、絮叨、像日记 |

**共存规则**：
- ✅ **轻度共存**（推荐）：visual-dehydration 管镜头化感官（视觉描写脱水）+ anti-ai-flavor 管句式节奏（人类语感）。两者作用层不同，可互补。
- ⚠ **重度冲突**（注意）：若某章 visual 强调"对话推进剧情"，而 anti-ai 强调"对话跑题 + 空白"，LLM 会不知所措。此时建议**某章只启用一个**。
- ❌ **不建议组合**的场景：纪实 / 正传 / 精确论证类段落——两者都不适合。

### 与结构骨架（所有 structure 类）——正交

本模块只管文笔层，与任何结构骨架无冲突。

### 与 `seven-emotion-peaks`——协同

七情管**章节级情绪锚点**（高层结构），本模块的"情绪回旋法"管**句段级情绪毛刺**（低层细节），两者互补。

### 与 `plot-coherence-scaffold`——协同

伏笔追踪层面，本模块的"无意义细节"可以**偶尔被后续章节回响为伏笔**（绿萝没浇水 → 主人公生活失序的象征）。

### 与 `pixar-22-rules`——协同

Pixar 第 11 条（把一切写出来再改）+ 第 16 条（每个场景都该推进角色或揭示人物）与本模块互不冲突：前者管**写法流程**，本模块管**每段毛刺**。

---

## 六、总结：AI 味的本质是「正确」，人味的本质是「毛刺」

一个章节生成后，**感觉"太干净"就必须反加毛刺**。没有毛刺的文字不是文学，是说明书。
