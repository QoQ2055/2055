# 期待四循环法 · 事件填充公式 + 6 维度螺旋升级

> **来源**：墨香阁柒爷网文创作课《预期管理的魔法》第四课「第三部分 · 期待四循环 · 事件制造公式」+「循环升级机制」。
> **定位**：craft 层 · **事件级填充工具型模块**（与 expectation-tug-method 主线-事件双层协同）。
> **核心命题**：单个事件的设计公式 = 建立预期 → 放大预期 → 超越预期 → 完成预期。**关键防错**：每次循环必须在 6 个维度任一升级 · 防止"原地踏步"。
> **核心价值**：把"凭感觉写场景"升级为"按公式填充"+"按 6 维度自检"。

---

## 适用边界

✅ **强推荐启用**：
- 都市爽文 / 玄幻升级 / 系统流 / 重生流（**升级 6 维度黄金资产**）
- 言情甜宠 / 大女主
- 短剧 / 动态漫
- 武侠 / 仙侠

⚠ **可选启用**：
- 严肃文学（部分采用 · 弱化机械性）
- 慢热成长（4 循环节奏更慢 · 多章 1 循环）

❌ **不要启用**：
- 散文式 / 意识流（破坏文学品味）
- 实验性反类型作品

## 与 dream-pacing-cycle 的关系

**两者是同事件级 · 不同视角**（互补不冲突 · 推荐双启用）：

| 维度 | dream-pacing-cycle | 期待四循环（本模块）|
|---|---|---|
| 视角 | 读者**情绪**曲线（憋 / 爽）| 创作者**预期管理**逻辑（画饼 / 满足）|
| 4 段 | 压力 / 引燃 / 爆发 / 展示发酵 | 建立 / 放大 / 超越 / 完成 |
| 黄金比例 | 25-30 / 5-10 / 30-35 / 30-40 | 灵活 |
| 重点 | 情绪强度最大化 | 预期满足度 + 升级机制 |
| 适用 | 爽文 / 短剧（强情绪型）| 通用更广 |

→ **同时启用 = 双重检查**：
- 用 dream-pacing 设计情绪曲线
- 用 expectation-cycle 检查预期是否管理到位

## 第一部分 · 期待四循环（事件公式）

### 循环 1 · 建立预期（画个小饼）

**操作**：给事件设定**明确、具体、有吸引力**的目标。让观众产生"想看下文"的期待。

**关键**：
- 目标必须**具体**（不是"主角去做什么" · 是"主角必须在 N 时间内完成 X 任务"）
- 目标必须**有吸引力**（与主角期望指针强相关）
- 时限 / 条件 / 障碍**明确化**

**示例**：
```
弱：男主决定救女主。
强：男主必须在天亮前 3 小时内 · 单枪匹马 · 不报警 · 救出被绑架的女主。
```

**LLM 注入**：
```
事件起手段必含：
- 目标动词（救人 / 揭穿 / 获得 / 阻止）
- 时限（具体时间 / 条件触发）
- 条件约束（不能 X / 必须 Y）
- 主角动机（为什么必须做这事）
```

### 循环 2 · 放大预期（把饼画大、画香）

**操作**：增加赌注 · 让观众觉得"这个目标太重要了 · 必须成功！"扩大已建立的期待。

**关键**：
- 失败后果**致命化**
- 阻力**升级**（外部 + 内部）
- 时间压力**强化**

**示例**：
```
基础（循环 1）：救人
放大（循环 2）：
- 绑匪要钱 + 私仇 + 天亮前撕票
- 警察把男主当嫌疑人正在追捕
- 男主受伤 + 没有装备 + 没有支援
- 女主即将被毒杀（如果不快）
```

**LLM 注入**：
```
循环 2 段强制增加 ≥ 2 项压力维度：
- 外部威胁加码（敌人变强 / 数量增多 / 立场变更）
- 内部约束加码（主角受伤 / 时间紧 / 资源缺）
- 间接压力加码（家人受牵连 / 第三方威胁）
- 时间压力加码（倒计时 / 无法回头）
```

### 循环 3 · 超越预期（不仅吃饼 · 还多给鸡腿）

**操作**：**一波三折** · 最后结果**比所有人想得还要好**！

**关键**：
- 主角**接近失败**（让观众绝望）
- **关键转折**（之前埋的伏笔 / 不起眼细节）
- 结果**超出预期**（不只完成原目标 · 还额外达成）

**示例**：
```
基础预期：救出女主
超越预期：
- 男主被打得半死 → 即将失败
- 利用之前镜头扫过的"松动消防栓"极限反杀
- 不仅救出女主 · 还在女主面前展现智慧 + 勇气
- 女主对男主刮目相看 → 额外达成"心动事件"
```

**关键技巧**：
- **伏笔回收**：之前章节埋的不起眼细节（道具 / 台词 / 人物）成为转折点
- **超额奖励**：原目标 + 1 个意外收获
- **关系升级**：通过事件改变了某个角色对主角的看法

**LLM 注入**：
```
循环 3 段必含：
- 主角接近失败的描写（让观众心提到嗓子）
- 关键转折点（伏笔回收 / 灵光一闪 / 助力出现）
- 超额奖励（原目标 + 1 个额外成就）
- 转折要"合理但意外"（埋过的伏笔 · 不能凭空降）
```

### 循环 4 · 完成预期（品尝胜利）

**操作**：留出时间 · 让主角和观众一起享受胜利的喜悦 · 自然过渡到下一事件。

**关键**：
- 给观众**回味时间**（不能匆匆收场）
- **关系状态**确认变化（主角 ↔ 其他角色）
- 自然抛出**下一事件钩子**

**示例**：
```
事件结束：男主为受伤的女主包扎伤口
紧张过后：气氛变得暧昧
关系变化：女主第一次崇拜地看着男主
状态确认：靠近事件成功 · 期望指针 +50
钩子：远处出现新威胁 / 暗中观察的对手
```

**LLM 注入**：
```
循环 4 段必含：
- 主角"享受胜利"的描写（≥ 半段）
- 与关键角色（伙伴 / 爱人 / 对手）的关系变化确认
- 主线推进的明确标注（哪个指针移动了多少）
- 下一事件钩子（不能闭合 · 要开启新循环）
```

## 第二部分 · 循环升级 6 维度（防原地踏步）★

### 核心问题：为什么打完小怪后不能继续打小怪？

**人性规律**：
- 第 1 次打脸 → 爽
- 第 2 次同样难度 → 一般
- 第 3 次还是同样 → 厌烦
- 第 4 次 → 弃书

**解决**：每次循环结束 · 必须在 **6 个维度任一升级** · 让"游戏"难度和复杂度提升。

### 6 维度详解

#### 维度 1 · 压力升级

**含义**：事情变得更棘手 · 挑战难度更大。

**示例**：
- 上次：街头混混
- 这次：有组织的黑帮头目
- 进阶：黑帮老大 + 警局内鬼联手

**LLM 强制**：每个新循环对手 ≥ 上次对手等级。

#### 维度 2 · 主线升级

**含义**：完成此事件后 · 主角离终极目标更近一步。

**示例**：
- 终极目标：为父报仇
- 上次循环：打败仇家小喽啰
- 这次循环：打败得力干将 → 获得大 BOSS 藏身处线索

**LLM 强制**：每事件后主角对终极目标"知道更多" / "更接近"。

#### 维度 3 · 资源升级

**含义**：主角获得更多金钱 / 装备 / 物品。

**示例**：
- 上次：100 两银子
- 这次：接管反派全部产业 → 月入万金
- 装备：破铁剑 → 削铁如泥宝剑

**LLM 强制**：循环结束主角资产 / 装备 / 资源**可见提升**。

#### 维度 4 · 技能升级

**含义**：主角学会更厉害的武功 / 魔法 / 技能。

**示例**：
- 战斗中临阵突破 · 领悟新剑法
- 任务后获得失传武功秘籍
- 特训中突破境界

**LLM 强制**：每 3-5 个循环至少 1 次技能突破。

#### 维度 5 · 身份升级

**含义**：主角的社会地位 / 名望 / 职位提升。

**示例**：
- 上次：无名小卒
- 这次：被皇帝封大内侍卫
- 下次：因护驾有功封将军

**LLM 强制**：身份变化 = 长线累积 · 每 5-10 个循环 1 次重大身份变化。

#### 维度 6 · 人脉升级

**含义**：结识更重要人物 / 获得更强盟友 / 收服更有用的手下。

**示例**：
- 结识当朝宰相之子并成朋友
- 收服被打败的对手为忠犬部下
- 救助路人后发现是隐藏大佬

**LLM 强制**：每事件后主角"人脉网"扩大 ≥ 1 人。

### 6 维度自检清单

每个事件设计完成时强制问：

```
✓ 压力维度：本次比上次难度高吗？
✓ 主线维度：本次让主角离终极目标更近了吗？
✓ 资源维度：主角获得了什么新资源？
✓ 技能维度：主角学会了什么新技能？（不要求每次都有）
✓ 身份维度：主角的地位 / 名望提升了吗？（不要求每次都有）
✓ 人脉维度：主角结识了什么新人脉？

至少 2 个维度 ✓ → 通过
0-1 个维度 ✓ → 重写（原地踏步风险）
```

**LLM 注入**：
```
事件设计后强制 6 维度自检：
- 列出本事件升级的维度（≥ 2 个）
- 标注升级前 vs 升级后的具体描写
- 与上一个循环对比 · 不能完全重复
```

## 第三部分 · 螺旋上升 vs 原地转圈

```
原地转圈（差作品）：
   ┌─────┐
   │ 打怪 │ → 同等级怪 → 同等级怪 → 同等级怪 ...
   └─────┘
   观众情绪：兴奋 → 平淡 → 厌烦 → 弃书

螺旋上升（好作品）：
        ╱ 大 BOSS（多维度全升级）
       ╱
      ╱  精英怪（4 维度升级）
     ╱
    ╱   小队长（3 维度升级）
   ╱
  ╱    小怪（2 维度升级）
 ╱
起点
   观众情绪：兴奋 → 期待 → 沉浸 → 上瘾
```

→ **螺旋 = 期待四循环 + 6 维度升级**

## 第四部分 · 从宏观到微观的创作流程

```
[Step 1] 用 expectation-tug-method 设计主线蓝图
            ↓
         确定需要：
         - N 个靠近事件
         - N 个远离事件
         - 1 个归零事件
         - 1 个新平衡事件
            ↓
[Step 2] 对每个事件用 expectation-cycle-method（本模块）填充
            ↓
         循环 4 步：建立 → 放大 → 超越 → 完成
            ↓
[Step 3] 对照 6 维度自检升级
            ↓
         通过 → 写下章
         不通过 → 重写本事件
            ↓
[Step 4] 用 information-asymmetry-method + 9-pleasure-types
         在每个循环节点引爆情绪
```

→ **完整工程学创作流程**：图纸 + 公式 + 升级路径 · 既保主线清晰 · 又保每环节精彩。

## 检验清单（dogfood 时人工抽检）

- [ ] 每个事件包含**完整 4 循环**（不缺循环 4 完成段）
- [ ] **超越预期**段含伏笔回收（不是凭空转折）
- [ ] **6 维度自检** ≥ 2 个维度升级
- [ ] 不与上一个循环**完全重复**（题材 / 对手 / 难度任一不同）
- [ ] **建立预期**段目标具体（不是模糊"主角要做什么"）
- [ ] **完成预期**段含下一事件钩子（不能闭合）

## 范例 · 一句话激活公式

```
事件开始 · 主角必须 [具体目标 + 时限 + 约束]（建立预期）
随后 [危险加码 + 时间紧迫 + 阻力升级]（放大预期）
主角接近失败 · 但通过 [伏笔回收 / 助力出现] 极限反杀
不仅完成 [原目标] · 还额外达成 [意外收获]（超越预期）
最后 [享受胜利 + 关系确认 + 状态变化] · 抛出 [下一事件钩子]（完成预期）

★ 6 维度升级 ≥ 2 项（压力 / 主线 / 资源 / 技能 / 身份 / 人脉）
```

把这段填空给 LLM · 单事件骨架自动出来。
