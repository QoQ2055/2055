# 情绪驱动法（Emotion-Driven · 逆向工程 · 先定果后推因）

> **来源**：墨香阁柒爷网文创作课《故事三驱动》第九课。
> **定位**：driver 层 · **故事引擎选择型模块**（与 character-driven / event-driven 互斥 · 一个项目同时只选一种主驱动）。
> **核心价值**：当主线故事的看点是**极致刺激 + 多巴胺 + 情绪宣泄**而非"人物深度"或"逻辑严谨"时，启用本模块让 LLM 像**产品经理一样**精准计算用户情绪 High 点，**为爽点让路一切**。

---

## 适用边界

✅ **强推荐启用**：
- 付费短剧（霸总 / 战神 / 假千金型）
- 网文爽文（赘婿 / 系统流 / 重生 / 穿越爽文）
- 新媒体连载（微信读书 / 番茄 / 七猫主流爆款）
- 抖音 / 快手短剧脚本

⚠ **可选启用**（次优）：
- 言情甜宠（爽点比逻辑重要）
- 部分都市职场（如果主打"打脸 / 装逼 / 升级"）
- 玄幻修真（金手指流）

❌ **不要启用**（错配）：
- 严肃文学 / 长篇正剧（应选 character-driven）
- 悬疑推理（应选 event-driven）
- 慢热成长向（应选 character-driven）
- 硬科幻（应选 event-driven）

---

## 核心心法

### 第一原则 · 一切为了"那一哆嗦"

你要像**产品经理一样**，精准计算用户的情绪 High 点。为了这个 High 点，**其他的都可以让路**：
- 逻辑可以让路（"为什么首富会去送外卖？" → 不重要 · 反正读者就是爽）
- 人物深度可以让路（反派降智一点也没关系 · 只要打脸到位）
- 现实主义可以让路（霸总每月赚 100 亿 · 不重要 · 满足白日梦）

### 第二原则 · 逆向工程

**起手式：先定果，后推因**。不要管逻辑严不严谨，先想"**这一章我要让观众产生什么情绪**"，下一章这个情绪我能不能接住，不让情绪断裂。

```
高 ▲     爽 ╲
   │       ╲     爽
   │         ╲   ╱╲
情 │       憋  ╲ ╱  ╲
绪 │         ╲ ╱    ╲      爽
   │     憋   ╳      ╲    ╱
   │       ╲ ╱╲       ╲  ╱
低 │ 憋     ╳   ╲       ╳
   └────────────────────────→ 时间
   ↑      ↑  ↑   ↑    ↑    ↑
   起手   羞辱  反击  打脸  升级
```

每个**爽点**之前必有**憋点**。情绪是**反复拉扯**的过程。

### 第三原则 · 高密度爽点

**短剧 / 爽文的标准节奏**：每 1000-2000 字必须有 1 个情绪节点（憋 / 爽 / 反转 / 钩子）。

→ LLM 生成时**强制按字数统计 emit 情绪节点**。

## 三步实操（LLM 提示词指引）

### 步骤 1 · 定靶心（核心情绪来源）

明确这个故事的**核心情绪驱动力**是什么：

| 核心情绪 | 触发场景 | 典型作品 |
|---|---|---|
| **复仇 / 打脸** | 被羞辱后强势反击 | 战神归来 / 都市赘婿 |
| **打怪升级** | 弱者变强 / 升级带来快感 | 玄幻修真爽文 |
| **金手指碾压** | 主角拥有外挂能力，秒杀普通人 | 系统流 / 重生流 |
| **强强配对** | 平起平坐的爱情对抗 | 霸总言情 |
| **白月光逆转** | 被错认 / 误会后真相反转 | 假千金 / 失忆梗 |
| **苦难逆袭** | 极致虐 → 极致爽 | 农村翻身 / 寒门崛起 |
| **超展开** | 完全意料之外的剧情 | 平行宇宙 / 时间循环 |

→ **每个故事只选 1 个主情绪 + 1 个副情绪** · 避免散点。

### 步骤 2 · 造事件（为爽点设计因果）

为了达到核心"爽" · 必须**反推需要什么样的事件**：

```
果（爽）：主角装逼成功
↑
因（憋）：主角必须先被一群势利眼羞辱
↑
背景（设局）：主角隐瞒真实身份 · 假装穷光蛋
```

**关键设计**：
- **憋点 → 爽点 时间间隔 ≤ 5000 字**（不能拖太久 · 否则读者弃书）
- **爽点强度 > 憋点强度**（不能 1:1 · 必须爽 > 憋）
- **每个爽点开启下一个憋点**（情绪不能断 · 防止读者弃书）

### 步骤 3 · 高密度产出（情绪节奏强制）

LLM 生成每章必须显式标记**情绪节点**：

```
第 N 章草稿
├─ 第 1 段（开头钩子）：憋点（轻度）
├─ 第 2-3 段（铺垫）：累积憋点
├─ 第 4-5 段（高潮）：爽点（重度）
├─ 第 6 段（回味）：满足感
└─ 第 7 段（钩子）：下一章憋点的引子
```

每章字数：1500-3500（短剧）/ 2000-5000（短篇爽文）。

→ LLM 生成时**显式标注每段的情绪类型**，最后整合自检。

## 检验清单（dogfood 时人工抽检）

- [ ] 第 1 章必须包含**1 个完整爽点**（首章不留客 → 直接弃）
- [ ] 每 2000 字至少 1 个**情绪节点**（憋 / 爽 / 反转 / 钩子任一）
- [ ] 单章结尾必须有**钩子或反转**（cliffhanger · 不能平淡结束）
- [ ] 主角"金手指"必须**全章可见**（不能藏到中后期才用）
- [ ] 反派的存在让爽点**更爽**（反派强但被打 = 爽 · 反派弱无意义）
- [ ] 爽点"那一哆嗦"必须**慢镜头化**（用 200-500 字详细描写打脸瞬间）

## 范例 · 一句话激活公式

```
{ 主角 } 是一个 { 隐藏身份 / 重生 / 系统加持 }，
他被 { 反派 / 现实 } { 羞辱 / 困境 / 误解 }，
此时主角的 { 金手指 / 真实身份 / 系统 } 突然发动，
让 { 反派 } 在 { 公开场合 } 被 { 打脸 / 反转 / 碾压 }，
并由此 { 升级 / 获得新资源 / 推进新目标 }。
```

把这段填空给 LLM · 爽点骨架自动出来。

## 与"信息差 / 预期管理 / 节奏控制"3 大理论的关系

情绪驱动法 = "**信息差服务于打脸**（主角隐藏 → 反派疯狂 → 揭穿）+ **预期管理就是憋 / 爽循环**（吊起来 → 爽下去）+ **节奏控制就是高密度爽点**（每 2000 字 1 个）"。

```
情绪驱动 = 信息差 × 预期管理 × 节奏控制 的情绪坐标系
```

→ 选了情绪驱动 = 三大理论自动从"情绪视角"展开。

## 警告 · 滑坡风险

情绪驱动法**最容易写崩**的两个失败模式：

1. **逻辑全无**（"为什么首富要去送外卖" → 读者出戏 · 弃书）
   - 缓解：保留 10% 的合理性桥段（比如"为了体验生活" / "调查公司内贼"）
2. **情绪麻木**（一直爽 → 不爽 / 一直虐 → 弃书）
   - 缓解：必须保持憋 / 爽**反复**循环 · 不能单边

→ **dogfood 时必须人工抽 5-10 章**对照"情绪密度 + 逻辑底线"。
