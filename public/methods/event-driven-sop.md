# 事件驱动 SOP · 6 步工业化生产流程 + 倒推法

> **来源**：墨香阁柒爷网文创作课《事件篇 · 实战技巧》第八课「落地流程 · 事件驱动的故事设计 SOP + 微观填充倒推法」。
> **定位**：driver 层 · **元流程整合型模块**（事件驱动专属 SOP · 与 character-810-blueprint / 6 个 method modules 强协同）。
> **核心命题**：事件驱动从来不是"等灵感"的艺术创作 · 是一门**严谨的、有流程的科学**。从 0 到 1 的工业化生产流水线 · 6 步搞定。
> **核心价值**：(1) 6 步 SOP 流程图；(2) 10 序列 → 8 要素**倒推法**（人物驱动反向）；(3) 各步骤交付物清单 · 立项 → 成品全流程可复制。

---

## 适用边界

✅ **强推荐启用**：
- 任何**事件驱动**项目立项时
- 想要稳定输出 / 可复制成功的工业化作者
- 团队协作（多人写同一项目需要标准化流程）
- 复杂题材（悬疑 / 权谋 / 喜剧 / 世界观）

⚠ **可选启用**：
- 人物驱动项目（部分流程通用 · 但倒推方向相反）

❌ **不要启用**：
- 凭灵感 / 手工作坊式创作（流程会束缚）

---

## 核心心法 · 从产品倒推生产

```
事件驱动的故事设计 = 从"产品"倒推"生产"的逆向工程

不从"我想写什么"开始
而从"我想让观众体验到什么"开始
```

## Step 1 · 产品定型 · 我要做的是什么车？

### 核心问题

**我的故事 · 想让观众"爽" / "烧脑" / "爆笑"还是其它？**

### 三大核心模块决策

| 体验 | 推荐模块 |
|---|---|
| **猜不透 + 细思极恐**（悬疑感）| `mystery-design-method` |
| **运筹帷幄 + 步步为营**（智力优越感）| `power-strategy-method` |
| **荒诞反差 + 啼笑皆非**（解压感）| `comedy-design-method` |
| 史诗感（宏大叙事）| `worldview-design-method` |

### 交付物

**一句清晰的产品定位宣言（一句话故事）**：
> "我要做一个关于追寻杀手破案的警察故事。"

→ 不要超过一行。能用一行说完的故事 · 才是好故事。

## Step 2 · 原型选择 · 这辆车用什么发动机？

### 核心问题

根据"产品定位" · 从 **10 个故事原型** 中选最匹配的基础框架。

### 选型决策表

| 定位 | 候选原型 |
|---|---|
| 悬疑 | 鬼屋型 / 侦探型 / 被制度化型 |
| 权谋 | 愚者成功型 / 被制度化型 |
| 喜剧 | 如愿以偿型 / 伙伴之情型 / 愚者成功型 |
| 成长 | 金羊毛型 / 变迁仪式型 |
| 爽文 | 超级英雄型 / 家伙遇到麻烦型 |

→ 详见 `ten-story-archetypes-pack`。

### 交付物

明确的故事原型 · 并写出其**核心三要素**。

#### 示例（承接上一步）

```
我选择侦探型原型。
核心三要素：
  零件 1：必须知道真相的人 = 一个偏执的侦探
  零件 2：足够吸引人的秘密 = 一个离奇的密室杀人
  零件 3：为了真相的牺牲 = 一次惨痛的代价
```

## Step 3 · 宏观搭建 · 设计大纲（10 序列）

### 核心方法

使用 **10 序列** · 将"原型三要素"转化为 10 个具体事件坑位。

### 10 序列模板（详见 character-810-blueprint）

```
开场建置（1-2）：
  序列 1：开场 · 主角日常 + 核心缺陷
  序列 2：建置 · 铺垫"原型核心冲突"

中段（3-8）：
  序列 3：激励 · "原型核心威胁"浮出水面
  序列 4：进展 · 主角初步反抗
  序列 5：转折 · 中点转折（被动→主动）
  序列 6：再转 · 游戏升级
  序列 7：危机 · 虚假胜利后陷入绝望
  序列 8：导入 · 必须独自面对的时刻

结局（9-10）：
  序列 9：高潮 · 终极对决
  序列 10：结局 · 新日常（呼应序列 1）
```

### 关键提示

> ⚠ 此时**还不知道主角叫什么长什么样** · 只用"主角"这个代号。

→ 这是事件驱动 vs 人物驱动的最大区别：**先定剧情坑 · 再找主角**。

### 交付物

**一份不含具体人名的"10 序列事件大纲"**。

#### 示例（侦探型）

```
序列 3 激励：发生一起密室杀人案 · 死者是市长的儿子。
序列 5 转折：主角发现凶手指向自己的导师 · 心态转变。
序列 7 危机：主角被陷害 · 面临开除 + 牢狱之灾。
序列 9 高潮：主角揭露真相 · 但需要付出至亲的代价。
```

## Step 4 · 角色倒推 · 定制主角（8 要素）★ 事件驱动核心方法

### 核心原理

```
剧情的痛点 · 就是人物的卖点
每一个序列都在大喊："我需要一个能演好这场戏的人！"
```

→ 把 10 序列分成三个阶段 · 分别**倒推**人物的起点、弱点和终点。

### 倒推法 3 阶段

#### 阶段 1 · 用结局/高潮（序列 9）倒推问题/负价值观

**剧情需求**：序列 9 高潮 · 主角"为了保护别人而牺牲 / 拼命"。

**倒推逻辑**：
```
如果主角一开始就是大英雄 · 那他最后拼命是应该的 · 不感人
谁来演最感人？
  → 一个自私、胆小、甚至有点猥琐的小人物
当这样一个烂人最后选择做英雄时 · 观众才会哭
```

**人物定型（填入 8 要素）**：
- **问题**：胆小怕事 · 没有担当
- **负价值观**："天塌下来有高个子顶着 · 我只要自己活着就行"

---

#### 阶段 2 · 用激励/开场（序列 1-3）倒推身份/欲望

**剧情需求**：序列 3 激励 · "商场爆发丧尸 · 主角被困"。

##### 身份倒推

谁会天天混在商场里 · 而且是个不起眼的小人物？

```
选项 A：逛街的富二代？
  → ❌ 不行 · 太有资源 · 容易逃跑

选项 B：商场保安或保洁员
  → ✅ 决定：商场保安
     - 对地形最熟（方便后面利用地形）
     - 但地位最低 · 平时受尽白眼（符合小人物设定）
```

##### 欲望倒推

灾难发生时 · 他为什么不自己躲起来 · 非要折腾？

```
决定：他的女儿也被困在商场另一头
  → 救女儿
  → 这是一个原始的、本能的、不可遏制的欲望
```

---

#### 阶段 3 · 用转折/危机（序列 5-7）倒推阻碍/动作

**剧情需求**：序列 7 危机 · "被人背叛 · 推向尸群"。

##### 阻碍倒推（反派）

谁最容易背叛这个保安主角？

```
决定：商场的经理（平时就欺负主角的精英）
  → 代表"极度的利己主义"
```

##### 动作倒推

主角前期靠什么生存？

```
他是保安 · 有点身手 · 但胆子小
所以他的动作是：躲避、带路、听经理的话
正是因为他还在用"听话/顺从"这个旧动作
  → 才导致危急时刻被经理出卖
  → 这证明了旧动作的失败
```

---

### 8 要素完整成型

通过 3 阶段倒推 · 一个**有血有肉、完全适配故事**的主角诞生：

```
身份：混日子的商场保安 · 平时唯唯诺诺
欲望：在尸潮中找到并救出自己的女儿
问题：胆小 · 习惯性顺从权威（经理）
阻碍：外部 = 丧尸 + 经理的背叛 / 内部 = 自己的恐惧
动作：前期靠躲藏和依附；后期觉醒 · 利用保安技能反杀
负价值观："听老板的话才有饭吃 · 别强出头"
正价值观："为了守护爱的人 · 烂泥也能变成墙"
结果：牺牲自己（或重伤）· 救出女儿 · 成为真正的父亲
```

### 交付物

**一份完整的"主角 8 要素小传"**。

### 倒推法 vs 正推法

| 方法 | 起点 | 终点 | 适用 |
|---|---|---|---|
| **正推法**（人物驱动）| 4 维灵魂 / 8 要素 | 10 序列 | character-driven |
| **倒推法**（事件驱动）| 10 序列 | 8 要素 | event-driven |

→ 详见 `character-810-blueprint`（正推法）+ 本模块（倒推法）。

### 倒推法的核心爽点

```
我们没有凭空捏造 · 只是回答了剧情提出的几个问题
一个活生生、有血有肉、完全适配故事的主角就诞生了

→ 这样设计出来的人物 · 天生就是为这个故事而生
→ 每一个设定（比如保安身份）在故事里都有大用（熟悉地形）
→ 绝对没有废笔
```

## Step 5 · 模块填充 · 优化你的故事

### 核心方法

将 Step 1 选择的"核心设计模块"（悬疑 / 权谋 / 喜剧）· **填充进 10 序列的每一个具体事件中**。

→ 这就是"精装修"环节。

### 模块填充表

| 项目类型 | 调用模块 | 操作 |
|---|---|---|
| 悬疑 | `mystery-design-method` | 用"可能性树" + "多线交互"为每序列设计假象和反转 |
| 权谋 | `power-strategy-method` | 用"资源棋盘" + "破局/布局"让主角在每序列进行资源博弈 |
| 喜剧 | `comedy-design-method` | 用"三番升级" + "角色/设定游戏"把每序列变成笑料包袱 |
| 世界观 | `worldview-design-method` | 用"事件嫁接" + "身份绑定"让主角与世界深度融合 |

### 交付物

**一份带细节的、精修版的分集 / 分场细纲**。

#### 示例（悬疑版）

```
序列 4 进展：
  剧情：主角根据线索 A · 推断凶手是死者的情人。
  模块填充：
    但我们（观众）知道 · 线索 A 是真凶故意留下的假象。
    （信息差铺垫 + 撞墙回头法预备）
```

## Step 6 · 剪辑执行 · 拧紧螺丝 · 喷上漆

### 核心方法

在动笔写正文时 · 使用 **`fast-narrative-method`** 的剪辑技巧 · 处理每一个场景的节奏。

### 剪辑师思维

拿着"精修细纲" · 开始写正文。同时用"剪辑师"的思维审视每一段文字：

#### 无戏部分（过场 / 背景 / 重复）

**毫不留情地使用**：
- **跳剪**（过场）：删过程 · 给结果
- **倒叙**（背景）：结果前置 · 原因后置
- **蒙太奇**（重复）：短句串联 · 画意象

#### 有戏部分（冲突 / 转折 / 高潮）

**慢下来 · 展开写**：
- 用动作、台词、画面技巧（详见 `character-skin-design`）
- 进行精雕细刻

### 交付物

**最终的成品剧本 / 小说**。它应该是**紧凑、有力、全程高能**的。

## 本节课结语（讲师原话）

> 事件驱动的故事设计 · 从来都不是"等灵感"的艺术创作 · 它是一门严谨的、有流程的科学。
>
> 这套 SOP · 就是把一个模糊的"想法" · 转化为一个可销售的"商业产品"的完整流水线：
>
> 1. **定产品**：你想让观众体验什么？
> 2. **选原型**：用哪种经典发动机？
> 3. **搭骨架**：用 10 序列画出蓝图。
> 4. **配角色**：用倒推法找到最合适的演员。
> 5. **精装修**：用悬疑/权谋/喜剧模块填充细节。
> 6. **快剪辑**：用快速叙事技巧打磨成品。
>
> 掌握了这套流程 · 你就不再是一个凭感觉写作的"手工作坊主" · 而是一个能稳定输出、可复制成功的"故事总工程师"。
>
