# Vlog 式纪实叙事 · 第一人称沉浸节奏

> **来源**：Jaygo Creativity v28 概念提取（视频分镜模板 4"Vlog 纪录"抽象为通用第一人称纪实叙事方法论）。
> **定位**：structure 层 · **第一人称纪实节奏模板**（与 kishotenketsu / heros-journey / save-the-cat 等大结构互补 · 但聚焦"日常 / Vlog 式 / 沉浸代入"题材）。
> **核心命题**：fili-web 现有结构 modules 大多是"全知视角"或"剧情驱动"。**第一人称 Vlog 式纪实**（都市 / 校园 / 职场 / 美食 / 治愈）的节奏方法论是空白。本模块提供 4 段 Vlog 节奏 + 5 类沉浸技巧 + 即时性写作要点。
> **核心价值**：(1) 4 段 Vlog 节奏（开场 / 日常 / 转折 / 收尾）；(2) 5 类沉浸技巧（即时感 / 旁白感 / 镜头感 / 烟火感 / 留白感）；(3) 与传统结构的对接方式。

## 适用边界

✅ **强推荐启用**：
- 都市日常（上班 / 通勤 / 下班）
- 校园生活（宿舍 / 食堂 / 课堂）
- 美食流（探店 / 做菜 / 美食散文）
- 治愈系（猫狗 / 田园 / 慢生活）
- 职场流（互联网 / 金融 / 创业）
- 旅行 / 旅游 / 探索类
- 第一人称回忆 / 自传体小说
- 短篇 / 单元剧

⚠ **可选启用**：
- 言情（部分章节用 Vlog 式 · 增日常感）
- 校园言情（适合）

❌ **不要启用**：
- 玄幻 / 仙侠 / 武侠（节奏不匹配）
- 末世 / 末日（紧张感冲突）
- 悬疑 / 推理（需要全知线索）
- 群像戏（多视角不适合 Vlog 式）

## 核心心法 · Vlog ≠ 流水账

### 痛点

```
新手写日常 / Vlog 式常犯错误：
  Bug 1：纯流水账（早上起床 → 上班 → 下班 → 睡觉）· 0 看点
  Bug 2：堆生活细节但**没情感线**（像菜谱）
  Bug 3：第一人称内心戏 0（只描写外景）
  Bug 4：每章一个"完整事件"（不像 Vlog · 像周记）
  Bug 5：没有镜头感（直白叙事 · 不像"拍下来"）

→ 这些 bug 让日常文枯燥
→ 读者 3 章弃书
→ 都市 / 校园流核心爽点丢失
```

### 解决方案 · 4 段节奏 + 5 类沉浸

```
真正的 Vlog 式 = 即时记录 + 情感锚点 + 镜头感

→ 即时感让"读者就在身边"
→ 情感锚点让"日常有意义"
→ 镜头感让"文字有画面"
```

## 一 · 4 段 Vlog 节奏 ★ 章节版

### 段 1 · 开场（章节开篇 · 0-15%）

```
任务：
  ├─ 立时间 / 地点
  ├─ 立今日心情（一句话）
  └─ 立今日"主线事件"（一件事）

写法：
  ├─ 时间锚点（"周三早上 7:30")
  ├─ 地点锚点（"出租屋 · 阳台")
  ├─ 心情锚点（"昨晚没睡好 / 今天有点期待")
  └─ 一件事（"今天要去见三年没见的高中同学")

字数：100-300 字
镜头：远景（环境）→ 特写（主角自己）
```

#### 实战示例

```
✅ 开场示范：
  周三早上 7:32。
  我盯着镜子里的自己 · 顶着两个黑眼圈。
  昨晚追剧到凌晨 2 点 · 现在后悔得要死。
  
  但今天必须有精神 ——
  下班要去见三年没见的高中同学。
  
  → 时间 7:32 + 地点 镜子前 + 心情 后悔 + 事件 见同学
```

---

### 段 2 · 日常（章节早中段 · 15-50%）

```
任务：
  ├─ 写今日日常 3-5 个小片段
  ├─ 每片段 1-2 个看点（非流水账）
  └─ 渗透情感（不直接说 · 用细节）

写法：
  ├─ 片段 1：早餐 / 通勤（看点：路上偶遇 / 偶发事件）
  ├─ 片段 2：工作 / 上课（看点：人物互动 / 矛盾）
  ├─ 片段 3：午餐 / 课间（看点：闲聊 / 感悟）
  ├─ 片段 4：下午 / 课后（看点：意外 / 期待）
  └─ 片段 5：下班 / 放学（看点：回家路 / 准备）

字数：800-1500 字
镜头：交替（中景 ↔ 特写）
```

---

### 段 3 · 转折（章节后段 · 50-80%）★ 关键

```
任务：
  ├─ 今日"主线事件"发生
  ├─ 与日常形成对比（情绪起伏）
  └─ 让今日"有意义"

3 类转折：
  ├─ 类型 A · 意外（突发事件 · 改变心情）
  ├─ 类型 B · 重逢（见到某人 · 回忆涌现）
  └─ 类型 C · 决定（做出选择 · 影响未来）

字数：600-1200 字
镜头：长慢镜（重要时刻拉慢）
```

#### 实战示例

```
✅ 转折段（重逢）：
  晚上 7:00。
  约定的咖啡店。
  
  我推门进去 · 抬头就看到了她。
  
  ——三年了。
  她还是老样子 · 头发齐肩 · 戴着银色耳钉。
  唯一不同的是 · 她笑起来时眼角有了细纹。
  
  「好久不见。」她站起来。
  我喉咙突然发紧 · 「好久不见。」
  
  → 与今日早上的疲惫形成对比
  → 重逢 = 转折点
```

---

### 段 4 · 收尾（章节末段 · 80-100%）

```
任务：
  ├─ 今日总结（一段独白 / 一个画面）
  ├─ 留余韵（情绪 · 不一定是事件）
  └─ 钩子或预告（明天 / 下周）

3 类收尾：
  ├─ 类型 A · 一段独白（"今天好像不一样了")
  ├─ 类型 B · 一个画面（看月亮 / 日出 / 雨停)
  └─ 类型 C · 一句话钩子（"明天 · 我决定要去找他")

字数：200-500 字
镜头：特写（情绪）→ 远景（拉远）
```

## 4 段速查矩阵

| 段 | 章节位置 | 字数 | 镜头 | 关键词 |
|:---:|:---:|:---:|:---:|---|
| 1 开场 | 0-15% | 100-300 | 远 → 特 | 时间 · 地点 · 心情 · 事件 |
| 2 日常 | 15-50% | 800-1500 | 交替 | 3-5 片段 · 看点 · 情感渗透 |
| 3 转折 | 50-80% | 600-1200 | 慢镜 | 主线事件 · 情绪起伏 |
| 4 收尾 | 80-100% | 200-500 | 特 → 远 | 总结 · 余韵 · 钩子 |

→ 总字数 1700-3500 / 章

## 二 · 5 类沉浸技巧 ★ 文笔层

### 技 1 · 即时感

```
让读者觉得"主角现在就在做这件事"

3 个写法：
  ├─ 现在时（"我推开门"·  不是"我推开了门")
  ├─ 时间锚点（"7:32"· 不是"早上")
  └─ 即兴感（"突然想到"· 不是"想到的是")
```

#### 对比

```
❌ 笼统：
  早上她起床 · 吃了早餐 · 然后去上班。

✅ 即时：
  7:30 · 闹钟响。
  我想再睡 5 分钟 · 但已经按了 3 次贪睡。
  起床 · 刷牙 · 把昨天买的牛奶加热到 50 度。
  喝完最后一口 · 看时间 · 7:48。
  完了 · 又要打车了。
```

### 技 2 · 旁白感

```
第一人称内心戏 · 像主角对自己说话

3 个写法：
  ├─ 自我吐槽（"我真是个废物")
  ├─ 反问（"为什么我每次都这样？")
  └─ 感叹（"哦 · 原来是这样")
```

### 技 3 · 镜头感

```
让文字像"被拍下来"

3 个写法：
  ├─ 视角切换（远 → 近 / 上 → 下）
  ├─ 慢镜头（关键瞬间拉慢）
  └─ 框选（"特写：她的手在颤抖")
```

### 技 4 · 烟火感

```
日常细节 · 让世界"活"

3 个写法：
  ├─ 五感描写（咖啡的苦 / 雨打窗 / 体温 / 香水）
  ├─ 路人侧写（旁边小孩 / 老大爷 / 卖花姑娘）
  └─ 城市声音（汽车 / 鸟叫 / 远处广场舞）
```

### 技 5 · 留白感

```
不写满 · 给读者想象空间

3 个写法：
  ├─ 省略号（"我..." )
  ├─ 跳过（"接下来发生的事 · 我不想说")
  └─ 画面定格（"她笑了。我也笑了。")
```

## 三 · 与传统结构的对接

```
Vlog 式 ≠ 抛弃大结构

每天的 Vlog 章可以是 kishotenketsu / heros-journey 的一段
```

### 对接方式 1 · Vlog 章 + 主线大结构

```
全书结构：heros-journey 12 阶段（主线）
单章风格：Vlog 式（每章 1 天）

例：
  阶段 1 平凡世界：5 章 Vlog（5 天日常）
  阶段 2 召唤：1 章 Vlog（出现意外事件）
  阶段 3 拒绝召唤：2 章 Vlog（犹豫）
  阶段 4 跨越：1 章 Vlog（决定）
  ...

→ Vlog 章只是节奏 · 不脱离主线
```

### 对接方式 2 · 全 Vlog 式 + 隐性主线

```
全书结构：100 章 = 100 天 Vlog
隐性主线：从某个起点 → 某个终点

例：
  Day 1：搬到新城市
  Day 5：认识同事
  Day 30：第一次失恋
  Day 60：重新出发
  Day 100：找到自己
```

### 对接方式 3 · Vlog 章 + 短篇 / 单元剧

```
每 3-5 章 = 一个完整故事
全书 = N 个故事集

例：
  Ch.1-3：偶遇咖啡店老板
  Ch.4-6：参加同学聚会
  Ch.7-9：暴雨之夜
  Ch.10-12：搬家
  ...
```

## 章节级自检（写完 Vlog 章后）

```
□ 4 段齐全（不是流水账）？
□ 5 类沉浸 ≥ 3 类？
□ 转折段有"今日意义"？
□ 收尾段有钩子？
□ 不只是外描写 · 有内心戏？
□ 这章在主线哪里（不脱离）？
```

## 常见错误

```
❌ 流水账（早 → 中 → 晚 · 0 看点）
❌ 0 内心戏（只外景描写 · 像剧本）
❌ 4 段缺段（直接日常 → 收尾 · 无转折）
❌ 5 类沉浸只用 1 类（节奏单一）
❌ 主线无对接（每章独立 · 全书无走向）
❌ 烟火感堆砌（路人 / 五感全堆 · 喧宾夺主）
❌ 即时感与时态混乱（一会现在时 · 一会过去时）
❌ 旁白感过度（全篇内心戏 · 缺动作 / 对话）
❌ 留白感过度（重要情节也留白 · 读者一头雾水）
❌ 第一人称 ≠ Vlog 式（视角错配）
```

## 范例 · 一句话激活公式

```
本章 Vlog 式设计：

时间 / 地点：[今日 X 时 X 分 / 地点]
今日心情：[一句话]
今日主线事件：[一件事]

4 段分配（按 2500 字章为例）：
  Sec 1 开场：300 字  远 → 特  时间 + 地点 + 心情 + 事件
  Sec 2 日常：1200 字 交替    [3-5 个片段]
  Sec 3 转折：800 字  慢镜    [意外 / 重逢 / 决定]
  Sec 4 收尾：200 字  特 → 远 [独白 / 画面 / 钩子]

5 类沉浸（用 ≥ 3 类）：
  □ 即时感：[现在时 / 时间锚点]
  □ 旁白感：[内心戏 / 自我吐槽]
  □ 镜头感：[视角切换 / 慢镜]
  □ 烟火感：[五感 / 路人 / 声音]
  □ 留白感：[省略号 / 跳过 / 定格]

主线对接：
  □ 这章在大结构哪里？[阶段 X / 第 N 天]
  □ 这章推动主线如何？[一句话]
```

把这段填空给 LLM · Vlog 章自动产出。
