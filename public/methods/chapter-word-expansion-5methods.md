# 章节字数扩充 5 法 · 正向补字工具书

> **来源**：网文审核官 v5.0 概念提取（重写为通用方法论 · 不是水文是有效扩充）。
> **定位**：craft 层 · **正向字数管理型模块**（与 visual-dehydration "去水"反向 · 形成"减字 + 补字" 完整字数管理）。
> **核心命题**：fili-web 现有 `visual-dehydration` 是**减字**（去水）· **缺主动补字工具**。本模块给出 5 种**有效扩充法**（不是水文）· 让 LLM 写不够字数时有正向工具 · 让用户人工补字时有清晰公式。
> **核心价值**：(1) 字数不足 5 大原因诊断；(2) 5 大有效扩充法（每法增字数 + 效果）；(3) 有效 vs 无效水文对照表；(4) 平台字数标准对接。

---

## 适用边界

✅ **强推荐启用**：
- 网文连载（每章字数下限）
- 投稿前发现章节不达标
- LLM 生成偏短时主动补字
- 中长篇所有项目

⚠ **可选启用**：
- 短篇 / 散文（字数自由）

❌ **不要启用**：
- 极简风 / 实验文学（字越少越好）
- 微小说 / 闪小说（强制短）

## 核心心法 · 扩充 ≠ 水文

### 痛点

```
新手作者最常见错误：
  字数不够 → 加形容词堆砌
  → "他非常非常非常的愤怒"
  → 字数上去了 · 质量下去了
  → 读者跳读 / 弃书

→ 这是"水文" · 不是扩充
→ 平台审核会标记"注水"
→ 完读率断崖
```

### 解决方案 · 5 法 + 有效 vs 无效

```
有效扩充 = 加"具体细节" / "情感锚点" / "节奏服务" / "场景服务"
无效水文 = 加"形容词堆砌" / "无意义感叹" / "信息重复" / "凑字数"

→ 同样是 +500 字
→ 有效扩充让读者更沉浸
→ 无效水文让读者更想跳读
```

## 一 · 字数不足 · 5 大原因诊断

```
扩字之前 · 先诊断为什么字数不够：
```

| 原因 | 诊断信号 | 修复方向 |
|---|---|---|
| **全是对话** | 几乎没有描写 | 加 5 法中的"动作细节"+"心理深化" |
| **AI 残留** | 像大纲不像正文 / 段落空洞 | 加 5 法中的"五感描写"+"场景丰富" |
| **赶稿压缩** | 流水账感强 / 节奏快但浅 | 加 5 法中的"对话潜台词"+"心理深化" |
| **删改过度** | 修改记录显示只减不增 | 全部 5 法选用 |
| **节奏失调** | 高潮来得突兀 / 过渡缺失 | 加 5 法中的"场景丰富"+"心理深化" |

→ 诊断后再选对应扩充法 · 不要盲目扩。

## 二 · 5 大扩充法 ★ 核心实操

### 法 1 · 五感描写

#### 核心技巧

```
选择 1-2 种与情节相关的感官强化：
  视觉 / 听觉 / 触觉 / 嗅觉 / 味觉
```

#### 增字数

```
+25-30 字 / 处
```

#### 效果

```
画面感强化 · 让读者"看到"场景
```

#### 实战示例

##### ❌ 单层视觉（缺感官）

```
他走进酒馆 · 找了个位置坐下。
（共 13 字）
```

##### ✅ 多感官（加听觉 + 嗅觉）

```
他推门走进酒馆 · 一股混着酒精和烤肉的气味扑面而来。
靠门的桌子有人在大笑 · 笑声夹杂着酒杯碰撞的脆响。
他走到角落最暗的位置坐下 · 木椅吱呀一声塌下去半寸。
（共 78 字 · +65 字）
```

→ 加了听觉（笑声 + 酒杯）+ 嗅觉（酒精 + 烤肉）+ 触觉（椅子塌陷）。

#### 写法注意

```
✅ 与情节相关的感官（紧张戏 → 听觉 / 触觉 / 心跳）
✅ 1-2 种就够（不要 5 感全堆）
❌ 与情节无关的感官（打斗时写"远处花香"）
```

---

### 法 2 · 对话潜台词

#### 核心技巧

```
3 种对话深化：
  ├─ 动作打断：对话中插入动作（手 / 眼 / 表情）
  ├─ 话里有话：表面说 A · 暗指 B
  └─ 沉默力量：用沉默代替回答
```

#### 增字数

```
+20-25 字 / 处
```

#### 效果

```
对话深度增强 · 角色立体
```

#### 实战示例

##### ❌ 干巴对话（信息流）

```
"你为什么这么做？"
"我有我的理由。"
"什么理由？"
"你不会懂的。"
（共 22 字 · 4 句对话）
```

##### ✅ 加动作打断 + 话里有话 + 沉默

```
"你为什么这么做？" 林深盯着他 · 手指在桌面慢慢敲。

老张端起酒杯 · 喝了半口才答："我有我的理由。"

林深的手指停了。

"什么理由？"

老张沉默 · 久到林深以为他不会回答了。
然后他笑了一下："你不会懂的。"
他眼神没看林深 · 看着杯中酒。
（共 102 字 · +80 字）
```

→ 同样 4 句对话 · 加了动作（敲桌 / 喝酒 / 看酒）+ 沉默 + 心理。

---

### 法 3 · 动作细节

#### 核心技巧

```
具体部位 + 具体动作 + 质感描述
  ❌ "他打了对方一拳"
  ✅ "他右手攥紧 · 关节发白 · 一拳擂在对方下巴 · 听到牙齿碰撞的脆响"
```

#### 增字数

```
+20-25 字 / 处
```

#### 效果

```
真实感增强 · 战斗 / 关键动作有重量感
```

#### 实战示例

##### ❌ 笼统动作

```
他冲过去 · 一刀劈下。
（共 9 字）
```

##### ✅ 部位 + 动作 + 质感

```
他左脚一蹬 · 身体前倾飞扑过去。
右手反握刀柄 · 刀尖朝天 · 借着惯性从上往下劈。
刀刃斩开空气的瞬间 · 发出尖锐的呼啸。
（共 60 字 · +51 字）
```

→ 写了脚（蹬）+ 身（飞扑）+ 手（反握）+ 刀（朝天 + 劈）+ 听觉（呼啸）。

---

### 法 4 · 心理深化

#### 核心技巧

```
3 种心理写法：
  ├─ 身体反应：心跳 / 呼吸 / 出汗 / 颤抖
  ├─ 思维噪音：脑中冒出无关画面 / 杂念
  └─ 时间错觉：1 秒被拉成 1 分钟 / 飞快流逝
```

#### 增字数

```
+20 字 / 处
```

#### 效果

```
情绪张力强化 · 读者代入主角
```

#### 实战示例

##### ❌ 简单告知情绪

```
他很紧张。
（共 4 字）
```

##### ✅ 身体反应 + 思维噪音 + 时间错觉

```
他听见自己的心跳——
不是慢慢加速 · 是直接跳进喉咙里。
脑中突然冒出妈妈早上做的早餐画面 · 鸡蛋还冒着热气。
然后是父亲那句"做事要狠"。
他攥紧拳头 · 等了一秒 ·
那一秒像一年。
（共 86 字 · +82 字）
```

→ 身体（心跳）+ 思维（早餐 / 父亲）+ 时间（一秒像一年）。

---

### 法 5 · 场景丰富

#### 核心技巧

```
3 层场景描写：
  ├─ 物理层：建筑 / 物品 / 空间布局
  ├─ 人文层：路人 / 背景音 / 烟火气
  └─ 情绪层：氛围（紧张 / 压抑 / 喜悦）
```

#### 增字数

```
+35-40 字 / 处
```

#### 效果

```
沉浸感强化 · 让读者"置身其中"
```

#### 实战示例

##### ❌ 单层场景（只物理）

```
他走在街上。
（共 5 字）
```

##### ✅ 物理 + 人文 + 情绪

```
他走在街上 · 路两边是临时搭的彩棚 · 卖糖葫芦和炸串的烟雾混在一起。
[物理层：彩棚 / 糖葫芦 / 炸串]

旁边小孩子追着风车跑 · 风车呼啦呼啦转。
卖艺人的二胡声和一个胖叔的笑骂声同时响着。
[人文层：小孩 / 卖艺 / 胖叔]

但他没看这些 · 他在找那个穿黑衣的女人。
人群越热闹 · 他的心越冷。
[情绪层：人群热闹 vs 主角心冷]

（共 130 字 · +125 字）
```

→ 物理层（彩棚 / 烟雾）+ 人文层（小孩 / 卖艺人 / 胖叔）+ 情绪层（热闹 vs 心冷）。

## 5 大扩充法 · 速查矩阵

| # | 扩充法 | 增字数 | 效果 | 适用场景 |
|:---:|---|:---:|---|---|
| 1 | 五感描写 | +25-30 | 画面感 | 场景切入 / 进入新空间 |
| 2 | 对话潜台词 | +20-25 | 对话深度 | 角色互动 / 关键对话 |
| 3 | 动作细节 | +20-25 | 真实感 | 战斗 / 关键动作 |
| 4 | 心理深化 | +20 | 情绪张力 | 紧张 / 决定 / 高潮前 |
| 5 | 场景丰富 | +35-40 | 沉浸感 | 章节开头 / 重要场景 |

→ **5 法叠加** = 单段最多 +120-140 字。

## 三 · 有效 vs 无效 对照表

| 有效扩充（推荐 ★）| 无效水文（避免 ❌）|
|---|---|
| **具体细节** · 拳头攥紧关节发白 | 形容词堆砌 · 非常的愤怒 |
| **情感锚点** · 想起妈妈早上做的鸡蛋 | 无意义感叹 · "唉" / "啊" / "哎" |
| **节奏服务** · 高潮前心理深化拉张力 | 信息重复 · 同一句话换说法说三遍 |
| **场景服务** · 物理 + 人文 + 情绪三层 | 凑字数 · 描写一棵树写 200 字 |

### 4 大判断标准

```
判断扩充是否"有效"：

□ 删掉这段后 · 读者会不会觉得"少了点什么"？
  → 是 → 有效
  → 否 → 水文

□ 这段是不是和情节相关？
  → 是 → 有效
  → 否 → 水文

□ 这段是不是塑造了人物 / 推动了剧情？
  → 是 → 有效
  → 否 → 可能是水文

□ 读者会不会愿意为这段买单（VIP 章节）？
  → 是 → 有效
  → 否 → 平台会标记注水
```

## 四 · 平台字数标准对接

```
不同平台对单章字数要求不同（参 platform-standards-fq-qd）：

番茄小说：
  ├─ 单章最低 1000 字+
  ├─ 全书 2 万字签约
  └─ 推荐字数：2000-3000 字

起点中文网：
  ├─ 单章最低 2000 字+
  ├─ 全书 10 万字+
  └─ 推荐字数：3000-4000 字

七猫中文网：
  ├─ 单章最低 1500 字+
  ├─ 全书 5 万字+
  └─ 推荐字数：2500-3500 字

→ 字数不达标时启用本模块 5 法
→ 但不要无脑扩到上限（上限是给好内容预留空间）
```

### 字数缺口决策树

```
当前章节字数 vs 目标字数 = 缺口 X 字

X < 200：用 1-2 法（局部扩充）
  → 选场景丰富 / 心理深化 / 动作细节

X = 200-500：用 2-3 法
  → 五感 + 对话潜台词 + 动作细节

X = 500-1000：用 4-5 法
  → 全部 5 法叠加

X > 1000：很可能不是字数问题
  → 检查是否"事件不够" → 加事件而非扩字
```

## 实战检验法

### 写完每章后 · 4 项自检

#### 自检 1 · 字数检查

- [ ] **当前字数**符合平台目标？
- [ ] 缺口**多少字**？

#### 自检 2 · 诊断字数不足原因

- [ ] 是**全对话** / **AI 残留** / **赶稿压缩** / **删改过度** / **节奏失调** 中哪一种？
- [ ] 选定了对应**扩充法**？

#### 自检 3 · 扩充质量

- [ ] 扩充内容**具体**（不是形容词堆砌）？
- [ ] 与**情节相关**（不是无关描写）？
- [ ] 删掉后**有损失感**（不是水文）？

#### 自检 4 · 4 大判断标准

- [ ] 通过"删掉测试"？
- [ ] 通过"情节相关测试"？
- [ ] 通过"塑造 / 推进测试"？
- [ ] 通过"VIP 买单测试"？

## 与 visual-dehydration 的关系

```
本模块（chapter-word-expansion-5methods）：
  → 正向：让段落"更丰满"
  → 用于：字数不足 + 情节单薄

visual-dehydration（已有）：
  → 反向：让段落"更精炼"
  → 用于：字数超标 + 节奏拖沓

→ 二者形成"减字 + 补字"完整字数管理
→ 同一作品不同章节可能需要不同方向

何时减、何时补：
  └─ 节奏紧张段（追逐 / 决战）→ 减字（visual-dehydration）
  └─ 情绪铺垫段（前夜 / 决定）→ 补字（本模块）
  └─ 高潮章 → 该补则补 · 该减则减
```

## 常见错误

```
❌ 字数不够 → 加形容词（"非常非常非常的愤怒"）
❌ 字数不够 → 重复信息（同一句话换说法 3 遍）
❌ 5 法全堆 → 单段 +500 字（变成水文）
❌ 与情节无关的扩充（打斗时写远处花香）
❌ 5 法选错（紧张戏用"场景丰富"30 字 → 节奏崩）
❌ 通过"VIP 买单测试"失败（平台标记注水）
❌ 对话场景不用"对话潜台词"法（错失增 +字 机会）
❌ 战斗场景不用"动作细节"法（错失重量感）
```
