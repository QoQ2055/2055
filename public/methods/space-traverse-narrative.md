# 空间穿越叙事 · 锚点 + 触发器 + 5 段结构

> **来源**：Jaygo Creativity v28 概念提取（视频分镜模板 5"空间穿越"抽象为通用穿越叙事方法论）。
> **定位**：structure 层 · **空间转场专用结构**（适用穿越流 / 重生流 / 异世界 / 系统流 / 末世流的核心场景）。
> **核心命题**：fili-web 现有 `plot-coherence-scaffold`（因果链）/ `pacing-emotional-curve`（节奏）/ `world-building-9-pillars`（世界观）等模块**没有专门的空间叙事方法论**。穿越流 / 重生流 / 异世界 / 系统流 / 无限流的核心场景设计完全依赖经验。本模块提供 5 段结构 + 3 类穿越模式 + 锚点设计 + 首穿 vs 后续节奏控制。
> **核心价值**：(1) 5 段结构（锚定 / 触发 / 过程 / 新空间 / 适应）；(2) 3 类穿越模式（单向 / 双向 / 多空间）；(3) 3 类锚点（视觉 / 知识 / 情感）；(4) 首穿 vs N 穿节奏差异。

---

## 适用边界

✅ **强推荐启用**：
- 穿越流（古穿今 / 今穿古 / 平行世界）
- 重生流（重生回过去 / 重生到他人）
- 异世界（异世大陆 / 修真界 / 末世）
- 系统流（突然觉醒系统 → 新规则世界）
- 无限流（任务世界切换）
- 末世流（突变 → 末世新规则）
- 平行宇宙

⚠ **可选启用**：
- 都市超能（觉醒 = 进入"新世界"）
- 仙侠（突破境界 = 接触新维度）

❌ **不要启用**：
- 现实题材纯都市
- 古言不带穿越元素
- 言情纯现实

## 核心心法 · 穿越 ≠ 换地图

### 痛点

```
新手写穿越常犯错误：
  Bug 1：穿越=换地图（"突然到了古代"）· 0 过渡
  Bug 2：穿越后秒接受新身份 · 不真实
  Bug 3：忘记原世界（无锚点 · 像两本书）
  Bug 4：每次穿越都从头铺垫（节奏崩溃）
  Bug 5：新空间规则与原空间一样 · 失去差异感

→ 这些 bug 让"穿越"沦为"换皮"
→ 穿越流核心爽点丢失
→ 读者跳读穿越段
```

### 解决方案 · 5 段 + 3 类锚点 + 节奏控制

```
真正的空间穿越 = 锚定 + 触发 + 过程 + 新空间 + 适应

→ 锚点维持"原世界存在感"
→ 触发器给"穿越合理性"
→ 过程让读者"代入感"
→ 新空间提供"差异冲击"
→ 适应让"接受过程真实"
```

## 一 · 5 段结构 ★ 必备

### 段 1 · 当前空间锚定

```
任务：
  让读者**深爱**当前空间
  让读者**记住**当前空间细节
  让读者**预感**有事要发生

3 项必含：
  ├─ 视觉锚点：标志物（北京胡同 / 学校大门 / 卧室书桌）
  ├─ 情绪锚点：与人 / 物的羁绊（妈妈 / 朋友 / 宠物）
  └─ 标志物：将来在新空间出现的物件（信物 / 道具）

字数：500-1500 字（视书的体量）
```

#### 实战示例

```
❌ 差示范（无锚定）：
  "陈砚一觉醒来，发现自己穿越到古代。"
  → 读者：你以前是谁？我为什么要关心你？

✅ 好示范（有锚定）：
  陈砚把外卖盒推到一边，盯着电脑屏幕上的辞职信。
  桌角是妈妈寄来的玉佩，刻着"宁"字。
  "明天就交。" 他低声说，伸手去拧灯。
  灯没拧灭。光反而越来越亮。
  
  → 读者：陈砚 / 辞职 / 玉佩 / 妈妈 → 4 个锚点全立
```

---

### 段 2 · 转场触发器

```
任务：
  让"穿越发生"的合理性成立
  
3 类触发器：
  ├─ 道具触发（玉佩 / 戒指 / 镜子 / 古书）
  ├─ 事件触发（车祸 / 落水 / 雷击 / 被刺）
  └─ 系统触发（突然出现的金光 / 提示音 / 老者）

写法：
  ├─ 触发瞬间**写细节**（光 / 音 / 触感）
  ├─ 触发后**主角第一反应**（疑惑 / 痛 / 黑暗）
  └─ 不要瞬间到位（保留 1-2 段过渡）

字数：100-300 字
```

#### 触发器选择决策树

```
你的题材是什么？
  ├─ 言情 / 古言 → 道具触发（信物 / 古玉 · 浪漫）
  ├─ 玄幻 / 修真 → 系统触发（金光 / 老者 · 玄妙）
  ├─ 现代都市 → 事件触发（车祸 / 雷击 · 现实）
  └─ 末世流 → 事件触发（蘑菇云 / 异变 · 突然）
```

---

### 段 3 · 转场过程 · 主角"在路上"

```
任务：
  让读者**代入**穿越体验
  让"过渡感"真实

5 类过渡感（任选 2-3 种）：
  ├─ 视觉错位：花火 / 黑暗 / 旋转 / 加速
  ├─ 听觉错位：巨响 / 死寂 / 时光倒流声
  ├─ 触觉错位：失重 / 撕裂 / 冰冷 / 燃烧
  ├─ 时间错位：1 秒拉成 1 分钟 / 时光高速倒退
  └─ 空间错位：身体被扯 / 灵魂飘 / 视角切换

字数：200-500 字（首穿）/ 50-150 字（后续）
```

#### 实战示例

```
✅ 多感官过渡：
  灯光剧烈跳动，刺眼的白扎进眼睛。
  陈砚下意识捂住脸——手却穿过自己的脸。
  耳边响起类似海浪退潮的声音，越来越响，又突然安静。
  风。
  从未感受过的风。
  他睁开眼。
  
  → 视觉（灯光 / 白光）+ 触觉（手穿过脸）+ 听觉（海浪 / 安静）
  → 自然过渡到新空间
```

---

### 段 4 · 新空间建立

```
任务：
  让新空间与旧空间形成**强对比**
  给读者**视觉冲击**
  立**新空间规则**（暗示 · 不全揭）

3 项必含：
  ├─ 与旧空间的对比（声音 / 气味 / 光线 / 人）
  ├─ 新空间标志物（古宫殿 / 异星 / 修真宗门 / 末世废墟）
  └─ 暗示新规则（地心引力不一样？时间慢？有魔法？）

字数：800-2000 字（首穿章节核心）
```

#### 对比技巧

```
新旧空间 5 维对比：

| 维度 | 旧（现代北京）| 新（架空唐朝）|
|---|---|---|
| 听觉 | 汽车声 / 空调嗡嗡 | 鸡鸣 / 远处铜锣 |
| 嗅觉 | 外卖 / 汽油 | 桂花 / 烟火 |
| 视觉 | 钢铁丛林 | 木檐青砖 |
| 服饰 | T 恤牛仔 | 长衫襦裙 |
| 语言 | 现代普通话 | 古汉语 / 文言 |
```

---

### 段 5 · 适应过程

```
任务：
  让"接受新身份"真实
  让"原世界羁绊"持续
  让"新空间规则"逐步学习

3 类适应：
  ├─ 身份适应：知道自己是谁了（XX 王爷 / 失忆继承人 / 系统宿主）
  ├─ 知识适应：学新规则（语言 / 礼仪 / 修炼 / 系统）
  └─ 情感适应：接受 + 怀念（接受新人 + 怀念原世界 / 妈妈 / 爱人）

时间分配：
  ├─ 首穿：5-15 章充分铺垫
  └─ 后续穿越：1-3 章（已熟练）
```

## 二 · 3 类穿越模式 ★

### 模式 1 · 单向穿越（一去不返）

```
特点：
  ├─ 穿越后回不去
  ├─ 主角必须在新空间扎根
  └─ 原世界变为"记忆 / 锚点"

代表题材：
  ├─ 古穿今 / 今穿古
  ├─ 异世界（搬到异世大陆）
  └─ 重生流（一次性重生）

写法重点：
  ├─ 段 5 适应过程要充分（接受是漫长的）
  ├─ 原世界锚点保留（思念 / 信物 / 习惯）
  └─ 不要让主角完全忘记原世界
```

### 模式 2 · 双向穿越（可往返）

```
特点：
  ├─ 主角能在 A B 两个世界来回
  ├─ A 是日常 · B 是冒险
  └─ 触发器可控（睡觉 / 物品 / 时间点）

代表题材：
  ├─ 双时空穿越（白天上班 + 晚上修仙）
  ├─ 系统流（戴上系统 = 进入新世界）
  └─ 异界商人（带货往返）

写法重点：
  ├─ A B 两边都立得住（双线设定 · 参 dual-line）
  ├─ 时间锚点（A 1 天 = B 1 月 / A B 同步）
  └─ 触发器规则化（不能随意 · 必有触发条件）
```

### 模式 3 · 多空间穿越（无限世界）

```
特点：
  ├─ 主角穿越多个世界
  ├─ 每个世界是一个"任务" / "副本"
  └─ 主世界是"中转站"

代表题材：
  ├─ 无限流（每个任务一个世界）
  ├─ 快穿（每章 / 每卷一个世界）
  └─ 系统副本（系统派任务到不同世界）

写法重点：
  ├─ 主角"主世界"立稳（不能每次都重新立）
  ├─ 每个新世界给"差异感"（不能换皮）
  ├─ 后续穿越**节奏压缩**（首穿 5 段 → 后续 2 段）
  └─ 跨世界主线（伏笔 / 大反派 / 终极目标）
```

## 三 · 3 类锚点 ★ 文笔层

```
锚点 = 让"原世界"在"新世界"中持续存在的钩子
```

### 锚点 1 · 视觉锚点

```
原世界的某个标志物 · 出现在新世界

例：
  ├─ 玉佩（妈妈给的 · 古代有同款）
  ├─ 手机（带不进去 · 但有手机壳）
  └─ 戒指（穿越前买的 · 古代有人也戴）

作用：
  ├─ 让主角随时记起原世界
  ├─ 给读者熟悉感
  └─ 可作伏笔（这玉佩为什么古代也有？）
```

### 锚点 2 · 知识锚点

```
原世界的某项知识 · 在新世界派用场

例：
  ├─ 现代医学（穿到古代救人）
  ├─ 数学公式（穿到异世解谜）
  └─ 历史知识（穿到古代预知未来）

作用：
  ├─ 给主角"金手指"（合理来源）
  ├─ 制造爽点（用现代知识碾压古人）
  └─ 限制爽点（不是所有知识都管用）
```

### 锚点 3 · 情感锚点

```
原世界的某段情感 · 在新世界引发回响

例：
  ├─ 妈妈（古代遇到长得像妈妈的人 → 内心戏）
  ├─ 初恋（古代遇到相似身影 → 对方就是穿越者？）
  └─ 朋友（在异世遇到相似性格 → 想念）

作用：
  ├─ 让主角有"血肉感"
  ├─ 给读者情感共鸣
  └─ 推主线（找到原世界的人 = 找回路）
```

## 四 · 首穿 vs N 穿 · 节奏差异 ★

```
关键认知：
  首穿要充分（占 1 卷篇幅）
  后续穿越要压缩（占 1-3 章）
```

### 首穿（第一次穿越）

| 段 | 章数 | 字数占比 |
|---|:---:|:---:|
| 段 1 锚定 | 1-2 章 | 10% |
| 段 2 触发 | 0.5 章 | 5% |
| 段 3 过程 | 0.5 章 | 5% |
| 段 4 新空间 | 2-4 章 | 30% |
| 段 5 适应 | 5-15 章 | 50% |

→ **首穿 = 浓墨重彩**

### N 穿（第 N 次穿越）

| 段 | 章数 | 字数占比 |
|---|:---:|:---:|
| 段 1 锚定 | 0.2 章（一段景） | 5% |
| 段 2 触发 | 0.1 章 | 2% |
| 段 3 过程 | 0.1 章 | 3% |
| 段 4 新空间 | 0.3 章 | 20% |
| 段 5 适应 | 0.3 章（仅新规则）| 70% |

→ **N 穿 = 一镜到位**

### 节奏控制原则

```
首穿失败 = 全书废
N 穿冗长 = 读者跳

→ 首穿宁慢勿快
→ N 穿宁快勿慢
→ 中间穿越**只写差异**（不写共性）
```


## 常见错误

```
❌ 锚定不足（"突然穿越"· 读者不记得旧世界）
❌ 触发器与题材不搭（言情用车祸 · 不浪漫）
❌ 过程只有视觉（缺听觉 / 触觉 / 时间感）
❌ 新空间无对比（看不出"换世界"感）
❌ 适应秒接受（不真实）
❌ 0 锚点（旧世界完全消失 · 像两本书）
❌ N 穿与首穿一样长（节奏崩溃）
❌ 模式混乱（说好双向 · 后来变单向）
❌ 多空间无主线（每章一个世界 · 散沙）
❌ 知识锚点过强（碾压一切 · 失去张力）
```

## 范例 · 一句话激活公式

```
本卷 / 本章穿越段设计：

穿越模式：[单向 / 双向 / 多空间]
是首穿还是 N 穿：[首 / N]

段 1 锚定：
  视觉锚点：[标志物]
  情绪锚点：[人 / 羁绊]
  标志物：[将来在新空间出现]

段 2 触发：
  类型：[道具 / 事件 / 系统]
  描述：[一句话]

段 3 过程：
  感官 1：[视觉 / 听觉 / 触觉 / 时间 / 空间]
  感官 2：[视觉 / 听觉 / 触觉 / 时间 / 空间]
  感官 3：[视觉 / 听觉 / 触觉 / 时间 / 空间]（可选）

段 4 新空间：
  与旧 5 维对比：[听觉 / 嗅觉 / 视觉 / 服饰 / 语言]
  标志物：[新空间 vs 旧空间]
  规则暗示：[一句话]

段 5 适应：
  身份适应：[新身份]
  知识适应：[新规则]
  情感适应：[接受 + 怀念]

字数预算：
  首穿：[1500-3000 字 · 跨章]
  N 穿：[200-500 字 · 一段]
```

把这段填空给 LLM · 穿越段自动产出。
