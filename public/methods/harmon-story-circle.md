# 丹·哈蒙 · 故事圈 8 步闭环（单元剧/连载专用骨架）

> **来源**：Dan Harmon（《瑞克和莫蒂》《社区》主创），基于英雄之旅简化的闭环模型。
> **定位**：结构层骨架 · **单元剧 / 连载网文 / 日更节奏 专用**。与其他结构骨架互斥。
> **核心价值**：解决 AI 写连载网文"每章流水账、无完整起承转合"的痛点。每一单元（章 / 卷 / 集）都是一个完整闭环，读者日更也能读到起承转合。

---

## 适用边界

✅ **推荐启用**：
- 每章独立小故事的连载网文（单元剧体）
- 番剧 / 网剧的单集结构（每集自洽）
- 游戏支线任务 / 关卡剧情
- 日更高速网文（每日一章需要独立钩子 + 收束）
- 短篇集（每篇完整）
- 长篇的**每一卷**内部结构（嵌套使用）

❌ **不要启用**：
- 单一超长弧线驱动的文学长篇（请用特鲁比 22 步）
- 言情（请用林赛·多兰七要点）
- 悬疑单本（请用三宅隆太 12 步）
- 纯慢节奏治愈系（请用起承转合）

## 一、故事圈 8 步（核心）

```
         A · You（你：舒适区）
        ╱                    ╲
       ╱                      ╲
   H · Change                  B · Need（需求）
   （改变）                      （有了目标）
       │                        │
       │                        │
   G · Return                  C · Go（出发）
   （回归）                    （进入陌生环境）
        ╲                      ╱
         ╲                    ╱
      F · Take             D · Search
      （代价）            （探索 / 对抗）
              ╲          ╱
               E · Find
               （获得）
```

| # | 步骤 | 一句话 | 占比 | 对应阶段 |
|---|---|---|---|---|
| **A** | **You**（你） | 主角在**舒适区** | 10% | 开场（日常） |
| **B** | **Need**（需求） | 主角**有了明确欲望 / 目标** | 10% | 激励事件 |
| **C** | **Go**（出发） | 主角**进入陌生环境** | 15% | 跨过门槛 |
| **D** | **Search**（探索） | 主角**适应 + 对抗** | 20% | 第二幕主体 |
| **E** | **Find**（获得） | 主角**得到了他想要的** | 10% | 伪高潮 |
| **F** | **Take**（代价） | 主角为此**付出代价** | 15% | 真高潮 |
| **G** | **Return**（回归） | 主角**回到熟悉的环境** | 10% | 返程 |
| **H** | **Change**（改变） | 主角发生**根本性变化** | 10% | 新起点 |

## 二、闭环的神圣分界（最关键硬律）

### 2.1 上半圈 vs 下半圈的镜像对称

故事圈被水平线分为上下两半：

```
上半圈（舒适区 / 熟悉）：A · B · G · H
下半圈（冒险区 / 陌生）：C · D · E · F
```

**硬律**：
- **A ↔ H**：必须视觉 / 状态押韵（同样的场景，状态已不同）
- **B ↔ G**：需求与归来对应（G 处主角带着"满足的 B"回归）
- **C ↔ F**：出发与代价对应（C 越轻松进入，F 越沉重付出）
- **D ↔ E**：探索与获得对应（D 越艰苦，E 才越值得）

### 2.2 半圈理论

- **左半圈**（A→B→C→D）= 主角**下降 / 冒险**
- **右半圈**（E→F→G→H）= 主角**上升 / 回归**

下降和上升必须**力度对等**。如果下降快而上升慢，故事散架；如果下降短而上升长，故事头重脚轻。

## 三、关键硬律（防流水账）

### 3.1 每个单元必须完整走完 8 步

**硬律**：一个单元（章 / 卷 / 集）**必须闭合**，即使只有 3000 字也必须有 A→H。短篇可以压缩每步，但不能跳过步。

**最小单元示例**（3000 字单章）：
- A：主角正在抓捕犯人（日常）→ 150 字
- B：突发消息：师父失踪（需求）→ 100 字
- C：赶往师父最后出现地（出发）→ 400 字
- D：与未知对手周旋（探索）→ 1200 字
- E：找到师父（获得）→ 400 字
- F：师父其实是敌人卧底（代价）→ 400 字
- G：带着真相回到单位（回归）→ 250 字
- H：主角从此不再信任权威（改变）→ 100 字

### 3.2 代价（F）必须真实，不能空挂

**硬律**：F 步的代价**必须改变主角外部 / 内部状态**，且不可逆。

- ✅ 外部：失去盟友 / 暴露身份 / 伤痕 / 资源损耗
- ✅ 内部：信念动摇 / 关系断裂 / 认知颠覆
- ❌ 受伤但瞬愈 / "吓出一身冷汗"/ 口头承诺

**硬律加成**：F 的代价**至少要在后续 3 个单元**中被提及或回响，否则等于没付。

### 3.3 改变（H）必须可观察

**硬律**：H 步的改变**必须通过外部行为可观察**，不能仅是"内心若有所思"。

**可观察的改变**：
- 下一章开头主角做了以前绝不会做的动作
- 原本说的口头禅换了
- 与某个角色的关系明显换姿态
- 主角的决策标准变了

### 3.4 长篇嵌套：大圈套小圈

**硬律**：长篇使用本法时，应采用**嵌套式**：
- 全书 = 一个大故事圈（A–H 对应开篇 / 结尾）
- 每卷 = 一个中故事圈
- 每章 = 一个小故事圈

**三层故事圈同时推进**。每层独立闭合但共享主题。

## 四、三种典型使用场景

### 4.1 单元剧 / 每章独立

每章就是一个完整 A→H 闭环。第二天读者读下一章又是一个新故事圈。适合：
- 破案文（每章破一案）
- 异闻录（每章一个怪谈）
- 冒险通关（每章一关）
- 职业文（每章一个客户 / 患者 / 案件）

### 4.2 连载网文的"卷闭环"

每卷是一个故事圈（6–15 章一卷）。章是节拍，卷是完整弧。读者追更感到每卷都有尾声，不会疲劳。

### 4.3 多线群像的"各角色圈"

群像小说时，每个主要角色独立走完自己的故事圈，主线汇合时各圈的 H 形成共振。

## 五、与其他骨架的互动

### 故事圈 vs 三幕式

| 三幕式 | 故事圈 |
|---|---|
| 第一幕（25%） | A + B + C（35%） |
| 第二幕（50%） | D + E（30%） |
| 第三幕（25%） | F + G + H（35%） |

故事圈**节奏更平衡**（三段各 30–35%），三幕式中间幕最长。故事圈适合短篇，三幕式适合长篇。

### 故事圈 vs 英雄之旅

故事圈是英雄之旅的**简化 8 步版**。英雄之旅 12 阶段 ≈ 把故事圈每步细分成 1.5 个阶段。故事圈轻量，英雄之旅深度。

## 六、章节分配参考

### 单章独立（3000 字）

见 3.1 硬律示例。

### 单卷闭合（8 章 / 3 万字）

| 步骤 | 章节 | 字数 |
|---|---|---|
| A 舒适区 | 1 | 3k |
| B 需求 | 2 | 3k |
| C 出发 | 3 | 3.5k |
| D 探索 | 4–5 | 8k |
| E 获得 | 6 | 4k |
| F 代价 | 6–7 | 5k |
| G 回归 | 8 | 3k |
| H 改变 | 8 | 1.5k |

### 全书大圈（20 万字 / 60 章 / 6 卷）

大圈嵌 6 卷，每卷一个中圈，每中圈再嵌 10 章小圈。

## 七、与其他模块协同

- **与其他结构骨架**：互斥。故事圈是主结构，不与 Save the Cat / 英雄之旅 / 三幕式 / 起承转合 / ATU 301 并存。
- **与 `seven-emotion-peaks`**：**极强协同**（必搭）。故事圈管宏观 8 步，七情节奏管每步内部的情绪锚点。
- **与 `plot-coherence-scaffold`**：强协同。长篇嵌套故事圈尤其需要伏笔追踪（F 步代价必须后续回响）。
- **与 `mbti-5step`**：协同。简化 MBTI 适合单元剧的快节奏（不需要深度认知功能分析）。
- **与 `pixar-22-rules`**：协同。Pixar 第 4 条（从前有 / 每天 / 某天 / 于是 / 最后）是故事圈的极简版。
- **与 `visual-dehydration`**：协同。单元剧需要每章清晰场景线，镜头化写法让 8 步之间转场利落。
- **与 `supernatural-webfiction-pack`**：强协同。超自然网文日更模式下，故事圈 + 超自然编码库组合是最高效的量产组合。
