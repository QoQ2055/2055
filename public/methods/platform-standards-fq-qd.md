# 平台投稿标准 · 番茄 vs 起点对比 + 量化清单

> **来源**：self-evolving-auditor v4.0 概念提取（standards-fanqie.md + standards-qidian.md · 重写为通用方法论 · 去除单平台 lock-in）。
> **定位**：craft 层 · **平台适配型模块**（与 audience-personas / serialization-paid-hooks / fast-narrative-method 强协同）。
> **核心命题**：fili-web 现有 `audience-personas` 是"读者心理画像" · 但**没有平台投稿的具体量化标准**。本模块提供番茄 / 起点两大平台的硬性数据：字数 / 高潮间隔 / 留存率优化 / 红线 / 题材热度 · 让 LLM 生成时有具体目标。
> **核心价值**：(1) 番茄 vs 起点 5 维对照表；(2) 番茄硬性标准（字数 / 开篇 / 章节 / 留存）；(3) 起点硬性标准（字数 / 开篇 / 章节 / 付费留存）；(4) 内容红线 + 发布前清单。

---

## 适用边界

✅ **强推荐启用**：
- 商业网文连载（番茄 / 起点项目）
- 长篇签约项目
- 需要平台数据指导的项目

⚠ **可选启用**：
- 其它平台（晋江 / 17k / 纵横 · 部分通用）

❌ **不要启用**：
- 实体出版（标准完全不同）
- 短篇 / 散文（无连载机制）
- 自费连载（无平台审核）

---

## 核心心法 · 不同平台 = 不同审美

### 痛点

```
新手作者最常见错误：
  用同一个写法投所有平台
  → 番茄编辑：太慢热 · 第 1 章没爽点 → 拒
  → 起点编辑：文笔粗糙 · 像快餐文 → 拒

平台 ≠ 渠道
平台 = 用户群 + 付费模式 + 算法偏好

→ 不同平台的"什么是好文"标准完全不同
→ 投稿前必须确定平台 · 按对应标准写
```

### 解决方案 · 平台优先决策树

```
项目立项时 · 第一问：投哪个平台？

番茄 → 免费阅读 + 流量分成
       18-35 岁下沉市场
       核心 KPI：完读率 / 追读率
       → 快节奏 + 短章 + 强爽点

起点 → VIP 付费 + 月票打榜
       20-40 岁核心读者
       核心 KPI：均订 / 月票 / 收藏
       → 长章 + 文笔 + 宏大世界观
```

→ 平台决定全部写作策略。

## 一 · 番茄 vs 起点 5 维对照表 ★ 核心实操

### 速查矩阵

| 维度 | 番茄 | 起点 |
|---|---|---|
| **付费模式** | 免费 + 广告分成 | VIP 付费（千字 5 分）+ 月票 |
| **核心 KPI** | 完读率 / 追读率 / 互动率 | 收藏 / 月票 / 均订 |
| **用户画像** | 18-35 岁 · 下沉市场 | 20-40 岁 · 核心网文读者 |
| **付费习惯** | 不付费 · 看广告 | 愿付费看好内容 |
| **签约门槛** | 2 万字 | 5 万字（30 万可申完本）|
| **VIP 上架** | 不适用 | 20-30 万字后 |
| **日更要求** | 4000+ 字 | 4000-6000 字（大神放宽）|
| **章节字数** | **2000-3000**（推荐）| **3000-4000**（推荐）|
| **开篇决定期** | **前 3 章**（推荐量看这）| **前 5 章**（编辑签约看这）|
| **节奏要求** | 快 · 短章 · 强爽点 | 中 · 允许慢热 · 文笔在线 |
| **小高潮间隔** | 3-5 章 | 3-8 章 |
| **大高潮间隔** | 15-25 章 | 20-40 章 |
| **铺垫释放比** | 1:1 ~ 3:1 | 1:1 ~ 5:1 |
| **日常章占比** | 尽量减少（>20% 拖沓）| **20-30%**（塑造角色）|
| **文笔要求** | 通顺即可 | **必须流畅**（病句拒签）|
| **世界观** | 简单直接 | **鼓励宏大** |
| **角色塑造** | 可脸谱化 | **必须立体** |
| **总字数** | 中短篇也可 | **长篇为主**（200 万+）|

### 题材热度对比

| 平台 | 主流题材 | 文风偏好 |
|---|---|---|
| **番茄** | 都市赘婿 / 神医 / 兵王 / 重生 / 系统流 / 无敌流 / 凡人修仙 | 直接、粗暴、爽感优先 |
| **起点** | 东方玄幻 / 高武 / 诸天万界 / 星际科幻 / 末日废土 / 修仙文明 / 架空历史 / 游戏 / 无限流 | 智谋在线、世界观优先 |

## 二 · 番茄硬性标准 ★

### 番茄痛点

```
免费 + 广告分成 → 平台只看用户行为数据
推荐机制 → 算法看前 3 章数据决定推荐池
完读率 → 章节超过 4000 字完读率断崖下跌
追读率 → 章末没钩子直接掉
```

### 番茄章节字数（按类型）

| 章节类型 | 推荐字数 | 备注 |
|---|---|---|
| 日常章 | 2000-2500 | 可短一点 |
| 冲突章 | 2500-3500 | 需要篇幅展开 |
| 高潮章 | 3000-4000 | 允许写长 |
| 过渡章 | 1500-2000 | 尽量短 |

### 番茄第 1 章铁律（500/1000 字）

- [ ] **500 字内**出现冲突 / 悬念
- [ ] **1000 字内**展示金手指 / 核心设定
- [ ] 有明确的"为什么继续看"的理由
- [ ] **不要**大段描写 / 设定介绍 / 回忆

### 番茄前 3 章必备

- [ ] 至少 1 个爽点
- [ ] 主角目标明确
- [ ] 核心冲突建立
- [ ] 世界观快速交代（不单独开段解释）
- [ ] 至少 1 个让人想继续看的钩子

### 番茄开篇禁忌

```
❌ 大段景物描写开头
❌ 主角醒来不知道在哪（除非有新意）
❌ 前 3 章全是铺垫没有释放
❌ 设定堆砌（世界观说明文）
❌ 角色太多记不住
```

### 番茄留存率优化

| 指标 | 关键操作 |
|---|---|
| **完读率** | 章节不超 4000 字 / 避免大段描写 / 对话动作交替 |
| **追读率** | 每章末留钩子 / 3-5 章一爽点 / 主角目标持续更新 |
| **互动率** | 制造讨论点（争议决策 / 反转 / 新角色）/ 适当留白 |

## 三 · 起点硬性标准 ★

### 起点痛点

```
VIP 付费 → 读者要"觉得值才付费"
均订指标 → 上架后保持订阅是关键
月票战 → 月底大高潮配合月票战
养书率 → 节奏太慢导致读者攒着不看
```

### 起点章节字数（按类型）

| 章节类型 | 推荐字数 | 备注 |
|---|---|---|
| 日常章 | 3000-3500 | 保持信息量 · 不纯水 |
| 冲突章 | 3500-4500 | 需要篇幅展开对抗 |
| 高潮章 | 4000-5000 | 节奏紧凑 |
| 过渡章 | 2000-3000 | 短但有信息量 |
| VIP 章 | 3000-5000 | 付费内容必须有信息量 |

### 起点第 1 章铁律（500/1000 字）

- [ ] **500-1000 字内**建立代入感（处境 / 性格 / 目标）
- [ ] 有明确悬念或冲突牵引
- [ ] **文笔流畅**（无明显病句 / 错字）
- [ ] 不大段设定介绍 · 但世界观可自然融入

### 起点前 5 章必备

- [ ] 主角性格鲜明（不只"普通人穿越"）
- [ ] 核心金手指 / 能力体系初步展现
- [ ] 至少 1 条主线冲突建立
- [ ] 世界观通过情节自然展开
- [ ] 至少 1 个让人想继续看的钩子
- [ ] **文笔质量在线**（起点读者要求高）

### 起点开篇禁忌

```
❌ 大段景物描写开头
❌ 前 3 章全是设定堆砌
❌ 主角性格模糊（"路人脸"主角）
❌ 文笔粗糙（病句 / 错字 / 口水话）
❌ 模仿痕迹过重
```

### 起点付费留存优化

#### 上架时机

```
通常 20-30 万字上架 VIP
上架前要积累足够收藏（通常 3000+）
上架章节要是"高潮章"或"关键转折"（不能平淡处上架）
上架前 1-2 章要制造强烈追读欲
```

#### 均订优化

```
均订 = 总订阅章节数 / VIP 章节数
保持更新频率稳定（断更 = 均订杀手）
定期释放大爽点（5-8 章一个）
保持主角成长线清晰
```

#### 月票 / 推荐票优化

```
制造投票动力（月票加更 / 推荐票加更）
月底是月票战关键期 · 需要大高潮配合
与读者互动（章末求票 / 回复书评）
```

#### 养书率优化

```
养书 = 读者攒着不看 · 等多了再看
养书率高 = 节奏太慢或更新太慢
对策：加快节奏 / 增加日更量 / 制造"不看就亏"的紧迫感
```

## 四 · 通用内容红线（番茄 / 起点 共同）

```
□ 无政治敏感内容
□ 无色情 / 暴力过度描写（起点比番茄严）
□ 无涉政 / 涉军 / 涉警敏感题材（除非过审）
□ 无抄袭 / 洗稿嫌疑
□ 无真实人物 / 事件影射
□ 无三观不正的明显引导（起点严格）
□ 宗教 / 民族 / 历史相关需谨慎
```

→ **触线一项 = 直接拒**。

## 五 · 章节结构铁律（两平台共同）

### 章节开头

| 维度 | 番茄 | 起点 |
|---|---|---|
| 风格 | 快速切入 / 不要慢热 | 自然衔接 / 可适当慢热 |
| 前 X 字要求 | 前 100 字有事件 / 对话 / 冲突 | 前 200 字事件推进 / 情绪变化 |
| 禁忌 | 不以上一章回顾开头 | 不生硬跳转 |

### 章节中段

| 维度 | 番茄 | 起点 |
|---|---|---|
| 主任务 | 推进剧情 / 深化角色 | 推进 / 深化 / 展开世界观 |
| 信息密度 | 不要注水 | 适中（不注水也不太赶）|
| 手法 | 对话 + 动作交替 | 对话 / 动作 / 心理 / 描写四种交替 |
| 留白 | 不需要 | 适当留白 |

### 章节结尾（两平台一致）

```
✅ 必须有钩子（悬念 / 反转 / 新信息 / 冲突升级）
✅ 不要在平淡处结束
✅ 让读者有理由点"下一章"

→ 高潮章可以戛然而止（追读欲）
→ 日常章结尾要有过渡到下一事件的引子
```

## 六 · 发布前检查清单（双平台对照）

### 番茄发布前

```
必查：
  □ 前 3 章有爽点
  □ 前 3 章有钩子
  □ 前 3 章角色不超过 5 个
  □ 第 1 章 500 字内有冲突
  □ 每章结尾有钩子
  □ 无内容红线
  □ 格式统一
  □ 无错别字 / 乱码
  □ 章节字数 2000-3000

推荐：
  □ 书名 2-6 字 + 悬念 / 关键词
  □ 简介 50 字内说清"看什么"
  □ 标签准确
  □ 封面吸引人
```

### 起点发布前

```
必查：
  □ 前 5 章文笔流畅
  □ 前 5 章主角性格鲜明
  □ 前 5 章有核心冲突
  □ 世界观通过情节展开（非说明文）
  □ 每章结尾有钩子
  □ 无内容红线
  □ 格式统一
  □ 无错别字 / 病句
  □ 章节字数 3000-4000

推荐：
  □ 书名 2-6 字 + 辨识度 / 记忆点
  □ 简介 100 字内说清"卖点 + 主角特点"
  □ 标签准确
  □ 封面专业
  □ 有大纲（编辑会看）
```

## 七 · 发布水平评分标准（双平台通用 10 分制）

| 分数 | 标准 |
|---|---|
| **9-10** | 完全达到平台标准 · 可直接签约 / 上架 |
| **7-8** | 基本达标 · 微调后可发布 |
| **5-6** | 部分达标 · 需要修改开篇或结构调整 |
| **3-4** | 多项不达标 · 需要较大改动 |
| **1-2** | 不建议在该平台发布 |

## 八 · 平台决策树（项目立项时）

```
你的目标读者群是？
├─ 18-35 岁 · 不付费 · 喜欢爽文 → 番茄
└─ 20-40 岁 · 愿付费 · 喜欢宏大 → 起点

你的题材是？
├─ 都市 / 赘婿 / 重生爽文 → 番茄
├─ 玄幻 / 科幻 / 仙侠 / 历史 → 起点（首选）
└─ 都行 → 双平台投（但起点优先 · 番茄做镜像版）

你的写作能力？
├─ 文笔较弱但节奏好 → 番茄
└─ 文笔好 + 世界观能力 → 起点

你的体量预期？
├─ 100 万字以下 → 番茄（中短篇可）
└─ 200 万字+ → 起点（长篇为主）
```

## 实战检验法

### 项目立项时 · 5 项自检

- [ ] **平台明确**（番茄 / 起点 · 不投机）？
- [ ] **章节字数**符合该平台标准？
- [ ] **开篇策略**符合该平台铁律（前 3 章 / 前 5 章）？
- [ ] **节奏配比**符合（小高潮间隔 / 铺垫释放比）？
- [ ] **内容红线**已避免？

### 投稿前 · 5 项最终验收

- [ ] 前 3 章 / 前 5 章**全部检查项过**？
- [ ] 文笔 / 角色 / 世界观符合**该平台调性**？
- [ ] **每章末有钩子**？
- [ ] 发布水平**评分 ≥7**？
- [ ] 内容红线 / 格式 / 错字**全清**？

## 常见错误

```
❌ 平台不分 · 用同一个版本投所有渠道
❌ 番茄章节超 4000 字（完读率断崖）
❌ 起点章节低于 3000 字（VIP 价值感低）
❌ 番茄前 3 章铺垫太多（推荐量为 0）
❌ 起点文笔粗糙（直接拒签）
❌ 番茄写智谋型主角（读者不买账）
❌ 起点写"普通人穿越秒变神"（编辑当快餐文）
❌ 触发内容红线还试图过审（黑名单 + 封号）
❌ 章节中段大段心理描写（番茄读者跳）
❌ 起点章末平淡收尾（订阅断崖）
```
