# 内容密度装填规则 · 4 级密度 + 4 切点决策树

> **来源**：Work-Fisher 视频分镜模板 V3 第 1.3 节"内容密度装填规则"概念提取（去除 15 秒分镜专用部分 · 重写为小说场景切分专用）。
> **定位**：rhythm 层 · **场景切分操作型模块**（与 fast-narrative-method / chapter-transition-7methods 强协同）。
> **核心命题**：写小说最常见困惑——**这一段写多长？什么时候断段？什么时候换章？** 凭直觉容易写散。本模块提供**工业化决策树** · 让"切场景"从艺术变科学。
> **核心价值**：(1) 4 级密度判断（过密 / 标准 / 偏疏 / 极疏）；(2) 4 切点决策树；(3) 对话密度特殊处理。

✅ **强推荐启用**（**所有连载作品必备**）：

## 核心心法 · 段落是容器 · 内容要适配容器

```
新手作者最常见困惑：
  "这一段是不是太长了？"
  "什么时候应该断段 / 换章？"
  "对话太多 · 是不是该拆？"
  "纯环境描写 · 该单独成段吗？"

→ 凭直觉 · 写出的节奏混乱
→ 本模块给"工业化决策树"
```

### 容器思维

```
每个段落 / 每个章节 = 一个容器
容器有"标准容量"
内容必须适配容器：
  ├─ 内容超出 → 必须拆分
  ├─ 内容不足 → 必须合并 / 补偿
  └─ 内容刚好 → 直接装填

→ 装填不是单纯写完事
→ 装填是"信息密度的精准管理"
```

## 4 级密度判断 ★ 核心实操

### 总览矩阵

| 密度等级 | 内容特征 | 处理策略 |
|---|---|---|
| **过密** | 3+ 轮对话 / 对峙 · 2+ 独立动作事件 | **必须拆分** |
| **标准** | 1 个完整动作闭环 / 1 轮对话+1 个伴随动作 | 1 段刚好 |
| **偏疏** | 纯行走 / 等待 / 环境交代 | 用视觉密度补偿叙事密度 |
| **极疏** | 纯空间展示 / 纯情绪铺垫 | **合并入相邻段** · 不独立 |

---

### 等级 1 · 过密

#### 特征识别

```
✅ 出现以下任一情况 = 过密：
  □ 3 轮以上对话
  □ 2 个以上独立动作事件
  □ 多角色情绪同时变化
  □ 多个空间转换
  □ 信息密度超过读者一次性消化能力
```

#### 处理策略 · 必须拆分

```
拆分原则：
  1. 找到"切点"（见下方 4 切点决策树）
  2. 每段只保留 1 个核心信息点
  3. 切点选择：情绪峰值 / 动作完成点 / 空间转换 / 信息交接

拆分后每段：
  开场（起势）→ 高潮 → 收束
```

#### 实战示例

##### 原文（过密）

```
赵嬷嬷叫出沈昭宁 → 拿戒尺点肩 → 威胁"三天后你病了" → 走开
→ 青禾害怕 → 沈昭宁说"先不急"

【密度判断】过密：
  - 2 轮对话
  - 2 个角色情绪变化
  - 1 个威胁事件
```

##### 拆法

```
段 A（嬷嬷威胁）：
  嬷嬷叫她出列 → 戒尺点肩 → "三天后你病了"
  → 落幅停在嬷嬷转身走开

段 B（沈昭宁消化）：
  青禾发抖问话 → 沈昭宁"先不急"
  → 食指在腿侧敲三下

切点选择：嬷嬷走开 = 动作完成点 · 情绪从压迫切向隐忍
```

---

### 等级 2 · 标准

#### 特征识别

```
✅ 标准段落 = 以下任一情况：
  □ 1 个完整动作闭环
  □ 1 轮对话 + 1 个伴随动作
  □ 1 个事件 + 1 个反应
```

#### 处理策略 · 1 段刚好

```
正文结构 = 起势 / 高潮 / 收束 三段式
  ├─ 起势（30-40%）：交代场景 + 引出冲突
  ├─ 高潮（30-40%）：动作 / 对话 / 关键时刻
  └─ 收束（20-30%）：结果 + 余韵

→ 不要拆 · 不要合
→ 直接装填
```

#### 实战示例

```
情节：女主在电梯里接到离婚律师电话
       说了 3 句话 · 出电梯时撞见前夫

【密度判断】标准偏密：
  - 2 句对话
  - 1 个空间转换
  - 1 个意外相遇

【拆法】拆成 2 段（电梯内 + 电梯外）：

段 A（电梯内）：
  接电话 → 对话 → 电梯门开

段 B（电梯外）：
  出门撞见前夫 → 两人对视

切点：电梯门开 = 空间转换点
```

---

### 等级 3 · 偏疏

#### 特征识别

```
✅ 偏疏段落 = 以下任一情况：
  □ 纯行走 / 等待
  □ 纯环境交代
  □ 主角在路上 · 没有事件
  □ 心理活动占主导
```

#### 处理策略 · 用视觉密度补偿叙事密度

```
偏疏段落允许独立成段
但必须用视觉密度补偿：
  ├─ 增加环境细节层（光影 / 气味 / 声音）
  ├─ 加入光影变化（明 → 暗 / 冷 → 暖）
  └─ 强化镜头运动感（远 → 近 / 高 → 低）
```

#### 实战示例

##### ❌ 偏疏 + 缺乏视觉密度

```
林深沿着走廊走到尽头。
他推开了门。
进了房间。

→ 太干瘪 · 偏疏未补偿
```

##### ✅ 偏疏 + 视觉密度补偿

```
林深沿着走廊走过去。
左侧的墙皮已经剥落 · 露出底下青灰的水泥；
右侧每隔三米就有一盏灯 · 但只有奇数位置亮着。
他踩在地板上 · 木板发出比上次更深的呻吟。
走廊尽头有一扇门 · 漆色发黑 · 边缘已经在脱落。
他停在门前 · 听见自己的呼吸。
然后伸手 · 推门。
```

→ 同样是"走过去推门" · 加入视觉细节后 · 段落有质感。

---

### 等级 4 · 极疏

#### 特征识别

```
✅ 极疏段落 = 以下任一情况：
  □ 纯空间展示（无人物）
  □ 纯情绪铺垫
  □ 单一意象描写
  □ 没有任何剧情推进
```

#### 处理策略 · 合并入相邻段 · 不独立成段

```
极疏内容禁止独立成段！

正确处理：
  方法 1：合并入相邻段的"起幅"（场景描写 + 角色出场）
  方法 2：合并入相邻段的"落幅"（角色离开 + 余韵描写）
  方法 3：作为段中的"过渡句"（不独立成段）
```

#### 实战示例

##### ❌ 极疏独立成段（错误）

```
段 1：天色昏暗 · 远处有云。

段 2：林深推开门 · 走进房间。

段 3：风吹过 · 窗帘飘动。

→ 全是极疏 · 节奏散乱
```

##### ✅ 合并处理（正确）

```
段 1（合并极疏到起幅）：
  天色昏暗 · 远处有云。林深推开门 · 走进房间——
  风吹过 · 窗帘飘动。他闭上门 · 转过身。

→ 三个极疏画面合并入一段
→ 服务于"林深进屋"这个标准动作
```

## 4 切点决策树 ★ 核心实操

```
当判断为"过密"必须拆分时
按以下决策树选择切点：
```

### 决策树

```
问 1：有明确的动作完成点？（枪响 / 门关 / 车停 / 落座）
  ├─ 是 → ✅ 在动作完成点切
  └─ 否 → 进入问 2

问 2：有情绪峰值？（怒吼 / 沉默 / 对视 / 转身）
  ├─ 是 → ✅ 在情绪峰值切
  └─ 否 → 进入问 3

问 3：有空间转换？（室内→室外 / 车内→车外）
  ├─ 是 → ✅ 在空间转换点切
  └─ 否 → 进入问 4

问 4：以上都没有？
  └─ ✅ 在信息交接点切（一句话说完 = 切点）

⚠ 绝对禁止：把一句台词切成两半分到两段
```

### 4 切点速查矩阵

| 优先级 | 切点类型 | 识别 | 示例 |
|:---:|---|---|---|
| 1 | 动作完成点 | 一个明确的物理动作结束 | 枪响 / 门关 / 车停 / 落座 |
| 2 | 情绪峰值 | 情绪推到顶点 | 怒吼 / 沉默 / 对视 / 转身 |
| 3 | 空间转换 | 物理位置改变 | 室内→室外 / 楼上→楼下 |
| 4 | 信息交接 | 一段话题完成 | 一句话说完 / 一个秘密揭晓 |

## 对话密度特殊处理 ★

### 对话长度分级处理

| 对话长度 | 处理 |
|---|---|
| **1-2 句台词** | 内嵌在动作中 · 1 段完成 |
| **3-4 句台词**（约 2 轮对话）| 1 段 · 但台词间必须有动作间隔 |
| **5+ 句台词** | **强制拆段** · 每段最多承载 2-3 句 |

### 1-2 句 · 内嵌在动作中

```
✅ 正确：
  林深推开门："是你？" 老张抬起头 · 笑了笑。

→ 台词内嵌在动作中 · 自然流畅
```

### 3-4 句 · 必须有动作间隔

```
✅ 正确：
  林深："你怎么来了？"
  （林深走到桌前 · 拉开椅子坐下）

  老张："找你聊聊。"
  （老张端起茶杯 · 吹了吹热气）

  林深："聊什么？"
  （林深的指尖在桌沿轻敲）

  老张：（沉默 · 然后才说）"昨天的事。"

→ 每句对话之间有走位 / 表情变化 / 道具互动
→ 不是"纯对白电影"
```

### ❌ 错误示范（无动作间隔）

```
× 林深："你怎么来了？"
  老张："找你聊聊。"
  林深："聊什么？"
  老张："昨天的事。"

→ 4 句纯对话 · 无任何动作 / 表情 / 走位
→ 像剧本台词 · 不像小说
```

### 5+ 句 · 强制拆段

```
当对话超过 5 句时：

切点选择：
  1. 话题转向处（话题 A → 话题 B）
  2. 情绪转折处（平静 → 激烈 / 试探 → 摊牌）

每段最多 2-3 句 · 不能再多
```

#### 实战示例

##### 原文（5 句对话 · 过密）

```
林深："你怎么来了？"
老张："找你聊聊。"
林深："聊什么？"
老张："昨天的事。"
林深："我已经处理完了。"
老张："不 · 你没有处理完。"
林深："你什么意思？"
```

##### 拆法

```
段 A（试探）：
  林深："你怎么来了？"
  （林深拉开椅子）
  老张："找你聊聊。"
  （老张端起茶 · 没喝）
  林深："聊什么？"
  老张：（停顿）"昨天的事。"

段 B（摊牌）：
  林深的手指在桌沿停了。
  "我已经处理完了。" 他说。
  老张放下茶杯：
  "不 · 你没有处理完。"
  
  屋里静下来。

切点：情绪转折（试探 → 摊牌）
```

## 实战检验法

### 写完一段 · 4 项自检

#### 自检 1 · 密度判断

- [ ] 这段是 **过密 / 标准 / 偏疏 / 极疏**？
- [ ] 处理策略**正确**（拆 / 装 / 补偿 / 合并）？

#### 自检 2 · 切点选择

- [ ] 切点是 **4 优先级中最优的**？
- [ ] **没有把一句台词切成两半**？

#### 自检 3 · 对话密度

- [ ] 对话句数与动作间隔**比例合理**？
- [ ] 5+ 句对话**有强制拆段**？

#### 自检 4 · 段落总览

- [ ] 段落不**过长**（建议 200-500 字）？
- [ ] 段落不**过短**（极疏未合并）？
- [ ] 段落有**起势 / 高潮 / 收束**结构？

## 章节级密度参考

```
章节字数 ≈ 段落数 × 平均段长

参考配比：
  ├─ 短章（1500-2500 字）：5-8 段
  ├─ 标准章（3000-5000 字）：10-15 段
  └─ 长章（5000-8000 字）：15-25 段

每章建议：
  ├─ 标准段：60-70%
  ├─ 偏疏段（含视觉补偿）：15-20%
  ├─ 过密段（必须拆）：10-15%
  └─ 极疏段（必须合并）：0%（独立出现 = 错误）
```

---

## 常见错误

```
❌ 标准段写成过密（一段塞太多事件）
❌ 偏疏不补偿（纯行走 + 无视觉细节 = 干瘪）
❌ 极疏独立成段（"天黑了。" 单独一段 = 错误）
❌ 把一句台词切成两半（破坏阅读连贯性）
❌ 对话 5+ 句不拆段（像剧本不像小说）
❌ 对话之间无动作间隔（像电影对白）
❌ 凭感觉切段（没用决策树）
```

## 范例 · 一句话激活公式

```

  切点选择：[动作完成点 / 情绪峰值 / 空间转换 / 信息交接]

    段 A：[内容]

  起势 / 高潮 / 收束 各 [%]

如果偏疏：
  视觉密度补偿：[环境层 / 光影 / 镜头运动]

如果极疏：
  合并入：[起幅 / 落幅 / 过渡句]

```
