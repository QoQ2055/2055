# 起承转合 · 东亚四段结构

> 来源：中国汉赋 / 唐诗 → 日本能乐 → 现代东亚短篇小说与漫画的主流结构。
> 与西方"冲突驱动"的三幕式 / 15 节拍不同，**起承转合不依赖冲突**，
> 也能形成完整的叙事弧。**特别适合：日常系 / 治愈系 / 散文化 / 成长小说**。

## 何时启用
- N2.1 全书分卷规划：日常系 / 群像 / 散文化的长篇网络小说
- N3.1 章节草稿：单章是一个完整四段时（短篇感的章节）

## 四段功能

| 段 | 名称 | 占比 | 功能 | 比照西方 |
|---|------|------|------|---------|
| 起 | 引入 | 0–25% | 设置情境与人物，无需设置冲突 | ≈ Setup，但不需要"日常即将被打破" |
| 承 | 展开 | 25–55% | 在情境内展开细节 / 关系 / 情绪 | ≈ 二幕上，但不需要冲突升级 |
| 转 | 转向 | 55–75% | **关键的视角变化或新元素**，不必是冲突 | 这是与西方最大不同：不一定是 Midpoint 反转 |
| 合 | 收束 | 75–100% | 让"起"和"转"在新的层面汇合 | ≈ Resolution，但常以"留白"结束 |

## 关键差异：转 ≠ 反转
- **西方反转**：A 想 X → 发现 Y → 改变行动
- **东亚 转**：A 在做 X → 同时发生 Z（看似无关） → A 在 Z 中看到 X 的另一面

举例（最经典）：
- **起**：祖父祖母经营豆腐店
- **承**：店里生意冷清，但他们悠然自得
- **转**：远方传来祖父年轻时朋友的死讯
- **合**：当晚两人多做了一块豆腐，摆在桌上没人吃

合不解决冲突——它**让先前的细节获得新重量**。

## 硬律
- **不强求冲突**：可以全篇没有"对手 / 敌人"
- **转必须是质变**：不能是"更多的承"
- **合必须留白**：忌总结陈词；忌道德说教
- **每段有"物件锚"**：四段都用同一物件 / 意象贯穿（如豆腐店例的"豆腐"）

## 输出契约
- N2.1 输出表格中**每卷必须标注**所属段（起/承/转/合）
- 总篇幅 4 段比例不得偏离 25/30/20/25 的 ±10%
- 卷与卷之间**禁止**用"突然 X 出现了！"作为推进力（那是西方冲突逻辑）

## 与其他方法的兼容性
- **与三幕式 / Save the Cat / 英雄之旅互斥**（同属结构层，世界观不同）
- **与 MBTI 五步法 / 七情节奏点 / Pixar 22 法则兼容**
- **与"去 AI 化润色"协同极佳**：AI 模型默认按西方冲突弧写作，套上起承转合后能强行扭转笔法
