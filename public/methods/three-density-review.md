# 三密度审查法 · 孤岛 / 密室 / 封闭空间悬疑专用

> **来源**：听花岛 v1.0 标准化模版。原资料完整流程（含 5 模块手动填表）归档到 `@docs/prompt-archives/three-density-template-v1.md`，本模块只保留 LLM 章节生成期可用的硬律与自检规则。
> **定位**：craft 工艺层 · **单章审查标准**（与结构骨架、角色层全正交）。
> **协同**：与 `twelve-step-mystery`（宏观 12 步悬疑骨架）**极强互补** —— 12 步管**全书结构**，本模块管**每章质量**。两层可同时启用。

---

## 适用边界

✅ **强推荐**：
- 孤岛悬疑 / 密室推理 / 封闭空间惊悚
- 暴风雪山庄派 / 限定场景推理
- 规则怪谈 / SCP 异常（**尤其适合**）
- 灵异 / 克苏鲁（压抑型）
- 心理悬疑 / 本格推理

✅ **推荐**（弱化某些硬律）：
- 普通悬疑 / 侦探小说（弱化"孤岛 2 章打破规则"）
- 惊悚 / 恐怖（启用恐惧四层递进）

❌ **不要启用**：
- 爽文 / 快节奏系统流（三密度节奏完全冲突）
- 言情 / 治愈 / 日常
- 奇幻冒险（本模块的"不可逆事件"硬律与传统英雄之旅节奏有张力）

## 一、三密度核心硬律

### 1.1 剧情密度硬律

每章必须满足：

| # | 硬律 | 违反后果 |
|---|---|---|
| P1 | **≥ 1 个不可逆事件**（人物关系 / 格局 / 认知永久改变） | 该章需重写 |
| P2 | **≥ 2 个明确剧情转折点** | 该章需重写 |
| P3 | **过渡段落 ≤ 500 字** | 该段需压缩 |
| P4 | **结尾必挂钩子**（悬念未解 / 新威胁 / 危险决定 / 信息反转 四选一） | 该章需重写 |
| P5 | **每场戏"删掉即消失"测试**：若删无影响，则该场景不应存在 | 删除场景 |
| P6 | **孤岛每 2 章打破一次规则事件**（持续压缩安全感） | 需新增规则破坏事件 |

### 1.2 信息密度硬律

| # | 硬律 | 违反后果 |
|---|---|---|
| I1 | **每段重要对话承载两层含义**：表面意思 + 潜台词 | 该段对话需重写 |
| I2 | **重要信息只说一次**，不重复不解释，信任读者 | 删除重复 |
| I3 | **每章 ≥ 1 处视觉 / 细节线索 + 回收计划** | 不允许悬空线索 |
| I4 | **答案前置原则**：真相必须在**第 1 章就已经"出现过"**，只是读者当时看不出 | 全书需重新布线索 |
| I5 | **人物说谎时必须在同段落内留可察觉破绽** | 该段需补破绽 |
| I6 | **禁止旁白直说**"这很重要" / "这是关键线索" | 删除旁白 |

### 1.3 情绪密度硬律

| # | 硬律 | 违反后果 |
|---|---|---|
| E1 | **情绪必须积累，不能直接爆发**：每个情绪高峰前 ≥ 2 个铺垫节点 | 该章需补铺垫 |
| E2 | **同章节内 ≥ 2 种对立情绪**（如：虚假安全感 vs 隐藏恐惧） | 需补对立情绪 |
| E3 | **禁用廉价煽情三件套**：①突然响起的背景音乐感描写 ②无铺垫的眼泪/崩溃 ③用天气对应情绪 | 该段需重写 |
| E4 | **情绪高峰后必有余震处理**：沉默 / 细节动作 / 环境描写，给读者消化空间 | 需补余震 |
| E5 | **恐惧四层递进**（孤岛 / 密室题材必遵）：① 对环境的不安 → ② 对他人的怀疑 → ③ 对自身判断的怀疑 → ④ 对真相的恐惧。**不可跳级，不可平铺** | 需重排恐惧层次 |

## 二、三密度协同铁律（最核心）

每个**关键事件**发生时，必须同时完成：

```
① 推动剧情（剧情密度）
② 传递或揭示信息（信息密度）
③ 激活人物或读者的情绪（情绪密度）
```

**三项缺一 = 该事件需重写。**

**禁止两类失败场景**：
- ❌ **纯功能性场景**（只推剧情不带情绪）
- ❌ **纯情绪场景**（只有感受没有信息）

---

## 三、章末密度自检（必做）

每章结尾 LLM 必须附一行自检（由 LLM 自动产出，不需外部填写）：

```
【本章密度自检】
· 剧情密度：[达标/未达标 + 原因]
· 信息密度：[达标/未达标 + 原因]
· 情绪密度：[达标/未达标 + 原因]
```

**如任一不达标 → 自动触发本章重写**。

---

## 四、密度一句话黄金法则

| 密度 | 决定 |
|---|---|
| **剧情密度** | 读者**愿意看** |
| **信息密度** | 读者**想看懂** |
| **情绪密度** | 读者**必须看完** |

**一场好戏 = 事件发生 × 信息传递 × 情绪共鸣，三项同时成立。**

## 五、与其他模块协同

### 与 `twelve-step-mystery`（**最佳搭档**）

- 12 步：全书 12 步悬疑骨架（日常崩坏 → 规则建立 → 规则反转 → 真相揭露 → 最终反转）
- 本模块：每章三密度审查
- **共用"公平前置"原则**（12 步的"关键线索公平前置"= 本模块的"答案前置"）
- 强烈建议双开

### 与 `plot-coherence-scaffold`

- plot-coherence：跨章因果链 + 伏笔追踪
- 本模块：单章内部的三密度
- 两层叠加，长篇悬疑必配

### 与 `anti-ai-flavor`

- anti-ai：字句层反 AI 毛刺（断句 / 对话毛刺 / 模糊语言）
- 本模块：场景层情绪节奏（余震 / 对立情绪 / 铺垫）
- 正交互补，可共存

### 与 `world-building-9-pillars`

- 世界观层的**柱 2 硬规则三条** = 本模块"孤岛每 2 章打破规则"的**铺垫前提**
- 世界观层的**柱 7 悬念表** = 本模块"答案前置"的**伏笔锚点**

### 与结构骨架

- 与 `twelve-step-mystery` 强协同（见上）
- 与其他结构骨架（Save the Cat / 英雄之旅等）可正交叠加，但三密度规则更适合悬疑类骨架

### 与 `mbti-*` / `character-three-elements-method`

- 正交。角色层决定"谁在场"，三密度决定"每章做什么/说什么/感受什么"

## 六、使用顺序建议

LLM 章节生成时按如下顺序应用：

1. **先读骨架**：从 `twelve-step-mystery` 确认本章在全书 12 步的哪一步
2. **再读世界观**：从 `world-building-9-pillars` 的悬念表和硬规则确认可用元素
3. **查伏笔状态**：从 `plot-coherence-scaffold` 检查需要回收的线索
4. **写作时应用三密度硬律**（本模块 P1–P6 / I1–I6 / E1–E5）
5. **章末自检**：输出【本章密度自检】
6. **若不达标 → 自动重写**
