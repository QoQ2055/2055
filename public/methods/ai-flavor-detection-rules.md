# AI 味检测规则库 · 30+ 关键词 + 5 比喻模板 + 4 过渡套路

> **来源**：self-evolving-auditor v4.0 概念提取（重写为通用叙事方法论 · 去除审核工具特定的 markdown 报告格式）。
> **定位**：craft 层 · **AI 味反向检测型模块**（与现有 anti-ai-flavor 互补 · 本模块提供"具体可检测的关键词清单" · anti-ai-flavor 提供"祛 AI 味原则"）。
> **核心命题**：现有 `anti-ai-flavor` 是"**叙事原则**"（怎样不像 AI）· 但**没有具体可检测的关键词清单**。本模块提供 30+ 高频 AI 用词 + 5 类 AI 比喻框架 + 4 类 AI 过渡句式 · 让 LLM 自检 / 用户人工查 / 审核 prompt 注入都有具体抓手。
> **核心价值**：(1) 30+ AI 关键词清单（动作 / 情绪 / 形容词三大类）；(2) AI 比喻模板（"像一盆冰水"等）；(3) AI 过渡句式（"时间过得很快"等）；(4) 句长 / 逗号 / 比喻密度 三大检测规则。

## 适用边界

✅ **强推荐启用**：
- LLM 辅助写作（防 AI 套路）
- 网文连载（防风格漂移）
- 需要"人味"的项目（言情 / 都市 / 文学）

⚠ **可选启用**：
- 商业短剧（节奏快 · AI 味检测优先级低）

❌ **不要启用**：
- 纯科普 / 说明文（AI 味反而合适）
- 实验意识流（用词反常本就不忌讳）

## 核心心法 · 反向评分

```
AI 味检测 = 反向评分
  分数越低越好（越没 AI 味 = 质量越高）

评分标准：
  1-2 = S（无 AI 痕迹 · 完全像人写的）
  3-4 = A（极轻微 · 偶有 1-2 处套路）
  5-6 = B（有一些 · 章内能识别）
  7-8 = C（明显 · 半段就能闻出来）
  9-10 = F（严重 · 看一眼就知道是 AI）
```

## 一 · 30+ 高频 AI 用词清单 ★ 核心实操

### 类 A · 情绪描写（过度使用）

| AI 用词 | 为什么 AI 爱用 | 修改建议 |
|---|---|---|
| **瞬间** | AI 最爱的转折词 · 几乎每个情绪变化都用 | 删除或替换为具体时长 |
| **瞳孔剧烈收缩** | AI 写震惊的默认反应 | "他愣了一下" / 直接动作 |
| **死死盯着** | AI 写注视的唯一方式 | "盯着" / "看着" / "目光锁定" |
| **眼神热切 / 锐利 / 深邃** | 万能眼神模板 | 用具体行为代替（眯眼 / 不眨眼 / 移开视线）|
| **目光里毫不遮掩** | AI 的直球表达 | "他没装" / 直接动作 |
| **显得有些兴奋** | 告诉读者而非展示 | 用呼吸 / 手势 / 语速展示 |
| **心中一动 / 一凛 / 暗道** | AI 写心理的三板斧 | 直接写动作或对白 |
| **微不可察的颤抖** | AI 写细微情绪的固定搭配 | "手抖了一下" / 具体描写 |

### 类 B · 动作描写（套路化）

| AI 用词 | 为什么 AI 爱用 | 修改建议 |
|---|---|---|
| **深吸一口气缓缓地** | AI 写紧张的标配 | "他停了停" / 直接行动 |
| **脸上堆满了笑** | AI 写讨好的固定搭配 | "笑得太用力" / 具体表情 |
| **嘴角勾起一抹弧度** | AI 写邪魅的万能句 | "他笑了" / 直接 |
| **嘴角勾起一抹冷笑** | AI 写嘲讽的万能句 | "冷笑了一声" / "嘁了一声" |
| **嘴角勾起玩味的弧度** | AI 写不屑的万能句 | "懒得理" / 具体动作 |
| **摸紧了拳头** | AI 写愤怒的唯一动作 | "捏到指节发白" / 多样化 |
| **指节因用力而发白** | AI 写紧张的升级版 | 一段中只用 1 次（不滥用）|
| **眉头紧锁** | AI 写思考的标配 | "皱眉" / "他想了想" |

### 类 C · 形容词（空洞堆砌）

| AI 用词 | 为什么 AI 爱用 | 修改建议 |
|---|---|---|
| **锐利的** | AI 形容一切目光和气势 | 删除或换具体词 |
| **不容置疑** | AI 写权威感的万能词 | 用语气 / 行动展示权威 |
| **不易察觉 / 微不可察** | AI 写细微的固定搭配 | 删除"察觉"层 · 直接写 |
| **纯粹 / 深邃** | AI 的万能形容 | 用具体细节代替 |
| **彻骨的冰寒 / 淬毒 / 冰冷** | AI 写冷的三种说法 | 物理描写（"冰得手指发疼"）|
| **轮廓分明的下颌** | AI 写帅的默认描写 | 删除或用具体细节 |
| **难以置信的** | AI 写震惊的形容词 | "他没想到" / 反应代替 |
| **死寂** | AI 写安静的唯一选择 | "没人说话" / 具体声音 |
| **恐怖如斯** | AI 写强的感叹词 | 删除 · 让事实说话 |
| **逻辑废话三剑客** | "毋庸置疑" / "不得不说" / "电光火石之间" | 全删 |

## 二 · AI 比喻模板（5 类）

### 模板特征

```
AI 的比喻有明显模式：
  用"像 / 宛如 / 仿佛 / 似乎"开头
  后面跟一个具象化的东西

→ 5 大典型 AI 比喻：
```

| AI 比喻 | 用于 | 修改建议 |
|---|---|---|
| **"像一盆冰水浇下来"** | 写震惊 | 直接写"愣住"或具体反应 |
| **"像一把精准的刻刀"** | 写精准 | 删除明喻 · 用动作描写 |
| **"像千年寒冰"** | 写冷 | 物理描写代替 |
| **"像一根滚烫的钢针"** | 写痛 | 具体身体反应 |
| **"像一记重锤"** | 写打击 | 直接写后果 |

### 检测规则

```
□ 一段中"像 / 宛如 / 仿佛"超过 2 次 → 标记
□ 命中上述 5 模板任一 → 直接标记"AI 味比喻"
□ 每章比喻句超过 3 个 → 标记过多

建议：
  少用明喻
  多用具体动作和细节代替
  人写的小说更多是隐喻 / 直接动作 · 而非"像..."
```

## 三 · AI 过渡句式（4 类）

```
AI 的场景过渡非常机械 · 4 个套路反复用：
```

| AI 过渡套路 | 修改建议 |
|---|---|
| **"时间过得很快 · 转眼就到了……"** | 直接切到目标时间点 |
| **"不知不觉中……"** | 删除 · 用具体时间标记 |
| **"就在这时……"** | 删除 · 直接接下一句 |
| **"正当他……的时候"** | 用动作打断（"门突然开了"）|

### 检测规则

```
□ 命中上述 4 套路任一 → 标记
→ 建议改为直接切入

人写小说的过渡：
  ✅ 用对话切场景
  ✅ 用动作切场景
  ✅ 用感官细节切（声音 / 气味 / 触觉）
  ✅ 用空行切（更克制）
```

## 四 · 三大句子层面检测规则

### 规则 1 · 句长检测

```
□ 单句超过 25 字 + 含 2 个以上逗号 → 标记
□ 连续 3 句都是长句（>20 字）→ 标记

建议：长短交替 · 节奏感更强
```

### 规则 2 · 逗号检测

```
□ 一句话中逗号超过 3 个 → 检查是否可以断句
□ 连续短句都以逗号结尾 → 合并或改用句号

AI 喜欢在每个可能的位置都加逗号 · 导致碎片化
人写：根据呼吸 / 节奏 / 强调来用逗号 · 不机械
```

### 规则 3 · 比喻密度

```
□ 每章比喻句超过 3 个 → 标记过多
□ 同一段连续 2 个比喻 → 标记

人写小说的比喻是稀缺品 · AI 是廉价品
```

## 五 · 结构层面检测

### 5.1 · 无意义总结句

```
AI 喜欢在对话或剧情之后加一段总结性文字 · 解释刚才发生了什么。

典型：
  ❌ 对话结束后接"这意味着……"
  ❌ 事件之后接"这让他明白了……"
  ❌ 场景转换时接"从某种意义上说……"

→ 检测：解释性总结句 · 直接标记删除
```

### 5.2 · 过度解释

```
AI 不信任读者的理解能力 · 总要把潜台词说出来。

典型：
  ❌ 角色做了一个动作 · 后面跟"这说明……"
  ❌ 对话中有明显的潜台词 · 但叙述还要再解释一遍
  ❌ 情绪已经通过动作展示 · 还要补一句"他感到……"

→ 检测：已经通过动作 / 对话展示的信息 · 再用叙述重复 → 标记删除
```

### 5.3 · 一本正经叙述腔

```
AI 写什么都像在写正式文章 · 缺少人味。

检测维度：
  □ 全文没有内心吐槽 → 标记"缺少人味"
  □ 全文没有幽默 / 自嘲 → 标记"过于严肃"
  □ 角色对话风格雷同 → 标记"角色同质化"

建议：适当加入内心吐槽 / 现代梗 / 打破第四面墙
```

### 5.4 · 角色无口癖

```
AI 写的角色说话方式都一样 · 没有个人特色。

检测维度：
  □ 主角没有固定口头禅或说话习惯 → 建议建立
  □ 配角说话方式与主角无区别 → 标记

建议：为重要角色建立语言标签（"老子"/"嘿嘿"/方言特征 等）
```

## 六 · 排版检测

```
AI 不注意手机端阅读体验。

检测维度：
  □ 单段超过 150 字 → 标记拆分
  □ 对话没有换行 → 标记
  □ 省略号使用不规范（应为"……"占两汉字宽）→ 标记
```

## AI 味检测 · 速查矩阵

| 检测层 | 项目 | 阈值 |
|---|---|---|
| **关键词** | 30+ 高频 AI 用词 | 命中即标记 |
| **比喻** | 5 类 AI 比喻模板 + 比喻密度 | 章内 >3 标记 |
| **过渡** | 4 类 AI 过渡套路 | 命中即标记 |
| **句长** | 单句字数 + 逗号数 | >25 字 + 2+ 逗号标记 |
| **结构** | 总结句 / 过度解释 / 叙述腔 | 命中即标记 |
| **角色** | 口癖 / 对话风格 | 缺失即建议 |
| **排版** | 段长 / 换行 / 省略号 | >150 字段标记 |

## 检测输出格式

```markdown
# AI 味检测报告 · [章节 / 段落]

## 严重程度：S / A / B / C / F
- 总评分：X / 10（反向：越低越好）

## 命中项
| 位置 | 类型 | 原文 | 建议修改 |
|------|------|------|----------|
| 第 X 段 | 高频用词 | "嘴角勾起一抹冷笑" | "他冷笑了一声" |
| 第 X 段 | 长难句 | "……" | 拆分为短句 |
| 第 X 段 | AI 比喻 | "像一盆冰水浇下来" | 删除明喻 · 用具体反应 |
| 第 X 段 | 过度解释 | "这意味着他已经被盯上了" | 删除 · 读者能推断 |

## 统计
- 高频用词命中：X 个
- AI 比喻数量：X 个（超标 / 正常）
- 长难句数量：X 个
- 过度解释：X 处
- 角色口癖：有 / 无
- 段落 >150 字：X 段

## 总评
[一段话总结 AI 味程度和主要问题]
```

## 实战检验法

### 写完每段 / 每章 · 5 项自检

- [ ] **30+ 关键词清单**逐一查（不命中 = 通过）
- [ ] **5 类 AI 比喻**逐一查
- [ ] **4 类 AI 过渡**逐一查
- [ ] **句长 / 逗号 / 比喻密度** 是否在阈值内
- [ ] **结构层 4 项**（总结句 / 过度解释 / 叙述腔 / 角色口癖）

### 整章自评

```
S 级（1-2 分）：完全没有 AI 痕迹 · 像老作家手写
A 级（3-4 分）：极轻微 · 偶有 1-2 处套路
B 级（5-6 分）：有一些 · 章内能识别
C 级（7-8 分）：明显 · 半段就能闻出来
F 级（9-10 分）：严重 · 一眼可知是 AI 生成
```

→ 商业项目目标：**B 级（5-6）以下**。

## 常见错误

```
❌ 每段都检测但不修改（检测无意义）
❌ 全删 AI 关键词 · 文笔变瘠（应是判断"用得对不对" 而非"绝对不用"）
❌ 比喻密度强行降到 0（人写小说也有比喻 · 关键是"非套路"）
❌ 角色口癖加得太刻意（"老子"出现 30 次 · 反而不像人）
❌ 修复 AI 味时用更 AI 的词替换（陷入"AI 修 AI" 套娃）
❌ 只查关键词 · 不查结构（漏掉过度解释 / 总结句）
❌ 把 AI 味检测当唯一标准（剧情和情感才是核心）
```
