# 情绪驱动 SOP · 4 车间 9 步工业化生产流程

> **来源**：墨香阁柒爷网文创作课《情绪篇 · 实战技巧》第九课「落地流程 · 情绪驱动的故事设计 SOP」。
> **定位**：driver 层 · **元流程整合型模块**（情绪驱动专属 SOP · 与 qdn-emotion-engine / pleasure-design / 其它 8 模块强协同）。
> **核心命题**：写情绪驱动故事 · 不是凭感觉 · 是**流水线作业**。4 车间 + 9 步 = 从立项到正文的完整工业化流程。
> **核心价值**：(1) 4 车间分工（构思 / 骨架 / 血肉 / 涂装）；(2) 9 步操作 + 自检；(3) 与人物 / 事件驱动 SOP 三足鼎立。

---

## 适用边界

✅ **强推荐启用**：
- 情绪驱动项目立项时
- 短剧 / 爽文 / 言情等以情绪为核心的项目
- 团队协作（多人写同一项目需要标准化流程）

⚠ **可选启用**：
- 情绪占主驱动 70%+ 的项目（部分流程通用）

❌ **不要启用**：
- 凭灵感 / 手工作坊式创作

## 车间 1 · 构思车间 · 定调性

> **核心任务**：确定"发动机"型号 · 在你只有几百字点子时就要决定的事。

### Step 1 · 选定"情绪卖点"

#### 为什么要做这步

```
不同类型的爽点 · 吸引完全不同的读者
想两头讨好（无脑爽 + 虐心深刻）= 两头不讨好
你需要在一开始就决定你的"主打菜"
```

#### 怎么做

**问自己**：我这个故事 · 主要是为了让读者感到——

| 选项 | 决策 |
|---|---|
| **掌控一切的爽**（求必得）| 选 emotion-needs-personas 模型 A |
| **感同身受的虐 / 感动**（求不得）| 选 emotion-needs-personas 模型 B |

#### 引擎选择

| 项目类型 | 推荐引擎 |
|---|---|
| 爽文 / 短剧 | 高频爽点引擎（emotion-engines-3 引擎 1）|
| 正剧 / 长篇 | 情绪过山车引擎（emotion-engines-3 引擎 2）|
| 复杂悬疑 / 长线连载 | 事件叠加引擎（emotion-engines-3 引擎 3）|

### Step 2 · 设定"初始匮乏"

#### 为什么要做这步

```
爽感 = 匮乏感的补偿
如果主角一开始什么都不缺
那他后面获得再多东西 · 读者也不会觉得爽
没有饥饿感 · 满汉全席也不香
```

#### 怎么做

在故事梗概的**第一句** · 必须明确写出主角"缺什么"。

##### 错误示范

> 张三是个很厉害的人 · 有一天他下山了。
> （读者 OS：哦 · 关我屁事。）

##### 正确示范

> 张三是个被家族遗弃、连狗都不如（缺尊严 / Q 值极低）的私生子 ·
> 为了拿回母亲唯一的遗物（缺情感寄托 / D 值极低）·
> 他发誓要杀回家族。

#### 自检

```
你的主角是不是一开始就很惨？
如果不够惨、不够缺 · 赶紧改！
```

### 车间 1 · 交付物

```
✅ 一句话故事定位（含情绪卖点）
✅ 引擎类型选定
✅ 初始匮乏明确（QD 起始位置）
```

## 车间 2 · 骨架车间 · 定事件

> **核心任务**：宏观"造势" · 排列故事里的大事件（转折点、里程碑）。
>
> **口诀**：大纲定起伏。

### Step 3 · 绘制"过山车曲线"

#### 为什么要做这步

```
小白容易写成流水账：
"打赢了 A · 然后打赢了 B · 然后打赢了 C……"
这种故事像一条直线 · 读者看着看着就困了
我们需要的是波浪线
```

#### 怎么做

拿出你的事件列表 · 检查它们的"冷热交替"。

##### 强制操作

```
在两个"爽点事件"之间 · 必须插入一个"至暗时刻事件"

例如：
  第 10 章 = 主角夺冠（高光）
  那第 8 章必须安排：主角受伤、被诬陷、差点退赛（至暗）
```

#### 自检

```
看你的大纲 · 有没有连续三个事件都是好消息？
如果有 · 删掉中间那个 · 换成一个坏消息！
```

### Step 4 · 埋设"震撼炸弹"

#### 为什么要做这步

```
普通的打怪升级只能"留住"读者
只有"震撼"能让读者"记住"你
震撼需要长期铺垫 · 必须在大纲阶段就设计好
否则后面根本圆不回来
```

#### 怎么做

利用 `shock-design-method` 的**三大失衡定律**（认知 / 能量 / 价值）· 专门设计你的高潮事件或结局。

##### 错误

```
"最后主角打败了大魔王。"
（这太普通了）
```

##### 正确

```
"最后主角发现 · 大魔王其实是他未来的自己（认知失衡）·
 他必须杀掉未来的自己才能拯救现在的世界（价值失衡）。"
```

#### 自检

```
你的结局是不是读者猜得到的？
如果是 · 能不能加一个"认知反转"？
```

### 车间 2 · 交付物

```
✅ 大纲（事件列表 · 含好坏交替的过山车曲线）
✅ 至少 1 个震撼炸弹（结局 / 关键转折）
✅ 至暗时刻位置已标注
```

## 车间 3 · 血肉车间 · 定情节

> **核心任务**：微观"入味"——大纲确定了"发生什么事" · 细纲要确定"这个事具体怎么演"。
>
> **口诀**：细纲定浓度。

### Step 5 · QDN 定向编程

#### 为什么要做这步

```
小白写情节很干巴："他很伤心。"
这种文字是没有感染力的
你需要用具体的画面来引发读者的化学反应
```

#### 怎么做

调用 `qdn-emotion-engine` · 别光写情绪词 · 要写"配方"。

##### 场景任务示例：父亲牺牲

###### 错误

```
"父亲死了 · 主角哭得很惨。"
```

###### 正确（QDN 化学式 = 悲 [-Q,-D,-N] 加重）

```
造 -Q（无力感）：
  主角跪在地上 · 想站起来但腿软得像面条

造 -D（绝望感）：
  冰冷的雨水打在他脸上 · 那是父亲最喜欢的雨天

造 +N（惊吓 / 意外 · 升级为愤怒）：
  父亲背后的刀 · 竟然是主角最信任的叔叔捅的
```

#### 自检

```
你的细纲里是不是只有"他很生气 / 伤心"这种词？
把它改成具体的动作和画面！
```

### Step 6 · 安装"拉扯放大器"

#### 为什么要做这步

```
单一情绪容易腻
通过信息差制造的"复合情绪" · 才更高级、更抓人
```

#### 怎么做

调用 `emotion-tug-3wrenches` · 在设计对话和过场戏时强行植入"信息差"。

##### 场景任务示例：男女主离别

###### 普通写法

```
两人依依不舍 · 挥手告别。
```

###### 拉扯写法（植入信息差）

```
男主笑着发誓："等我打完这仗 · 回来娶你。"
（男主视角：希望）

但一定要加一句旁白或镜头给观众看：
男主的绝症诊断书就藏在他身后的口袋里 · 他知道自己回不来了。
（观众视角：绝望）
```

#### 自检

```
这一场戏 · 是不是角色知道的和观众知道的一样多？
如果是 · 能不能让观众多知道一点残酷的真相？
```

### Step 7 · 规划"爽感四阶段"

#### 为什么要做这步

```
小白写爽文最大的问题是"早泄"——
铺垫不够就打了 · 或者打完就跑了
这会让爽感大打折扣
```

#### 怎么做

调用 `pleasure-design-method` · 在细纲里把每一个"爽感情节"拆分成 4 段。

| 阶段 | 配比 | 内容 |
|---|:---:|---|
| 1 · 压抑 | 30% | 反派怎么嘲讽？路人怎么看不起？（多写！）|
| 2 · 点燃 | 5% | 哪一句话/动作彻底引爆？（要短！）|
| 3 · 爆发 | 15% | 主角怎么一招制敌？（要快！）|
| 4 · 展示 | 50% | 反派怎么跪？美女怎么惊？大佬怎么夸？（重点 · 多写！）|

#### 自检

```
你的打脸戏 · 是不是打完就结束了？
有没有留出一半的篇幅来写别人的反应？
```

### 车间 3 · 交付物

```
✅ 细纲（每场戏的 QDN 配方 + 信息差 + 4 阶段配比）
✅ 关键情绪段落的具体画面 / 动作 / 台词设计
```

## 车间 4 · 涂装车间 · 控节奏

> **核心任务**：临场"执行"——保证读者"不跳读" · 并且"点开下一章"。

### Step 8 · 实施"情绪回落阻断"

#### 为什么要做这步

```
读者爽完之后是会进入"贤者时间"的
这时候最容易弃书
你必须在他冷静下来之前 · 给他新的刺激
```

#### 怎么做

调用 `emotion-amplifier`（情绪回落阻断技巧）· 在主角装完逼、打完脸 · 准备潇洒离场的时候——**禁止直接换场 / 睡觉**！

##### 强制操作

```
马上安排一个电话 / 一个意外 / 一声尖叫

例子：
  主角刚领完奖杯（爽点结束）·
  还没走下领奖台 ·
  警察突然冲进来把他铐走了（阻断成功 · 新悬念开始）
```

#### 自检

```
你的章节中间 · 有没有那种"大家都挺开心 · 然后各自回家"的段落？
如果有 · 在他们回家前搞点事！
```

### Step 9 · 挂上"结尾钩子"

#### 为什么要做这步

```
这是为了让读者付费、追更
每一章的结尾都是一个广告位 · 推销你的下一章
```

#### 怎么做

调用 `chapter-hook-3wrenches` · 在每一章的最后一行 · 使用"三把扳手"。

| 情况 | 扳手 | 操作 |
|---|---|---|
| **A · 这一章结局挺好** | 势能扳手 | 最后一句加个**坏消息反转**：他笑了 · 但身后的阴影里伸出了一只手 |
| **B · 这一章是情绪戏** | 动能扳手 | 把情绪变成**动作**：不要写"他很绝望" · 要写"他把那张全家福撕得粉碎" |
| **C · 这一章冲突打完了** | 裂变扳手 | 引入**新人物**：被打败的反派喊了一声"师父救我！" |

#### 自检

```
你的章节结尾是不是句号？
能不能改成问号或感叹号？
```

### 车间 4 · 交付物

```
✅ 每章中段的情绪回落阻断设计
✅ 每章末尾的钩子（势能 / 动能 / 裂变）
✅ 最终成品（紧凑、有力、全程高能）
```

## 与人物 / 事件驱动 SOP 的对照

| 维度 | 人物驱动 | 事件驱动 | **情绪驱动**（本 SOP）|
|---|---|---|---|
| 起点 | 4 维灵魂 | 产品定位 | **情绪卖点 + 初始匮乏** |
| 核心方法 | 正推 4→8→10 | 倒推 10→8 | **QDN 编程 + 信息差** |
| 节奏控制 | 自然弧光 | 6 步 SOP | **9 步 + 4 阶段配比** |
| 灵魂武器 | 矛盾驱动 | 可能性树 / 资源棋盘 | **震撼三大失衡** |
| 适用题材 | 言情 / 文艺 | 悬疑 / 权谋 | **爽文 / 短剧 / 虐文** |

→ 三种 SOP **互为补充** · 立项时根据 driver 选择。

## 总检验清单 · 4 期监工

> 以后写书 · 拿着这张表 · 像监工一样检查你的故事。

### 梗概期

- [ ] 主角**够不够惨**？缺不缺东西？（**没有匮乏不动笔**）

### 大纲期

- [ ] 有没有"**好坏好坏**"的波浪线？
- [ ] 高潮有没有**认知大反转**？

### 细纲期

- [ ] "打脸"有没有留足 **50% 的篇幅**给观众看戏？
- [ ] 对话有没有**加信息差**？

### 正文期

- [ ] 爽完有没有**马上出事**？
- [ ] 章尾有没有**留钩子**？
