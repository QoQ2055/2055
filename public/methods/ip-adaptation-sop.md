# IP 改编工业化 SOP · 清洗 + 对标 + 重构 三步法

> **来源**：V7.7 短剧分镜模板概念提取（去除平台/视频专用部分 · 重写为通用 IP 改编方法论）。
> **定位**：driver 层 · **改编流程型模块**（与 event-driven-sop / character-driven-sop / emotion-driven-sop 形成 SOP 四件套 · 但聚焦"改编"而非"原创"）。
> **核心命题**：fili-web 现有 modules 全部聚焦"**原创创作**" · 但**已有 IP 改编**这条工作流完全空白。本模块填补这个盲区——**长篇小说 → 短剧/网文/影视**的工业化改编 SOP。
> **核心价值**：(1) 三步法整合（清洗→对标→重构）；(2) 三大对标方向（国民 IP / 现实题材 / 动作奇观）；(3) 量化执行标准（前几集进主线 / 单场时长 / 对话上限）。

---

## 适用边界

✅ **强推荐启用**：
- 长篇小说改编短剧 / 影视
- IP 跨媒介改编（小说→漫画 / 漫画→剧）
- 网文连载改电视剧 / 电影
- 经典作品现代化改编

⚠ **可选启用**：
- 同人衍生（部分采用 · 主要看原作骨架保留度）

❌ **不要启用**：
- **完全原创项目**（请用 driver-blueprint-method + 对应 SOP）
- 散文 / 诗歌（非情节性作品）

---

## 核心心法 · 改编 ≠ 复述

```
新手最常见错误：
  把原著从头到尾"读出来" · 一字不漏
  → 慢热 / 拖沓 / 失去原著精华

正确改编逻辑：
  改编 = 把"长篇文字" 转换为 "短篇视觉/快节奏" 的能量转换器
  
  需要：
  ├─ 砍掉 70-90% 内容（清洗）
  ├─ 找到正确目标受众（对标）
  └─ 重组为现代节奏（重构）

→ 不是删减 · 是转化
→ 不是缩写 · 是重铸
```

### 三步法总览

```
┌──────────────────────────────────────────────────┐
│  第一步 · 清洗（Wash）                            │
│   去水 + 去油 + 提炼情绪点                        │
│   → 砍到只剩"骨头 + 高能时刻"                     │
└──────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────┐
│  第二步 · 对标（Benchmark）                       │
│   选定三大方向之一（国民 IP / 现实 / 动作奇观）   │
│   → 锁定改编风格 · 不四不像                       │
└──────────────────────────────────────────────────┘
                       ↓
┌──────────────────────────────────────────────────┐
│  第三步 · 重构（Rebuild）                         │
│   加钩子 + 加节奏 + 加冲突                        │
│   → 重组为现代连载 / 短剧节奏                     │
└──────────────────────────────────────────────────┘
```

## 第一步 · 清洗（Wash）★ 砍到只剩高能

### 三种清洗类型

#### 清洗 A · 去水（删除铺垫赘述）

| 删除目标 | 具体操作 |
|---|---|
| **慢热铺垫** | 第 1-3 集（章）必须直接进主线 · 不允许"开场介绍世界观再展开" |
| **世界观赘述** | 设定不通过"作者讲解" · 通过角色行动 / 对话 / 字幕弹窗自然带出 |
| **心理描写** | 内心活动 ≠ 戏剧 · 必须外化为行动 / 表情 / 台词 |

##### 实战示例

**❌ 原著（去水前）**：
> 林深站在窗前 · 想起了三年前的那个夜晚。那时他还是个普通的实习生 · 对未来充满憧憬。父亲告诉他要好好学习 · 母亲为他做了拿手菜……（300 字内心独白）

**✅ 改编（去水后）**：
> 林深站在窗前 · 看着办公楼下的夜雨。
> 他想起父亲那句话——"做事要狠"。
> 然后转身 · 拿起手机：
> "通知董事会 · 明早九点。"

→ 300 字铺垫 → 60 字行动。

#### 清洗 B · 去油（替换过时爽点）

```
不同时代的"爽点"不同：
  10 年前的爽点 ≠ 今天的爽点
  
原著如果是 5+ 年前作品 · 必须替换：
  ├─ 老式霸总（"我什么时候说过我喜欢你了？"）→ 替换为干脆利落
  ├─ 矫情男主（"我这是为你好"）→ 替换为直接行动派
  ├─ 玛丽苏开局（突然有钱/突然有人爱）→ 替换为渐进式打脸
  └─ 长篇道歉戏（"对不起我错了"）→ 替换为行动证明
```

#### 清洗 C · 提炼情绪点

```
从原著中提取最突出的情绪内核：
  问题：这部作品的"情绪关键词"是什么？
        （仅 1-3 个）

例：
  《琅琊榜》→ 隐忍 / 复仇 / 兄弟情
  《甄嬛传》→ 步步为营 / 黑化 / 意难平
  《三体》→ 恐惧 / 渺小 / 终极抉择

→ 改编时围绕这 1-3 个核心情绪展开
→ 偏离这些情绪的内容 · 即使精彩 · 也要砍
```

### 清洗执行标准

| 维度 | 量化标准 |
|---|---|
| **进主线** | 第 1-3 集（前 10%）必须见主线冲突 · 不能再铺垫 |
| **保留比例** | 一般砍到 10-20%（即压缩比 5-10:1）|
| **核心情绪** | 锁定 1-3 个 · 全片围绕展开 |
| **去水检查** | 任何"作者解释"都是删除候选 |

## 第二步 · 对标（Benchmark）★ 选定方向

### 三大改编方向

#### 方向 1 · 国民 IP 路线

```
适用题材：神话 / 名著 / 历史
核心策略：放大复仇与逆袭 · 不讲流水账

操作：
  ├─ 用观众最熟悉的人物
  ├─ 讲他们没看过的"燃爆故事"
  └─ 经典桥段做现代化重写

经典案例：
  《西游记》改编 → 不讲全程 · 只讲孙悟空被压五指山的"前夜"复仇
  《白蛇传》改编 → 不讲恋爱 · 只讲法海视角的"AI 法师 vs 人妖"
```

##### 优势 / 风险

| ✅ 优势 | ❌ 风险 |
|---|---|
| 观众熟悉度高 | 期待管理难 |
| 自带话题 | 改编争议（粉丝反弹）|
| 营销容易 | 不能太离谱 |

#### 方向 2 · 现实题材路线

```
适用题材：非遗 / 年代 / 职场 / 行业
核心策略：放大专业度和反差爽感

操作：
  ├─ 把专业知识变成主角"打脸别人的武器"
  ├─ 突出行业潜规则 / 真实困境
  └─ 用专业碾压式爽感代替传统打脸

经典案例：
  非遗类 → 主角用古老技艺解决现代问题
  职场类 → 普通员工用专业能力打脸领导
  年代类 → 90 后视角看 60 年代的物质匮乏
```

##### 优势 / 风险

| ✅ 优势 | ❌ 风险 |
|---|---|
| 真实感强 · 共鸣度高 | 专业度门槛 |
| 题材政策友好 | 难做出爽感 |
| 易出"金句" | 易拍成纪录片 |

#### 方向 3 · 动作 / 奇观路线

```
适用题材：玄幻 / 武侠 / 仙侠 / 修真
核心策略：放大视觉奇观和打斗节奏

操作：
  ├─ 台词少 · 动作多
  ├─ 前 3 秒必须见"大招"
  ├─ 利用环境打斗（不是站桩对轰）
  └─ 视觉冲击 > 剧情逻辑

经典案例：
  《一人之下》→ 一上来就是"清风诀"VS"金光咒"对轰
  《诛仙》→ 开篇就是张小凡屠村现场（视觉冲击）
```

##### 优势 / 风险

| ✅ 优势 | ❌ 风险 |
|---|---|
| 视觉爆款率高 | 制作成本高 |
| 不依赖台词 · 海外友好 | 剧情容易薄 |
| 短视频传播好 | 同质化严重 |

### 对标方向决策树

```
原著有"大众熟悉的角色 / 故事"？
├─ 是 → 国民 IP 路线
└─ 否 → 进入下一问

原著的"主角能力"是专业知识 / 现实技能？
├─ 是 → 现实题材路线
└─ 否 → 进入下一问

原著有大量"超现实战斗 / 奇观"内容？
├─ 是 → 动作 / 奇观路线
└─ 否 → 重新考虑（可能不适合改编）
```

## 第三步 · 重构（Rebuild）★ 重组节奏

### 三种重构类型

#### 重构 A · 加钩子

```
原著的"自然结尾" 不是改编的"集结尾"

每集结尾必须重新设计钩子：
  优先方案：动作未完成 + 画面切断
  
  操作：
  ├─ 在主角"举刀劈下"时切断 · 不让劈到
  ├─ 在主角"拨通电话说出第一个字"时切断
  └─ 在反派"枪口对准"主角的瞬间切断

→ 让观众必须看下一集才知道结果
```

#### 重构 B · 加节奏

```
原著节奏 ≠ 改编节奏

量化标准：
  ├─ 单场戏不超过 2 分钟（120 秒）
  ├─ 单集不超过 3-5 个主要场景
  ├─ 信息密度比原著高 3-5 倍
  └─ 每 30-40 秒必须有一个情绪小高峰

→ 原著一章可能改成 2-3 集
→ 也可能 5 章压缩到 1 集
```

#### 重构 C · 加冲突

```
原著的"温吞过渡" 必须改成"硬冲突"

操作：
  ├─ 废话立刻转场（不能让角色"思考一会儿"）
  ├─ 连续对话镜头不超过 4 个（视觉疲劳）
  ├─ 每个场景必须带"冲突 / 信息 / 反转"至少 1 个
  └─ 没有冲突的场景 = 删除候选

→ 改编后的节奏：每个场景都"在干活"
→ 没有"喘气场景"
```

### 重构量化标准

| 维度 | 量化标准 |
|---|---|
| **单场戏时长** | ≤120 秒 |
| **连续对话镜头** | ≤4 镜 |
| **集结尾钩子** | 100% 必须 · 优先动作未完成 |
| **情绪高峰频率** | 30-40 秒 1 个 |
| **信息密度** | 原著的 3-5 倍 |

## 实战完整流程

### 阶段 1 · 原著分析（开工前）

```
1. 通读原著 · 记录情绪点位置
2. 提取核心情绪关键词（1-3 个）
3. 判断对标方向（IP / 现实 / 动作奇观）
4. 估算压缩比（多少字 → 多少集）
```

### 阶段 2 · 清洗（删减）

```
5. 砍掉所有"作者讲解"
6. 砍掉所有"内心活动 > 行动"段落
7. 砍掉所有"过时爽点"
8. 砍到只剩骨架 + 高能时刻
```

### 阶段 3 · 对标（定位）

```
9. 锁定三大方向之一
10. 按方向重写主角的"打脸 / 复仇 / 奇观"路径
11. 调整故事重心（如非遗 → 突出专业度）
```

### 阶段 4 · 重构（重组）

```
12. 设计每集结尾钩子（100% 覆盖）
13. 切分场景（单场 ≤120 秒）
14. 检查情绪高峰密度（30-40 秒 1 个）
15. 删除"无冲突场景"
```

### 阶段 5 · 校验

```
16. 单集是否前 3 秒就有冲突？
17. 单集是否有 1-2 句"金句"？
18. 集结尾钩子是否够强？
19. 整剧是否围绕核心情绪展开？
```

## 常见错误

```
❌ 直接把原著文字改成对话（最常见错误 · 节奏死亡）
❌ 保留原著所有内心活动（拖沓）
❌ 改编后还有"开场介绍"（前 3 集必须进主线）
❌ 三大方向选错（武侠选了"现实题材"路线 → 失去观众）
❌ 集结尾留一个"自然段落"（不是钩子 · 是收尾）
❌ 单场戏超过 3 分钟（节奏崩）
❌ 连续对话超过 4 镜（观众疲劳）
❌ 偏离核心情绪（增加"作者觉得有意思但观众不要"的内容）
❌ 试图保留原著"所有细节"（注定失败）
```

- [ ] **原著分析**完整（情绪点 + 压缩比 + 对标方向）

- [ ] **对标方向唯一**（不混用三大路线）
- [ ] **每集结尾有钩子**（动作未完成优先）
- [ ] **单场戏 ≤120 秒**
- [ ] **连续对话 ≤4 镜**
- [ ] **核心情绪贯穿全剧**
