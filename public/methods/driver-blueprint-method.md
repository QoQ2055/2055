# 故事三驱动蓝图法 · 配方学 + 选型决策

> **来源**：墨香阁柒爷网文创作课《故事的发动机 · 三大核心驱动》第六课。
> **定位**：driver 层 · **元知识 / 选型决策型模块**（与现有 3 driver modules 互补 · 不互斥）。
> **核心命题**：**商业创作的本质 = 做选择题**。不能"既要又要还要" · 必须根据产品定位（长篇/短剧/电影）选择主驱动 · 再用其它两驱动作为有轻有重的辅料。
> **核心价值**：(1) **配方学**——三大理论（信息差/预期/节奏）如何按主辅料组合成 3 driver；(2) **3 角度应用**（宏观/中观/微观）；(3) **错配大忌**避坑；(4) **选型口诀**快速决策。

---

## 适用边界

✅ **强推荐启用**（**所有项目立项必读**）：
- 任何商业写作项目（爽文 / 短剧 / 言情 / 玄幻 / 推理 / ...）
- 立项阶段尚未确定主驱动时
- 已写过项目想"复盘选型是否正确"

⚠ **可选启用**：
- 已确定主驱动 + 单 driver 实操 → 阅读对应 character/event/emotion-driven-method 即可
- 不再需要 meta 选型工具

❌ **不要启用**：
- 实验性 / 反类型作品（故意打破 driver 选择规律）
- 同人 / 命题作文（产品定位已固定）

## 第一部分 · 三大理论 × 3 driver 配方学 ★ 核心枢纽

### 命题：3 driver = 三大理论的不同主辅料组合

```
三大理论（前 5 批已落库）：
  ├─ 信息差魔术（戏剧的火花）
  ├─ 预期管理（故事的骨架）
  └─ 节奏控制（情绪的阀门）
```

→ 不存在"3 理论平均拉满" · 必须分主次。

### 配方对照表

| 驱动 | 信息差 | 预期管理 | 节奏控制 |
|---|---|---|---|
| **人物驱动** | 主料 1（人物魅力 + 身世好奇）| 主料 2（共情羁绊）| 辅料（允许慢）|
| **事件驱动** | 辅料（希区柯克炸弹）| 主料 1（压力恐惧）| 主料 2（紧迫感）|
| **情绪驱动** | 主料 1（剧烈反差）| 辅料（情绪自带预期）| 主料 2（高效传递）|

### 配方详解

#### 人物驱动 · 主料 = 信息差(身世) + 预期管理(共情)

**信息差 · 主料 1**：
- 不直接看透主角 · **像剥洋葱一样**层层揭开秘密
- 表面（已知）：废柴 / 普通人 / 边缘人
- 内里（未知）：眼神沧桑 / 偶尔流露的本事 / 神秘背景
- → 观众产生"他到底是谁？经历过什么？"的**长线好奇**

**预期管理 · 主料 2**：
- 把主角的渴望 → 变成观众的渴望
- 主角悲惨 + 内心希望 → 观众产生"老母亲心态"
- "我不能看他失败" → 长线情感羁绊

**节奏 · 辅料**：
- 培养感情需要时间（不能一上来结婚）
- 允许大量心理描写 / 生活细节
- 慢节奏 = 因为观众愿意花时间了解主角

→ **特点**：韧性最强（写百万字观众都爱看）· 烈度较弱 · 适合**长篇陪伴型**产品

#### 事件驱动 · 主料 = 预期管理(压力) + 节奏(紧迫)

**预期管理 · 主料 1**：
- 故事开头给观众画"即将爆发的事件"
- 例："三天后 · 丧尸围城 · 全城都要死"
- → 观众想知道结果："到底能不能活？"

**节奏 · 主料 2**：
- 必须有"倒计时"（炸弹还有 5 分钟）
- 不能让主角谈恋爱 / 回忆童年（拖泥带水）
- 每个情节都为"拆弹"服务 · 快准狠

**信息差 · 辅料（特殊用法 · 希区柯克炸弹理论）**：
- **观众的信息量 > 主角**
- 观众知道桌子底下有炸弹 · 主角还在打牌
- 不是制造爽感 · 是制造**"替主角着急"的焦虑感**

→ **特点**：韧性与烈度平衡 · 结构最完整 · 适合**电影 / 悬疑剧 / 中篇**

#### 情绪驱动 · 主料 = 信息差(反差) + 节奏(冲刺)

**信息差 · 主料 1**：
- 拉得越大越好（**反差**）
- 爽文：主角是世界首富（隐形）/ 反派以为是乞丐（表象）→ 差距越大 · 打脸越爽
- 虐文：女主快死了（观众知）/ 男主还在误会装病（不知）→ 误会越大 · 哭得越惨

**节奏 · 主料 2**：
- "百米冲刺"
- 铺垫委屈 ≤ 300 字 → 马上爆发
- 铺垫 3 万字未打脸 → 情绪断了
- 精准控制每个爽点的密度

**预期管理 · 辅料**：
- 极端情绪本身**自带预期**
- 看到坏人极致作恶 → 天然产生"他必须死"的预期
- 不需要作者额外费力设计预期蓝图

→ **特点**：烈度最强 · 韧性不足（吃多了会麻木）· 适合**短篇 / 付费短剧 / 沙雕漫**

## 第二部分 · 3 角度应用（宏观/中观/微观）

### 宏观：故事承载什么主题？

| 驱动 | 主题方向 | 经典作品 |
|---|---|---|
| 人物驱动 | **成长与命运** | 凡人修仙传 / 哈利·波特 / 阿甘正传 |
| 事件驱动 | **考验与挑战** | 流浪地球 / 名侦探柯南 / 三体 |
| 情绪驱动 | **欲望与宣泄** | 赘婿 / 虐恋短剧 / 重生爽文 |

### 中观：故事的风格长什么样？

| 驱动 | 视角风格 | 关键描写 |
|---|---|---|
| 人物驱动 | **世界大 · 上帝视角全** | 像上帝俯瞰众生 · 展现人物在时代中的沉浮 |
| 事件驱动 | **聚焦现场 · 真实细腻** | 像纪录片 · 逻辑严丝合缝 · 不能有 BUG |
| 情绪驱动 | **主观视角 · 代入感强** | 第一人称"我"或紧贴主角 · "我爽不爽"才重要 |

### 微观：动笔前优先准备什么？

| 驱动 | 第一步 | 第二步 | 第三步 |
|---|---|---|---|
| 人物驱动 | **设计人物**（反差/弱点/魅力）| 不急想剧情 | 人物立住 → 故事自然来 |
| 事件驱动 | **设计困局**（无解的难题）| 滴答倒计时 | 压力够了 → 故事自然好看 |
| 情绪驱动 | **研究用户**（读者是谁/想看什么）| 找情绪痛点 | 围绕痛点 → 编故事 |

→ 建立"动笔前优先级"避免**先想错方向 · 后期返工**。

## 第三部分 · 错配大忌深化 ★

### 铁律 · 主次分明 · 众星捧月

混合不代表"平均分配"。**一个成功的故事 · 必须只有一个"主驱动"** · 其它两种作为有轻有重的辅助。

观众的注意力 / 你的文字分配 = **有上限**。全拉满 → 观众累 / 乱 / 弃。

### 错配 1 · 用"人物驱动"思维写"付费短剧" · 拖拉机上赛道

**错误场景**：
- 短剧前 10 集慢悠悠铺垫
- 主角童年多么不幸 / 性格多么内向 / 喜欢吃红烧肉…
- 想塑造立体深度人物

**为什么死**：
- 短剧用户 = 碎片化（地铁 / 厕所 · 几分钟）
- 要 **烈度**（瞬间爽 / 反转）· 不要**韧性**（慢慢品）
- 第 3 集还在童年 = **观众滑走**

**正确做法**：
- 即使想写人物成长 · 在短剧里**先用情绪驱动开路**
- 上来给主角一巴掌（强冲突）→ 留住观众
- 再在冲突中慢慢带出人物性格

### 错配 2 · 用"情绪驱动"思维写"长篇小说" · 长途货车装硝化甘油

**错误场景**：
- 200 万字小说
- 第 1 章打脸岳母 · 第 2 章打脸富二代 · 第 3 章打脸战神
- 短期数据好看
- 50 万字时：主角除了"会打脸"是个**空壳** · 没亲情 / 没软肋 / 没成长

**为什么死**：
- 长篇读者 = 沉浸式 · 要**陪伴**
- 单纯情绪刺激 = 吃辣椒（第 1 口爽 · 连吃 3 天反胃）
- 主角无魅力 → 读者不关心命运 → **审美疲劳 → 弃书**

**正确做法**：
- 长篇必须以**人物驱动为核心**
- 可以用情绪（打脸）吸引读者**进门**
- 但必须尽快让读者**爱上人物**才能陪走百万字

### 经典案例对照 · 复仇者联盟

```
主驱动：人物驱动 ← 灵魂
辅驱动：事件驱动 ← 舞台

观众买票最在乎的：钢铁侠会不会死？美队会不会老？雷神会不会振作？
如果换成无名机器人 + 同等打斗 → 无聊弃片

灭霸打响指（事件）= 巨大压力容器
逼迫英雄们必须团结
让人物魅力在极致压力下展现

事件是舞台 · 人物是舞者 · 事件为人物服务
```

→ **辅驱动是为主驱动服务的** · 不可喧宾夺主。

## 第四部分 · 选型口诀

### 想写让人哭、笑、陪过日子（长篇 / 剧集）
```
首选：人物驱动
口诀：先立人，后生事，事为人变
```

### 想写让人紧张、手心出汗、猜不到结局（电影 / 悬疑）
```
首选：事件驱动
口诀：先设局，后入人，人在局中
```

### 想写让人上头、充钱、欲罢不能（短剧 / 爽文）
```
首选：情绪驱动
口诀：先找点（爽点 / 痛点），后爆破，人是引线
```

### 选型决策树

```
[Q1] 你的产品是什么？
  ├─ 长篇连载（≥ 30 万字）/ 电视剧 / 动漫 → 人物驱动
  ├─ 电影 / 悬疑剧 / 中篇（5-30 万字）→ 事件驱动
  └─ 短剧（10-30 集）/ 爽文 / 沙雕漫 → 情绪驱动

[Q2] 你的目标用户是谁？
  ├─ 沉浸式陪伴型（B2 关系者型）→ 人物驱动
  ├─ 烧脑思考型（B1 部分 / 智识型）→ 事件驱动
  └─ 碎片化即时满足（B1 掌控者 / B3 逃避者）→ 情绪驱动

[Q3] 你的目标平台？
  ├─ 起点 / 番茄 / 七猫长篇 → 人物驱动 主 + 情绪驱动 辅
  ├─ 抖音短剧 / 听花岛 → 情绪驱动 主 + 信息差 辅
  ├─ 漫画 / 动漫 → 人物驱动 主 + 事件驱动 辅
  └─ 严肃文学 → 人物驱动 主 + 事件驱动 辅
```

## 检验清单（dogfood 时人工抽检）

- [ ] 项目立项**显式选定主驱动**（不能模糊）
