# 系统分析六子系统（Six Systems Analysis）

> **来源**：SKILL-010 项目圣经模板节录提炼。原模板完整 9 章归档到 `@docs/prompt-archives/project-bible-template-v1.md`，本模块只保留 LLM 注入期可用的"六子系统设计硬律"。
> **定位**：craft 工艺层 · **世界观细化模块**（注入 `novel.1.1`，与 `world-building-9-pillars` **正交叠加**）。
> **分工**：
> - `world-building-9-pillars`：9 柱世界观**宏观骨架**（势力格局是粗粒度）
> - **本模块**：六子系统**微观运转规则**（政治如何运转 / 经济如何分配 / 战争如何爆发 / 金融如何危机）

---

## 适用边界

✅ **强推荐**（系统复杂度高）：
- 权谋 / 宫斗 / 政治
- 商战 / 金融 / 经济
- 科幻 / 硬科幻 / 末世 / 赛博朋克
- 架空历史 / 历史架空

✅ **推荐**（部分子系统适用）：
- 玄幻 / 仙侠（门派 / 资源 / 战争复杂时）
- 悬疑（涉及政商勾结时）

⚠ **可选**（只填政治 + 经济）：
- 现代都市 / 言情（弱化使用）

❌ **不推荐**：
- 校园 / 治愈 / 日常 / 短篇
- 单一场景 / 密室封闭题材（系统层面不重要）

---

## 一、六子系统总览

世界观的"运转层"必填 6 个子系统（按题材选择性填充，**至少填 3 个**）：

| # | 子系统 | 必填字段 | 核心硬律 |
|---|---|---|---|
| 1 | **政治系统** | 权力结构 + 关键政治冲突 + 对叙事的影响 | 权力流转方式必须明确 |
| 2 | **军事系统** | 武装力量架构 + 战斗等级 + 战争规则 | "什么情况打 / 什么情况不打"必须清晰 |
| 3 | **经济系统** | 货币体系 + 资源分配逻辑 + 阶级与财富关系 | 货币背后必须有锚定物 |
| 4 | **商业系统** | 主要商业势力 + 垄断格局 + 黑市经济 | 垄断结构推动剧情冲突 |
| 5 | **金融系统**（可选） | 金融工具制度 + 债务杠杆 + 危机机制 | 危机机制即剧情催化剂 |
| 6 | **魔法 / 科技系统** | 能量来源 + 使用代价 + 等级体系 + 硬性限制 | "什么不能做"比"能做什么"更重要 |

**填充原则**：每个子系统的最后一栏必须写**对叙事的影响**——若填不出来，说明该子系统是无效设定，应删除或简化。

## 二、六子系统详解 + 硬律

### 子系统 1 · 政治系统

**必填三段**：

```
【权力结构】
顶层：（决策者 / 名义权威 / 实权派）
中层：（执行层 / 既得利益集团）
底层：（无权者 / 抗争者）
权力流转方式：（世袭 / 选举 / 武力 / 财力 / 神授）
```

```
【关键政治冲突】
（至少 1 条贯穿全书的政治矛盾）
```

```
【对叙事的影响】
（这套系统如何改变主角的选择？）
```

**硬律**：
- **S1.1**：权力结构必须有**至少 3 层**（顶/中/底），否则就是扁平化空架子
- **S1.2**：**权力流转方式**必须具体到一个动词（如"世袭" / "靠功勋" / "靠押注皇位"）
- **S1.3**：政治冲突必须能**驱动至少 1 条主线 / 大支线**

### 子系统 2 · 军事系统

**必填**：
- 武装力量架构（常备军 / 民兵 / 雇佣兵 / 修士 / 异能者）
- 战斗等级体系（如有）
- 战争 / 冲突规则

**硬律**：
- **S2.1**：**战争触发条件必须明确**——什么情况下会打？什么情况下不会打？
- **S2.2**：若有战斗等级体系，**每一级必须对应代表人物**（与 `world-building-9-pillars` 柱 5 协同）
- **S2.3**：必须有**军事禁忌或停战机制**（如"不杀俘"/"修士不入凡战"），否则战争烈度无上限

### 子系统 3 · 经济系统

**必填**：
- 货币体系（货币种类 + 锚定物 + 流通范围）
- 资源分配逻辑（按需 / 按劳 / 按权 / 按血脉）
- 阶级与财富关系

**硬律**：
- **S3.1**：货币必须有**锚定物**（黄金 / 灵石 / 算力 / 信用 / 神迹），否则是无源之水
- **S3.2**：**资源稀缺性**必须明确——什么稀缺 → 什么是冲突焦点
- **S3.3**：阶级与财富的关系必须**双向流动**（向上 / 向下渠道分别是什么）

### 子系统 4 · 商业系统

**必填**：
- 主要商业势力
- 垄断 / 竞争格局
- 黑市 / 地下经济

**硬律**：
- **S4.1**：**垄断结构**是商战类小说的核心冲突源
- **S4.2**：**黑市必有**——任何明面经济系统下都存在地下经济，是反派 / 灰色角色的栖息地
- **S4.3**：商业势力与政治势力的**勾结关系**必须明确（哪个商家背靠哪个政治势力）

### 子系统 5 · 金融系统（可选 / 商战金融题材必填）

**必填**：
- 金融工具 / 制度（票号 / 期货 / 信贷 / 保险 / 灵脉债券）
- 债务 / 杠杆 / 危机机制
- 对剧情的影响

**硬律**：
- **S5.1**：**金融危机机制 = 剧情催化剂**——什么情况下会爆发金融危机？这往往是中后段剧情高潮的引爆点
- **S5.2**：**杠杆与风险必须成正比**，不能有"无风险高收益"的金融工具

### 子系统 6 · 魔法 / 科技系统

**必填**：
- 能量来源
- 使用代价
- 等级 / 分类体系
- **硬性限制（什么不能做）**

**硬律**（**最核心**）：
- **S6.1**：**"什么不能做"比"能做什么"更重要**——能力清单写一行就够，限制清单必须写满
- **S6.2**：能量来源必须**有限**（不能"凭空召唤"），否则金手指无限强
- **S6.3**：使用代价必须**实际生效**——若代价从未真正影响主角，就是装饰

## 四、与其他模块协同

### 与 `world-building-9-pillars`（**最佳搭档**）

- 9 柱法：宏观世界观骨架（柱 3 势力格局是**粗粒度**）
- 本模块：微观运转规则（**细粒度**）
- 例子：9 柱柱 3 写"玄门沈家 vs 彼岸"（势力名 + 关系）；本模块子系统 1 政治写**玄门的权力流转规则**（祖师指定 / 弟子推举 / 修为决断），子系统 2 军事写**玄门与彼岸的开战阈值**

### 与 `supernatural-webfiction-pack`

- 子系统 6（魔法）的"能量来源 + 使用代价 + 硬性限制"= 超自然包的"魔法物品三维结构"
- 双开时，魔法物品按超自然包编码，魔法体系按本模块子系统 6 设计

### 与 `plot-coherence-scaffold`

- 子系统级冲突（政变 / 战争 / 金融危机）= 跨章因果链的**大节点**
- 本模块定**冲突结构**，plot-coherence 定**因果回响**

### 与结构骨架

- 子系统 5（金融危机）和子系统 1（政变）天然适配 **三幕式 / Save the Cat 中点**
- 子系统 2（战争爆发）天然适配 **英雄之旅"试炼之路"** 阶段

## 五、硬律自检（写作前 / 修订时）

LLM 输出世界观文档前必须自检：

- [ ] 至少填了 3 个子系统？
- [ ] 每个子系统的"对叙事影响"是否填了具体内容？
- [ ] 政治权力流转方式是否具体到一个动词？
- [ ] 经济货币是否有锚定物？
- [ ] 魔法 / 科技的限制清单是否长于能力清单？
- [ ] 任意子系统的设定能否触发一次主线 / 大支线冲突？

任一不满足 → 子系统设计需重做。

---

## 六、一句话原则

> **世界观不是介绍，是机器。六子系统是这台机器的传动结构——政治传导权力，经济传导资源，军事传导暴力，商业传导利益，金融传导风险，魔法 / 科技传导可能性。每条传动失灵的地方，就是剧情冲突爆发的地方。**
