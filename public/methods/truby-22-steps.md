# 约翰·特鲁比 · 22 步故事结构（深度人物驱动骨架）

> **来源**：John Truby 《故事写作大师班》，迪士尼 / 华纳御用编剧导师。
> **定位**：结构层骨架 · **人物驱动 / 深度剧情 / 权谋 专用**。与其他结构骨架互斥。
> **核心价值**：业内公认的"人物 + 剧情双在线"模板。每一步**同时推进剧情和人物成长**，彻底解决"事件堆砌但人物脱节"的问题。

---

## 适用边界

✅ **推荐启用**：
- 人物驱动型长篇小说（主角弧光极强）
- 权谋 / 宫斗 / 政治小说
- 严肃文学 / 成长小说
- 复仇 / 救赎 / 堕落主题
- 多层伪装揭露的故事（间谍 / 卧底 / 身份剧）

❌ **不要启用**：
- 爽文 / 快节奏网文（22 步颗粒度过细，节奏跟不上）
- 单元剧（本法是单一长弧结构）
- 言情（请用林赛·多兰七要点）
- 悬疑（请用三宅隆太 12 步）

## 一、22 步框架（核心）

### 第一部分 · 前提与设计（1–4 步）

| # | 步骤 | 核心内容 |
|---|---|---|
| **1** | **弱点 + 需求** | 主角内在**致命弱点**（character flaw）+ 必须解决的**人生需求**（moral need） |
| **2** | **欲望**（Desire） | 主角的**外在核心目标**（与需求不同，甚至冲突） |
| **3** | **对手**（Opponent） | 与主角**欲望相同**的强力对手（核心冲突来源，不是单纯反派） |
| **4** | **计划**（Plan） | 主角为达欲望的初始行动方案 |

**硬律**：需求（内在成长）与欲望（外在目标）**必须不同**。如果一致，主角就不需要成长，只需要执行。

### 第二部分 · 对抗升级（5–12 步）

| # | 步骤 | 核心内容 |
|---|---|---|
| **5** | 第一幕对抗 | 主角初次遭遇对手，计划受挫 |
| **6** | 盟友出现 | 支持性角色介入（但盟友常是**表里不一**的） |
| **7** | 考验与选择 | 主角面临**第一次道德抉择** |
| **8** | 对手加大压力 | 主角被逼向更极端的选择 |
| **9** | **伪装自我揭露**（False Self-Revelation） | 主角**对自己撒的谎**被揭穿——但他以为"自己已经认清了自己" |
| **10** | **第二幕中点：真正自我揭露** | 中点处，主角**第一次真正看见自己的弱点**（但尚未改变） |
| **11** | 考验升级 | 真相被看见后，外部压力达到顶点 |
| **12** | 主角的选择 | **道德层面的抉择**：坚守弱点 / 开始改变 |

### 第三部分 · 终极对决与蜕变（13–22 步）

| # | 步骤 | 核心内容 |
|---|---|---|
| **13** | 对决准备 | 主角与对手各自做最后部署 |
| **14** | 终极对决 | 主角与对手最终对抗 |
| **15** | **真实自我揭露**（True Self-Revelation） | 主角在对决中**彻底认清自己**，完成内在蜕变 |
| **16** | 过渡 | 进入新世界（物理或心理） |
| **17** | 新的平衡点 | 主角完成蜕变，进入全新人生状态 |
| **18** | 结局 | 所有故事线收束 |
| **19** | 主题表达 | 故事的核心观点浮出 |
| **20** | 形象画面押韵 | 结尾画面**与开头形成对照**（结构美学） |
| **21** | 复合主题 | 多层主题共振（副线与主线互证） |
| **22** | 故事高潮 | 主人公**最终那一个选择**（往往是极小但极重的动作） |

## 二、核心硬律（防人物脱节）

### 2.1 需求 ≠ 欲望（本法魂）

**硬律**：第 1 步「需求」（内在必须解决的）与第 2 步「欲望」（外在想要的）**必须不同或对立**。

- ✅ 欲望：报仇；需求：学会放下 → 复仇完成但失去所有
- ✅ 欲望：成为总统；需求：学会信任他人 → 当选但孤独
- ✅ 欲望：找到父亲；需求：承认自己已长大 → 找到后反而离开
- ❌ 欲望：当英雄；需求：变强 → 同向，无矛盾
- ❌ 欲望：赚钱；需求：成功 → 同向，无成长

### 2.2 对手必须与主角共享同一欲望

**硬律**：第 3 步「对手」**不是单纯反派**。对手和主角**想要同一样东西**（王位 / 女人 / 真相 / 宝物），这才是最深的冲突。

**示例**：
- 《教父》：迈克与死对头都想要家族（不是好人 vs 坏人）
- 《这个杀手不太冷》：里昂与 Stansfield 都想**掌控小女孩**（保护 vs 消灭）
- 《黑天鹅》：妮娜与莉莉都想要**完美主角的位置**

### 2.3 两次自我揭露的差距必须巨大

**硬律**：第 9 步「伪装自我揭露」与第 15 步「真实自我揭露」**必须层级差异巨大**。

- 伪装自我揭露：主角以为自己看清了（如"我原来是怕失败"）
- 真实自我揭露：主角真正看清了（如"我其实是怕被爱"）

伪装揭露让主角**感到自己已经成长**（虚假安全感），真实揭露才让他真正崩塌重建。

### 2.4 盟友必须是"镜像"

**硬律**：第 6 步「盟友」最好与主角**有同类弱点但处理方式不同**（或同类处境做出不同选择）。这样盟友才是主角的镜子。

- 纯工具盟友（提供信息 / 打手）会让主角独立性崩塌

### 2.5 结局画面必须与开场押韵

**硬律**：第 20 步「形象画面押韵」不是选项，是必做。开场第一个画面 + 结尾最后一个画面必须**形成视觉对照**（同一场景不同状态 / 相同构图反向动作）。

- 《美国丽人》：开场俯拍小镇 → 结尾俯拍尸体
- 《阿甘正传》：开场羽毛落下 → 结尾羽毛飞起

## 三、三种典型 22 步变体

### 3.1 复仇弧（外在达成，内在失去）

```
1 弱点：无法放下过去
2 欲望：报仇
3 对手：仇人（他们都想独占"正义"的定义权）
9 伪装揭露：我为了正义而复仇
15 真实揭露：我其实是在用复仇逃避悲伤
22 最终选择：完成复仇 / 放下复仇（二择都是蜕变）
```

### 3.2 救赎弧（从错误到救赎）

```
1 弱点：曾犯下无法弥补的错
2 欲望：逃避过去 / 买赎罪券
3 对手：受害者的遗族 / 自己的良心化身
9 伪装揭露：我已经付出足够多了
15 真实揭露：救赎不是代价而是承担
22 最终选择：直面 / 承担
```

### 3.3 堕落弧（消极蜕变）

```
1 弱点：自傲 / 无法承认脆弱
2 欲望：权力 / 完美
3 对手：比主角更极端的版本（未来的自己）
9 伪装揭露：我只是在追求我应得的
15 真实揭露：我已经成为了我最恨的人
22 最终选择：坚持堕落 → 悲剧收场
```

## 四、章节分配参考（按 30 万字超长篇）

| 部分 | 步骤 | 字数占比 |
|---|---|---|
| 前提与设计 | 1–4 | 5%（1–2 章） |
| 对抗升级 | 5–12 | 45%（包含第 9–10 步两次揭露高潮） |
| 终极对决与蜕变 | 13–22 | 50% |

**硬律**：第 10 步「中点真正自我揭露」应精确落在 50% ± 5%。这是全书最重要的结构支点。

## 五、与其他模块协同

- **与其他结构骨架**：互斥。本模块颗粒度远细于三幕式，与 Save the Cat / 英雄之旅 / 三幕式 / 起承转合 / ATU 301 不共存。
- **与 `mbti-cognitive-functions`**：**极强协同**（最佳搭档）。第 1 步「弱点」可直接对应 MBTI 劣势功能，第 15 步「真实自我揭露」对应 Jung 个体化的"自性涌现"阶段。两套方法论天然共振。
- **与 `mbti-16-archetype-cards`**：协同。对手设计可使用「阴影 = 最鄙视类型」公式（主角最鄙视 X 型，对手就是极端 X 型）。
- **与 `plot-coherence-scaffold`**：强协同。22 步对伏笔回收要求极高，需要一致性脚手架守护。
- **与 `pixar-22-rules`**：协同。Pixar 第 4 条（一次一个主角弧）+ 第 14 条（"你为什么要讲这个故事"）与本法内核一致。
- **与 `seven-emotion-peaks`**：强协同。宏观 22 步 + 单章情绪锚点，双层节奏支撑 30 万字级别的长篇张力。
- **与 `visual-dehydration`**：弱冲突。本法需要厚心理描写（尤其第 9、15 步），脱水法会压缩这类描写厚度。
