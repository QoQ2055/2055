# 角色视觉 ID 卡 · 5 维外观锁定 + 跨章节一致性

> **来源**：Work-Fisher 视频分镜模板 V3 第 1.4 节"角色视觉 ID 卡"概念提取（去除视频专用部分 · 重写为小说写作专用）。
> **定位**：character 层 · **角色外观锁定型模块**（与 character-skin-design / character-810-blueprint 强协同）。
> **核心命题**：长篇小说最常见的"角色描述漂移"问题——同一个角色在第 1 章是"长发飘飘的女孩" · 到第 50 章变成了"短发利落的女孩" · 作者自己都忘了。**5 维 ID 卡 = 角色外观的工业化锚点**。
> **核心价值**：(1) 跨章节角色描写一致性；(2) LLM 反复重生成时的视觉锚定；(3) 多角色项目的角色辨识度对照。

---

## 适用边界

✅ **强推荐启用**：
- 长篇小说（>10 万字 · 易出现描写漂移）
- 多角色项目（>5 个主要角色）
- LLM 辅助写作（防止生成时角色形象漂移）
- 改编 / IP 项目（需要保持原作角色一致性）

⚠ **可选启用**：
- 短篇 / 单元剧（角色相对稳定 · 部分采用）

❌ **不要启用**：
- 散文 / 第一人称内心独白（无外观描写需求）

---

## 核心心法 · 锚点比描写更重要

### 痛点

```
新手作者最常见错误：
  第 1 章：林晚是一个长发的女孩 · 笑起来很温柔
  第 30 章：林晚利落的短发在风中飘动
  第 60 章：林晚的卷发被汗水打湿
  
→ 同一个角色 · 三个发型
→ 读者出戏
→ 作者自己都忘了

LLM 辅助写作时更严重：
  每次生成都"重新发明"角色外观
  没有锚点 → 每次都不同
```

### 解决方案 · ID 卡机制

```
ID 卡 = 角色外观的"宪法"
       一旦确定 · 跨章节锁死
       不允许漂移

每次写到角色 · 不需要每次重新描述
       → 引用 ID 卡的"视觉签名"即可
       → 一句话激活全套外观
```

### 核心原则

```
锚点 > 描写
特征 > 全貌
独特性 > 通用性
```

## 5 维视觉 ID 卡 ★ 核心格式

### ID 卡模板

```
角色视觉 ID 卡
├─ [角色名]
│  ├─ 体型：[身高体态 · 一句话]
│  ├─ 面部锚点：[2-3 个最具辨识度的面部特征]
│  ├─ 发型 / 发色：[精确描述]
│  ├─ 基础服装：[默认着装 · 可被场景覆盖]
│  └─ 视觉签名：[一个标志性视觉元素]
```

### 5 维详解

#### 维度 1 · 体型

**要求**：**一句话**写出身高体态。

**核心**：不要堆形容词 · 给一个**比例感 / 力量感**。

| ✅ 好示范 | ❌ 差示范 |
|---|---|
| 高挑紧致 · 腿长腰细但肩线有力 | 长得很漂亮 |
| 精瘦高个 · 骨架宽但肉量少 | 身材很好 |
| 体态臃肿 · 走路重心靠后 | 比较胖 |
| 标准身材 · 不瘦不胖 · 穿衣服不出错但也不出挑 | 普通身材 |

#### 维度 2 · 面部锚点 ★ 最关键

**要求**：**2-3 个最具辨识度**的面部特征。

**核心**：不写"五官端正""眉清目秀"——**写差异化特征**。

##### 好的面部锚点公式

```
[具体部位] + [独特状态 / 形状] + [情感暗示]
```

##### 示例对比

| ✅ 好示范 | ❌ 差示范 |
|---|---|
| 冷锐眼尾上挑 · 薄唇永远微抿 · 颧骨线条分明 | 长得很美 |
| 眉骨深 · 下颌线硬 · 永远带一丝没睡醒的松弛 | 帅气阳光 |
| 眉眼清冷如霜覆寒松 · 笑起来右侧有极浅酒窝（几乎没人见过）| 长得很冷 |
| 眼下有淡淡的细纹（加班留下的）· 笑起来好看但很少笑 | 工作辛苦 |

→ 注意：每个锚点都**带一点性格暗示** · 不只是外观。

#### 维度 3 · 发型 / 发色

**要求**：**精确描述** · 不能漂移。

| ✅ 好示范 | ❌ 差示范 |
|---|---|
| 利落黑色高马尾 · 战斗中不散 | 黑色长发 |
| 半长深棕碎发 · 额前总有一缕遮眼 | 棕色头发 |
| 黑色齐肩发 · 永远别在耳后 | 短发 |
| 油亮黑发紧梳在脑后 · 一丝不苟（古装管事嬷嬷）| 古装发型 |

→ 关键词：**长度 + 颜色 + 状态 + 标志性细节**。

#### 维度 4 · 基础服装

**要求**：**默认着装** · 可被场景覆盖。

##### 写法

```
基础服装 = 角色"日常会穿什么"
         不是"今天穿什么"
         不是"这一场戏穿什么"
```

##### 示例

| 角色定位 | 基础服装示范 |
|---|---|
| 战士 | 暗色战术紧身衣+高跟战靴 |
| 浪荡 | 敞口机车夹克+灰色工装裤 |
| 末等宫女 | 灰蓝色末等宫女粗布衣裳 · 袖口磨毛边 |
| 都市白领 | 黑色通勤西装外套+白T+阔腿裤 |

#### 服装覆盖规则

当某场戏角色着装与基础服装不同时 · 使用**覆盖标记**：

```
@角色：老 K → ID 卡[服装覆盖：007 式高定燕尾服+黑色漆皮鞋]
@角色：沈昭宁 → ID 卡[服装覆盖：尚仪局浅青色女官服制]
```

→ 覆盖只针对**单场戏** · 不改变 ID 卡基础设定。

#### 维度 5 · 视觉签名 ★ 标志性元素

**要求**：**一个**标志性视觉元素 · 能让读者一眼认出角色。

**核心**：**唯一性** · 这个东西其他角色不会有。

##### 类型分类

| 类型 | 示例 |
|---|---|
| **饰品** | 右手腕银色细链环 / 左耳银色耳钉 / 脖子上三圈金链 |
| **伤疤** | 左手腕内侧一道旧疤（关键身份标记）/ 右手无名指有一圈戒指印（离婚后摘掉的痕迹）|
| **道具** | 手中永远攥着那根竹戒尺（管事嬷嬷）|
| **姿态习惯** | 左肩旧伤位置 · 阴天时会无意识抬手按压 |
| **特殊体征** | 左眼比右眼大一点（罕见但极辨识）|

##### 视觉签名的双重作用

```
1. 辨识度：读者一眼认出这是哪个角色
2. 伏笔功能：可以承载剧情（如旧疤=身份秘密 / 戒指印=过往婚史）
```

→ 高级用法：**视觉签名 = 剧情伏笔**。

## 实战书写规则

### 规则 1 · 引用而非重写

**写作时**：

```
❌ 错误：
  第 1 章：林晚是一个标准身材的女子 · 黑色齐肩发别在耳后 ·
           眼下有淡淡的细纹……（每次都重新描述全套）

✅ 正确：
  第 1 章：林晚走进会议室 · 习惯性地把齐肩发别在耳后。
            （只激活视觉签名 + 1 个动作）
  第 30 章：她无名指上那圈戒指印还没消……
            （只激活视觉签名）
```

### 规则 2 · 视觉签名优先

```
每次提及角色 · 优先用"视觉签名"作为辨识标记
其它维度按场景需要选择性提及

→ 视觉签名 = 角色的"商标"
→ 用得越多 · 读者印象越深
```

### 规则 3 · 服装覆盖只在场景需要时使用

```
重要场景（如：婚礼 / 葬礼 / 重大社交）→ 覆盖
普通日常 → 不写服装 · 默认基础服装
```

### 规则 4 · 锚点不能改

```
ID 卡一旦写定 · 不允许中途改变：
  ❌ 长发改短发（除非是剧情节点 · 如自我重生）
  ❌ 视觉签名替换（除非角色"摘下"或"获得"新签名）

→ 改动 = 必须有剧情解释
→ 不能"作者忘了"
```

## ID 卡管理建议

### 单角色项目

```
1 个 ID 卡 · 直接放在 character bible 文档开头
```

### 多角色项目（5+ 角色）

```
所有 ID 卡集中放在 character bible 顶部
排序：主角 → 配角 → 反派 → 重要工具人

每个 ID 卡之间留空行 · 视觉清晰
```

### 长篇连载

```
建议建立"ID 卡变更日志"：
  - 何时（哪一章）
  - 何变（如：长发剪短）
  - 何因（剧情驱动）

→ 防止后期混乱
```

## 与 LLM 协作的最佳实践

### Prompt 模板

```
你写一段关于 [角色名] 的描写。
该角色的视觉 ID 卡如下：
  [完整 5 维 ID 卡]

要求：
  - 不要重复 ID 卡所有内容（读者已知）
  - 优先激活视觉签名 + 1-2 个面部锚点
  - 服装：[基础 / 覆盖：X]
  - 不允许偏离 ID 卡设定
```

### 检验

每次 LLM 生成段落后 · 检查：

- [ ] 描写是否**与 ID 卡一致**？
- [ ] 没有**新发明**的外观特征？
- [ ] 视觉签名**至少出现一次**？
- [ ] 服装与场景**逻辑一致**？

## 实战检验法

### 写完 character bible · ID 卡 5 维自检

- [ ] 体型**一句话**说完？
- [ ] 面部锚点**2-3 个**（不多不少）？
- [ ] 锚点是**差异化特征**（不是"长得好看"）？
- [ ] 发型**精确**（颜色 + 长度 + 状态 + 细节）？
- [ ] 基础服装**符合角色定位**？
- [ ] 视觉签名**唯一**（其他角色没有）？
- [ ] 视觉签名**有辨识度**（读者能记住）？

### 写完一卷 · 角色一致性自检

- [ ] 所有角色描写**与 ID 卡一致**（无漂移）？
- [ ] 视觉签名**至少每章出现 1 次**？
- [ ] 服装覆盖**有标记**（不是随意改）？
- [ ] 没有发明**ID 卡之外**的特征？

## 常见错误

```
❌ 面部锚点写成"五官端正"（毫无辨识度）
❌ 视觉签名写成"长得漂亮"（不是物理特征）
❌ 5 个维度全堆形容词（没有差异化）
❌ 服装写得太死（没有覆盖空间）
❌ 中途改变 ID 卡（剧情未解释 · 是 bug 不是 feature）
❌ ID 卡只写主角 · 配角混乱
❌ 用"她长得很美"代替具体描写（视觉锚点失效）
```

```
角色视觉 ID 卡 · [角色名]
├─ 体型：[一句话身高体态]
├─ 面部锚点：[2-3 个差异化特征]
```
