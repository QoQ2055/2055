# 梦境强化真实感 · 理性脑警察催眠 3 手法

> **来源**：墨香阁柒爷网文创作课《观众心理学与梦境关系》第二课「梦境三大指标 · 指标三」。
> **定位**：dream 层 · **守梦型模块**。**几乎所有 fili-web 项目都应启用**（除严肃文学）。
> **核心命题**：观众**理性大脑像梦境警察** · 时刻寻找逻辑漏洞 · 一旦发现就把观众从梦中叫醒。我们的工作就是用各种方法**贿赂和催眠这个警察**。
> **核心价值**：用 3 个手法压制理性脑、激活感性脑，让观众"在情感上认同"从而主动忽略逻辑缺失。

---

## 适用边界

✅ **强推荐启用**（几乎全部）：
- 都市爽文 / 玄幻升级 / 系统流 / 重生流
- 短剧 / 动态漫
- 甜宠 / 大女主 / 言情
- 武侠 / 仙侠（除硬核武侠）

⚠ **可选启用**（适度采用）：
- 现代正剧（部分采用 · 不能完全压制理性）
- 慢热成长向（少用 OS 强解，多用情感渐进）

❌ **不要启用**：
- 严肃文学 / 纯文学（理性碰撞是卖点）
- 硬核悬疑推理（事件逻辑严谨是卖点）
- 硬科幻（科学合理性是卖点）
- 反讽 / 黑色幽默（让读者保持理性距离）

---

## 核心心法 · 真实感悖论

```
观众明知道这是假的（梦）→ 但渴望它感觉是真的
理性大脑（警察）：寻找逻辑漏洞 → 一旦发现 → 强制醒来
我们的工作：在警察找到漏洞前 → 用情感淹没他 / 给他官方解释 / 让其他人佐证主角"对"
```

→ **不是消灭逻辑漏洞**（不可能）· 而是**淹没理性脑**让它来不及质疑。

## 3 大手法 · 实操指引（LLM 提示词）

### 手法 1 · 逻辑的"扬情抑理"

**核心**：故事推进**完全由角色情绪驱动**，而非复杂的现实因果。

**做法**：
- 角色态度转变**不需要现实中漫长的过程** → 一件事瞬间从"恨"变"爱"，从"轻视"变"崇拜"
- 困难**简化** / 挑战**直接** · 不需要观众思考
- **直给** · 不要刺激观众的理性脑

**反例**（激活理性脑 → 出戏）：
- ❌ "经过 3 个月的相处，配角逐渐发现主角的善良本质…"（理性："这逻辑链太长了"）
- ❌ "解决这个商业危机需要 5 个步骤：第一步…"（理性："这是商战教科书"）
- ❌ "因为受国际政治影响，公司股价下跌 3%…"（理性："信息密度过载"）

**正例**（激活感性脑 → 沉浸）：
- ✅ "她看着他的眼睛，那一刻，多年的恨意烟消云散，只剩下心疼。"（感性："多浪漫啊"）
- ✅ "主角眼神一冷，反派当场跪下：'大佬，是我有眼无珠。'"（感性："好爽！"）
- ✅ "随手一指，对方公司股价瞬间跌停。"（感性："碾压感！"）

**关键判断**：写完一段 · 自问"读者读到这里会停下来思考吗？"
- 会 → 重写 · 简化逻辑 / 强化情绪
- 不会 → 通过

**LLM 注入**：
```
章节生成 (novel.3.1 / novel.3.2) 强制：
- 角色情绪转变的字数 ≤ 200 字（瞬间转变 · 不解释为什么）
- 复杂因果链 → 单线情绪因果（"X 让 Y 怎样了"，不是"因为 A 所以 B 所以 C"）
- 信息密度审查：每段是否有"非情绪 / 非动作"的信息（数据 / 解释 / 推理）→ 删除或包装为情绪
```

### 手法 2 · 强化反馈认同（氛围组群体催眠）★ 爽文核心

**核心**：主角的任何行为 → 周围角色（**氛围组**）必须**极其夸张地、一边倒地反馈**。这是**守护梦境最核心的技巧**。

**做法**：
- 主角展示实力 → **所有人**倒吸冷气、惊呼"恐怖如斯！"
- 主角说一句骚话 → 立刻有配角吐槽 / 接梗，**说出观众的心声**
- 主角处理事情 → 周围人感叹"果然厉害" / "我从未见过如此…"
- **所有人都要表现出同一种情绪**（震惊 / 崇拜 / 羡慕 / 恐惧）

**目的**：**群体性催眠** · 当故事里所有人都表现出同一种情绪时，观众下意识认为"我的感觉是对的，大家都是这么想的，所以这一切都是真实的"。

**反例**（破坏催眠）：
- ❌ 主角秒杀反派 · 围观者无反应（观众："为什么没人惊讶？"→ 出戏）
- ❌ 围观者各有看法（观众："这个人觉得没什么大不了…"→ 怀疑主角真的厉害吗）
- ❌ 反派被打后不服 · 嘴硬（观众："好吧，反派觉得也没什么…"→ 主角威严打折）

**正例**（强化催眠）：
- ✅ 主角秒杀反派 → 围观者 5 个不同身份的人**全部**惊呼 + 倒吸冷气 + 颤抖
- ✅ 反派的小弟亲眼目睹后跪地求饶："大哥饶命！再给我一次机会！"
- ✅ 主角说话后 · 旁边小妹捂嘴："好酷啊！"，老大爷点头："这年轻人不简单！"
- ✅ 反派被打后**当场态度 180 度反转**（恶吼 → 跪求 / 求加入主角阵营）

**氛围组配置标准**：
- 每个爽点场景 ≥ 3 个氛围组成员（不同身份 · 全部反馈一致情绪）
- 反派被打后**必须立刻服软**（不能还嘴硬 · 否则削弱主角威严）
- 配角"说出观众心声"作为内置 OS（"这就是大佬吗？"/"这一手太牛了！"）

**LLM 注入**：
```
章节生成 (novel.3.1 / novel.3.2) 爽点场景必含：
- 氛围组反馈（≥ 3 个不同身份角色 · 全部表达同一情绪）
- 反派被打后服软（不能嘴硬 · 必须态度 180 度转变）
- 配角"说出观众心声"OS（"这就是大佬吗" / "我从未见过如此…"）
```

### 手法 3 · OS（内心独白）的强行解释

**核心**：在观众**即将产生疑问**的节点 → 用主角或旁白的 OS **直接给出"官方解释"**，**堵住观众的思考路径**。

**目的**：不给梦境警察（理性大脑）提出疑问的机会。在警察开口之前 → 用一个简单粗暴的答案打发掉。

**适用媒介**：
- 短剧 / 动态漫（OS 是核心叙事手段）
- 网文（适度使用）
- 长篇小说（少用 · 影响文学品味）

**做法**：
- 观众可能产生的"疑问点"前置出现 OS 给出解释
- OS 必须**简短粗暴**（≤ 30 字）· 不能展开
- OS 风格匹配主角性格（霸总冷酷 / 修真高深 / 现代调皮）

**反例**（让观众思考）：
- 主角面对反派威胁不慌张 → 没有解释（观众："为什么不慌？是真的有底气还是装的？"）
- 主角拒绝美女投怀送抱 → 没有解释（观众："这反人性？还是有原因？"）
- 主角放过明显的复仇机会 → 没有解释（观众："为什么放过？心慈手软？"）

**正例**（堵住思考）：
- 主角面对反派威胁不慌张 + OS：「这种程度的小角色 · 我连出手都觉得浪费时间」
- 主角拒绝美女投怀送抱 + OS：「我心里只有一个人 · 其他都是浮云」
- 主角放过反派 + OS：「让你多活几天 · 看你能蹦跶到几时」

**OS 类型库**（LLM 可选）：
| 类型 | 触发场景 | 模板 |
|---|---|---|
| **优越感型** | 主角面对挑战不在意 | "这种小事不值得我出手" |
| **专情型** | 主角拒绝诱惑 | "我心里只有 [X]" |
| **猫戏型** | 主角延迟反击 | "急什么 · 让你再蹦跶几天" |
| **蔑视型** | 反派挑衅 | "这种水平也敢叫嚣？" |
| **回忆型** | 关键决策 | "这让我想起当年…" |

**LLM 注入**：
```
章节生成时（适用项目）：
- 主角行为可能引发观众疑问 → 立即穿插 OS 解释（≤ 30 字）
- OS 风格匹配主角设定（霸总 / 修真 / 现代）
- 短剧 / 动漫项目：OS 密度 ≥ 每 2 段 1 次 · 长篇小说：每章 2-3 次
```

## 3 手法协同 · 真实感锚定

```
                ┌─ 扬情抑理（情绪洪流淹没理性）
                │
理性脑警察 ──→ 被压制 ←─ 反馈认同（群体共识催眠 · "大家都是这感觉"）
                │
                └─ OS 强解（在质疑出现前堵住）
                          ↓
                   观众主动忽略逻辑漏洞 · 沉浸继续
```

**3 手法缺一**：
- 缺扬情抑理 → 理性脑保持活跃 → 容易出戏
- 缺反馈认同 → 观众不确定自己的感受是否对 → 沉浸感下降
- 缺 OS 强解 → 观众产生疑问 → 强制思考 → 醒梦

## 检验清单（dogfood 时人工抽检）

- [ ] 每个爽点场景**都有 ≥ 3 个氛围组反馈**（不同身份角色 · 一致情绪）
- [ ] 反派被打后**当场态度反转**（不能嘴硬到下一章）
- [ ] 主角"反常行为"**前置 OS 解释**（不能让观众停下来思考）
- [ ] 角色情绪转变**单段内完成**（≤ 200 字 · 不能跨章铺垫）
- [ ] **0 段落**含"复杂逻辑链"（A → B → C → D · 必须简化或情感包装）

## 范例 · 守梦三件套实施模板

每个爽点场景按此模板写：

```
[1. 主角行为]      主角 [一句话动作 · 显示力量 / 智慧 / 魅力]
[2. 氛围组反馈]    ★ 必须 ≥ 3 个不同身份角色立刻反应：
                   - 角色 A（敌方）：恐惧 / 服软
                   - 角色 B（中立）：震惊 / 崇拜
                   - 角色 C（友方）：自豪 / 兴奋 · 说出观众心声
[3. 主角 OS]      ★ 简短解释主角"为什么这样" / "接下来怎样"（≤ 30 字）
[4. 反派态度反转]  ★ 反派当场服软（求饶 / 投降 / 改换阵营）
[5. 推进下一爽点]  钩子开启下一个爽点 / 憋点
```

→ LLM 按此模板生成 · 真实感自然守护。
