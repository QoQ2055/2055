# MBTI · 认知功能派角色设计法（Beebe 八功能模型）

> **来源**：用户上传《MBTI 认知功能角色设计方法论》，基于 John Beebe 原型模型 + von Franz 劣势功能理论。
> **定位**：角色层深度方法论。**与 `mbti-5step`（简化版 MBTI 五步法）互斥**——同一项目只能选一个。
> **核心理念**：**功能优先于类型**。不是"我要写 INTJ → 查行为清单"，而是"我的角色以 Ni 为主导 → 类型自然浮现"。

---

## 适用边界（**先看清楚再启用**）

✅ **推荐启用**：
- 严肃文学 / 文艺向 / 心理深度导向
- 多主角群像 / 每个主要角色都需要明显内在张力
- 角色有清晰成长 / 堕落 / 整合弧线（不是简单打怪升级）
- 反派需要有深度（不是工具人 / 纸片人）
- 慢节奏 / 长线铺陈 / 读者愿意读心理细描

❌ **不要启用**（改用 `mbti-5step`）：
- 爽文 / 快节奏商业网文 / 系统流 / 无限流
- 单主角爽点驱动 / 配角主要是工具人
- 短篇 / 中篇体量紧张
- 读者只要 MBTI 风味点缀，不要深度剖析

> 启用本模块的注入开销 ≈ 900 token，是简化版的 1.5 倍。**只在文学性需求明确时启用**。

## 一、八认知功能速查（角色的心理镜头）

### 1.1 感知功能（摄取世界信息）

| 功能 | 时间取向 | 注意力 | 日常行为 | 压力反应 (Grip) | 语言标记 |
|---|---|---|---|---|---|
| **Ni** 内倾直觉 | 未来"它将通向…" | 收敛聚焦找底层模式 | 战略性沉默；长远布局；忽视当下享乐 | 执着单一负面愿景；与现实脱节 | "这通向…""时候未到" |
| **Ne** 外倾直觉 | 未来"它可能是…" | 发散跳跃生成多种可能 | 联想跳跃；抗拒单一 commit | 可能性间疯狂跳跃无锚点 | "如果我们…？""还有另一种可能" |
| **Si** 内倾感觉 | 过去"这让我想起…" | 回溯比对经验模板 | 引用过去；重视传统；渐进改变 | 沉溺负面记忆循环 | "以前是怎么做的""细节很重要" |
| **Se** 外倾感觉 | 现在"正在发生…" | 即时扫描感官刺激 | 即时行动；感官敏锐；活在当下 | 冲动感官寻求；鲁莽冒险 | "现在就开始""别想了做吧" |

### 1.2 判断功能（做决策）

| 功能 | 核心标准 | 决策速度 | 冲突处理 | 语言标记 |
|---|---|---|---|---|
| **Te** 外倾思考 | 外部效率 + 可测量结果 | 快，先行动再调整 | 结果导向，不惜打破和谐 | "最有效的是…""别废话，行动" |
| **Ti** 内倾思考 | 内部逻辑一致性 | 慢，需完整逻辑框架 | 真理导向，逻辑高于人情 | "逻辑上说不通""定义你的术语" |
| **Fe** 外倾情感 | 群体和谐 + 他人需求 | 中等，需读取群体反应 | 调和导向，回避直接对抗 | "大家感觉如何？""这样会让人不舒服" |
| **Fi** 内倾情感 | 个人价值真实性 | 慢，需与内心对齐 | 原则导向，宁可孤立不妥协 | "这对我真实吗？""我不能违背…" |

### 1.3 同一行为的驱动力鉴别（硬律）

**写任何角色行为必须追问"为什么这样做"**，而非只写"做了什么"：
- 「整理房间」：Si 为秩序 / Te 为效率 / Se 享受动手过程 —— 三种根因写出来的章节气质完全不同
- 「关心下属」：Fe 想"他们会怎么想" / Fi 想"我怎么看这件事" / Te 算"士气影响产出"

## 二、四功能位置原型（Beebe 意识模型）

每个角色由**四个有意识功能**（位置 1–4）+ **四个阴影功能**（位置 5–8）组成"内在议会"：

| 位置 | 原型 | 意识程度 | 角色体验 | 叙事呈现 |
|---|---|---|---|---|
| **1st 主导** · 英雄 | 完全意识 | "这就是我" | 主动使用，流畅自信，引以为傲 |
| **2nd 辅助** · 好父母 | 高度意识 | "我也擅长" | 关心他人时调用，略刻意 |
| **3rd 第三** · 永恒少年 | 间歇意识 | "很有趣但做不到持续" | 放松时的爱好，压力下的逃避 |
| **4th 劣势** · 阿尼玛 | 边缘意识 | "渴望但不理解" | 最不想暴露的弱点，也是最高理想 |

### 2.1 位置的叙事用途（硬律）

- **主导 = 身份** ：角色一出场的招牌行为
- **辅助 = 关怀方式** ：他怎么对待最亲的人
- **第三 = 可爱缺陷** ：「既想保护又想摇晃」的特质 —— **最容易写出来的魅力点**
- **劣势 = 成长引擎** ：全书弧线的终极考题 ——  "第四功能永远是人生的大问题"（von Franz）

### 2.2 十六型堆叠速查（前四功能）

| 类型 | 1st | 2nd | 3rd | 4th | 阴影（5–8） |
|:-:|:-:|:-:|:-:|:-:|:-:|
| INTJ | Ni | Te | Fi | Se | Ne-Ti-Fe-Si |
| INFJ | Ni | Fe | Ti | Se | Ne-Fi-Te-Si |
| ENTJ | Te | Ni | Se | Fi | Ti-Ne-Si-Fe |
| ENFJ | Fe | Ni | Se | Ti | Fi-Ne-Si-Te |
| INTP | Ti | Ne | Si | Fe | Te-Ni-Se-Fi |
| INFP | Fi | Ne | Si | Te | Fe-Ni-Se-Ti |
| ENTP | Ne | Ti | Fe | Si | Ni-Te-Fi-Se |
| ENFP | Ne | Fi | Te | Si | Ni-Fe-Ti-Se |
| ISTJ | Si | Te | Fi | Ne | Se-Ti-Fe-Ni |
| ISFJ | Si | Fe | Ti | Ne | Se-Fi-Te-Ni |
| ESTJ | Te | Si | Ne | Fi | Ti-Se-Ni-Fe |
| ESFJ | Fe | Si | Ne | Ti | Fi-Se-Ni-Te |
| ISTP | Ti | Se | Ni | Fe | Te-Si-Ne-Fi |
| ISFP | Fi | Se | Ni | Te | Fe-Si-Ne-Ti |
| ESTP | Se | Ti | Fe | Ni | Si-Te-Fi-Ne |
| ESFP | Se | Fi | Te | Ni | Si-Fe-Ti-Ne |

**关键规律**：每类型的阴影四功能 = 其 E/I 相反类型的前四。INTJ 的阴影（Ne-Ti-Fe-Si）正是 ENTP 的前四 —— **INTJ 压力下会浮现劣化版 ENTP 行为**。这是写"反常但可信"行为的公式。

## 三、阴影渐进激活（反派 + 主角黑化引擎）

压力越大，阴影功能位次越深：

| 位 | 原型 | 压力等级 | 核心行为 | 叙事功能 |
|---|---|---|---|---|
| 5 | 对立人格 | 轻度 | 顽固抵抗；唱反调；防御性投射 | 主角追求目标时自我设限 |
| 6 | 长老 / 女巫 | 中度 | 严苛批判；羞辱；使失去行动力 | 暴露内在审判声音，自我瘫痪 |
| 7 | 小丑 / 骗子 | 严重 | 制造悖论；欺骗；混乱 | 解构确定性，迫使面对认知盲区 |
| 8 | 恶魔 / 守护神 | 极端危机 | 毁灭性爆发 or 超越性转变 | 最黑暗时刻 or 最深刻顿悟 |

## 四、关系设计矩阵（群像张力引擎）

### 4.1 四组功能轴

| 轴 | 性质 | 核心冲突 | 共享类型群 |
|---|---|---|---|
| Ni ↔ Se | 挑战型 | 长远愿景 vs 即时行动 | NJ ↔ SP |
| Ne ↔ Si | 共生型 | 变化探索 vs 传统稳定 | NP ↔ SJ |
| Te ↔ Fi | 互补型 | 结果导向 vs 原则优先 | TJ ↔ FP |
| Ti ↔ Fe | 互补型 | 真理追求 vs 关系维护 | TP ↔ FJ |

### 4.2 五种关系配对模式（写主配 / CP / 对手戏时必选其一）

| 模式 | 条件 | 叙事效果 | 示例 |
|---|---|---|---|
| **同轴互补** | 共享同一轴方向相反 | 最强化学反应 | INTJ ↔ ESFP |
| **对轴冲突** | 主导功能来自不同轴 | 世界观层面的战争 | TJ ↔ FJ |
| **交叉轴张力** | 共享一个功能不共享完整轴 | 暧昧张力 + 持续误解 | INTJ ↔ ENTP |
| **镜像共振** | 同一功能同向 | 灵魂伴侣 or 危险相似 | INFJ ↔ INTJ |
| **功能真空** | 双方均不擅长某轴 | 该领域反复失败 → 团队须找缺失功能 | 纯 TJ+TP 群像缺情感视角 |

### 4.3 群像八功能覆盖原则（硬律）

**完整群像必须覆盖全部 8 种认知功能**。创建群像后列出每个功能的"代表角色"——缺谁，那维度的叙事就单薄。

## 五、五步角色设计流程

### Step 1 · 功能锚定（**不先定类型**）

用下列问题反推主导功能：

| 场景 | 问题 | 指向 |
|---|---|---|
| 走进陌生房间 | 注意可能出口和隐藏联系 / 当下氛围 / 未来走向 / 与记忆相似 | Ne / Se / Ni / Si |
| 面临两难抉择 | 拆解逻辑 / 评估外部最优 / 扫描群体影响 / 追问内心价值 | Ti / Te / Fe / Fi |
| 解释复杂概念 | 比喻让人"感受" / 定义让人"理解" / 步骤让人"知道怎么做" / 经历让人"感同身受" | Ne+Fe / Ti / Te / Fi |

### Step 2 · 堆叠建构

主导确定后推导完整四功能堆叠（参考"二、2.2"速查表）。**重点设计第三与劣势**：
- 第三 = 可爱缺陷
- 劣势 = 阿喀琉斯之踵，同时是最高理想的隐藏地

### Step 3 · 阴影开发

推导阴影四功能 5–8，设计激活场景：**阴影不是"邪恶面"，而是主导受挫后的扭曲回弹**。在角色日常行为中预埋细微的阴影痕迹。

### Step 4 · 签名检验

四维"心理指纹"相互印证：
- **感知签名** · 他注意什么、忽略什么
- **决策签名** · 如何权衡选择
- **语言签名** · 句式偏好、高频词汇、语气
- **压力签名** · 崩溃时 Grip / Loop 的具体形态

**越轨诊断**：区分设计缺陷（无解释的行为突变）与成长信号（有情节触发的行为变化）。

### Step 5 · 动态化

场景-功能激活映射：日常 → 主导默认在线；危机 → 劣势原始浮现。**同一场景让多个功能层交互**，而非单一功能独白。

## 六、角色弧线（Grip / Loop / 成熟度）

### 6.1 Grip 状态 · 劣势功能劫持

极端压力下劣势功能以原始方式突然接管，角色"完全不像自己"。
**叙事作用**：暴露最深层脆弱，为成长打开入口。

### 6.2 Loop 状态 · 主导-第三闭环

跳过辅助功能，主导和第三互相确认、自我封闭。**不是崩溃，是偏执而不自知**。
**叙事作用**：制造慢性中毒式困境——角色用精密内部逻辑为自己越来越不健康的行为辩护。

### 6.3 16 型 Grip / Loop 速查（写崩溃 / 黑化 / 整合场景时必用）

| 类型 | Loop 模式 | Grip 反应 | 典型触发 |
|:-:|---|---|---|
| INTJ | Ni-Fi：偏执愿景+情绪化拒反馈 | Se：冲动暴食 / 感官放纵 | 混乱环境 / 计划失控 |
| INFJ | Ni-Ti：脱离现实的阴谋论 | Se：过度锻炼 / 冒险 | 被迫快速决策 |
| INTP | Ti-Si：过度分析过去 / 极度孤僻 | Fe：情绪爆发 / 感觉被排斥 | 严格规则 / 无逻辑冲突 |
| INFP | Fi-Si：沉浸创伤 / 愤世嫉俗 | Te：严苛批判 / 效率痴迷 | 价值观被强制违背 |
| ENTJ | Te-Se：强迫性行动不顾长远 | Fi：脆弱敏感 / 怀疑自我价值 | 完全失控感 |
| ENFJ | Fe-Se：过度取悦+冲动满足他人 | Ti：分析瘫痪 / 冷酷批评 | 被群体排斥批评 |
| ENTP | Ne-Fe：破坏性玩乐 / 操纵人际 | Si：执着过去错误 / 身体症状担忧 | 微观管理 / 常规重复 |
| ENFP | Ne-Te：强迫性执行失去价值核心 | Si：怀旧沉溺 / 感到被边缘 | 被微观管理 |
| ISTJ | Si-Fi：固守过去 / 情绪僵化 | Ne：灾难化想象 / 偏执找隐藏模式 | 计划突变 / 杂乱无序 |
| ISFJ | Si-Ti：过度细节控制 / 情感封闭 | Ne：焦虑螺旋 / 鲁莽冲动 | 不被感谢 |
| ISTP | Ti-Ni：分析过度+黑暗预感 | Fe：情绪化 / 恐惧被排斥 | 严格规则 |
| ISFP | Fi-Ni：价值偏执+负面预感 | Te：严苛批判 / 效率狂热 | 价值观被忽视 |
| ESTJ | Te-Si：强迫控制 / 拒绝新信息 | Fi：感觉不被爱 / 情绪崩溃 | 规则被挑战 |
| ESFJ | Fe-Si：过度传统 / 情感操控 | Ti：冰冷逻辑 / 偏执猜疑 | 他人被虐待 |
| ESTP | Se-Ti：危险冒险+冷酷计算 | Ni：黑暗预感 / "一切都不重要" | 长期计划约束 |
| ESFP | Se-Fi：感官放纵+情绪爆发 | Ni：悲观不信任 / 焦虑螺旋 | 常规无聊 / 被忽视 |

### 6.4 三种弧线（选一种作为主角弧线骨架）

| 类型 | 起点 → 终点 | 动力 |
|---|---|---|
| **积极变化** | 主导霸权 → 主导+辅助协同+劣势初步整合 | 外部挑战迫使未发展功能觉醒 |
| **消极堕落** | 已整合 → 主导极端膨胀 / 阴影接管 | 整合失败，逐步退行 |
| **平稳测试** | 已完成整合 → 整合深化 | 极端压力测试已整合状态 |

### 6.5 Jung 个体化四阶段 × 弧线节拍映射（落地到章节位置）

把弧线转化为**可落地到结构骨架的四个节拍点**：

| Jung 阶段 | 意识状态 | 在结构骨架中的位置 | 典型事件 |
|---|---|---|---|
| **① 面具适应** | 主导功能过度依赖 | 第一幕 / Save the Cat 的 Setup–Catalyst | 角色用最熟练的招式解决所有问题，暗伏"劣势功能"的第一次微挫 |
| **② 阴影遭遇** | 危机迫使面对被压抑的自我 | 第二幕 / 15 节拍的 B-story 激活 ↔ 至死亡时刻 | 劣势功能被暴露，主角第一次真正崩溃或怀疑自己 |
| **③ 对立整合** | 功能轴两端的和解尝试 | 中点 → 第三幕前半 / 15 节拍的 Break Into Three | 主角开始**主动调用劣势或辅助功能**，不再全靠主导 |
| **④ 自性涌现** | 超越类型的完整人格 | 高潮 + 结局 / 15 节拍的 Finale | 主角以整合后的人格做出关键决策，体现"类型不变，功能成熟度变了" |

**弧线类型与 Jung 阶段的配合**：
- 积极变化弧线 → 完整走过 ①→②→③→④
- 消极堕落弧线 → 停留在 ②，或从 ③ 回退到阴影功能接管
- 平稳测试弧线 → 在 ④ 的状态下被外部危机反复测试

## 八、反刻板 + 安全边界（硬律）

1. **类型 ≠ 能力**：ENTP 可以谨慎，ISTJ 可以即兴。类型描述**偏好倾向**，不是行为许可证。
2. **类型偏差设计法**：每个角色**至少设计一个与主导功能相矛盾的特质**——"非典型"比"典型"更有趣。
3. **类型是起点不是终点**：最好的角色永远保有一块任何理论都无法完全解释的空间——那就是人性本身。
4. **弧线终点是功能成熟度变化，不是类型转换**：INTJ 不会变成 ENFP；INTJ 会整合 Se，变成"更完整的 INTJ"。

### 8.1 三方法协同（MBTI 不够用时的扩展路径）

MBTI 回答的只是认知维度，当角色复杂度超出 MBTI 可解释范围时，叠加另外两个框架：

| 框架 | 回答的问题 | 补充维度 |
|---|---|---|
| **MBTI** | 角色**如何**处理信息与决策 | 认知功能（已覆盖） |
| **Enneagram 九型人格** | 角色**为什么**行动 | 核心动机 / 欲望 / 恐惧（可与本模块的"核心恐惧 / 核心欲望"字段直接挂钩） |
| **大五人格（Big Five）** | 角色情绪与行为的**幅度** | 尤其是 Neuroticism 神经质维度（解释同一 MBTI 类型为何有人稳定、有人易崩溃） |

**实操建议**：主角必须 MBTI 齐全，复杂反派或关键配角可额外标注 Enneagram 号 + 神经质等级（低/中/高）。非重要角色不必。

```
    第5 对立人格: ...（轻压触发场景）

- 语言签名: ...（句式偏好、高频词、语气标记）
- Loop 模式: 1st-3rd 封闭时的具体行为
- Grip 触发: 劣势爆发的典型场景
- 弧线类型: 积极变化 / 消极堕落 / 平稳测试
- 与主角关系模式: 同轴互补 / 对轴冲突 / 交叉轴张力 / 镜像共振 / 功能真空
- 至少一个类型偏差: ...（与主导功能矛盾的特质）
```

## 十、创作检查清单

- [ ] 主导功能锚定前是否先追问了"核心认知偏好"而非先贴类型标签？
- [ ] 四功能堆叠是否自洽（主导-辅助态度相反，感知-判断交替）？
- [ ] 第三功能是否被用来制造"可爱缺陷"？
- [ ] 劣势功能是否被设计为成长弧线的引擎？
- [ ] 压力下的 Grip / Loop 是否与类型功能结构一致？
- [ ] 阴影功能是否被用于制造"反常但可信"的行为？
- [ ] 群像是否覆盖了全部八种认知功能？
- [ ] 每个角色是否至少有一个类型偏差（反刻板）？
- [ ] 语言风格是否与认知签名一致？
- [ ] 弧线终点是**功能成熟度变化**而非类型转换？

## 十一、与其他模块协同

- **与任意结构骨架（ATU 301 / 英雄之旅 / Save the Cat / 起承转合 / 三幕式）**：正交。结构管"何时发生什么"，本模块管"角色内在动力"。主角弧线类型应与结构骨架的成长曲线对齐（如英雄之旅 → 积极变化；堕落悲剧 → 消极堕落）。
- **与 `mbti-5step`（简化版）**：**互斥**。同一项目只启用一个。本模块适合文学性需求；简化版适合商业网文。
- **与 `plot-coherence-scaffold`**：强协同。本模块输出的 YAML 角色卡里的"语言签名 / Loop 模式 / Grip 触发"可直接作为连贯性守则里「角色状态知识库」的内容。
- **与 `pixar-22-rules`**：正交协同。Pixar 的"角色欲望 vs 真正需要"可理解为"主导功能的追求 vs 劣势功能的隐藏渴望"。
- **与 `visual-dehydration`**：正交。本模块定义"为什么这样演"，脱水法定义"镜头怎么拍"。
