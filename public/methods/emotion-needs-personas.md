# 情绪需求画像 · 求必得 vs 求不得 + 共情高速公路

> **来源**：墨香阁柒爷网文创作课《情绪篇 · 实战技巧》第九课「用户画像与情绪需求」。
> **定位**：craft 层 · **情绪驱动用户定位型模块**（与 audience-personas / emotion-driven-sop 强协同）。
> **核心命题**：人类所有情绪需求 · 追根溯源 = **匮乏感的补偿（求必得）+ 共鸣感的宣泄（求不得）**。负面情节不是卖惨 · 是"对暗号"——和观众的现实痛点对接 · 让他们"魂穿"主角。
> **核心价值**：(1) 两大情绪需求模型（A 求必得 / B 求不得）；(2) 共情高速公路 3 步法（找暗号/造扳机/前置植入）；(3) 喜悲剪刀差（观众预期 vs 角色现实信息差）。

---

## 适用边界

✅ **强推荐启用**：
- 情绪驱动项目立项（用户定位）
- 短剧 / 网文目标人群锁定
- 设计开篇负面情节
- 设计甜文 / 虐文核心场景

⚠ **可选启用**：
- 中性题材（部分采用）

❌ **不要启用**：
- 工具书 / 说明文 / 纯学术

---

## 核心心法 · 情绪药丸的两大配方

```
我们是"情绪制造商"
但好的制造商必须先做市场调研——
  我的目标用户是谁？
  他们内心最渴望什么？
  只有搞清楚"病症" · 我们才能对症下药

人类所有情绪需求 · 追根溯源 = 两大底层心理动机：
  ├─ 模型 A · 求必得（匮乏感的补偿）
  └─ 模型 B · 求不得（共鸣感的宣泄）
```

---

## 模型 A · 求必得 · 匮乏感的补偿机制

### 一句话定义

> **现实中越缺什么 · 故事里就越要给什么 · 而且要加倍给**。

### 核心产品

```
爽 / 甜 / 燃
本质 = "掌控感"和"获得感"的虚拟体验
```

### 心理学原理 · 替代性成就

```
现实中我们是受气的员工、卑微的乙方、被发好人卡的追求者
我们的欲望被压抑 · 能力被限制 · 充满无力感和"匮乏感"

大脑为了寻求心理平衡 · 会极度渴望在虚拟世界中
体验一种"无所不能"的感觉

当主角获得我们渴望的东西时
我们大脑的奖励中枢（多巴胺系统）会被激活
产生一种"仿佛是我自己做到了"的愉悦感
```

→ **求必得 = 高浓度白日梦 = 现实不如意的强效"精神鸦片"**。

### 实操 3 步法

#### Step 1 · 找到"匮乏点"

你的目标用户最缺什么？

| 类型 | 痛点 |
|---|---|
| **缺钱** | 房贷压力 / 月光族 / 拜金压力 |
| **缺爱** | 单身狗 / 受过伤害 / 缺安全感 |
| **缺尊重** | 职场被打压 / 家庭被忽视 / 社交被冷落 |
| **缺力量** | 校园霸凌 / 现实无力感 |

#### Step 2 · 设计"反向金手指"

| 缺什么 | 给什么 |
|---|---|
| 缺钱 | "点石成金系统" |
| 缺爱 | "无条件忠犬男友" |
| 缺尊重 | "龙王归来"的隐藏身份 |
| 缺力量 | 满级账号重生 / 系统流外挂 |

#### Step 3 · 无情地碾压

让主角用这个金手指 · 去**碾压那些在现实中让他们感到匮乏的人事物**：

- 势利眼亲戚
- 拜金前女友
- 傲慢上司
- 校园施暴者

→ 碾压得越彻底 · 补偿感越强。

## 模型 B · 求不得 · 共鸣感的宣泄机制

### 一句话定义

> 把现实中我们想哭但不敢哭、想喊但喊不出的痛苦 ·
> **在故事里用最极致、最淋漓尽致的方式替我们演出来** ·
> 让我们能借着角色的壳 · 痛痛快快地释放一次情绪。

### 核心产品

```
虐 / 憾 / 悲（深度共情体验）
```

### 心理学原理 · 情绪代理 + 虚拟世界免责性

```
作为一个"体面"的成年人
肆意宣泄负面情绪是一种奢侈品
我们被社会角色和自我理性所束缚 · 不敢轻易暴露脆弱

故事的"虚拟性"为我们提供了一层完美的"心理保护壳"
当观众看到主角经历了和自己类似的痛苦时
他们会将自己的情绪"外包"给主角
以"欣赏作品"的名义
安全地、无负担地完成一次"情绪泄洪"

这个过程在心理学上称为"净化"（catharsis）
```

→ **求不得 = 匿名一次性"心理诊所"**——为现实中必须扮演"情绪稳定"的成年人 · 提供绝对安全、完全免责的渠道 · 释放积压的负面能量。

### 实操 3 步法

#### Step 1 · 找到"共情点"

你的目标用户内心最深的伤痕是什么？

| 类型 | 创伤 |
|---|---|
| **爱而不得** | 错过的初恋 / 暗恋无果 / 失败的婚姻 |
| **原生家庭** | 重男轻女 / 父母离异 / 童年阴影 |
| **理想破灭** | 高考失利 / 创业失败 / 中年危机 |
| **友情背叛** | 闺蜜抢男友 / 兄弟反目 |

#### Step 2 · 设计"放大器"

将这种伤痕**戏剧化、极端化**。

| 现实 | 故事极端化 |
|---|---|
| 情侣吵架 | "为救女二而误伤女主" |
| 遗憾错过 | "一步之遥 · 阴阳两隔" |
| 父母不理解 | "亲生父母为利益将女儿献祭" |

#### Step 3 · 营造"仪式感"

必须给情绪的宣泄设计一个**标志性的场景**：

| 场景元素 | 作用 |
|---|---|
| 大雨 | 与泪水共振 |
| 悬崖 | 极致的绝望与孤独 |
| 病床 | 生死边界的无力感 |

用极致的画面和台词 · 引导观众的情绪在此刻**彻底引爆**。

## A vs B · 速查矩阵

| 维度 | 模型 A · 求必得 | 模型 B · 求不得 |
|---|---|---|
| **本质** | 匮乏感补偿 | 共鸣感宣泄 |
| **产品** | 爽 / 甜 / 燃 | 虐 / 憾 / 悲 |
| **心理机制** | 替代性成就 | 情绪代理 + 净化 |
| **比喻** | 高浓度白日梦 | 匿名心理诊所 |
| **关键词** | 掌控感 / 获得感 | 共情 / 释放 |
| **典型题材** | 战神归来 / 系统流 / 甜宠 | 大女主复仇 / 虐文 / 悲剧 |
| **目标用户** | 现实中"无能为力"者 | 现实中"必须坚强"者 |

## 共情高速公路 · 负面情节"对暗号"3 步法 ★ 革命性认知

### 颠覆性认知 · 负面情节本质

```
"负面情节"的首要目的不是为了让观众感受"负面情绪"

它的真正目的 · 是像一个"身份验证器"——
  通过复现一个观众在现实生活中
  大概率经历过的"痛点"
  来和观众对上"暗号"

让观众在看到这个情节的瞬间
产生一种强烈的反应：
  "卧槽！这不就是我吗？！"

→ 一旦"暗号"对上 · 观众的心理防线就会瞬间被突破
→ 他不再是一个挑剔的、置身事外的"读者"
→ 而是变成了一个感同身受的"亲历者"
→ "共情高速公路"才算真正铺通
```

### Step 1 · 找暗号 · 用户定位 · 寻找"普遍痛点"

#### 操作

精准描绘目标用户画像 · 挖掘他们生活中**最大概率会遭遇的、具有普遍性的"负面体验"**。

#### 案例分析 1 · 都市职场 / 赘婿爽文

```
目标受众：初入社会或处于事业瓶颈期的年轻男性

普遍痛点（暗号）：
  ├─ 被领导/客户无理打压
  ├─ 被同事抢功劳
  ├─ 被丈母娘/女友家人看不起
  └─ 因为没钱而被羞辱
```

#### 案例分析 2 · 古风宅斗 / 大女主

```
目标受众：面临家庭、情感或职场困境的年轻女性

普遍痛点（暗号）：
  ├─ 遭遇 PUA（被打压、被否定价值）
  ├─ 被恋人误解或背叛
  ├─ 在不公平的环境中被排挤
  └─ 真心付出却得不到回报
```

### Step 2 · 造扳机 · 情节放大 · 设计"戏剧扳机"

#### 操作

将"普遍痛点"进行**戏剧化的夸张和放大** · 变成一个强有力的"情节扳机"。

→ 源于生活 · 高于生活。
→ 既能让观众一眼认出"这是我的经历" · 又比真实经历更极端、更具冲突性。

#### 案例分析 1 · "被领导当众批评" → 戏剧扳机

```
现实：被领导当众批评

戏剧扳机（放大）：
  主角呕心沥血做的方案 ·
  不仅被领导当众贬得一文不值 ·
  还被当成垃圾扔在地上 ·
  并被同事当面窃取成果 ·
  抢走了本该属于他的晋升机会
```

#### 案例分析 2 · "和恋人吵架" → 戏剧扳机

```
现实：和恋人吵架 · 被说了伤人的话

戏剧扳机（放大）：
  女主为了给男主准备生日惊喜 ·
  在大雨中等了三小时 ·
  结果等到的是男主扶着受伤的女二号出现 ·
  并冷漠地对她说："你能不能别这么不懂事？"
```

### Step 3 · 验暗号 · 前置植入 · 完成"身份验证"

#### 操作

将设计好的"情节扳机" · **毫不犹豫地放在故事的开篇部分**。

#### 为什么必须前置

```
因为它的核心功能就是"快速验票入场"
你必须在观众的耐心耗尽之前 ·
迅速和他对上"暗号" · 完成"身份验证"
```

#### 效果展示

##### 男频用户（被老板 PUA）

```
看到主角开篇就被抢功劳、被羞辱时
他积压的愤怒和委屈会瞬间被这个"情节扳机"点燃
他会立刻代入主角 · 并产生强烈的期待：
  "弄他！必须弄死这帮孙子！"

→ 共情高速公路 · 铺设成功！
```

##### 女频用户（感情受伤）

```
看到女主开篇就被误解、被辜负时
她内心的伤痕会被瞬间激活
她会立刻与女主同呼吸共命运
渴望看到女主后续如何清醒、如何搞事业、
如何让渣男追悔莫及

→ 共情高速公路 · 铺设成功！
```

### 小结 · 钥匙的作用

```
负面情节不是故事的主体 · 更不是情绪的主题
它是一把钥匙

这把钥匙 · 精准地插入了目标观众
内心最柔软、最疼痛的那个锁孔里
咔嚓一声 · 心门打开

观众不再是你 · 你不再是他
你和他 · 合二为一 · 成为主角

只有完成了这步至关重要的"合体"
后续的一切情绪产品——
  无论是"求必得"的爽
  还是"求不得"的虐
——才能真正地作用于观众的灵魂深处
```

## 喜悲剪刀差 · 预期与现实的信息差

### 核心命题

```
如何精准控制、放大观众"喜"和"悲"的情绪强度？
答案在于一把"剪刀"——
观众的"预期"和角色的"现实"之间的信息差

剪刀张开角度越大 · 情绪烈度越强
```

### 喜剪刀 · 制造"喜"（甜 / 喜悦）

#### 公式

```
观众的认知 > 角色的认知
```

#### 原理

观众提前知道了"爱意的真相"或"误会的实情" · 而故事里的主角们 · **特别是那对正在"闹别扭"或"搞暧昧"的男女主 · 对此一无所知**。

#### 嗑 CP 的上帝视角

```
这种信息差 · 让观众从一个被动的"故事接收者"
变成了一个"全知全能的 CP 粉头子"

我们不再为主角们的感情进展而焦虑
反而会像看自家孩子谈恋爱一样
带着一种"姨母笑"和"看破不说破"的优越感
去期待故事的发展
欣赏他们在我们眼皮子底下的各种"笨拙"和"口是心非"
```

#### 糖分期待的积累

```
主角们的每一次小误会、每一次言不由衷的"推开"
在观众看来 · 都只是在为最终"发糖"的那一刻积蓄能量

我们不担心他们会真的分开
我们只期待看到他们何时才能捅破那层窗户纸
这种"稳稳的幸福"的期待感本身就是持续、甜美的享受
```

#### 实战示例 · 双向暗恋

```
观众知道的（甜美的预期）：
  通过男主 OS / 日记 / 对兄弟的倾诉 · 我们知道
    高冷学霸男主其实暗恋班花女主三年了
    他每天绕远路 · 就是为了能"偶遇"她
    他拼命学习拿第一 · 就是为了在开学典礼上
    作为学生代表发言时 · 让她多看自己一眼

  通过女主 OS / 画册 / 对闺蜜的悄悄话 · 我们知道
    胆小班花女主也一直偷偷喜欢着学霸男主
    她画的每一幅画 · 主角都是他

角色不知道的（笨拙的现实）：
  当女主鼓起勇气 · 拿着自己画的画想送给男主时
  男主因为紧张 · 表面上只是冷冷地说了句"谢谢"
  然后就抱着书匆匆走开
  （女主心碎：他果然讨厌我）

  当男主想约女主周末去图书馆
  却别扭地问出口："你周末有空吗？我有个数学题想请教你。"
  （女主心碎：原来他只把我当学习工具人）

观众的感受：
  看着这两个明明爱惨了对方 ·
  却因为各自"小九九"而不断错过的"笨蛋" ·
  观众不会感到虐心 · 反而会急得跺脚 ·
  全程带着"姨母笑"在弹幕里狂喊：
    "求求你们快点在一起吧！"
    "他超爱你的啊！你个傻瓜！"
```

### 悲剪刀 · 制造"悲"（虐）

#### 公式

```
观众的认知 > 角色的认知（同样的信息差结构）
```

观众提前知道了"坏结果"或"残酷的真相" · 而故事里的角色对此一无所知 · 还在天真地憧憬着美好的未来。

#### 原理

```
这种信息差会让观众产生一种
"旁观的无力感"和"巨大的同情心"

角色越是幸福、越是期待
观众就越是心疼
因为他们知道这一切都是假象
悲剧的达摩克利斯之剑随时会落下

→ 角色的每一个笑容 · 都像一把刀子 · 扎在观众心上
```

#### 实战示例 · 死亡预告

```
故事开头 · 旁白响起：
  "那是我见到他的最后一面。"

然后再开始描写两人当天如何甜蜜地约会
```

#### 实战示例 · 阴谋视角

```
用一个镜头告诉观众：
  男主送给女主的定情信物里
  被女二下了无药可解的剧毒

然后再用大量篇幅描写：
  女主如何视如珍宝地佩戴着它
```

#### 核心

```
让观众成为悲剧的"第一目击者"
眼睁睁地看着角色一步步走向那个早已注定的、不可逆转的悲惨结局
```

## 喜悲剪刀差速查

| 类型 | 信息差 | 观众心态 | 实战工具 |
|---|---|---|---|
| **喜剪刀** | 观众知爱意 / 角色不知 | 姨母笑 + 等糖 | 双向暗恋 / 误会即将解开 |
| **悲剪刀** | 观众知悲剧 / 角色不知 | 旁观无力 + 心疼 | 死亡预告 / 阴谋视角 |

→ 注意：**两者公式相同**（观众认知 > 角色认知）· 区别在于**信息内容是甜还是苦**。

|---|---|

| 立项时**先用此选大方向** | 立项时**再用此细化** |

→ 两者**串联使用** · audience-personas 在前 · 本模块在后。
