# 世界观设计法 · 创世五步 + 入局五步 + 主线嫁接 + 身份绑定

> **来源**：墨香阁柒爷网文创作课《事件篇 · 实战技巧》第八课「事件设计 · 世界篇」（含先前截断后补齐的"上帝造世 + 凡人入局"两阶段）。
> **定位**：craft 层 · **题材级别设计型模块**（与 ten-story-archetypes-pack / event-driven-sop 强协同 · 闭合事件篇生态）。
> **核心命题**：世界观设计**不是写说明书 · 是编织因果**。先有树（造世）· 再走路（入局）· 然后嫁接主线 + 绑定身份 · **让世界成为主角命运的土壤**。
> **核心价值**：(1) 创世五步法（后台设计）；(2) 入局五步法（前台激活）；(3) 事件嫁接（让家仇升级国恨）；(4) 身份绑定（让主角成为天选之子）。

---

## 适用边界

✅ **强推荐启用**：
- 玄幻 / 仙侠 / 科幻 / 奇幻 / 异世界
- 含独立世界设定的长篇
- 想做"宏大叙事"的项目
- 男频史诗 / 女频架空

⚠ **可选启用**：
- 都市穿越（部分采用 · 部分用现实）
- 历史架空（结合真实历史）

❌ **不要启用**：
- 纯都市 / 纯现实 / 纯文学

## 核心心法 · 设计世界 = 编织因果

```
世界观设计 ≠ 写说明书
世界观设计 = 编织因果

不理解因果 → 你设计出来的只是死板的地图
理解了因果 → 你设计出来的就是活的生态

→ 一个不需要主角、也能自己运转和爆发冲突的"活世界"
```

## 阶段 1 · 上帝造世 · 创世五步法

### 核心命题

```
你是这个世界的造物主
要先在没有任何主角的情况下
设计一个能"自己运转"的世界
```

### Step 1 · 定锚点（The Anchor）

#### 灵魂拷问

> 如果这个世界只有一个核心设定 · 那它是什么？

#### 操作

找到那个**唯一的、能定义整个世界的核心差异点**——这就是世界的"锚"。

#### 示例

```
锚点：这个世界信仰旧神 · 但旧神已死 · 新神即将到来。
```

→ 一句话能说完。能定义整个世界。

### Step 2 · 定基调（The Tone）

#### 操作

由锚点出发 · 推导出这个世界的**基础生存法则和情感基调**。

#### 示例

```
因为"旧神已死" → 基调是：秩序崩坏 / 末日 / 迷茫
因为"新神将至" → 基调是：希望 / 变革 / 残酷竞争
```

→ 锚点决定基调 · 基调决定全篇情感色彩。

### Step 3 · 填骨肉（Flesh and Bones）

#### 操作

基于基调 · 设计与此匹配的**种族 / 技术 / 社会结构**等基础设定。

#### 示例

```
因为"秩序崩坏" → 社会分裂为"守旧派"和"革新派"
因为"残酷竞争" → 诞生了能听到神谕的"通神者"这一特殊阶层
```

→ 每一个设定都从基调推导出来 · 不是凭空想象。

### Step 4 · 建生态（The Ecosystem）

#### 操作

让设定之间**相互作用** · 建立它们之间的**供需关系**和**冲突关系** · 形成动态平衡。

#### 示例

```
通神者需要"圣物"来维持能力
圣物由"守旧派"掌控
因此"革新派"必须从守旧派手中抢夺圣物
```

→ **供需 + 冲突 = 动态生态**。世界开始"自己运转"。

### Step 5 · 织罗网（The Web of Conflict）

#### 操作

从生态中 · 找到那些**最尖锐、最不可调和**的矛盾点。这些就是未来故事的**"火药桶"**。

#### 示例

```
矛盾 1：革新派想迎接新神 · 守旧派想复活旧神
矛盾 2：通神者内部 · 有人想独占成神之路 · 有人想广布福音
```

→ **多重矛盾叠加** · 火药桶随时可能引爆。

### 创世五步法速查矩阵

| Step | 名称 | 输出 | 关键问 |
|:---:|---|---|---|
| 1 | 定锚点 | 一句话核心设定 | 这个世界**最独特**的是什么？|
| 2 | 定基调 | 生存法则 + 情感基调 | 在这个锚点下 · 人们**怎么活**？感觉**如何**？|
| 3 | 填骨肉 | 种族 / 技术 / 社会结构 | 与基调**匹配**的设定有哪些？|
| 4 | 建生态 | 供需 + 冲突关系 | 设定之间**如何互动**？|
| 5 | 织罗网 | 矛盾点（火药桶）| 哪些矛盾**不可调和**？|

### 阶段 1 交付物

```
✅ 一份不含主角的"活世界"设定
✅ 锚点 + 基调 + 骨肉 + 生态 + 火药桶
✅ 这个世界即使没有主角 · 也会自己爆发冲突
```

## 阶段 2 · 凡人入局 · 入局五步法

### 核心命题

```
设计完世界 · 就要把主角扔进去
但不能一上来就让主角看到全貌
要让他像玩游戏一样 · 一步步发现世界的真相

→ 信息释放的"入局五步法"——主角的"新手村教学"
```

### Station 1 · 日常（The Normal）

#### 操作

从主角**最熟悉、最 mundane 的日常生活**开始。

#### 作用

```
建立基线
让读者代入主角的"普通人"视角
这样后面的"异常"才会显得震撼
```

#### 示例

```
主角是边境小村的猎户儿子
每天打猎、卖肉、和邻居拉家常
对"旧神已死""新神将至"这些大事毫无概念
```

### Station 2 · 异常（The Inciting）

#### 操作

一个事件 · 让主角**第一次接触到世界的"冰山一角"**。

#### 作用

```
打破日常 · 制造好奇
不是揭示全貌 · 只是露出一角
让主角和读者同时产生疑问："这是什么？"
```

#### 示例

```
村里来了一个奇怪的旅人 · 身上有发光的纹身
深夜被一群黑袍人追杀
旅人临死前把一个石头塞给主角："交给…… 革新派……"
然后断气

主角第一次知道：
  原来世界上还有"发光纹身""黑袍人""革新派"这些东西
```

### Station 3 · 导师（The Mentor）

#### 操作

通过一个"引路人"· 对世界的规则进行**第一次口头解释**。

#### 作用

```
信息密度爆发的入口
但通过"导师"这个角色来递送 · 让读者觉得"自然"而不是"作者强行讲解"
```

#### 示例

```
主角带着石头逃到镇上
遇到一个老酒馆老板（其实是退隐的革新派成员）
老酒馆老板边喝酒边讲：
  "孩子 · 你要去的地方叫革新派
   这个世界啊…… 旧神早就死了……
   通神者…… 圣物……"

→ 一段独白 · 读者获得 60% 的世界观信息
```

### Station 4 · 实践（The Practice）

#### 操作

主角**亲身体验**世界的核心规则 · **通常会失败或出丑**。

#### 作用

```
理论 ≠ 实践
让主角（和读者）真正"get"到这个世界的规则
失败/出丑 = 让规则的"刚硬"被身体记住

→ 也是确立成长起点
```

#### 示例

```
主角到达革新派据点
被告知要先通过"通神测试"
他自信满满去试 · 结果根本听不到神谕
被同期的天才嘲笑："你这种凡人也来革新派？"

→ 主角的弱小被具象化
→ 读者明白：通神者不是想当就能当的
```

### Station 5 · 远征（The Journey）

#### 操作

主角**离开新手村** · 真正踏入宏大的世界 · 开始探索未知。

#### 作用

```
正式宣告"新手村教学结束"
开启长篇的主线征程
也是 10 序列中"序列 3 激励"的对应点
```

#### 示例

```
主角发现自己其实是某种"特殊血脉"（埋下伏笔）
被推荐到革新派总部学习
踏上前往神圣山脉的旅程
途中将遇到守旧派的暗杀、通神者内部的派系斗争……

→ 真正的故事开始
```

### 入局五步法速查矩阵

| Station | 名称 | 主角状态 | 信息密度 |
|:---:|---|---|:---:|
| 1 | 日常 | 完全无知 / 普通人 | 0% |
| 2 | 异常 | 接触冰山一角 | 10% |
| 3 | 导师 | 听到规则解释 | 60% |
| 4 | 实践 | 亲身体验 + 失败 | 80% |
| 5 | 远征 | 进入主线 | 100%（核心规则）|

### 阶段 2 交付物

```
✅ 主角"新手村"5 阶段流程
✅ 信息密度的渐进释放
✅ 序列 1-3 与入局 5 站的映射关系
```

## 阶段 3 · 主线嫁接 · 程序设计

### 核心命题

```
有了世界（树）· 也有了主角入局（路）
还需要把主线事件"嫁接"到世界的核心冲突上
让"家仇"升级为"国恨"
让主角的个人故事成为世界进程的一部分
```

### 第一步 · 事件嫁接 · 主线事件 → 世界冲突

#### 嫁接激励事件（序列 3）

##### 主线需求

```
需要一个"灭村"的惨案来刺激主角
```

##### 世界观寻宝

```
素材 A：山贼屠村？（太普通 · 格局小）
素材 B：妖魔入侵？（可以 · 但不够黑）
素材 C：圣光教廷为了寻找某样东西 · 血洗了村子
        并嫁祸给血魔教
        （这个好！既有惨案 · 又有阴谋
         还把两大势力都拉下水了）
```

##### 嫁接结果

```
主角的"家仇" · 不再是个人恩怨
而是被嫁接到了"圣光教廷与血魔教的斗争"这棵大树上

→ 个人事件 + 世界冲突 = 故事格局升级
```

#### 嫁接转折事件（序列 5）

##### 主线需求

```
主角以为仇人是血魔教 · 追杀途中需要一个反转
```

##### 世界观寻宝

```
我们设定过：血魔教的高层其实是被圣光教廷放逐的叛徒
```

##### 嫁接结果

```
主角抓到了一个血魔教的小头目 · 逼问之下发现
这个小头目当年就是圣光教廷的成员 · 亲身参与了屠村！

真相反转：仇人不是魔 · 而是神
```

#### 嫁接危机事件（序列 7）

##### 主线需求

```
主角得知真相后 · 势单力薄 · 需要一个"灵魂黑夜"般的绝望
```

##### 世界观寻宝

```
我们设定过：圣光教廷的教皇伪造神谕 · 控制着整个世界
```

##### 嫁接结果

```
主角试图揭露真相 · 结果发现整个世界都信仰圣光教廷
没人相信他一个无名小卒
他被当成异端 · 遭到全世界的追杀

他的"个人复仇" · 升级成了"对抗整个世界的谎言"
```

#### 嫁接高潮事件（序列 9）

##### 主线需求

```
主角需要一个翻盘的契机
```

##### 世界观寻宝

```
我们设定过：光明神沉睡的真相 · 以及他留下的圣物"光明火种"
```

##### 嫁接结果

```
主角在绝境中 · 根据线索找到了光明神沉睡的圣地
并意外获得了"光明火种"的认可
他手持真正的圣物 · 当众揭穿了教皇的伪神谕
```

### 第二步 · 身份绑定 · 主角与世界的"灵魂深度连接"

#### 核心命题

```
光是事件嫁接还不够
还要让主角的"个人身份"
也和世界的"核心秘密"深度绑定

→ 从"旁观者"升级为"天选之子"
```

#### 低级写法 vs 高级写法

##### 低级写法

```
主角是个普通人
只是运气好捡到了宝物
```

##### 高级写法

```
主角的身世 · 本身就是世界观的一部分
```

#### 绑定 1 · 血统

##### 世界观设定

```
光明神当年有个唯一的血脉后裔 · 流落民间
```

##### 主角身份绑定

```
主角就是那个后裔
```

##### 解释了什么

```
为什么只有他能获得"光明火种"的认可？
  → 因为他有血统挂

他的复仇不再是私仇 · 而是"王子复仇记"
是拿回本该属于自己的一切
```

#### 绑定 2 · 预言

##### 世界观设定

```
创世神话里有一个古老的预言：
"当圣光被阴影笼罩 · 神之血裔将手持火焰归来 · 重塑秩序。"
```

##### 主角身份绑定

```
主角的行动 · 一步步印证了这个预言
```

##### 带来的效果

```
赋予了宿命感 · 让主角的冒险充满了史诗感和神圣感
团结了盟友：那些同样知道预言的"先知"或"守护者"势力
            会主动来帮助主角
```

### 阶段 3 交付物

```
✅ 关键主线事件（序列 3/5/7/9）全部嫁接到世界冲突
✅ 主角身份与世界核心秘密绑定（血统 + 预言）
✅ 主角从"幸运儿"升级为"天选之子"
✅ "家仇"升级为"国恨" / "拯救世界"
```

## 实战检验法

### 写完世界观设定后 · 三阶段自检

#### 阶段 1 自检（上帝造世）

- [ ] 锚点是**一句话能说完**的吗？
- [ ] 基调与锚点**逻辑通顺**吗？
- [ ] 骨肉设定与基调**匹配**（不是凭空捏造）？
- [ ] 生态有**供需 + 冲突**双关系？
- [ ] 矛盾点至少 **2 个不可调和**？

#### 阶段 2 自检（凡人入局）

- [ ] 主角日常**够 mundane**（普通到读者能代入）？
- [ ] 异常事件**只露冰山一角**（不直接揭全貌）？
- [ ] 导师解释**信息密度足够**（不是挤牙膏）？
- [ ] 实践阶段主角**真的失败 / 出丑**？
- [ ] 远征阶段主角**真的踏入宏大世界**？

#### 阶段 3 自检（主线嫁接）

- [ ] 至少 **3 个主线事件嫁接到世界冲突**？
- [ ] 主角身份**与世界核心秘密绑定**？
- [ ] 主角的复仇**升级为更大格局**？
- [ ] 没有"幸运儿"违和感（设定能解释金手指来源）？

## 常见错误

```
❌ 锚点太多 · 一开始就抛出 5 个核心设定 → 读者懵逼
❌ 基调与锚点不符 · 锚点冷酷但基调甜美 → 违和
❌ 骨肉太冗杂 · 写了 100 个种族但与主线无关 → 设定集 ≠ 故事
❌ 生态没有冲突 · 各势力相安无事 → 没有戏剧张力
❌ 直接 Station 5 远征 · 跳过新手村 → 读者跟不上
❌ 主线事件与世界设定脱节 → 世界观沦为背景板
❌ 主角是绝对幸运儿 · 没有身份绑定 → 缺乏宿命感
```
