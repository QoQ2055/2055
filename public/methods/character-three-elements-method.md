# 立体人物三要素法（外表 + 欲望 + 弱点）

> **来源**：墨香阁柒爷的「立体人物教学案例集」+「让人物与故事长出来」双篇合并。本质是**特鲁比弱点/欲望 + 戏剧反差 + 生长哲学**的古风网文落地版。
> **定位**：character 层 · **教学型 + 范本档案型模块**。与 MBTI 系列正交不互斥，与 `truby-22-steps` 强协同（可视为 Truby 的轻量入门版）。
> **核心价值**：提供"外表反差 + 内在欲望 + 致命弱点"三元素公式 + 四级压力递进模板 + 一句话激活公式 + 5 个古风完整 demo + 故事弧线自发生成模型，LLM 可直接抄作业。
>
> **创作心法**：**别把大纲当圣经，把角色当活人。** 故事不是"造"出来的，是**种**出来的：
>
> ```
> 种子（人物设定） → 土壤（世界观） → 阳光雨露（情节冲突） → 生长（人物在压力下的选择）
> ```

---

## 适用边界

✅ **推荐启用**：
- 古风 / 武侠 / 仙侠 / 玄幻
- 权谋 / 宫斗 / 古言
- 江湖 / 民国 / 架空历史
- 复仇 / 杀手 / 谋士类型化角色
- **需要"反差感立得住"**的任何题材

⚠ **可选启用**（效果略弱）：
- 现代都市（反差多为职场 vs 私生活）
- 校园 / 青春
- 末世 / 科幻

❌ **不要启用**：
- 爽文纯系统流（角色是工具人，不需要立体）
- 纯甜宠 / 日常治愈（反差感会破坏氛围）

## 一、三要素公式（核心）

```
立体人物 = 外表（第一印象/反差）
       + 欲望（表层目标 → 中层动机 → 深层缺失 三层）
       + 弱点（与欲望矛盾或自我毁灭的致命点）
```

### 1.1 外表 · 反差感是关键

**硬律**：外表必须是一个**强视觉标签 + 固定动作 / 口头禅 / 物件**。读者一句话就能复述"他是谁"。

**推荐元素**（至少 3 种）：
- 固定穿着 / 配色（如"永远深灰长袍，袖口雪白"）
- 习惯性小动作（如"摸着串断了无数次的佛珠"）
- 经典台词 / 口头禅（如"那您再考虑考虑"）
- 他人评价（一句话精准刻板印象，**将在全书被颠覆**）
- 功能性道具（如"从不喝热茶"/"永远干干净净的刀"）

**反差触发**：外表标签必须与**弱点**形成反差（冷血商人的弱点却是"抵抗不了信任"），这是立体感的源头。

### 1.1.1 外表深度范式：一个画面背后藏一句话

好的外表描写不是"剑眉星目"，而是**一个画面背后藏着一句话**。三大范式：

| 范式 | 画面 | 背后的故事 |
|---|---|---|
| **历史** | "他左手掌心有一道从虎口斜贯到腕部的疤" | 年轻时替人挡刀留下的 |
| **处境** | "她总穿着不合身的西装，袖口挽了三道" | 生活还没安定下来 |
| **创伤** | "他从来不让人站在他身后" | 曾被背后捅过刀 |

**硬律**：外表描写**每一条都应携带故事信息**——不是外貌，是历史 / 处境 / 创伤 三选一。纯颜值描写一律砍掉。

### 1.2 欲望 · 必须三层

| 层级 | 定义 | 写作要点 |
|---|---|---|
| **表层** | 主角明面上想要什么 | 通常是物质 / 地位 / 具体目标 |
| **中层** | 为什么想要这个 | 往往是某个过去事件的反应 |
| **深层** | 不想面对的真相 | **童年创伤 / 被否定经历 / 无法弥补的遗憾** |

**硬律**：深层必须是**"缺失"**而非"渴望"。例：
- ✅ 深层 = 从未被认可过（缺失）
- ❌ 深层 = 想被所有人崇拜（渴望 → 这其实是中层）

### 1.3 弱点 · 不能是显而易见的

**硬律**：弱点**不能是读者一眼就猜到的**（贪财 / 好色 / 怕死）。真正的弱点是与外表**相反**的那一点。

**反差范式**：
| 外表标签 | 常见猜测弱点 | 真正弱点 |
|---|---|---|
| 冷血商人 | 贪财 | **抵抗不了信任** |
| 躺平咸鱼 | 懒 | **放不下责任感** |
| 完美剑仙 | 自傲 | **不懂与人相处的孤独** |
| 笑面商人 | 圆滑虚伪 | **害怕动真心** |
| 冰冷杀手 | 嗜血 | **下不了手杀无辜** |

**弱点验证**：弱点必须能**主动毁掉主角原有成就 + 必须能触发成长弧线**。否则只是"可爱缺陷"。

### 1.3.1 弱点 = 模式，不是性格标签

**硬律**：弱点**不是**一个形容词（"他冲动"/"她胆小"），而是**一个会重复触发灾难的行为模式**：

```
弱点（模式） → 特定情境触发 → 错误决定 → 付出代价 → 是否改变？
```

- ❌ 错误写法：「他性格太善良，容易心软」（这是标签，抽象无锚点）
- ✅ 正确写法：「只要有人表现出对他的信任，他就会失去判断力」（这是模式，可在具体情境中反复触发）

**验证标准**：一个"模式"必须能在**至少 4 种不同情境**里重复触发（这也是四级压力递进的理论基础）。如果只能触发一两次，那是情节巧合，不是真正的弱点。

## 二、四级压力递进模板（通用公式）

每个立体人物都需要一段"弱点被反复测试 + 不断升级"的成长轨迹，分**四级压力**：

| 级别 | 压力来源 | 主角反应 | 弱点状态 | 章节占比 |
|---|---|---|---|---|
| **轻压** | 小事件触动弱点（日常场景 / 次要角色） | 破例、为此付出小代价 | 弱点首次暴露 | 5% |
| **中压** | 中等事件，弱点被对手利用 | 被动陷入，开始付出中等代价 | 弱点发力 | 15% |
| **重压** | 核心危机，弱点直接导致崩盘 | 失败 / 失去重要东西 / 自我怀疑 | 最低点（真高潮） | 20% |
| **终极压** | 反派将弱点武器化 / 揭露真相 | **被迫做出与过去相反的选择** | 生长起点 | 15% |

**硬律**：
- 四级必须**单向递进**，不能折返
- 终极压的"相反选择"**必须可观察**（具体动作而非内心独白）
- 终极压**不等于结局**，它是生长的起点，后续还需要 2–3 章展示"新的平衡"

## 三、冲突孕育 · 三类冲突 × 角色暴露

**核心洞察**：故事不是大纲写出来的，是**冲突喂养**出来的。把立体角色放进冲突场景，故事会**自己长出来**。

| 冲突类型 | 角色暴露什么 | 故事能长出什么 |
|---|---|---|
| **与他人冲突** | 欲望 vs 他人的欲望 | 对手 / 反派 / 联盟 / 背叛 |
| **与环境冲突** | 弱点的代价 | 资源争夺 / 规则突破 / 阶层跃迁 |
| **与自我冲突** | 欲望 vs 核心价值观 | 内心戏 / 转变节点 / 高光时刻 |

**操作方法**：先写好立体角色（三要素齐备），再问：

> 现在把这几个角色关进同一个冲突场景，**以他们的三要素，会自然发生什么事？**

**硬律**：不要"写"故事，要**"发现"**故事。就像不"造"一棵树，而是种下种子、浇水、看它长成什么样。允许角色做出**出乎作者意料**的选择——那是它真的活了的标志。

## 四、故事弧线 · 四阶段自发生成

当人物三要素立体后，故事弧线会**自然生长**。这与 `truby-22-steps` 的 22 步是同一逻辑的压缩版：

```
─── 第一阶段 · 欲望初显 ───
欲望驱动行动 → 弱点导致失败 → 欲望升级 / 修正

─── 第二阶段 · 代价升级 ───
新的行动 → 旧弱点再次导致更大代价 → 角色开始怀疑自我

─── 第三阶段 · 最低点（对应 truby 第 10 步"真正自我揭露"）───
欲望几乎放弃 + 弱点完全击垮角色
→ 核心价值观被极限挑战 → 产生觉醒

─── 第四阶段 · 重生（对应 truby 第 15 步"真实自我揭露"）───
欲望被重新定义（或根本不变但动机深化）
+ 弱点被识别并主动对抗
→ 做出与第一阶段截然不同的选择
```

**硬律**：**每写一步，角色的选择制造后果，后果创造新的情境，新的情境测试角色更深层的东西。** 这就是生长。不允许"为了推进情节"让角色做违背三要素的选择——如果必须违背，那是作者在"造故事"，而非角色在"长故事"。

### 4.1 让读者"看到"生长——不写内心 OS，让行为说话

**错误写法**：在关键章节花一整段写"他变了"、"他想通了"、"他开始明白……"

**正确写法**：让角色做出**与之前不同的具体选择**，读者自己看出来：

```
前 30 章：有人当街羞辱他，他笑着走了（符合"不惹事"的一贯模式）
第 70 章：同样的人同样的话，他捡起路边酒瓶就直接往对方头上砸
```

不需要任何心理描写，读者自然知道——**这个人在这里生长了**。

## 五、一句话激活公式（logline 级）

每个立体人物的最终塑造应能浓缩为**一句话**，这句话**同时绑定三要素**：

```
他用 [外表对应的行为动词 + 时间] 把自己活成 [外表隐喻物]，
就是为了验证——[弱点对应的深层质疑]。
```

**5 个范例（凝练句式）**：

| 人物 | 一句话激活 |
|---|---|
| 冷血商人 | 他用十年把自己活成一柄刀，就是为了验证——这世上到底有没有一个人，值得他把刀放下 |
| 躺平咸鱼 | 他想躺平一辈子，可这个狗日的人间，连一张能躺平的床都不肯给他 |
| 完美剑仙 | 他们把最好的剑术教给了他，却没教他——一个人该怎样笑 |
| 笑面商人 | 她用十五年学会怎么笑给所有人看，却用尽一生学不会——怎么笑给自己看 |
| 冰冷杀手 | 他靠仇恨活了十二年，到头来才发现——让他活下来的从来不是恨，是那把刀下还藏着一颗没死透的心 |

**结构共性**：
- 前半句陈述**外表 / 欲望的表现**
- 后半句揭露**弱点驱动的终极质疑**（常用"却"/"可"/"到头来"转折）

**写作用途**：
- 写人物卡时必做此句，作为全书塑造的"北极星"
- 每章写该角色时先读一遍，保持一致性
- 后续润色检查：角色行为是否在回应这句话

## 六、5 个古风完整 demo（精简版，可直接抄）

### 6.1 冷血商人 · 赵九渊

- **外表**：京城最大地下钱庄老板；深灰长袍雪白袖口；柜台永远凉透的茶；"砍左手还是右手"面不改色
- **欲望**：表层=天下第一富商 / 中层=让抛弃他母子的赵家跪下 / 深层=从未被认可
- **弱点**：**抵抗不了信任**——所有人以为是贪财好色，全错
- **四级压力**：伙计一句"我信你"多给三倍工钱 → 卧底潜伏两年收作干儿子 → 干儿子卷走所有资金 → 对手把干儿子打残扔回他面前
- **激活句**：他用十年把自己活成一柄刀，就是为了验证——这世上到底有没有一个人，值得他把刀放下

### 6.2 躺平咸鱼 · 沈青木

- **外表**：村口废柴；打六个补丁的短褐；唯一热情是钓鱼"因为鱼不上钩我可以心安理得发呆"
- **欲望**：表层=躺到死 / 中层=不想再卷（武试废了右手筋）/ 深层=输一次后不敢全力做任何事
- **弱点**：**责任感**——嘴上"关我屁事"腿却不听使唤
- **四级压力**：村长让他接任连夜跑山上 → 地痞打卖豆腐的王婶半夜去揍了 → 山贼屠村他折断渔竿说"就这一次" → 山贼首领正是当年废他手筋的主考官
- **激活句**：他想躺平一辈子，可这个狗日的人间，连一张能躺平的床都不肯给他

### 6.3 完美剑仙 · 陆清商

- **外表**：天道宗最年轻元婴长老；白衣如雪；三百年百战全胜；脸上少了那根笑的神经
- **欲望**：表层=飞升 / 中层=证明不是"为剑而生的工具" / 深层=从小被当最强的剑培养没有童年
- **弱点**：**不懂与人相处的孤独**——深夜用剑尖在月光下写师妹教的诗
- **四级压力**：小师妹缠他他冷着脸避开但她受伤第一个飞去 → 魔道设局要修士动情破阵他第一次在公开场合笑 → 师尊说"培养你就是为让你碎剑献祭"他第一次问"为什么是我" → 献祭阵启动师妹扑过来挡剑他终于吼出"我自己决定我怎么活"
- **激活句**：他们把最好的剑术教给了他，却没教他——一个人该怎样笑

### 6.4 笑面商人 · 柳如是

- **外表**：江南商会副会长"笑面狐"；30 岁妇人永远挂恰到好处的笑；手串檀木佛珠；"您说得好"/"那您再考虑考虑"
- **欲望**：表层=天下第一商 / 中层=再不回到求人的日子 / 深层=15 岁被卖给绸缎商做妾三年，后来杀了那男人
- **弱点**：**害怕动真心**——一发现对谁有真感情第一反应是推远
- **四级压力**：年轻人帮她大忙不求回报她加倍还钱再不见他 → 朝廷要查她选中他当盟友刻意保持公事距离 → 他为她挡暗箭性命垂危她床前守三天捻断佛珠 → 他醒了问"你喜欢我" 她笑说"您想多了"转角蹲下哭
- **激活句**：她用十五年学会怎么笑给所有人看，却用尽一生学不会——怎么笑给自己看

### 6.5 冰冷杀手 · 燕七

- **外表**：悬榜司金牌杀手；黑斗篷帽檐压得很低；一刀封喉从不多看死者；刀永远擦得干净一丝血迹不留
- **欲望**：表层=赚钱变强 / 中层=找十二年前屠燕家堡的凶手 / 深层=七岁躲在母亲尸体下听凶手脚步走过头顶，每晚被那脚步声惊醒
- **弱点**：**下不了手杀无辜**——与职业完全冲突
- **四级压力**：目标贪官有八岁女儿他杀了贪官但留信让她找亲戚 → 悬榜司派他杀的叛徒是当年知情者他没杀反逼问线索 → 真凶浮出是合作的情报贩子反手出卖他，破庙里自己缝伤口第一次哭 → 情报贩子挟持那八岁女孩作人质他丢掉那把刀空手走进包围圈
- **激活句**：他靠仇恨活了十二年，到头来才发现——让他活下来的从来不是恨，是那把刀下还藏着一颗没死透的心

## 七、教学使用法（四步训练 LLM）

写角色 bible 时按此四步推进，让人物立体感自然生长：

1. **先出外表**：让读者形成"我以为他是这种人"的第一印象（stereotype）
2. **再揭欲望**：让读者看到外表的"原因"，**修正第一印象**（表层 → 中层 → 深层）
3. **最后曝弱点**：让读者**恍然大悟"原来这才是他"**——弱点与外表的反差是立体感的核心
4. **展示压力生长**：让读者看到四级压力如何驱动角色成长，**写到终极压时三要素全部被触发**

**硬律**：任何立体角色的设计**顺序不能颠倒**——先想弱点再编外表会生硬，先有外表再挖欲望才自然。

## 八、避坑指南 · 5 条常见错误

| 常见错误 | 后果 | 修正 |
|---|---|---|
| 外表写一大段「剑眉星目」/ 颜值描述 | 读者记不住 | 写**一个**关键视觉记忆点，且必须附带**历史/处境/创伤**信息 |
| 欲望写得太笼统（"想变强"/"想报仇"） | 没有动力源 | **追到第三层**——为什么想变强？缺的是什么？ |
| 弱点是「太善良」/「太正义」（伪弱点） | 不真实、不带来代价 | 真弱点**必须让角色真的吃亏**——带来具体的、不可逆的损失 |
| 角色从头到尾行为一致 | 没生长 | 每个重大事件后必问：**这件事会改变他的哪个要素？** |
| 所有角色都按作者意志行事 | 没有生命力 | 允许角色做出**出乎作者意料**的选择——那是它真的活了 |

## 九、与其他模块协同

- **与 `truby-22-steps`**：**极强协同**（最佳搭档）。本模块=Truby 第 1、2 步 + 弧线压缩版；Truby 第 9、10、15 步对应本模块四级压力的重压/终极压/生长起点。长篇用 Truby，中短篇用本模块。
- **与 `mbti-5step` / `mbti-cognitive-functions`**：正交叠加。MBTI 管**认知方式**（怎么想），本模块管**外显反差**（怎么看起来）。两者同时启用时，弱点可绑定 MBTI 劣势功能（如 INTJ 的 Se 劣势 = 抵抗不了当下的信任冲动）。
- **与 `mbti-16-archetype-cards`**：**强协同**。本模块提供 5 个古风人物的完整四级压力路径，可作为 16 型档案的"落地示例"补充。
- **与 `seven-points-romance`**：强协同。言情主角的"情感缺陷"就是本模块的"弱点"；情感缺陷 = 害怕动真心 / 不相信真心等，与柳如是 demo 结构完全一致。
- **与 `supernatural-webfiction-pack`**：强协同。三要素法 + 超自然元素三维编码 = 完整的"古风修仙主角套餐"（如陆清商 demo）。
- **与 `pixar-22-rules`**：协同。Pixar 第 4 条（角色弧）+ 第 17 条（反对派擅长什么）都能从三要素里导出。
- **与结构骨架**：正交，不参与结构层。
