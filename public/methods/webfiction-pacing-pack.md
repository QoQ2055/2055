# 爽文/网文节奏全家桶（Webfiction Pacing Pack）

> **来源**：番茄小说 16 门写作课程体系 v2.0 提炼 +《天眼女相师》项目实例验证（实例归档：`@docs/reference-works/tianyan-female-psychic-style-guide.md`）。
> **定位**：craft 工艺层 · **爽文/网文专用节奏与爽点结构模块**。注入 `novel.2`（结构分卷应用宏观五阶段）+ `novel.3.1` / `novel.3.2`（章节草稿应用单章 5 段式）。
> **与其他模块边界**：
> - `seven-emotion-peaks` = 通用情绪美学（任何题材）
> - `anti-ai-flavor` = 反 AI 文风（字句层）
> - `plot-coherence-scaffold` = 防散架（因果层）
> - **本模块** = **爽文专属节奏 + 爽点设计 + 钩子工程**（商业向连载层）

## 适用边界

✅ **强推荐**（爽文核心题材）：
- 爽文 / 网文 / 系统流 / 重生 / 穿越
- 修仙 / 玄幻 / 都市异能 / 玄学捉鬼
- 战神 / 神豪 / 龙王 / 兵王 / 神医

✅ **推荐**：
- 都市言情 / 古言 / 灵异
- 武侠 / 仙侠（爽感向）

✅ **弱推**（部分技法可借鉴）：
- 悬疑 / 推理（钩子设计部分可用）
- 历史架空（宏观节奏可用）

❌ **不推荐**：
- 严肃文学 / 纯爱 / 治愈
- 校园日常 / 散文化作品
- 短篇 / 微小说（爽点结构开销 > 收益）

## 一、风格定位三要素（写作前必填）

LLM 应用本模块前先确认 3 件事：

| 要素 | 内容 |
|---|---|
| **类型标签** | 现代都市 / 玄学捉鬼 / 爽文 / 悬疑复仇 等（3-5 个） |
| **行文基调** | 简洁有力 / 紧张诡异 / 甜宠暧昧 / 热血励志（一句话） |
| **核心卖点** | 一句话说出读者为什么追这本书 |

## 二、黄金前三章规范

### 2.1 第一章开篇 5 句公式

```
第1句（冲突）：呈现困境/诡异感知/危机（≤ 50 字）
第2-3句：核心悬念（为什么/怎么回事）
第4-5句：场景延续（事件继续）
结尾：留钩（读者必须追下一章）
```

### 2.2 黄金前三章 5 必备要素

| 要素 | 实现位置 |
|---|---|
| **核心冲突 / 危机** | 第 1 章即呈现 |
| **主角性格展示** | 第 1 章通过台词 + 行动展示（不靠旁白） |
| **金手指 / 能力初显** | 第 1 章即小秀一次 |
| **主线悬念埋入** | 第 1 章埋入主线钩子（家族 / 仇人 / 身世） |
| **章节钩子** | 每章结尾必留悬念 |

### 2.3 开篇 6 条禁忌

- ❌ 以背景介绍 / 环境描写开篇（第 1 句不能是天气 / 场景描写）
- ❌ 用"三年前 / 十年前"做时间跳跃（第 1 章从头讲）
- ❌ 一次性透露超过 **3 个新设定**
- ❌ 开篇出现超过 **3 个新角色**
- ❌ 前 300 字超过 **4 句对话**
- ❌ 上来就超过 **2 句内心独白**

## 三、单章 5 段式爽点结构（核心硬律）

> **基于"钩子九连环"+"副本三段式"提炼**

### 3.1 5 段标准比例（以 3000 字章节为基准）

| 段 | 字数 | 内容 |
|---|---|---|
| ① 开篇冲突 | **200-300**（10%） | 直接呈现困境 / 危机，无铺垫 |
| ② 铺垫蓄力 | **800-1000**（30%） | 调查 / 感知 / 推理，让爽点有依据 |
| ③ 爽点爆发 | **1000-1200**（35-40%） | 主角行动 / 反击 / 揭底牌 |
| ④ 配角反应 | **300-500**（15%） | 配角震惊 / 愤怒 / 不敢相信，把爽感"转化"成读者情绪 |
| ⑤ 章节钩 | **200-300**（10%） | 留下下一悬念 / 更大危机 |

### 3.2 字数自动缩放规则（不是 3000 字章节时）

| 章节字数 | ① 开篇 | ② 蓄力 | ③ 爆发 | ④ 反应 | ⑤ 钩 |
|---|---|---|---|---|---|
| 2000 字 | 150-200 | 500-650 | 700-800 | 200-300 | 150-200 |
| 3000 字 | 200-300 | 800-1000 | 1000-1200 | 300-500 | 200-300 |
| 4000 字 | 300-400 | 1100-1300 | 1400-1600 | 400-600 | 300-400 |
| 5000 字 | 400-500 | 1400-1600 | 1700-2000 | 500-800 | 400-500 |

**硬律**：① + ⑤ ≈ 总字数 20%；② + ④ ≈ 总字数 45%；③（爆发） ≈ 总字数 35%。爆发段不足 30% = 该章爽感不足。

## 四、长篇宏观 5 阶段节奏（百章基准比例）

> **以 100 章为基准比例缩放**：50 章 / 200 章 / 300 章按比例放大或压缩

### 4.1 五阶段总览

| 阶段 | 占比 | 名称 | 核心任务 | 爽点密度 |
|---|---|---|---|---|
| **第一阶段** | 0–10% | **开篇立势** | 主角亮相 + 第一个副本 + 命运对手登场 | 每章 1 个小爽点 |
| **第二阶段** | 10–30% | **悬念铺陈** | 反派组织登场 + 主线线索铺设 + 感情线起航 | 每 5 章 1 个单元爽点 |
| **第三阶段** | 30–60% | **高潮密集** | 真相分层揭开 + 反派对抗 + 终极悬念逼近 | 每 3 章 1 个爽点 |
| **第四阶段** | 60–85% | **余韵收束** | 残余清剿 + 感情确认 + 配角支线收束 | 每 5 章 1 个 |
| **第五阶段** | 85–100% | **终章余波** | 各角色最终命运 + 情感余韵 | 每 5–10 章 1 个 |

### 4.2 阶段间衔接硬律

- **每阶段末必留大悬念钩**（卷尾钩，引读者进入下阶段）
- **第三阶段是爆发阶段**，所有伏笔在这里集中回收
- **第五阶段不再设新悬念**，只做情感收束

### 4.3 三种章节切片

| 切片 | 用途 | 频率 |
|---|---|---|
| **副本章**（独立小冲突 + 当章解决） | 单元爽点载体 | 70-80% |
| **推进章**（主线大事件 / 真相揭示） | 主线引擎 | 15-20% |
| **呼吸章**（感情 / 日常 / 互动） | 情绪缓冲 | 5-10% |

**禁忌**：连续 3 章以上同一切片类型 = 节奏失衡。

## 五、情绪 5 类型频率管理（阅读体验）

| 情绪类型 | 出现频率 | 持续时长 | 作用 |
|---|---|---|---|
| **悬疑 / 诡异** | 始终保持 | 贯穿全文 | 任何时候都要有一个未解悬念 |
| **紧张 / 危机** | 每 3-5 章 | 1-2 章 | 副本 / 反派追击 / 危机事件 |
| **释放 / 打脸** | 每次危机后 | 0.5-1 章 | 蓄力后的爽感释放 |
| **甜蜜 / 暧昧** | 每 10-15 章 | 0.5-1 章 | 感情互动，不能喧宾夺主 |
| **温情 / 感动** | 每 20-30 章 | 0.5 章 | 配角 / 感情温情场景，点缀 |

**节奏 4 禁忌**：
- ❌ 全程紧张无舒缓（读者疲劳）
- ❌ 全程平缓无起伏（无爽感）
- ❌ 高潮拖得太长（每章高潮不超过 3 段）
- ❌ 章节结尾写完整事件（只写 80%，下章再揭示结果）

## 六、爽点设计体系

### 6.1 爽点 3 级优先级

| 优先级 | 类型 | 频率 |
|---|---|---|
| **核心爽点** | 金手指碾压 / 毒舌打脸 | 每章至少 1 次 |
| **二级爽点** | 悬疑揭示 / 命定 CP 互动 | 每 8-15 章 1 次 |
| **三级爽点** | 路人不识货 / 配角高光 | 每 5-15 章点缀 |

### 6.2 爽点 4 步公式（每个爽点必走 4 步）

```
① 触发条件：什么场景 / 什么对手出现，启动爽点
② 蓄力方式：先让对方充分表演 / 充分丢人，让爽感蓄力
③ 爆发方式：主角一句话 / 一个动作，简短有力，不解释
④ 后续延伸：爽点不孤立——必须延伸到主线（指向新线索 / 新仇人）
```

**硬律**：
- 步骤 ②（蓄力）字数 ≥ 步骤 ③（爆发）字数（蓄力不够 = 爆发无力）
- 步骤 ③（爆发）必须**当场打脸**（不拖到下一章）
- 步骤 ④（延伸）必须有，否则爽点变成无意义片段

### 6.3 爽点禁忌

- ❌ **同一种打脸套路连用 3 次**（必须换花样）
- ❌ **爽点孤立**（不延伸到主线 = 水文）
- ❌ **解释爽点的原理**（金手指为什么有用？不解释，让读者爽就行）

## 七、对话写作基准

### 7.1 4 类场景的对话密度规范

| 场景类型 | 对话密度 | 每句平均字数 | 潜台词要求 |
|---|---|---|---|
| **打脸 / 副本** | 高（4-6 句/段） | ≤ 20 字 | 必须有 |
| **悬疑 / 紧张** | 极低（1-2 句/段） | ≤ 15 字 | 必须有，用沉默 / 动作代替 |
| **日常 / 感情** | 低（2-3 句/段） | ≤ 25 字 | 可省略 |
| **揭秘 / 高潮** | 极低（1-2 句/段） | ≤ 15 字 | 必须有，言简意赅 |

### 7.2 对话 5 钩子技巧

- **对话留白**："算了，没什么。"——让读者追问
- **对话中断**：被打断的动作 / 话语，制造悬念
- **反常回答**：问 A 答 B，出乎意料
- **毒舌一句**："就这？"（标志性句式）
- **沉默胜有声**：关键时刻的沉默比任何台词都有分量

### 7.3 对话硬律

- 主角应有 **3 个标志性句式**（贯穿全文，开篇即确立）
- 主角内心独白 **≤ 200 字 / 段**（用感知/视觉代替"我觉得"）
- **不写"本座 / 贫道 / 施主"等套话**（除非定位为古风仙侠）

## 八、章节收尾规范

### 8.1 4 类章节钩子（必择其一）

| 类型 | 用途 |
|---|---|
| **悬念钩** | 留下未解问题（最常用，70%） |
| **冲突钩** | 正要发生冲突，戛然而止（高潮章后） |
| **反转钩** | 出乎意料的转折（揭秘章） |
| **情感钩** | 情感高潮点截断（感情章） |

### 8.2 章节收尾 4 禁忌

- ❌ **把完整事件写完**（只写 80%，下一章开头再揭示结果）
- ❌ **以感叹号强行制造高潮**
- ❌ **以旁白 / 总结句收尾**
- ❌ **以"本章完"或类似字样**

## 九、人物描写硬律（爽文专属）

### 9.1 主角（金手指角色）

| 维度 | 规范 |
|---|---|
| **性格展示** | 通过行动展示，不直接陈述内心（用感知/视觉代替"我觉得"） |
| **行动逻辑** | 危机 → 感知 / 判断 → 行动 → 结果，不凭空行动 |
| **语言风格** | 简短有力，毒舌三连：讽刺 / 反问 / 轻飘飘一句话 |
| **禁忌** | 不解释金手指原理 / 不对敌人啰嗦 / 不悲春伤秋 |

### 9.2 命运对手（CP 男主 / 女主）

| 维度 | 规范 |
|---|---|
| **与主角区分度** | 主角张扬 → 对手沉静；主角毒舌 → 对手少言；反差出彩 |
| **出场节奏** | 第 1-3 章即出场，但不能抢主角高光 |
| **专属反差萌** | 高冷外表 + 唯独对主角软化 |

### 9.3 反派分级硬律

| 反派级别 | 描写要点 |
|---|---|
| **小反派**（章级） | 一个可笑 / 可恨的点，1-2 章内打脸解决 |
| **中反派**（卷级） | 有自己的逻辑，行为有动机，打脸附带代价 |
| **大反派**（书级） | 不能纯粹邪恶，必须有读者能理解的理由（伏笔到大揭秘） |

### 9.4 配角硬律

- 每个配角必须有 **1 个核心记忆点**
- 不允许超过 **3 个相似配角**（同质化 = 配角失败）
- **工具人**（委托客户 / 路人）功能性即可，不需要弧光

## 十、语言禁区 11 条

- ❌ "此外 / 然而 / 值得注意的是" 等 AI 词汇
- ❌ 连续 3 个 "的" 字结构
- ❌ 环境描写超过 200 字 / 段
- ❌ 同一场景超过 3 句环境描写
- ❌ 以恐怖 / 恶心为目的的描写（诡异感 ≠ 恐怖感）
- ❌ 鬼怪 / 反派有完整人类情感（保持神秘）
- ❌ 配角反应完全雷同（每个角色独特反应模式）
- ❌ 重复打脸套路（每次必须新花样）
- ❌ 玄学 / 设定知识说教（融入剧情而非旁白解释）
- ❌ 主角圣母 / 软弱 / 恋爱脑
- ❌ 任何一方舔狗行为（感情靠相互吸引）

## 十一、与其他模块协同

| 模块 | 协同方式 |
|---|---|
| `seven-emotion-peaks` | 七情绪峰是**单章情绪曲线**美学，本模块的"5 段式 ② → ③ → ④"实际就是 mountain 型情绪峰的爽文具象化 |

| `plot-coherence-scaffold` | 双开。plot-coherence 管"防散架"（伏笔回收），本模块管"加爽点"（钩子工程） |

| `pixar-22-rules` | 弱协同。pixar 偏反套路；本模块偏"用套路用得对" |
| 结构骨架 | 本模块的五阶段比例可与任何骨架（三幕式 / 英雄之旅 / Save the Cat 等）互相套用，不冲突 |

## 十二、章末自检（写作完成后）

LLM 完成章节后必须自检：

- [ ] 单章 5 段比例是否达标（爆发段 ≥ 30%）？
- [ ] 章节钩子类型（4 类之一）？
- [ ] 至少 1 个核心爽点？
- [ ] 爽点 4 步公式是否走完（特别是步骤 ④ 延伸到主线）？
- [ ] 是否触及任意一条 11 语言禁区？
- [ ] 对话密度是否符合本场景类型规范？

任一不达标 → 该章需重写或调整。

## 一句话原则

> **爽文的 350 万字不是写出来的，是按节奏配出来的。** 单章 5 段是**点**，宏观 5 阶段是**线**，情绪 5 类型是**面**，三者交织成读者**追文**的引力场。
