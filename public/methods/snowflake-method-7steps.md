# 雪花写作法 · 立项收紧七步（Snowflake Method）

> **来源**：Randy Ingermanson 1998 提出的国际经典写作方法论 + 实战中文整理版（原文归档：`@docs/prompt-archives/snowflake-method-original.md`）。
> **定位**：craft 工艺层 · **立项阶段的"先收紧再展开"硬律模块**。
> **作用层级**：在结构骨架（Save the Cat / 英雄之旅 / 三幕式 等 9 选 1）**之前**生效。
> - 9 大结构骨架告诉 LLM「故事的形状」
> - 雪花法告诉 LLM「故事的生成方式」
> - 两者**正交叠加，不冲突**

---

## 适用边界

✅ **强推荐**：
- 长篇 / 超长篇连载（避免越写越散）
- 新手项目 / 第一次启动该题材的项目
- 卷与卷之间需重启大纲的连载项目
- 多线索 / 多 POV 复杂叙事

✅ **推荐**：
- 中篇 / 标准长度小说
- 任何注重结构稳定性的项目

❌ **不推荐**：
- 短篇 / 微小说（开销 > 收益）
- 散文化 / 意识流作品（不需要骨架）
- 已有清晰大纲的成熟项目（重复劳动）

---

## 一、雪花法核心理念

> **把一个故事，从小到大慢慢长出来。就像雪花一样，一层一层展开。**

**解决三大新手痛点**：

| 痛点 | 雪花法的解决 |
|---|---|
| 大纲写得太细，细到自己头疼 | 从一句话开始，逐步扩展 |
| 凭感觉写，想到哪写到哪 | 有结构化框架，不跑偏 |
| 伏笔一堆，最后填不上 | 每层扩展时验证结构完整性 |

---

## 二、立项前置：先回答两个问题

LLM 在生成立意总纲前必须先回答：

### 问题 1 · 小说类型？
玄幻 / 都市 / 悬疑 / 历史 / 言情 / 科幻 / ……（一个主类型 + 1-2 个子标签）

### 问题 2 · 目标读者**偏好**（不是年龄性别）？

⚠ **关键**：目标读者不是"18-30 男性"，而是**阅读偏好**：

| 读者偏好 | 对应写法 |
|---|---|
| 喜欢升级打怪 | 爽点密集，升级快 |
| 喜欢权谋智斗 | 智斗多，反转多 |
| 喜欢反套路剧情 | 打破常规，意外感强 |
| 喜欢甜宠互动 | 感情线密度高，CP 戏足 |
| 喜欢悬疑解密 | 钩子层叠，每章揭一层 |

**硬律**：两个问题都没回答清楚 → 不允许进入立意总纲。

## 三、第一步 · 一句话故事（≤ 25 字）

> **90% 的新人死在这一步**——因为太复杂或太模糊。

### 硬律

- ✅ 一句话讲清楚
- ✅ **≤ 25 个字**
- ✅ 不剧透结局
- ✅ 可以直接当卖点

### 公式

```
主角 + 面临核心冲突 + 必须做出的关键行动
```

### 经典范例

| 作品 | 一句话概括 |
|---|---|
| 《功夫》 | 一个整天想加入黑帮的街头混混，意外发现自己是个武学奇才 |
| 《泰坦尼克号》 | 一个穷小子跟一个富家女在轮船上相爱了，结果船撞上冰山沉了 |
| 《盗梦空间》 | 一个能进入梦境窃取秘密的人，接下了一个反向植入想法的任务 |

### 写法示例

```
落魄修士被逐出宗门，为复仇踏上禁忌修行之路。
```

> 故事味道立刻出来了。

**自检**：写出来的句子是否同时满足"故事味"+"卖点感"+"≤ 25 字"？任一不满足 → 重写。

---

## 四、第二步 · 五句话故事骨架

把一句话扩展为 5 句话。**每句话只写方向，不写细节**。

### 5 句结构

| 序号 | 内容 | 作用 |
|---|---|---|
| 1 | **故事背景** | 交代世界观 / 设定 |
| 2 | **冲突出现** | 引发故事的事件 |
| 3 | **第一次重大灾难** | 逼主角做决定 |
| 4 | **第二次灾难升级** | 剧情推到新阶段 |
| 5 | **最终危机** | 高潮对决 |

### 灾难性事件三作用（核心理论）

每一次"灾难"必须同时实现：
- **① 给读者情绪刺激**
- **② 逼主角做决定**
- **③ 把剧情推到新阶段（剧情换轨道）**

**硬律**：
- 三作用任一缺失 = 该"灾难"是无效事件，需重设
- 第一次灾难和第二次灾难**必须升级**（不可平级）

### 经典范例 · 《回家的诱惑》

> 灾难 1：女主林品如坠海，所有人都以为她死了。
> 结果：① 读者情绪被点燃 ② 她决定改名换姓 ③ 剧情从"被欺凌的妻子"换轨到"复仇女王"

## 五、第三步 · 一页人物介绍（5 问法）

> **人物先立住，故事才能好看。**

### 5 问法

| 问 | 说明 | 示例（《星汉灿烂》程少商） |
|---|---|---|
| **是谁？** | 名字 + 身份 | 程少商，被忽视的世家女 |
| **最想得到什么？** | 核心目标 | 在复杂家族和权力斗争中活下来，掌握自己的命运 |
| **最大阻碍？** | 核心冲突 | 家族内斗 / 礼教束缚 / 朝堂权谋 |
| **价值观？** | 行为准则 | 人必须掌控自己的命运 |
| **最后会改变什么？** | 人物弧光 | 明白真正的强大不是一个人对抗全世界，而是学会信任和守护别人 |

### 硬律

- 5 问必须**每问都回答**，缺一不可
- 主角 5 问必填，重要配角和反派可简化（必填问 1 / 2 / 3）
- "最后会改变什么"必须**指向人物弧光**——回答不出来 = 角色无成长 = 不值得写

### 与三要素法的区别

| 模块 | 视角 | 关注点 |
|---|---|---|
| `character-three-elements-method` | **描述层**（外表 + 欲望 + 弱点） | 角色是什么样 |
| 本模块 5 问法 | **问询层**（是谁 / 想要 / 阻碍 / 价值观 / 改变） | 角色为何而活 |

**两者可双开互补**：5 问法定方向，三要素法定细节。

## 六、第四步及以后 · 不断"放大"

### 雪花放大流程

```
一句话（≤ 25 字）
   ↓ 扩展 5 倍
五句话（5 个方向）
   ↓ 扩展 10 倍
一页人物（5 问 × N 个角色）
   ↓ 扩展 5 倍
多页剧情（5 句 → 每句扩 5-10 段）
   ↓ 扩展 10 倍
每章细纲（章 = 段的具象化）
   ↓ 扩展 100 倍
具体场景（章 → 场景 → 字句）
```

### 每层扩展的硬律

每次扩展前**必须验证上一层结构完整**：

- 一句话写好 → 才能写五句
- 五句立住 → 才能写人物
- 人物立住 → 才能写剧情
- 剧情成形 → 才能写章节

**违反 = 后期高概率写崩**。

## 七、4 类冲突类型（写五句话时必选其一为主轴）

| 类型 | 内核 | 示例 |
|---|---|---|
| **利益冲突** | 资源争夺 | 权力斗争 / 商战 / 修仙资源 |
| **价值观冲突** | 理念对立 | 正邪对抗 / 旧道德 vs 新觉醒 |
| **生存冲突** | 生死存亡 | 末世 / 追杀 / 危机四伏 |
| **情感冲突** | 爱恨情仇 | 三角恋 / 师徒决裂 / 内心挣扎 |

**硬律**：
- 主线**主轴冲突 1 类**（不可超过 2 类，否则散）
- 支线可补充**1-2 类辅助冲突**
- 4 类全用 = 主线模糊

## 八、cineforge-web 流水线投影

雪花法的层层放大本质上就是 cineforge-web 流水线的精神内核：

| 雪花法层级 | cineforge-web 节点 | 本模块作用 |
|---|---|---|
| 一句话（≤ 25 字） | `novel.1`（立意总纲）开头 | **强制硬律**：节点产物头部必有一句话 |
| 五句话 | `novel.1`（立意总纲）主体 | **强制硬律**：必含五句话骨架 |
| 一页人物 | `novel.1.2`（人物） | **强制硬律**：每个核心角色必走 5 问法 |
| 多页剧情 | `novel.2`（结构分卷） | 由结构骨架（9 选 1）展开 |
| 每章细纲 | `novel.2` 末端 / `novel.3.1` 头 | — |
| 具体场景 | `novel.3.1` / `novel.3.2`（章节） | — |

## 九、与其他模块协同

### 与 9 大结构骨架（**正交叠加**）

雪花法在**前置生成**阶段，结构骨架在**展开**阶段：
- 雪花法用一句话 + 五句话先**收紧**故事
- 然后选一个结构骨架（Save the Cat / 英雄之旅 / 三幕式 / ATU 301 等）**展开**
- 五句话的"灾难 1 / 灾难 2 / 最终危机"会自然映射到结构骨架的"中点 / 第二幕高潮 / 终局"

### 与 `character-three-elements-method`

5 问法定**方向**（角色为何而活），三要素法定**细节**（外表 + 欲望 + 弱点）。**双开互补**。

### 与 `world-building-9-pillars`

雪花法第一步问"小说类型"= 9 柱柱 1（故事类型与基调）。**入口共用**。

### 与 `webfiction-pacing-pack`

雪花法的"灾难性事件三作用" = 爽文 5 段式中的"爆发段"理论基础。**节奏映射**。

## 十、立项前 5 项自检

LLM 完成立意总纲（`novel.1`）和人物（`novel.1.2`）后必须自检：

- [ ] 一句话是否 ≤ 25 字？
- [ ] 一句话是否包含主角 + 核心冲突 + 关键行动？
- [ ] 五句话是否完整（背景 / 冲突 / 灾难 1 / 灾难 2 / 最终危机）？
- [ ] 两次灾难是否都满足三作用（情绪刺激 / 逼决定 / 推新阶段）？
- [ ] 主角 5 问是否都回答了，特别是"最后会改变什么"？

任一不达标 → 立意 / 人物节点需重写。

---

## 一句话原则

> **故事不是一次性写出来的，是从一颗种子（一句话）层层长出来的雪花。每一层的稳固，决定下一层的可能性。**
