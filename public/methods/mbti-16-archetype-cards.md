# MBTI 16 型角色档案速查卡（工业化量产包）

> **来源**：用户上传《MBTI 角色设计方案（进阶版）》。
> **定位**：**档案参考型模块**，不提供方法论（方法论见 `mbti-5step` 或 `mbti-cognitive-functions`），只提供 16 型每一型的 5 字段速查档案 + 团队配置配方 + 反刻板避坑表。
> **与其他 MBTI 模块关系**：**正交叠加**（不互斥）。可与 `mbti-5step` **或** `mbti-cognitive-functions` 任一方法论模块同时启用，为方法论提供"可直接抄用的档案"。
> **不叠加的场景**：若项目 token 预算紧张、方法论模块已足够用，本模块可不启用。

## 二、团队配置配方（直接套用）

### 2.1 万能主角团（5–7 人，基础款）

| 职位 | 推荐类型 | 主导功能 | 职责 |
|---|---|---|---|
| **决策核心** | ENTJ / ENFJ | Te / Fe | 最终拍板、领导方向 |
| **智囊分析** | INTP / INTJ | Ti / Ni | 分析局势、预判风险 |
| **行动执行** | ESTP / ISTP | Se / Ti | 危机处理、战斗 / 技术输出 |
| **润滑连接** | ESFJ / ENFJ | Fe / Si | 维护关系、调节氛围 |
| **稳定支柱** | ISTJ / ISFJ | Si / Fe | 可靠后勤、细节把关 |
| **理想旗帜** | INFP / ENFP | Fi / Ne | 道德准绳、激励启发 |

**配组硬律**：核心 5 个职位必须到位，"润滑连接"和"理想旗帜"可合并到其他角色身上（如 ENFJ 一人兼两职），**但主导功能覆盖率必须 ≥ 6 种**（群像才不单薄）。

### 2.2 经典反派团（4 人配置）

| 职位 | 推荐类型 | 功能 | 角色定位 |
|---|---|---|---|
| **Mastermind** 幕后策划 | INTJ / ENTP | Ni+Te / Ne+Ti | 制定全盘计谋 |
| **执行者** | ESTP / ISTP | Se+Ti | 暴力输出 / 战斗核心 |
| **门面** | ENTJ / ESTJ | Te+Si | 公开权力象征 / 正面对抗主角 |
| **心理战** | INFJ / ENFJ | Fe+Ni | 操控人心 / 制造分裂 |

**配组硬律**：4 个职位不必四人四角色，但**Mastermind 和门面不应是同一人**（最终 BOSS 揭示的戏剧性需要这种错位）。

### 2.3 六大功能冲突配对（CP / 对手戏设计用）

| 冲突轴 | 一方立场 | 另一方立场 | 戏剧场景 |
|---|---|---|---|
| **Te ↔ Fi** | 为结果可以牺牲情感 | 个体价值不可被牺牲 | "必要的代价"困境 |
| **Ne ↔ Si** | 为什么不试试新的？ | 以前这样做很稳妥 | 改革 vs 保守 |
| **Fe ↔ Ti** | 你应该顾及大家感受 | 逻辑上这不是你的责任 | 情感 vs 理性责任 |
| **Se ↔ Ni** | 为什么不活在当下？ | 我看到的是十年后的结果 | 即时 vs 长远 |

## 三、黑化 / 堕落简化公式

**主角阴影 = 主角最鄙视类型的核心特质。**

| 主角 | 最鄙视 | 压力下阴影 | 堕落剧情引擎 |
|---|---|---|---|
| INFP | ESTJ 的死板 | 变严苛批判 / 用规则压迫 | 理想主义者变暴君 |
| ENTP | INTJ 的阴郁 | 变偏执封闭 / 阴谋论 | 乐天派展现深沉黑暗面 |
| ISTJ | ENFP 的不靠谱 | 变冲动逃避 / 放弃原则 | 最可靠的人突然崩溃 |
| ESFJ | ISTP 的疏离 | 变冷漠批判 / 情感抽离 | 温暖的人突然伤人 |
| INTJ | ENTP 的散乱 | 变过度发散 / 无法决策 | 战略家突然犹豫不决 |
| ENFJ | INFJ 的独处 | 变过度内省 / 隐秘操控 | 领袖变独断隐秘 |

**写黑化弧线时**：从"主角嘲笑 X 类型的 Y 特质"开始埋伏笔，最后让他**在极端压力下恰好变成那个 Y**，剧本结构感最强。

## 四、5 大避坑硬律（反刻板）

| 误区 | 错误理解 | 正确修正 |
|---|---|---|
| **I = 社恐 / E = 话痨** | 把能量获取等同于社交表现 | I 型可以善于社交（只是需要独处充电）；E 型在陌生场合也可能安静 |
| **T = 冷血 / F = 情绪化** | 忽略 T 有情感，F 也会理性 | T 型为在意的人会打破原则；F 型面对重大决策可以极度冷静 |
| **J = 死板 / P = 拖延** | 混淆判断态度与时间管理 | J 追求"决策已定"；P 追求"保持开放"；两者都可有序或混乱 |
| **用标签替代人物** | "他是 INTJ，所以冷漠" | 认知功能是**理解起点**，不是行为说明书 |
| **功能与背景脱节** | 只写功能，不写来龙去脉 | 角色 MBTI 应从**人生经历**里"生长"出来，不是贴上去的 |

**正确示范**：
> 他 8 岁时算出父亲的帝国将在三年内崩溃，但没人相信他。从此他学会：只有逻辑和系统是可靠的。这就是为什么他现在是 INTJ —— Ni 让他看穿模式，Te 让他建立系统，而 Fi（第三功能）让他私下保留着那些他没能救下的人的名字。

**错误示范**：
> 这是一个 INTJ 反派，因为他冷漠、高效、有控制欲。

## 五、四种主导功能的对话关怀模板（写对话时直接套）

关怀 / 安慰 / 鼓励场景里，不同主导功能的角色表达方式完全不同。**写他如何关心别人，等于写他是谁**：

| 主导功能 | 关怀表达方式 | 典型台词风格 |
|---|---|---|
| **Te 主导**（ENTJ / ESTJ） | 效率包装的关怀 | "这个方案成功率最高，你按这个做" / "别想那么多，先把第一步完成" |
| **Fe 主导**（ENFJ / ESFJ） | 直接共情 | "我理解你的痛苦" / "你不是一个人在扛" /（主动拥抱 / 递水） |
| **Ti 主导**（INTP / ISTP） | 逻辑框架支撑的关怀 | "让我帮你拆解这个问题，其实它分成三层" / "你的担忧在第二层是可解的" |
| **Fi 主导**（INFP / ISFP） | 沉默陪伴 | 不说话但整夜坐在旁边 / "我以前也这样过"（用自身经验而非建议） |

**写对话硬律**：同一场景不同 MBTI 角色关怀同一人的反应**必须不同**，否则群像同质化。

## 六、协同使用

- **与 `mbti-5step`**：本模块是其档案扩展。mbti-5step 的 YAML 模板需要填"MBTI 类型 + 类型标签 + 主导功能表现…"，本模块的 16 型档案可直接查用作为填写依据。
- **与 `mbti-cognitive-functions`**：本模块是其"档案化落地"。cognitive-functions 偏理论模型（Grip / Loop / Beebe 原型），本模块提供"每类型具体长什么样"的速查。
- **与其他方法论（结构 / 节奏 / 工艺层）**：完全正交。本模块只提供角色档案，不参与结构 / 节奏 / 文笔层面。
