# 音频参考标准（dB 数值 / 题材 AUDIO_REFS / 强制声明模板）

> 给 LLM 的 dB 参考表与按题材分组的音量基准模板。
> 数据来源：EBU R128 / ATSC A/85 / Netflix Sound Mix Spec / 通识录音行业标准。
>
> 用途：让分镜单元 prompt 中的音量数值（`-XXdB`）有据可依，
> 不再凭空捏造。配合 `numerical_anchors.md` 的「数值合规自检」。

---

## 1. 全局响度基准

短剧 / 网剧 / 流媒体的混音参考（最终母带响度）：

| 标准 | 综合响度 LUFS | 真峰值 dBTP | 用途 |
|---|---|---|---|
| EBU R128 | -23 LUFS | -1 dBTP | 欧洲广播 |
| ATSC A/85 | -24 LKFS | -2 dBTP | 北美广播 |
| Netflix | -27 LUFS | -2 dBTP | 流媒体 |
| YouTube | -14 LUFS | -1 dBTP | 短视频 |
| 短剧 / 抖音 / 即梦 | -16 ~ -14 LUFS | -1 dBTP | 移动端响度 |

> 本知识库的所有 dB 是**相对参考量**，不是绝对响度。在 prompt 里写 `-18dB` 意为"相对最响音轨低 18dB"。

## 2. 音类层次表（核心：合理填值参照）

### 2.1 完整层次

| 层次 | 类别 | dB 区间（相对） | 物理含义 / 示例 |
|---|---|---|---|
| L0 | 静默底噪 | -36 ~ -30dB | 录音棚静默 / 真空房 |
| L1 | 自然底噪 | -32 ~ -24dB | 室内电流声 / 空调最弱 |
| L2 | 环境底噪（室内） | -22 ~ -16dB | 室内空调 / 远处人声 |
| L2' | 环境底噪（室外）| -22 ~ -14dB | 微风 / 海浪底涌 / 远车流 |
| L3 | 轻音效 | -16 ~ -10dB | 翻页 / 钥匙 / 衣物摩擦 |
| L4 | 中音效 | -12 ~ -6dB | 脚步 / 关门 / 键盘 / 倒水 |
| L5 | 主题旋律低频铺底 | -16 ~ -10dB | 仅"主题铺底"音频策略允许 |
| L6 | 对白基准 | -8 ~ -4dB | 标准对白响度 |
| L7 | 重音效 | -6 ~ -2dB | 爆炸 / 水花 / 碰撞 / 枪声 |
| L8 | 命中 / 关键音效 | -4 ~ 0dB | 武戏命中 / 终结音 |
| L9 | 极限音 | 0dB | 上限，不允许超过 |

## 3. 音效与画面同步规则

### 3.1 严格同步（误差 ≤1 帧）

- 对白（口型对位）
- 命中 / 撞击 / 爆炸（视觉冲击点）
- 武器抽出 / 收回
- 关门 / 开门
- 脚步落地（每一步）
- 弹壳落地

### 3.2 允许偏移（前导 / 后挂）

| 类型 | 允许偏移 | 用途 |
|---|---|---|
| 主题旋律前导 | -2 ~ 0 秒（提前） | 仪式感建立 |
| 环境音淡入 / 淡出 | ±1 秒 | 转场 |
| 余韵尾音 | +0 ~ 3 秒（延后） | 情绪挽留 |
| 雷声（光后声） | +1 ~ 5 秒 | 物理真实 |

### 3.3 主题旋律（themeBed）特许规则

只有当项目音频策略为 `themeAsLowBed` 时允许，必须满足：

1. 音量 ≤ -10dB（不能盖过对白）
2. 不作为独立 BGM 轨道，混入音效层
3. 频段限制：仅低频弦乐 / 风琴铺底，**禁止旋律线**清晰可辨
4. 写入 prompt 时标注 `(主题旋律以音效层底部低频形式呈现, 非 BGM)`

## 4. 衰减与递增标注规则

### 4.1 静态音量

```
[全程] 海浪底噪（-18dB）
[0-2秒] 水花爆开（-3dB）
```

### 4.2 渐变音量

```
[9-13秒] 主题旋律渐入（-20→-12dB）
[10-15秒] 环境音渐出（-18→-30dB）
```

格式：`起始dB → 结束dB`。

### 4.3 多层叠加

```
[全程]
  - 海浪底噪（-18dB, L2'）
  - 远处港区钠灯余音（-22dB, L2）
[2-6秒]
  - 装甲缝隙渗水（-14dB, L3）
  - 海水包裹金属（-15dB, L3, 层次随身体没入递进）
```

## 5. 拟声词 / 人声字数计入规则

| 类型 | 是否计入对白字数上限 |
|---|---|
| 对白 | ✅ |
| V.O. / O.S. | ✅ |
| 拟声词「啊 / 唔 / 嗯」 | ✅ 按字计 |
| 系统提示音（可读人声） | ✅ |
| 标点 | ❌ |
| 环境音 / 物件音 | ❌ |
| 模糊不可辨人声（如电话另一端） | ❌ |

## 6. 强制音频声明模板（按题材）

### 真人短剧

```
禁止任何背景音乐；禁止非指定音效；所有音效与人物动作完全同步
```

### 机甲科幻 + 仪式蒙太奇

```
禁止任何背景音乐（主题旋律作为音效层底部低频情绪支撑，不作为独立 BGM 轨道）；
禁止任何非指定音效；
所有音效必须和人物动作完全同步；
（仪式蒙太奇追加）禁止与旋律节奏错位
```

### 武侠 / 仙侠

```
禁止任何背景音乐（古琴 / 箫笛仅作为环境音效层 ≤-12dB）；
禁止现代电子音色；
所有招式音效必须和动作完全同步
```
