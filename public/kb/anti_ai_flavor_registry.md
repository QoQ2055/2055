# 🛡️ 去 AI 味注册表（Anti-AI-Flavor Registry）

> **单一真源**：所有涉及"剧本/台词/叙事文字"的 agent（`screenwriter` / `seedance_engineer` / `nanobananapro_engineer` / `voice_director` / `emotion_architect` / `script_analyst`）在输出前必须对照本表自检。
>
> 违反本表视为 `REVISION_MINOR`，由 `script_analyst` 首轮扫描 + `chief_editor` R9 终审复检。
>
> 适用上下文：剧本正文 / 台词 / V3 切片正文 ⑦ / 关键分镜图 prompt / 场景描述。
> **不适用**：技术元数据（① META/PLOT）、结构化字段（key_beats）、平台 API 专用术语（Dolly/Arc/AU4 等）。

## 二、剧本反模式（四禁）

### 2.1 不过度解释
> 场景已展示情感时，**不再重复文字说明**。让观众通过动作/表情/物理反应自行解读。

❌ `她皱起眉头，显得十分愤怒，心中充满了怨恨。`
✅ `她捏碎了手中的茶杯。`

### 2.2 不情感直白声明
> 禁止 `X 感到 Y` / `X 内心 Y` 句式。用**行为 + 感官 + 肢体反应**替代。

❌ `沈砚感到悲痛欲绝。`
✅ `沈砚跪在碑前，指节抵着石缝磨出血丝。`

### 2.3 不完美对话
> 真实对话有**假起头**、**打断**、**半句不说**、**词不达意**。AI 生成的"完美对仗"台词立刻暴露。

❌ `"我本以为我的师父会教我如何成为真正的武者。"`
✅ `"师父他……算了。"`

### 2.4 AI 稳定性陷阱（强制允许"坏结局"）
- 角色在故事结尾**必须与开头真正不同**（含伤痕/代价）
- 让坏事保持坏状态——不是所有事都能修复
- 允许**不可逆转**的决定、**无法挽回**的损失

## 三、散文工艺四则

### 3.1 具体性
> 不是"一朵花"而是"**一朵枯了半边的月季**"。
> 不是"旧书"而是"**书脊脱胶、扉页盖着三次图书馆印章的旧书**"。

### 3.2 节奏变化
> **短句和长句交替**。连续 3 句以上相同长度**必须打破**。

参考节奏：`长-短-短-长` / `短-短-长` / `长-长-短`

### 3.3 克制
> **力量来自省略而非堆砌**。能用 1 个动词说清的，不用 3 个形容词。

❌ `她非常温柔而小心翼翼地抚摸着那本泛黄的古老书册。`
✅ `她抚过书脊，动作比翻开时还轻。`

### 3.4 感官锚定
> 每个场景**至少锚定 2 种具体感官**（视 / 听 / 嗅 / 触 / 味）。

例：月光冷蓝（视）+ 铜铃低鸣（听）+ 雾气过膝（触）

## 四、对话硬约束

### 4.1 一句一爆点
每句台词必须至少完成一项：
- 推进冲突
- 揭示人物
- 制造转折

**纯寒暄 / 复读台词立即删除**。

### 4.2 潜台词优先
对话不直说角色真实意图。每句台词先明确：
- **外部目标**（角色想让对方做什么）
- **内部目标**（角色真正想要什么）

### 4.3 行为化
每句台词都是一个**动作** —— 威胁 / 恳求 / 试探 / 反击 / 挑衅 / 示弱 / 讽刺。
连续 3 句**相同动词类别**必须改写。

### 4.4 剥标签测试（硬校验）
**去掉角色名后，读者/观众仍能分辨谁说话** —— 否则该角色没有"语音指纹"。
每个角色必须有可区分的：
- 用词特点（文言/口语/网感/专业）
- 句式长度（长独白 vs 短促）
- 口头禅（1-2 个高频词）

### 4.5 节奏规则
- **紧张场景**：短句（3-8 字）、快速交替、碎片化
- **情感场景**：允许长句、加入沉默和停顿（用 `……` 或动作替代台词）

### 4.6 硬约束
- 优先**两人对话**；三人以上场景，核心冲突仍锚定两人
- 每场戏**第一句台词 = 情绪钩子**（禁寒暄开场）
- 每场戏**最后一句 = 悬崖或悬念**

---

## 五、视觉优先原则

### 5.1 写能拍的
**不写抽象心理活动，写具体视觉动作**。
"紧张"→"他第三次看表"；"悲伤"→"她把照片翻了面"。

### 5.2 镜头思维
- **全景**：交代环境
- **中景**：展示互动
- **近景**：捕捉表情
- **特写**：强调细节（物件 / 眼神 / 手指动作）

### 5.3 动作先于对话
先写**角色在做什么**，再写角色说什么。
台词前的动作为台词提供**上下文**和**情绪标记**。

## 六、自检清单（screenwriter / seedance_engineer commit 前执行）

```
[ ] 中文禁词 0 命中
[ ] 英文禁词 0 命中（若启用英文）
[ ] 无 "X 感到 Y" / "内心 Y" 句式
[ ] 无连续 3 句以上相同长度
[ ] 每场景至少 2 种感官锚定
[ ] 每句台词通过"一句一爆点"测试
[ ] 角色通过"剥标签测试"（去名后仍可分辨）
[ ] 每场戏首句 = 情绪钩子；末句 = 悬崖/悬念
[ ] 情感场景允许 `……` 和停顿
[ ] 动作先于对话（每段台词前有动作铺垫）
[ ] 结尾角色与开头真正不同（含代价）
```
