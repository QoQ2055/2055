# 改编压缩 5 策略 + 必删 / 必留清单

> 来源：ShadowScript 影语 `agents/novel_adapter/kb/compression_strategies.md` 精简版。
>
> ⚠️ **仅当本项目处于「改编模式」时注入**。
>
> 用途：当下游需要把原作大体量内容压成短剧节奏时，从下面 5 种战术中选择并组合。

---

## 策略 1：冲突合并法

```
原作：章 1 冲突 A + 章 2 过渡 + 章 3 冲突 B + 章 4 过渡 + 章 5 冲突 C
        ↓
短剧：第 N 集（A+B+C 合并，过渡全删）
```

原则：删除所有过渡章节；保留冲突和爽点；合并同类冲突。

## 策略 2：时间跳跃法

```
原作：5 章修炼过程详细描写
        ↓
短剧：【蒙太奇】10 秒展示 + 【字幕】"三天后"
```

原则：删除过程描写；只保留结果展示；用特效和文字说明时间跨度。

## 策略 3：信息前置法

```
原作：章 1-5 铺垫 → 章 6 爆发
        ↓
短剧：第 N 集直接爆发 → 用【闪回】补充背景
```

原则：爽点前置，先爽再解释；用闪回 / 对话补充信息；不要慢节奏铺垫。

## 策略 4：删繁就简法

### 必删内容
- ❌ 环境描写（山川风景 / 房间布置）
- ❌ 心理独白（长篇内心戏）
- ❌ 过渡情节（赶路 / 日常 / 闲聊）
- ❌ 支线剧情（与主线无关）
- ❌ 重复内容（相似情节只保留最精彩的）

### 必留内容
- ✅ 冲突对话
- ✅ 动作场景
- ✅ 情绪爆点
- ✅ 悬念设置
- ✅ 关系展示

## 策略 5：支线取舍法

```
主线         完整保留（80% 篇幅）
重要支线     精简保留（15% 篇幅）
次要支线     极度压缩（5% 篇幅）
无关支线     完全删除
```

判断标准：

- 主线 = 直接关系主角成长和终极目标
- 重要支线 = 影响主线发展的关键人物线
- 次要支线 = 丰富世界观但可有可无
- 无关支线 = 删除不影响理解

## 心理描写转化三选一

凡是「内心戏 / 心理独白」，必须三选一处理：

1. **心理 → 动作**：把"她心里很慌"改写成"她攥紧了袖口"
2. **心理 → 对话**：把"他在质疑自己"改写成对配角说"我是不是错了"
3. **心理 → 删除**：实在转不出来的就直接砍掉，不解释

## 改编核心公式

> 改编的本质：不是"翻译"，而是"重构"。
>
> 网文改编 = 情绪钩子提取 + 冲突密度压缩 + 视觉语言转化 + 节奏强制重构

优先级（从高到低）：

1. 情绪钩子密度 > 故事完整性
2. 视觉冲击力 > 文学性描写
3. 快节奏刺激 > 慢节奏沉浸
4. 算法友好性 > 戏剧逻辑性
