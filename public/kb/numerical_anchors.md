# 数值规范与触发阈值（身高 / 速度 / 距离 / 拍数升级 / metrics 数据源）

> 给 LLM 的可量化字段上下界 + 拍数升级阈值 + 数据源优先级三合一。
>
> 用途：防止 LLM 在高精度分镜模式下写出离谱数值
> （"机甲 200 米高 / 步速 50m/s"），同时为「找不到出处的数值」提供合理的兜底默认。

---

## 1. 数值上下界

### 1.1 角色身高 / 尺寸

| 题材 | 角色类型 | 身高 / 尺寸合理区间 |
|---|---|---|
| 真人短剧 | 成人男 | 1.65-1.95m |
| 真人短剧 | 成人女 | 1.55-1.80m |
| 真人短剧 | 儿童 | 0.9-1.5m |
| 机甲科幻 | 中型机甲 | 8-15m |
| 机甲科幻 | 大型机甲 | 15-30m |
| 机甲科幻 | 巨型 / Jaeger 级 | 50-80m |
| 武侠 / 仙侠 | 凡人 | 同真人 |
| 武侠 / 仙侠 | 化形妖兽 | 2-10m |
| 武侠 / 仙侠 | 神祇真身 | 不限（通常云海尺度） |
| 战争 | 步兵 | 同真人 |
| 战争 | 装甲车 / 坦克 | 长 6-10m / 高 2.5-3m |
| 战争 | 战机 | 翼展 10-30m |

### 1.3 相机运动速度

| 类型 | 速度上下界 |
|---|---|
| 推 / 拉（dolly in/out） | 0.1-1.0m/s |
| 横移（truck） | 0.1-2.0m/s |
| 升降（boom） | 0.05-0.5m/s |

| 题材 | 允许倍率范围 |
|---|---|
| 真人 | 0.3-2x |

### 1.5 距离 / 空间

### 1.6 能量 / 状态百分比

| 类型 | 取值 | 含义 |
|---|---|---|

## 2. 拍数升级触发的"操作定义"

文戏默认 3 拍，高精度模式允许升级到 4-5 拍。判定规则：

> sceneType 标准 5 类（**文戏 / 快文戏 / 武戏 / 动作非武 / 环境**）权威源：`src/pipeline/storyboardPlan.ts` 中 `SCENE_TYPES`。本文所有「文戏」「武戏」「环境」均为该枚举值。

### 2.1 话轮密度（文戏 / 快文戏适用）

| 单元内话轮数 | 推荐拍数 |
|---|---|
| 0 | 文戏不适用 / 走「环境」sceneType 1-2 拍 |
| 1 | 3 拍 |
| 2 | 3 拍 |
| 3 | **升级 4 拍** |
| ≥4 | **升级 4-5 拍 + 拍均时长 ≤4 秒** |

**话轮**定义：一次完整的「A 说 → B 应」算 1 话轮。A 一直说没有 B 回应不计。

### 2.2 信息揭示密度

| 单元内"剧情关键事实首次披露"数 | 推荐拍数 |
|---|---|
| 0 | 默认 |
| 1 | 默认 + 1 拍特写定格 |
| ≥2 | **升级到 4 拍** |

**关键事实首次披露**定义：观众首次得知一个改变后续判断的事实（如身份揭穿、真凶揭示、关键道具出现）。

### 2.3 情绪转折次数

| 单元内角色情绪状态切换次数 | 推荐拍数 |
|---|---|
| 0 | 默认 |
| 1 | 默认 |
| ≥2 | **升级到 4 拍 + 每次转折独占 1 拍** |

**情绪转折**定义：角色情绪从 A 状态进入明显的 B 状态（平静→紧张算 1 次 / 紧张→崩溃算 1 次 / 崩溃→冷静算 1 次）。

### 2.4 武戏拍数判定

| 武戏内容 | 拍数 |
|---|---|
| 单回合（1 攻 1 防 1 受创） | 4 拍 |
| 双回合 | 5 拍 |
| 三回合 | 6 拍 |
| 群战 | 6-7 拍（容器限 13-15 秒） |

### 2.5 仪式蒙太奇 / 入场（genreSubtag 维度，可叠加任意 sceneType）

> 「仪式蒙太奇 / 入场 / 名场面」**不是 sceneType，是 genreSubtag**，与 sceneType 正交。可叠加在文戏 / 武戏 / 动作非武 / 环境之上。

| 入场类型 | 底层 sceneType | 拍数 |
|---|---|---|
| 普通入场 | 文戏 / 动作非武 | 3 拍 |
| 仪式入场（含逆光 + 慢动作） | 文戏 / 武戏 / 动作非武 | **4 拍**（含 1 拍 1.5x 慢动作） |
| 名场面入场（含海报帧 + 慢动作 + 主题旋律前导） | 武戏 / 动作非武 | **4-5 拍** |

### 2.6 sceneType ↔ 推荐拍数总表

各 sceneType 的默认拍数（无子风格叠加时）：

| sceneType | 默认 | 上限 |
|---|---|---|
| 文戏 | 3 | 4 |
| 快文戏 | 4 | 5 |
| 武戏 | 4 | 7（叠加战争场面子风格时） |
| 动作非武 | 3-5 | 5-7（叠加战争场面子风格时） |
| 环境 | 1-2 | 2 |

详细两维度合并表见 `storyboard_pro_mode.md` §5。

## 3. metrics 字段数据源优先级

高精度分镜要求 metrics 数值能在源里找到。**冲突解决规则**：

### 3.1 优先级（高 → 低）

| 级别 | 数据源 | 示例 |
|---|---|---|
| L1 | user message 显式提供（unitMetricsHints / scenes） | `spaceDistance: "100m 外水下 15m 深"` |
| L2 | 剧本原文（用括号或描述写出） | "（机体高 22 米）站立涉水" |
| L3 | 设定集 / 世界观文档（外部知识库引用） | "本世界观机甲身高 20-25m" |
| L4 | 题材默认值（本文第 1 节中位数） | 机甲默认 22m |
| L5 | 留空 | 不写 metrics 该子字段 |

**L5 优先于编造**：找不到数值 = 留空，**绝不编造**。

### 3.2 冲突解决

```
若 L1 与 L3 冲突 → 取 L1（user message 优先）
若 L2 与 L3 冲突 → 取 L2（剧本原文优先）
若多源同等优先 → 取最高数值（保守原则，更视觉冲击）
冲突时必须在 NOTE 区列出: "数值冲突: L2 写22m, L3 写25m, 取 22m"
```

### 3.3 视听签名默认值表（L4 兜底）

> 本表 key 是 `audiovisualSignature`（10 类视听签名），不是 30 原子题材。映射规则见 `genre_to_av_signature_mapping.md`。


| 题材 | 角色身高 | 步速 | 主体距镜头（MS） |
|---|---|---|---|
| 真人 | 1.75m | 1.0m/s | 3m |
| 机甲 | 22m | 1.5m/s | 8m |
| 武侠 | 1.75m | 1.0m/s | 3m |
| 战争 | 1.75m | 1.5m/s | 3m |

## 4. 数值合规性自检

输出后跑一遍：

| # | 检查 | 失败动作 |
|---|---|---|
| N1 | 所有数值能在 user message / 剧本 / 设定集找到出处？ | 删除无源数值 |
| N2 | 数值在本文第 1 节合理区间内？ | 限制到区间内 |
| N3 | 速度 / 距离 / 尺寸单位用公制（米 / m/s）？ | 转换为公制 |
| N4 | dB 数值 ≤ 0dB？ | 限制到 ≤ 0 |
| N5 | 光比格式是 `1:N`？ | 改为标准格式 |
| N6 | 慢动作倍率与题材允许范围一致？ | 改为合规倍率 |
| N7 | 焦段（mm）与景别匹配（参考 `cinematography_terms.md` 第 1.4 节）？ | 改焦段或改景别 |
| N8 | 拍数与单元 sceneType 匹配（本文第 2 节）？ | 改拍数 |
