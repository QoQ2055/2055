# IP 与合规风险扫描清单

> 来源：ShadowScript 影语 `agents/legal_compliance_officer/agent.md` (UCR57 系列) 精简版。
>
> ⚠️ **仅当本项目处于「改编模式」时注入**，主要用于 R9' 终审的 `ipRiskCheck` 决策。
>
> 用途：把"模型空中飞行的 IP 风险评估"换成"逐项扫描表"。每条命中都要在 `criticalIssues` 中显式列出。

---

## 一、版权合规（UCR57.1）

| 风险源 | 命中即 | 处理 |
|---|---|---|
| 未授权的已知 IP 角色（名人、动漫形象等） | **FAIL** | 必须改名 + 改造型 |
| 受版权音乐 / BGM | **WARN** | 改用原创或公版音乐 |
| 他人剧本未授权改编 | **FAIL** | 取得授权或彻底重写 |
| 未合作品牌的 Logo | **WARN** | 强制打码 / 重构画面 |
| 他人摄影作品作为参考图 | **WARN** | 标注来源或换图 |

## 二、肖像权（UCR57.2）

- ❌ 角色卡 `aiPrompt` 不得描写真实存在人物外貌
- ❌ 名人相似（触发相似度风险）
- ❌ 换脸 / Deepfake 绝对禁止（除非本人授权）

## 三、涉政 / 涉军 / 涉警 / 涉宗教（UCR57.3）

| 类别 | 关键词举例 | 等级 |
|---|---|---|
| 涉政 | 具体国名 / 党派 / 时政人物 | **FAIL** |
| 涉军 | 真实军事机密 / 武器参数 | **WARN** |
| 涉警 | 模仿真实警务行动而无"虚构"声明 | **WARN** |
| 宗教 | 攻击 / 歪曲 / 嘲讽宗教 | **FAIL** |

## 四、未成年保护（UCR57.4）

- ❌ 未成年面部可识别出现 → 必须打码
- ❌ 涉及未成年情感 / 情色 → **FAIL**
- ⚠️ 校园题材中成年演员演未成年角色 → 必须显式声明

## 五、平台差异化（UCR57.5）

| 平台 | 额外红线 |
|---|---|
| 抖音 / 快手 | 禁特效过度夸张 / 禁医美虚假 |
| 小红书 | 禁医美虚假宣传 |
| B 站 | 禁低俗 |
| YouTube 海外 | COPPA 儿童保护 |
| TikTok 海外 | DSA（欧盟） |

---

## 六、ipRiskCheck 决策表

| 命中清单 | 输出 |
|---|---|
| 任意一项 P0/FAIL（未授权 IP / 真实人物 / Deepfake / 涉政 / 宗教攻击 / 未成年情色） | **FAIL** |
| 仅 P1/WARN（涉军 / 涉警 / Logo / 受版权音乐 / 平台特殊红线） | **WARN** |
| 全部清单零命中 | **PASS** |

> R9' 在 `criticalIssues` 中至少列出**所有** WARN 与 FAIL 命中项，并给出 `mitigation` 建议（改名 / 打码 / 换音乐 / 加声明）。

## 七、原作改编专属

- 当原作是 **网文 / 小说**：检查原作版权方是否已授权改编；未授权一律 FAIL
- 当原作是 **旧剧本翻拍**：检查跨语言 / 跨地区翻拍许可；公共领域作品 PASS
- 当原作含 **真实事件元素**：必须声明"本剧情节为虚构，与现实无关"
