# 🗡️ 影视动画道具设计方法论

> 核心来源：《影视美术设计》、《电影美术设计语言》、《游戏道具设计》、道具设计行业标准流程
> 本文件是提示词包预制师、场景概念师、角色视觉分析师、图片提示词工程师的**道具设计圣经**。
>
> ⚠️ 核心理念：道具不是"好看的物件"——它是角色内在的外化、世界观的基石、剧情的推动器。每个道具都有三重身份：功能性（推动剧情）、符号性（外化角色）、情感性（渲染情绪）。

---

## 一、道具三重身份

| 身份 | 描述 | 经典案例 | 设计要求 |
|------|------|---------|---------|
| **功能性** | 道具推动剧情发展 | 《泰坦尼克号》海洋之心→推动寻宝线 | 道具必须在剧情中有明确作用 |
| **符号性** | 道具外化角色性格 | 《哈利·波特》魔杖→身份+力量象征 | 道具形态必须匹配角色性格 |
| **情感性** | 道具承载情感记忆 | 《这个杀手不太冷》绿植→温情/生命 | 道具出现时必须触发情感共鸣 |

## 二、道具分类体系

### 2.1 按功能分类

| 类别 | 描述 | 设计重点 | 示例 |
|------|------|---------|------|
| **戏用道具** | 角色直接使用/互动 | 手感/质感/特写细节 | 武器/信物/工具 |
| **陈设道具** | 营造环境氛围 | 时代感/文化背景/陈旧度 | 家具/器皿/书架 |
| **特技道具** | 产生特殊视觉效果 | 光效/动态/变化状态 | 魔法物品/机关装置 |
| **标记道具** | 暗示角色身份或伏笔 | 辨识度/独特性/可重复出现 | 家族徽章/神秘符文 |

### 2.2 按体量分类

| 体量 | 描述 | AI提示词侧重 |
|------|------|------------|
| **手持小件** | 可单手握持 | 细节质感/手部互动/特写友好 |
| **中型物件** | 家具/器具级别 | 空间占比/与角色的比例关系 |
| **大型装置** | 载具/建筑构件 | 透视/规模感/环境融合 |

### 2.3 按题材分类

| 题材 | 典型道具 | 风格要点 | AI提示词关键词 |
|------|---------|---------|-------------|
| **古代/武侠** | 刀剑/玉佩/卷轴/令牌 | 金属锻造纹理/玉石温润/竹简质感 | `ancient Chinese, jade ornament, forged steel blade` |
| **魔幻/奇幻** | 法杖/水晶球/符文石/魔法书 | 发光效果/能量纹路/神秘符号 | `magical artifact, glowing runes, crystal orb, ethereal energy` |
| **科幻/未来** | 全息投影/能量武器/芯片/机械义肢 | 金属光泽/LED指示灯/精密结构 | `sci-fi gadget, holographic display, sleek metallic, LED glow` |
| **现代/都市** | 手机/钥匙/文件/杯子 | 工业设计感/品牌暗示/磨损痕迹 | `modern everyday object, minimalist design, used condition` |
| **恐怖/暗黑** | 诅咒物/骨制品/锈蚀铁器/布偶 | 腐蚀/血迹/不规则/诡异比例 | `cursed artifact, rusted iron, eerie bone carving, unsettling` |
| **历史/战争** | 盔甲/旗帜/地图/勋章 | 历史准确/磨损做旧/时代材料 | `historical military, battle-worn armor, weathered leather map` |

## 三、道具材质表现

### 3.1 八大核心材质

| 材质 | 视觉特征 | 高光特性 | 磨损表现 | AI提示词 |
|------|---------|---------|---------|---------|
| **金属** | 冷硬光泽/反射 | 锐利高光/镜面反射 | 锈蚀/划痕/氧化 | `polished metal, sharp reflections, scratched steel surface` |
| **木材** | 温润纹理/年轮 | 柔和高光/半透 | 虫蛀/裂纹/磨损 | `aged wood, visible grain, warm brown tones, weathered surface` |
| **石材** | 粗糙/颗粒感 | 低反射/哑光 | 风化/碎裂/苔藓 | `rough stone, weathered granite, mossy cracks, ancient texture` |
| **布料** | 柔软/褶皱/垂坠 | 丝绸亮/棉麻哑 | 褪色/破损/污渍 | `flowing fabric, silky sheen, worn cotton, frayed edges` |
| **玻璃** | 透明/折射/彩色 | 强反射/棱镜效果 | 裂纹/碎片/雾化 | `clear glass, light refraction, prismatic effects, cracked surface` |
| **皮革** | 纹理/柔韧 | 半光泽 | 褪色/裂纹/包浆 | `aged leather, rich patina, creased surface, worn brown leather` |
| **骨/角/牙** | 乳白/不规则 | 微光泽/半透明边缘 | 黄化/裂纹/雕刻 | `carved bone, ivory tones, translucent edges, ancient relic` |
| **能量/光效** | 发光/流动/半透明 | 自发光/光晕 | 闪烁/脉动/消散 | `glowing energy, pulsating light, ethereal luminescence, particle effects` |

### 3.2 材质组合叙事

| 组合 | 叙事暗示 | 示例 |
|------|---------|------|
| 金属+宝石 | 权力/财富/王室 | 镶嵌红宝石的王冠 |
| 木材+布料 | 朴素/平民/温暖 | 粗布包裹的木质护身符 |
| 金属+骨 | 野蛮/部落/原始力量 | 兽骨柄的铁制战斧 |
| 玻璃+能量 | 魔法/神秘/超自然 | 内含流动光芒的水晶球 |
| 皮革+金属 | 冒险/旅行/实用 | 铜扣皮革弹药带 |
| 石材+符文 | 远古/神殿/仪式 | 刻满符文的祭坛石板 |

## 四、道具叙事设计

### 4.1 道具弧线（道具随故事变化）

| 阶段 | 道具状态 | 设计变化 |
|------|---------|---------|
| **初始** | 完整/崭新/隐藏 | 展示道具的"理想状态" |
| **使用** | 磨损/变化/激活 | 增加使用痕迹/功能变化 |
| **受损** | 破损/变形/失效 | 裂纹/断裂/能量消散 |
| **转化** | 重铸/升级/赋予新意 | 形态变化/材质升级/新光效 |
| **终局** | 毁灭/传承/纪念 | 碎片/遗物/纪念品 |

### 4.2 道具与角色关系

| 关系类型 | 描述 | 设计策略 |
|---------|------|---------|
| **身份标记** | 道具标记角色身份 | 独特造型+角色专属色+辨识度 |
| **能力延伸** | 道具增强角色能力 | 道具风格=角色能力的视觉化 |
| **性格外化** | 道具反映角色性格 | 整洁=严谨/破旧=流浪/华丽=权贵 |
| **情感纽带** | 道具承载角色情感 | 做旧+磨损+温暖材质=珍视 |
| **命运象征** | 道具预示角色命运 | 裂纹=将破/发光=觉醒/褪色=衰落 |

### 4.3 道具伏笔设计

```
契诃夫之枪原则：
"如果第一幕墙上挂了一把枪，第三幕它就必须开火。"

伏笔道具三步法：
  1. 展示（不经意出现/背景中）
  2. 提醒（再次出现/引起注意）
  3. 触发（关键时刻使用/改变剧情走向）

AI管线中的应用：
  - 伏笔道具必须在分镜/关键帧中至少出现3次
  - 第一次：背景/陈设中（不强调）
  - 第二次：角色互动/近景（引起注意）
  - 第三次：特写/高潮使用（剧情反转）
```

## 五、道具设计AI提示词模板

### 5.1 道具提示词公式

```
[道具名称] + [材质描述] + [尺寸/比例] + 
[磨损/使用状态] + [光影/光效] + 
[细节特征] + [文化风格] + [背景环境]

示例：
"Ancient Chinese jade pendant, translucent pale green jade,
palm-sized, smooth polished surface with faint crack,
warm side lighting highlighting translucency,
intricate dragon carving, thin red silk cord,
traditional Chinese aesthetic,
displayed on dark wooden surface, 
product photography style, soft bokeh background"
```

### 5.2 道具状态变化提示词

| 状态 | 提示词后缀 |
|------|----------|
| 崭新 | `brand new, pristine condition, gleaming surface, unused` |
| 日常使用 | `well-used, minor scratches, comfortable patina, familiar wear` |
| 战斗磨损 | `battle-damaged, deep scratches, dented, blood-stained edge` |
| 严重受损 | `heavily damaged, cracked, partially broken, chipped edges` |
| 古老/远古 | `ancient relic, centuries old, weathered, moss-covered, eroded` |
| 能量激活 | `energy activated, glowing runes, pulsating light, power surge` |
| 毁灭 | `shattered fragments, broken pieces, fading glow, disintegrating` |

## 六、道具@标签注册规范

### 6.1 标签命名规则

```
@道具_[名称] = (材质, 颜色, 尺寸, 核心特征, 默认状态)
@道具_[名称]_[状态] = (状态变化描述)

示例：
@道具_陨铁剑 = (陨铁, 暗银+蓝光纹, 90cm长剑, 剑身星辰纹路, 入鞘状态)
@道具_陨铁剑_出鞘 = (剑身发出冷蓝光芒, 星辰纹路亮起)
@道具_陨铁剑_碎裂 = (剑断为三截, 光芒消散, 纹路暗淡)
```

### 6.2 道具提示词包结构

```
道具@标签 → 图片生成提示词 → V2视频提示词

@道具_陨铁剑
├── 图片提示词：[完整英文描述，用于AI图片生成]
├── V2引用格式：【@道具_陨铁剑】为关键道具
└── 状态变体：
    ├── @道具_陨铁剑_出鞘 → [出鞘状态英文描述]
    └── @道具_陨铁剑_碎裂 → [碎裂状态英文描述]
```

## 七、道具设计师自检清单

| # | 检查项 | 标准 |
|---|--------|------|
| P1 | 道具是否有叙事功能？ | 功能/符号/情感至少占一项 |
| P2 | 材质描述是否具体？ | "剑"→"陨铁锻造，剑身有星辰纹路" |
| P3 | 道具是否有状态变化？ | 至少2个状态（默认+变化） |
| P4 | 道具与角色关系是否明确？ | 谁用/为何用/代表什么 |
| P5 | 是否注册了@标签？ | 格式：@道具_[名称] |
| P6 | 伏笔道具是否至少出现3次？ | 展示→提醒→触发 |
| P7 | 道具风格是否与世界观一致？ | 匹配整体视觉风格 |
| P8 | 图片提示词是否完整？ | 材质+尺寸+状态+光影+风格 |
