# 分镜工作流规范（TODO 占位 / 字数压缩 / 多版本输出）

> TODO 命名规范扩展 + 字数压缩优先级 + 多版本输出三合一。
>
> 用途：让 LLM 在「素材未就绪 / COPY 区超字数 / 不同 stakeholder 需要不同长度版本」时
> 有标准操作，避免凭主观裁剪关键信息。

---

## 1. TODO 占位命名规范

### 1.1 完整 TODO 类别

| 前缀 | 含义 | 何时使用 |
|---|---|---|
| `@TODO_Audio_` | 音频素材待制作 | 主题旋律 / 自定义音效 / 配音演员未就位 |
| `@TODO_VFX_` | 视觉特效待制作 | 法术 / 能量光纹 / 爆炸 / 粒子 |
| `@TODO_Image_` | 角色 / 场景 / 道具立绘待制作 | 新角色版本 / 新场景图 |
| `@TODO_Mocap_` | 动作捕捉数据待录制 | 复杂动作戏 / 武戏 / 仪式 |
| `@TODO_Set_` | 实景搭建待完成 | 影棚搭景 / 大型场景 |
| `@TODO_Costume_` | 服装定制待完成 | 角色新造型 / 朝代服 |
| `@TODO_Prop_` | 道具制作待完成 | 武器 / 法器 / 关键道具 |
| `@TODO_Stunt_` | 特技替身 / 武指待协调 | 危险动作 / 高难度武戏 |
| `@TODO_Composite_` | 后期合成待完成 | 绿幕 / 背景替换 / 多层合成 |
| `@TODO_Voice_` | 配音演员待录音 | 已知声线 ID 但未实录 |
| `@TODO_Render_` | 3D 渲染素材待出 | CG 角色 / CG 环境 |
| `@TODO_Color_` | 调色未定 | 风格化镜头 |
| `@TODO_Loc_` | 外景待勘景 | 实景拍摄 |

### 1.2 命名格式

```
@TODO_<类别>_<标识符>

示例:
  @TODO_Audio_Theme_main          ← 主题旋律
  @TODO_Audio_SFX_qiBurst         ← 真气爆发音效
  @TODO_VFX_Bioluminescence_amber ← 琥珀色生物荧光特效
  @TODO_Image_LinWan_v2           ← 林晚新版立绘
  @TODO_Mocap_Combat_unit4        ← 第 4 单元武戏动捕
  @TODO_Costume_QinDynasty_male   ← 秦代男装
  @TODO_Prop_WujiSword            ← 无极剑道具
```

### 1.3 在 prompt 中的使用规则

| 区域 | 是否允许 @TODO_ |
|---|---|
| COPY 区（喂给 Seedance / Sora 类视频生成器） | ✅ 允许（视频生成 API 会忽略，不影响生成） |
| NOTE 区（人读区） | ✅ 必须列出对应素材规格 |
| 自检报告 | ✅ 必须标注「待补素材清单」 |

**NOTE 区标注格式**:

```
## 待补素材清单
- @TODO_Audio_Theme_main: 主题旋律, 时长 8 秒, 风格低频弦乐, 用于第 9-13 秒铺底
- @TODO_VFX_Bioluminescence_amber: 琥珀色荧光轮廓特效, 用于角色2 水下浮现
- @TODO_Image_LinWan_v2: 林晚战损版立绘, 用于第 12-15 单元
```

## 2. 字数压缩优先级

高精度模式 COPY 区超 1500 字时，按以下顺序删除内容。

### 2.1 优先压缩（先删 → 后删）

#### Step 1：NOTE 区冗余溯源

只保留段号和自检 ✅/❌ 标记，删描述性文字。

```
压缩前:
  G3 无新增: ⚠️ 发现 1 处新增已修正
    原: "林晚左手在身侧握拳又松开"
    问题: 原文只说"手在抖", 未提左手握拳
    改: 删除左手握拳描述

压缩后:
  G3 无新增: ⚠️ 已修正左手握拳描述
```

#### Step 2：重复的环境描述

同一环境在多个 sub-shot 重复时只保留首次。

```
压缩前:
  0-3秒: 写字楼电梯内, 白色日光灯, 金属内壁, 林晚走入...
  3-12秒: 写字楼电梯内, 白色日光灯, 金属内壁, 林晚听电话...

压缩后:
  0-3秒: 写字楼电梯内, 白色日光灯, 金属内壁, 林晚走入...
  3-12秒: 林晚听电话...
```

#### Step 3：参考图后附带文字重述

参考图本身承载视觉信息，文字重述是冗余。

```
压缩前: @Image1b 林晚（黑色西装+白T+阔腿裤, 嘴闭紧, 眼神涣散）
压缩后: @Image1b 林晚
```

#### Step 4：dB 数值的解释性括号

保留数值，删括号说明。

```
压缩前: 海浪底噪（低频波涌持续, 音量 -18dB）
压缩后: 海浪底噪（-18dB）
```

#### Step 5：焦段说明的中文重述

```
压缩前:
  焦距: 标准视角
  焦段: 35mm

压缩后:
  焦段: 35mm（标准）
```

### 2.2 谨慎压缩（中段删）

#### Step 6：起幅 + 落幅描述

保留主体姿态，删环境形容。

```
压缩前: 林晚站在电梯中央偏门口位置, 身体微前倾等门开, 白色日光灯均匀打在她侧脸上
压缩后: 林晚站在电梯门口微前倾
```

#### Step 7：微表情字段多余条目

保留核心 3 项。

```
压缩前:
  - 持手机的右手在抖
  - 嘴唇紧闭后开口说话
  - 眼神没有聚焦
  - 喉结滚动一下
  - 眉头略皱

压缩后:
  - 持手机的右手在抖
  - 嘴唇紧闭后开口说话
  - 眼神没有聚焦
```

#### Step 8：强制声明的题材追加项

保留 1-2 条最关键的。

### 2.3 禁止压缩（绝不删）

❌ **数值锚** — 米 / m/s / dB / mm / 百分比 / 光比 一律保留
❌ **Must-Show 列表项** — 全部保留
❌ **Must-not 列表项** — 全部保留
❌ **时序拍数和切分** — 0-3秒 / 3-13秒 等
❌ **轴线声明** — 多角色单元必保留
❌ **能量百分比 / 装甲状态** — 高精度单元的状态锚
❌ **角色 @ 绑定** — 参考图绑定不能删
❌ **强制声明（视觉）核心条款** — 字幕水印 / 物理真实 / 题材通用禁忌

### 2.4 压缩后字数目标

| 阶段 | 目标字数 |
|---|---|
| 高精度模式默认区间 | 1100-1500 |
| 第一轮压缩后 | ≤ 1500 |
| 第二轮压缩后 | ≤ 1400 |
| 极限压缩（保数值锚） | ≤ 1200 |
| 硬上限（API 截断阈值） | < 2000 |

## 3. 多版本输出规范（可选扩展）

如果同一单元需要给不同 stakeholders 看不同长度版本：

| 版本 | 受众 | 字数 | 删什么 |
|---|---|---|---|
| 完整版（COPY+NOTE） | 内部审稿 / LLM 自检 | 1500-2000 | 不删 |
| Seedance 版（仅 COPY） | 喂模型 | 1100-1500 | 删 NOTE |
| 导演版 | 现场参考 | 600-900 | 删音频 dB / 焦段 mm，保动作描述 |
| 摄影师版 | 镜头清单 | 400-600 | 仅保相机 + 焦段 + 轴线 + 起幅落幅 |
| 录音师版 | 音频清单 | 200-400 | 仅保音频字段 |

---

## 4. 衔接到自检系统

字数超限触发：

| 字数 | 自检状态 | 动作 |
|---|---|---|
| < 1100 | ⚠️ 偏稀薄 | 按描述精度指南补充 |
| 1100-1500 | ✅ 理想区间 | 通过 |
| 1500-1700 | ⚠️ 偏冗余 | 按本文 Step 1-3 压缩 |
| 1700-2000 | ❌ 过冗余 | 按本文 Step 1-8 全压缩 |
| ≥ 2000 | ❌ 截断风险 | 强制重写，必须降到 < 2000 |
