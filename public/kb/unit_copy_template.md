# 单元 COPY 区字段排版模板（11 字段固定排序 + 多题材对照）

> Phase E-G 逐单元 Seedance prompt 的 **COPY 区字段排版规范**。
> 本文不规定"写什么内容"（那是上游事实清单 + 各 KB 的事），
> 只规定"怎么排版 / 字段顺序 / 行内格式 / 占位符"。
>
> 配套阅读：
> - `audio_db_reference.md` — dB 数值与 AUDIO_REFS 模板
> - `cinematography_terms.md` — 景别 / 焦段 / 慢动作 / 轴线词典
> - `genre_taxonomy_and_taboos.md` — 题材 5 维度 / 题材禁忌
> - `numerical_anchors.md` — 数值上下界 / 拍数升级阈值
> - `storyboard_pro_mode.md` — 进阶模式总览
> - `storyboard_workflow_norms.md` — TODO 占位 / 字数压缩

## 1. 字段总骨架（11 字段固定顺序）

每个单元 COPY 区**必须**按以下顺序输出 11 个字段段落。漏字段或乱序触发 T24 / T25 重写器。

```
## 锚点
## 时序（XX 秒，N 拍：a+b+c[+d+e]）
## Must-Show
## Must-not
## 相机
## 微表情
## 音频
## 强制音频声明
## 强制声明（视觉）
## 起幅
## 落幅
## 落幅末状态（{题材}版本 5 维度）
```

> 严格意义上是 **12 段**（起幅 / 落幅是分行段落但视为同一组），算字段类是 **11 类**。
> 若上游事实清单缺失某些数据（如无台词单元），对应字段**保留段头 + 写"本单元..."占位**，**不许整段缺失**。

## 2. `## 锚点`

声明本单元画面内**关键空间坐标**。给视频生成器一个明确的"画面内主体在哪 / 朝哪 / 距离多少"约束。

### 2.1 字段语法

```
锚点: {主体A}（位置描述 + 朝向）
{关键参考物}: {方位 + 距离}
{隐藏角色 / 二次主体}: {方位 + 距离 + 可见度修饰}
```

每行 1 个锚点，**至少 1 行（主体 A）**，**最多 5 行**。
位置使用 **画面九宫格语言**（画左 / 画右 / 上方 / 下方 / 中央 / 三分之一 / 三分之二 / 边缘）+ **公制距离**（参考 `numerical_anchors.md` §1.5）。

### 2.2 多题材示例

**机甲科幻（参考样式原貌）**:
```
锚点: {主体A}（画面右侧三分之二，移动方向由画左向画右）
{光源}: 画面右侧边缘地平线下方，向上撕开一条缝
{隐藏角色}: 海面下约 100 米外，位于 {主体A} 正前方水下 15 米深处，仅琥珀荧光轮廓可见
```

**真人短剧（电梯独角戏）**:
```
锚点: {主体A}（画面中央偏画左，朝向电梯门即画面正前方）
{道具}: 手机贴在 {主体A} 右耳，屏幕背向镜头
```

**武侠对峙**:
```
锚点: {主体A}（画面左侧三分之一，剑指画右）
{主体B}（画面右侧三分之二，距 {主体A} 约 4 米，剑横身防守）
{环境标志}: 后景竹林由上至下覆盖画面三分之二
```

## 3. `## 时序`

声明总时长 + 拍数 + 拍秒切分 + 每拍内画面（景别 + 机位 + 主体动作）。

### 3.0 sceneType 枚举速查（决定默认拍数）

> 权威源：`src/pipeline/storyboardPlan.ts` 中 `SCENE_TYPES`。**5 类标准枚举，不得自创变体**。
> 上游事实清单 UNIT 块的 `sceneType` 字段必须是以下 5 个值之一。

| sceneType | 默认拍数 | 适用场景 |
|---|---|---|
| **文戏** | 3 | 对话 / 情绪 / 信息传递 |
| **快文戏** | 4 | 高密度对话 / 多线信息 / 反转节点 |
| **武戏** | 4-6 | 武打对决 / 招式交锋 / 命中受创 |
| **动作非武** | 3-5 | 追逐 / 奔跑 / 高强度体力戏（非武打） |
| **环境** | 1-2 | 空镜 / 氛围 / 过场 / 转场 |

子风格（仪式蒙太奇 / 海报帧 / 战争场面 等）在以上之上**叠加**升级触发，详见 `storyboard_pro_mode.md` §5 / `numerical_anchors.md` §2。

### 3.1 段头格式

```
## 时序（{总秒数} 秒，{拍数} 拍：{a}+{b}+{c}[+{d}[+{e}]]）
```

约束：`a+b+c+...` 求和**严格等于** `总秒数`（违反触发 DP-4）。

### 3.2 每拍格式

每拍 1 行 list item：

```
- {累计起秒}-{累计止秒}秒: {景别代号} {机位/运动描述}，{主体动作描述}[，{特殊技法}]
```

- **景别代号** 用 `cinematography_terms.md` §1.1 的标准缩写（LS / MS / MCU / CU / ECU / ELS / VLS / MLS / BCU / POV / OTS / 2S / HA / LA / DA 等）
- **机位/运动描述**：是定机位 / 横移 / 跟随 / 升降 / 推拉 / 摇 等之一，可叠加速度（`m/s` 或 `°/s`）
- **特殊技法**：可选，如 `1.5x 慢动作` / `定格` / `急摇` 等

### 3.3 多题材示例

**机甲科幻 4 拍 2+4+3+4（参考样式原貌）**:
```
## 时序（13 秒，4 拍：2+4+3+4）
- 0-2秒: LS 定机位，{主体A} 踏入海湾第一脚，海水在脚下向两侧爆开
- 2-6秒: MS 跟随横移，海水没过 {主体A} 膝甲，然后腰甲，然后胸甲，装甲缝隙渗水
- 6-9秒: MCU 平视地平线，朝阳从海面边缘撕开一道缝，水面漂浮细碎波光
- 9-13秒: ELS 低角度（水面一米高）1.5x 慢动作，{主体A} 剪影逆着朝阳，主题旋律从音场底部低低升起
```

**真人短剧 3 拍 3+5+4**:
```
## 时序（12 秒，3 拍：3+5+4）
- 0-3秒: LS 定机位，{主体A} 走入电梯，按下楼层按钮
- 3-8秒: MCU 慢推 0.2m/s，{主体A} 接起电话，听对方说话
- 8-12秒: BCU 定机位，{主体A} 嘴唇紧闭后开口，回应一句
```

**武侠武戏 5 拍 2+3+2+3+3**:
```
## 时序（13 秒，5 拍：2+3+2+3+3）
- 0-2秒: LS 定机位（交战轴外侧），{主体A} 与 {主体B} 拔剑相对
- 2-5秒: 2S 横移 1.5m/s，双方剑刃首次交击
- 5-7秒: ECU 急推，剑尖闪过 {主体B} 颈侧三寸
- 7-10秒: MCU 1.5x 慢动作，{主体A} 内力外放，剑身光纹由 30% 升至 80%
- 10-13秒: MS 1.5x 慢动作，{主体B} 退步格挡，重心后移
```

## 4. `## Must-Show` / `## Must-not`

成对必填字段，分别声明本单元**必须出现**与**绝对不能出现**的元素。

### 4.1 `## Must-Show` 语法

- 用无序列表（`-` 开头）
- **至少 3 项，最多 6 项**
- 每项 ≤ 25 字
- 优先级：**关键剧情节点 > 题材签名画面 > 数值锚定的物理特征**

### 4.2 `## Must-not` 语法

- 用无序列表（`-` 开头）
- **至少 1 项，最多 5 项**
- 每项 ≤ 25 字
- **必须包含至少 1 项 4 类兜底**（即使其它项已存在）：
  1. **角色身份泄漏**（如「{隐藏角色} 的脸不出现」「反派全身不出现」）
  2. **损伤 / 状态错配**（如「本单元装甲仍完好」「{主体A} 此时未中毒」）
  3. **题材专属禁忌**（参考 `genre_taxonomy_and_taboos.md` §3）
  4. **字幕水印**（兜底，每个单元都写）

### 4.3 多题材示例

**机甲科幻（参考样式原貌）**:
```
## Must-Show
- 第一脚入水的双侧水花爆开（高度约 15 米）
- 膝 / 腰 / 胸三阶段涉水清晰可见
- 朝阳从海面破裂的一道缝
- {主体A} 逆光剪影（海报帧构图）
- 水下 {隐藏角色} 琥珀荧光轮廓（遥远而模糊）

## Must-not
- 任何完整的 {隐藏角色} 身体结构（只能荧光轮廓）
- {驾驶员} 的脸不出现
- 任何已损毁的装甲（本单元装甲仍完好）
- 字幕/水印
```

**真人短剧**:
```
## Must-Show
- {主体A} 持手机的右手在抖
- 嘴唇紧闭后开口说话
- 眼神没有聚焦

## Must-not
- 电话另一端的 {对方} 出现在画面（仅 O.S.）
- 任何文字 / 楼层数字读得清
- 字幕/水印
```

**武侠武戏**:
```
## Must-Show
- 剑刃交击时的火星
- {主体A} 内力光纹由 30% 升至 80%
- {主体B} 退步格挡的重心偏移

## Must-not
- 现代道具入画
- 凡人角色突然飞行
- 法器凭空召唤（未见拔剑动作）
- 字幕/水印
```

## 5. `## 相机`（五行硬模板）

**严格 5 行**，行序固定：`机位 / 运动 / 焦距 / 焦段 / 轴线`。
任何一行缺失或顺序错误触发 T22 重写器。

### 5.1 五行模板

```
## 相机
机位: {每拍机位描述用 → 连接，拍数 = 时序拍数}
运动: {每拍运动描述用 / 连接，与时序拍数一一对应}
焦距: {混合 | 标准 | 广角 | 长焦}（描述性，单一选项或"混合"）
焦段: {每拍焦段 mm 用 / 连接，与时序拍数一一对应}
轴线: {轴线类型}; {方向}; {不越轴声明 或 越轴借口}
```

### 5.2 各行细则

| 行 | 必填? | 写法 | 校验 |
|---|---|---|---|
| **机位** | ✅ | 每拍 1 段，**用 `→` 连接**（强调时间推进），段内可含距离（米）/ 高度 / 视角（俯/仰） | 段数 = 时序拍数 |
| **运动** | ✅ | 每拍 1 段，**用 `/` 连接**（并列描述），段内含动作（定机位 / 横移 / 跟随 / 推拉 / 升降）+ 速度 | 段数 = 时序拍数；速度需在 `numerical_anchors.md` §1.3 范围 |
| **焦距** | ✅ | 仅 4 选项之一：`混合` / `标准` / `广角` / `长焦`。多拍混合用就写"混合" | — |
| **焦段** | ✅ | 每拍 1 段 mm 数值，**用 `/` 连接**，可含景别代号前缀（如 `LS 24mm`） | 段数 = 时序拍数；与景别匹配（`cinematography_terms.md` §1.4） |
| **轴线** | 多角色 / 切镜单元必填 | 格式：`{轴线类型}; {方向}; {声明}`（参考 `cinematography_terms.md` §4.4）；单角色静态文戏可写 `单体, 无轴线` | — |

### 5.3 多题材示例

**机甲科幻（参考样式原貌）**:
```
## 相机
机位: LS 定机位（港口防波堤上，距 {主体A} 约 40 米）→ MS 水面伴随滑轨（机甲侧面约 6 米，同步前进）→ MCU 远处长焦拍地平线 → ELS 低角度低平面（水面一米高处，对准 {主体A} 背后朝阳）
运动: 0-2秒 定机位 / 2-6秒 跟随横移（速度 1.0m/s 同步机甲）/ 6-9秒 定机位 / 9-13秒 1.5x 慢动作 + 极缓慢轨向右移 0.3m/s
焦距: 混合
焦段: LS 24mm / MS 35mm / 地平线 MCU 85mm / ELS 低角度 35mm
轴线: {主体A} 入海方向轴（从画左向画右），全程不越轴
```

**真人短剧（单角色 3 拍）**:
```
## 相机
机位: LS 电梯门外（距 {主体A} 约 4 米）→ MCU 电梯内壁前壁（距 {主体A} 约 1.8 米）→ BCU 同位置略高
运动: 0-3秒 定机位 / 3-8秒 慢推 0.2m/s / 8-12秒 定机位
焦距: 标准
焦段: 35mm / 50mm / 85mm
轴线: 单体, 无轴线（电梯内全程定空间）
```

**武侠双人交战（5 拍）**:
```
## 相机
机位: LS 交战轴外侧（距双人中点约 8 米）→ 2S 同侧横移轨道 → ECU 剑尖（距剑刃约 0.5m，微距）→ MCU {主体A} 侧脸 → MS {主体B} 半身后撤
运动: 定机位 / 横移 1.5m/s / 急推 / 1.5x 慢动作 定机位 / 1.5x 慢动作 跟随后撤 0.8m/s
焦距: 混合
焦段: LS 24mm / 2S 35mm / ECU 100mm 微距 / MCU 85mm / MS 50mm
轴线: 交战轴; {主体A} 在画左 / {主体B} 在画右; 第 4 拍随 {主体A} 内力外放视点拉近，不越轴
```

**仪式蒙太奇（4 拍含升格）**:
```
## 相机
机位: ELS 远景定机位 → MS 跟随主体 → MCU 半逆光剪影 → ELS 低角度逆光（地平线高度）
运动: 定机位 / 跟随 1.0m/s / 定机位 / 1.5x 慢动作 极缓推 0.2m/s
焦距: 混合
焦段: 24mm / 35mm / 85mm / 35mm
轴线: 主体行进轴（画左→画右），全程不越轴
```

## 6. `## 微表情`

### 6.1 题材变体（参考 `cinematography_terms.md` §3）

| 题材 | 写法 | 字段格式 |
|---|---|---|
| 真人情绪戏 | 身体部位 + 动词 + 原文出处 | 无序列表 ≤5 项，每项可附 `（原文"..."暗示）` |
| 机甲 / 装甲 / 逆光剪影 | **光学描述**：亮度比 + 轮廓光方向 + 反光质感 | 1-2 行段落 |
| 武侠 / 仙侠 | 真人微表情 + 法术能量层 | 真人列表 + 1 行能量层（`<颜色/强度/形态/位置>`） |

### 6.2 多题材示例

**真人短剧**:
```
## 微表情
- 持手机的右手在抖（原文"手在抖"）
- 嘴唇紧闭后开口（原文"声音平稳"暗示）
- 眼神没有聚焦（原文"强撑"的视觉外化）
```

**机甲科幻（参考样式原貌）**:
```
## 微表情
- 第 4 拍：{主体A} 剪影与朝阳的亮度比约 1:12，轮廓光从右上方勾出装甲边缘
```

**武侠**:
```
## 微表情
- {主体A} 眉骨微沉
- 剑指无名指有节奏地轻颤
- 能量层：青木色光纹 / 强度 30%→80% / 沿剑身流动 / 流光速度约 5m/s / 位置剑身周身
```

## 7. `## 音频`（@Audio1 / @Audio2 双通道排版）

**严格双通道结构**。即使本单元无人声，**也要保留 @Audio1 段头 + 写跳过声明**，不允许整段缺失。

### 7.1 通道总骨架

```
## 音频

@Audio1 (台词通道)
{台词行 或 无人声占位}

@Audio2 (音效通道)
- {音效行}
- {音效行}
- ...
```

**两通道之间空一行**，**通道头单独占行**，**台词行不加 `-` 前缀，音效行加 `-` 前缀**。

### 7.2 @Audio1 台词通道行格式

```
[{起秒}-{止秒}秒] {主体} → "{台词原文}" (声线: @Audio_VN_{主体ID}) [{N} 字]
```

字段：
- `[起秒-止秒秒]`：时间段，**必须是 `## 时序` 拍数切分内的子区间**
- `{主体}`：角色绑定（与上游 `analysisContext` 的 character ID 一致）
- `"{台词原文}"`：用半角双引号包裹，**字数严格按 `audio_db_reference.md` §5 计入规则**
- `(声线: @Audio_VN_{主体ID})`：声线 ID 占位；未确定时写 `(声线: @TODO_Voice_{主体ID})`
- `[N 字]`：字数计数（验算用），**计入对白 + 拟声词，不计标点 / 环境音 / 模糊不可辨人声**

### 7.3 @Audio1 边界情况标准写法

| 情形 | 写法 |
|---|---|
| 本单元无人声 | `本单元无人声（跳过 @Audio1）` |
| 画外音 (V.O.) | `[X-Y秒] {主体} (V.O.) → "..." [N 字]` |
| 旁白 / 屏外音 (O.S.) | `[X-Y秒] {主体} (O.S.) → "..." [N 字]` |
| 电话另一端（模糊不可辨） | 在 `## 音频` 下方注释 `（电话另一端 {对方} 的回应仅作为背景模糊处理，归入 @Audio2，不计入字数）` |
| 拟声词「啊 / 唔 / 嗯」 | 算 1 字进入 `[N 字]`，写法同台词：`{主体} → "啊—" [1 字]` |
| 多角色快速对话 | 每行独立写，时间段允许相邻或重叠（重叠用注释说明）：<br>`[3-5秒] {主体A} → "..." [6 字]`<br>`[5-7秒] {主体B} → "..." [4 字]` |
| 群戏（≥3 人同时说） | 写主导角色，其余归入 `@Audio2` 作"群声底噪"：`[X-Y秒] 群声底噪（路人讨论，不可辨内容，-14dB）` |
| 系统提示音（可读人声） | 算入 @Audio1，标注来源：`[X-Y秒] 系统语音 → "请注意安全" (合成音, @Audio_TTS) [6 字]` |

### 7.4 @Audio2 音效通道行格式

```
- [{起秒}-{止秒}秒] {音效描述}（音量 -XX dB[, 渐变 -XX→-YY dB][, {层次/位置}]）
```

字段：
- `[起秒-止秒秒]`：使用 `[全程]` 表示整段
- `{音效描述}`：自然语言描述，**避免模糊词**（"大声"→具体 dB；"远处"→具体距离）
- `（音量 -XX dB）`：必填，dB 引用 `audio_db_reference.md` §2.1 + 上游 AUDIO_REFS 块（±3dB）
- 渐变：`递增 -20→-12 dB` 或 `递减 -18→-30 dB`
- 层次注释：可选，如 `L2'` / `层次随身体没入递进`

### 7.5 多层叠加缩进规则

同一时间段多层音效叠加时，**用嵌套缩进**（2 空格）：

```

  - 远处港区钠灯余音（-22dB, L2）
- [2-6秒]

  - 海水包裹金属（-15dB, L3, 层次随身体没入递进）
```

## 8. `## 强制音频声明`

完整的 6 题材模板见 `audio_db_reference.md` §6。本节仅给出**字段排版规范**：
