在编写 AI 视频提示词时，遵循以下统一结构确保运镜精准：

```
[基础画质参数] + [特定风格描写] + [动态要求] + [固定场景描述] + [核心运镜逻辑] + [负向/约束提示词]
```

```
4K超清, HDR, 电影级写实, 60fps, 全程无切镜, 一镜到底, 画面稳定,
[固定场景描述]: 古风山巅云海, 剑客白衣持剑而立,
核心运镜: 10秒内机位从人物正面5米处匀速向前推进至面部特写, 0-3秒中景全身, 4-7秒半身近景, 8-10秒面部超特写,
全程画面主体清晰, 不要生成音乐和字幕, 无穿帮, 无黑屏。
```

## 四、提示词工程专家建议 (Tips)

### 4.1 单变量测试法
在调试运镜时，**保持场景固定不变**，仅修改"核心运镜"逻辑，以精准观察不同运镜对画面的影响。

### 4.2 节奏控制技法
利用时间轴写法控制动作节奏：
```
前3秒保持完全静止 → 第4秒急速启动 → 5-8秒匀速运动 → 最后2秒减速至停止
```
这种写法能有效引导 AI 理解动作的停顿感与爆发力。

### 4.3 分层控制技法
对于复杂 AI 运镜效果，使用空间分层描述：
```
画面拆分为前景、中景、远景、背景4个独立分层，
前景人物保持高速运动，中景烟尘向两侧扩散，远景山体静止，背景云海以0.5倍速流动
```

### 4.4 场景适配推荐

| 场景类型 | 推荐运镜组合 |
|:---------|:------------|
| **打斗场景** | 连招动作锁定 + 大招第一视角 + 快慢时间同框 |
| **玄幻场景** | 次元壁穿梭 + 神识扫描视角 + 功法特效绑定 |
| **电影感叙事** | 手持纪实风格 + 平滑连续推拉 + 吊臂升降 |
| **情感表达** | 呼吸感推拉 + 浅景深 + 循环呼吸焦点 |
| **宏大场景** | 无限尺度变焦 + 上升揭示 + 上帝俯视 |
| **悬疑/恐怖** | 希区柯克变焦 + 荷兰角 + 心跳冲击联动 |
| **转场衔接** | 元素匹配锚定 + 回忆杀瞳孔切入 + 光影覆盖 |

### 4.5 约束指令模板
在所有提示词末尾附加以下约束，确保输出质量：
```
全程画面主体清晰, 无黑屏, 无穿帮, 无字幕, 不要生成音乐,
画面稳定无抖动（除非特定要求抖动效果）,
运动过程连贯自然无跳变
```

## 六、运镜组合逻辑 (Combo)

高级用法：将多种运镜串联组合，形成复合运镜：

```
[0-3秒] 吊臂上升 + 360度环绕启动 → 
[3-6秒] 急速推进至面部特写 →
[6-8秒] 子弹时间冻结 + 微幅环绕 →
[8-10秒] 急速拉出至全景揭示
```

**组合原则**：
1. 每段运镜持续2-4秒为宜
2. 相邻运镜之间保持运动方向的逻辑连贯性
3. 在时间轴中明确标注每段的起止时间
4. 速度变化（加速/减速）要有过渡，避免AI理解出错
