# 类型化改编策略（6 类速查）

> 来源：ShadowScript 影语 `agents/novel_adapter/kb/genre_adaptation.md` 精简版。
>
> ⚠️ **仅当本项目处于「改编模式」时注入**。原创模式无需关注。
>
> 用途：当下游写手不知道「这类型该砍什么、该留什么」时，直接查表。先识别原作 `genreType`（玄幻武侠 / 都市现代 / 言情古言 / 悬疑推理 / 科幻末世 / 重生复仇），再按表执行。

---

## 一、玄幻 / 武侠

**核心驱动**：境界体系清晰可视化、打脸节奏密集（每 2-3 集一次）。

- ✅ 必保留：境界突破 / 打脸羞辱 / 越级挑战 / 身份曝光 / 宝物争夺
- ❌ 必删除：修炼过程 / 功法原理 / 环境风景 / 赶路过渡
- ⚡ 必强化：数值展示 / 力量对比 / 打脸反应

压缩手段：修炼 → 蒙太奇 10 秒 ；战斗 → 保留关键招式 ；突破 → 特效 + 数值。

---

## 二、都市 / 现代

**核心驱动**：身份对比现实化、打脸方式多样化。

- ✅ 必保留：身份反差 / 财富对比 / 地位碾压 / 真相大白 / 商战对决
- ❌ 必删除：日常琐事 / 工作细节 / 心理独白 / 城市风景
- ⚡ 必强化：语言交锋 / 身份反转 / 打脸时刻

---

## 三、言情 / 古言

**核心驱动**：误会合理化、虐点精准狠辣、宠溺甜到极致。

- ✅ 必保留：误会产生 / 虐心痛苦 / 真相大白 / 甜宠片段 / 吃醋争风
- ❌ 必删除：过度心理独白 / 重复日常甜蜜 / 环境描写 / 无关支线
- ⚡ 必强化：情感冲突 / 误会解除 / 虐心时刻 / 虐转甜反差

---

## 四、悬疑 / 推理

**核心驱动**：线索清晰、反转震撼、节奏紧张。

- ✅ 必保留：关键线索 / 反转时刻 / 真相揭露 / 紧张追逐 / 凶手曝光
- ❌ 必删除：过度详细推理 / 细节描写 / 日常调查琐事
- ⚡ 必强化：悬念设置 / 反转冲击 / 紧张氛围 / 时间压力

---

## 五、科幻 / 末世

**核心驱动**：世界观快速建立、危机持续紧张。

- ✅ 必保留：危机爆发 / 异能觉醒 / 黑科技展示 / 基地争夺 / 怪物对抗
- ❌ 必删除：世界观详细铺垫 / 科学原理 / 环境描写 / 日常求生
- ⚡ 必强化：视觉特效 / 紧张节奏 / 危机升级

---

## 六、重生 / 复仇

**核心驱动**：前世今生对比强烈、先知优势爽快利用、复仇节奏密集。

- ✅ 必保留：重生回归 / 前世闪回 / 先知优势利用 / 打脸仇敌 / 布局复仇
- ❌ 必删除：过长前世回忆 / 重生原理 / 过度纠结 / 重复先知展示
- ⚡ 必强化：前世今生对比 / 先知优势 / 布局感 / 打脸时刻 / 命运改变

### 重生题材专属处理

- **开场（第 1 集）**：前世死亡 (15s) → 惊醒重生 (10s) → 决心改变 (15s) → 卡黑 (10s)
- **前世记忆使用**：碎片化【闪回】每次 3-5 秒；只在关键节点闪回（打脸 / 复仇 / 改变命运时）
  - 禁：单独一集全是回忆 / 重复闪回 / 闪回 > 10 秒
- **先知优势展示**：提前预判 → 提前布局 → 改变剧情（三选一）
- **复仇节奏**：每 5 集打脸 1 个仇敌 / 每 20 集击败 1 个主要仇敌
- **爽点密度**：每集必有先知 / 打脸 / 改变 / 布局之一

---

## 七、5 大改编致命错误（必避）

| 错误 | 问题 | 正确做法 |
|---|---|---|
| ❌ 过度忠于原著 | 全留 → 节奏拖沓 | 大胆删减，只留核心冲突和爽点 |
| ❌ 节奏过慢 | 保留铺垫和过渡 → 观众滑走 | 3 秒进冲突，删除所有铺垫 |
| ❌ 心理描写过多 | 画面无法展现 → 看不懂 | 心理 → 动作 / 心理 → 对话 / 心理 → 删除 |
| ❌ 支线过多 | 主线模糊 → 不知道看什么 | 主线 80% + 重要支线 15% + 其他删除 |
| ❌ 人物过多 | 记不住 → 人物混乱 | 主角 + 主要配角 5-8 人，工具人合并 |

---

## 八、5 大核心原则

1. **情绪钩子优先**：有爽点 > 完整故事；能让观众"卧槽" > 逻辑严密
2. **视觉化优先**：能拍画面 > 抽象描写；动作 > 心理
3. **快节奏强制**：3 秒进冲突，每 30 秒必有推进，每集必有【卡黑】
4. **尊重原作结构**：保持小说原有故事结构，不强行重构三幕式
5. **算法友好**：完播率（强悬念）+ 互动率（争议点）+ 传播率（金句台词）
