# 视听签名（audiovisualSignature）体系与禁忌库

> 10 类视听签名标签 + 5 维度落幅末状态变体 + 签名专属禁忌 + 子风格信号词四合一。
>
> **视听签名 ≠ 原子题材**：
> - 原子题材（`genres`）是用户输入维度，**30 类**，多选 1-3，权威源 `src/data/projectTaxonomy.ts`。
> - 视听签名（`audiovisualSignature`）是下游分镜维度，**10 类**，单选，由原子题材映射而来。
> - 映射规则详见 `genre_to_av_signature_mapping.md`。
>
> 本文后续所有「题材」一词默认指 **audiovisualSignature**，不是原子题材。
>
> ⚠️ 专属禁忌和默认值是**通识层**。具体项目可能有自己的世界观规则，
> 应在「项目设定 / 改编原作 KB」中覆盖本文条款。

### 2.1 各维度词汇库（精简版）

- **姿态**：站 / 坐 / 蹲 / 跪 / 卧 / 半侧身 / 前倾 / 后撤 / 弓步 / 横身
- **手部**（真人/古装/悬疑）：空手 / 持物 / 扶 / 握 / 攥 / 撑 / 搂 / 揽 / 推
- **执行器**（机甲）：双臂贴身 / 单臂前展 / 双手持武器 / 武器系统就位/收纳 / 推进器开/收
- **法器**（仙侠）：剑离手 / 剑回鞘 / 剑横身 / 剑斜指 / 法诀手势 / 持珠 / 持符
- **武器**（武戏/战争）：枪管前指/下垂 / 刀架颈侧 / 弓拉满 / 上膛 / 出鞘 / 收鞘
- **义体**（赛博）：机械臂展开/收纳 / 接驳点开/闭 / 义眼亮灯/熄灯
- **朝向**：正面 / 侧面 / 背面 / 朝 X 方向 / 头部朝 X / 视线落在 Y
- **受力**：不适用 / 重心偏 X / 双膝软 / 后撤步 / 站定 / 失衡
- **重心**：重心前 / 重心后 / 重心落右脚 / 重心落左脚 / 重心稳
- **能量 / 压力**（机甲/赛博）：反应堆 X% / 装甲完整度 X% / 信号 X% / 散热 X% / 弹药 X%
- **真气 / 法力**（仙侠）：真气 X% / 法力 X% / 内力流转/凝聚 / 神识涣散/凝聚
- **气场**（古装宫斗）：威严 / 平和 / 凌厉 / 肃静 / 端庄 / 哀戚
- **警觉**（悬疑）：全神戒备 / 听音辨位 / 余光扫视 / 屏息
- **受惊**（恐怖）：僵住 / 后退 / 屏息 / 颤抖 / 瞳孔放大
- **伤亡**（战争）：完好 / 轻伤 / 重伤倒地 / 牺牲 / 失血 X mL
- **情绪**（校园 / 都市，仅原文有暗示时）：平静 / 紧张 / 强撑 / 释然 / 怅然

## 3. 题材专属禁忌库

### 3.1 真人短剧
- ❌ 现代场景出现 wuxia 飞行
- ❌ 角色无合理动机的暴力
- ❌ 对白用文言

### 3.2 机甲 / 科幻
- ❌ 大驾驶员脸出现（除非剧本明确"驾驶舱内"特写）
- ❌ 损毁状态在剧本指定单元前出现
- ❌ 外星生物色彩跨流派混用（如"琥珀单色"则全片琥珀）
- ❌ 装甲凭空再生
- ❌ 能量爆发无视觉回授（必须有蓄力光纹 / 排气 / 散热）
- ❌ 飞行无脚下气流
- ❌ 武器开火无后坐力

### 3.3 武侠 / 仙侠
- ❌ 法术能量颜色跨流派混用
- ❌ 飞行无脚下气流反馈
- ❌ 法器凭空召唤（必须有"取/抽/掏/召唤"动作）
- ❌ 凡人角色突然飞行
- ❌ 现代道具入画
- ❌ 内力 / 真气没有蓄力 / 释放过程

### 3.4 古装宫斗
- ❌ 服饰朝代错乱（清装≠明装≠唐装）
- ❌ 礼仪规范错（跪拜方向 / 称谓不对）
- ❌ 现代道具入画
- ❌ 妆容 / 发饰朝代错

### 3.5 战争
- ❌ 武器型号与时代错位
- ❌ 弹道无反作用力
- ❌ 爆炸无冲击波 / 无碎片
- ❌ 中弹无血迹（除非分级要求）
- ❌ 通讯频道音色错

### 3.6 悬疑刑侦
- ❌ 关键证据画面前置出现（破坏推理）
- ❌ 真凶面部前置清晰出现
- ❌ 案件细节与设定矛盾
- ❌ 警员着装规范错

### 3.7 赛博朋克
- ❌ 自然光主导（必须霓虹 / 屏幕光主导）
- ❌ 干净街景（必须有雨 / 蒸汽 / 涂鸦）
- ❌ 义体无接驳痕迹
- ❌ AI 角色情绪过度人类化

### 3.8 恐怖惊悚
- ❌ 怪物前置全身清晰出现（必须遮挡 / 模糊 / 局部）
- ❌ 充满色彩的高对比
- ❌ 主体在画面正中
- ❌ 高频背景音（除非 jump scare）

### 3.9 全题材通用
- ❌ 字幕 / 水印 / 文字 / Logo
- ❌ 可读文字（除非剧本明确）
- ❌ 超现实夸张（除非题材允许）
- ❌ 无反作用力动作

## 4. 子风格技法库（详版）

### 4.1 仪式蒙太奇

**必含技法（≥3 项）**:
- 慢动作终拍（1.5x，仅末 1-2 秒）
- 主题旋律低频铺底（≤ -10dB）
- 强逆光剪影（光比 ≥ 1:8）
- 强对称 或 中央构图
- 主体占画面 30-50%

**反例**:
- ❌ 主体没有"入场感"
- ❌ 没有逆光 / 慢动作 / 主题旋律 三件套之一
- ❌ 镜头切换太快（< 2 秒/拍）

### 4.2 海报帧

**必含技法**:
- 极强逆光（光比 ≥ 1:12）
- 1.5x 慢动作或定格（至少 1-2 秒）
- 中央构图 或 三分构图
- 主体占画面 30-50%
- 至少 1 个清晰可辨的剪影轮廓

**反例**:
- ❌ 构图主体不在中央也不在三分点
- ❌ 光比 < 1:6
- ❌ 主体被前景遮挡

### 4.3 长镜头

**必含**:
- 一镜到底（不切 sub-shot）
- 跟拍 或 定机位
- 持续 12-15 秒
- 内部允许复杂空间移动 / 多动作连续

**禁止**:
- sub-shot 切分
- 任何剪辑切点

### 4.4 蒙太奇剪辑

**必含**:
- 4-7 拍密集切
- 每拍 1.5-3 秒
- 景别跨度 ≥ 3 类（如 ELS+CU+ECU）
- 与音效 / 鼓点同步切镜

### 4.5 平行蒙太奇

**必含**:
- 双线（或多线）交叉切
- 同一时间不同空间
- 每条线至少 2 拍
- 切点必须有强对应（同一动作 / 同一情绪 / 视觉匹配）

### 4.6 梦境 / 闪回

**必含**:
- 浅虚化（背景模糊）
- 暖色饱和或冷色饱和
- 略漂浮的镜头感
- 与现实段落色温对比明显
- 进入 / 退出有明确视觉过渡（如对焦虚化、白光、声音抽真空）
