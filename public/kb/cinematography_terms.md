# 摄影语言词典（景别 / 焦段 / 慢动作 / 微表情光学描述 / 轴线）

> 给 LLM 的摄影术语五合一参考。
> 与本系统已有的「运镜术语库」（117 种运镜中英对照）互补：
> 本文聚焦"**景别 / 焦段数值 / 升格场景 / 光比 / 轴线**"五大数值化要素。

## 1. 景别代号词典

### 1.1 标准景别表

| 代号 | 全名 | 中文 | 物理范围 | 主体占画面 | 推荐焦段（35mm 等效） |
|---|---|---|---|---|---|
| **ELS** | Extreme Long Shot | 大全景 / 极远景 | 主体融入环境 | < 10% | 14-24mm |
| **VLS** | Very Long Shot | 远景 | 全身 + 大量环境 | 10-20% | 24-35mm |
| **LS** | Long Shot / Wide Shot | 全景 | 全身入画 + 适量环境 | 20-35% | 24-35mm |
| **MLS** | Medium Long Shot | 中全景 / 七分身 | 膝盖以上 | 35-50% | 35-50mm |
| **MS** | Medium Shot | 中景 | 腰以上 | 50-65% | 35-50mm |
| **MCU** | Medium Close-Up | 中近景 / 近景 | 胸以上（胸像） | 65-80% | 50-85mm |
| **CU** | Close-Up | 特写 | 头肩 | 80-95% | 85-105mm |
| **BCU** | Big Close-Up | 大特写 | 整张脸 | 95-100% | 100-135mm |
| **ECU** | Extreme Close-Up | 极特写 | 五官局部（眼/嘴/手） | 局部 | 100-200mm（含微距） |

### 1.2 视角性景别（独立类别）

| 代号 | 全名 | 中文 | 用途 |
|---|---|---|---|
| **POV** | Point of View | 主观视角 | 模拟角色感官 |
| **OTS** | Over the Shoulder | 过肩 | 双人对话标配 |
| **2S** | Two Shot | 双人镜 | 两人同框 |
| **3S** | Three Shot | 三人镜 | 三人同框 |
| **GS** | Group Shot | 群像 | ≥4 人 |
| **HA** | High Angle | 俯拍 | 主体显弱 |
| **LA** | Low Angle | 仰拍 | 主体显强 |
| **DA** | Dutch Angle | 倾斜镜 | 失衡 / 紧张 |
| **BEV** | Bird's Eye View | 鸟瞰 | 极俯视 |
| **WEV** | Worm's Eye View | 蚁视 | 极仰视 |

### 1.3 焦段语义对照

| 焦段 | 视觉特征 | 典型用途 |
|---|---|---|
| 14-24mm | 强透视变形 / 边缘弯曲 / 空间感强 | 大全景 / 室内压迫 / 主观穿越 |
| 24-35mm | 轻透视 / 接近人眼 | 全景 / 中全景 / 街景 |
| 35-50mm | 自然视角 / 无变形 | 中景 / 对话戏 / 标准镜 |
| 50-85mm | 轻压缩 / 立体感好 | 中近景 / 人像 |
| 85-135mm | 中压缩 / 背景虚化强 | 特写 / 情绪戏 |
| 135-200mm | 强压缩 / 拍远摄近 | 远距特写 / 跟踪体育 |
| 200-400mm | 极强压缩 / 远摄 | 偷拍感 / 隔离主体 |

### 1.4 焦段-景别强匹配规则

| 景别 | 推荐焦段 | 不推荐焦段 | 理由 |
|---|---|---|---|
| ELS / LS | 14-35mm | ≥85mm | 长焦丢空间感 |
| MS | 35-50mm | ≥135mm | 长焦面部畸变方向反 |
| CU | 85-135mm | ≤24mm | 广角拍特写鼻子变大 |
| ECU | 100-200mm + 微距 | ≤50mm | 距离不够会戳到主体 |

## 2. 慢动作（升格）使用场景库

### 2.1 允许场景

| 场景类型 | 推荐倍率 | 推荐时长 | 理由 |
|---|---|---|---|
| **武戏命中** | 1.5-2x | 0.5-1.5 秒 | 让观众看清打击点 |
| **武戏受创** | 0.5-1x | 0.5-2 秒 | 强化身体反馈 |
| **武戏终结 / 倒地** | 0.5x | 1-3 秒 | 仪式感 |
| **海报帧 / 名场面** | 1.5x | 1-2 秒 | 让"明信片画面"驻留 |
| **入场仪式** | 1.5-2x | 2-4 秒 | 增强角色登场分量 |
| **爆炸 / 冲击波** | 2-3x | 0.5-2 秒 | 物理细节展示 |
| **水花 / 飞溅** | 1.5-3x | 1-2 秒 | 流体细节 |
| **眼神交汇 / 顿悟** | 1.5x | 1-1.5 秒 | 情绪节点 |
| **死亡瞬间** | 0.3-0.5x | 1-3 秒 | 经典戏剧手法 |

### 2.2 禁止场景

- ❌ 走位 / 移动 / 步行（除非"入场仪式"）
- ❌ 对话 / 说话过程
- ❌ 铺垫 / 信息传递
- ❌ 空镜 / 转场
- ❌ 闲置时间 / 无事件
- ❌ 整段超 5 秒（变成"全片慢动作"会失去节奏）

### 2.3 倍率换算参考

| 倍率 | 拍摄帧率（输出 24fps） | 视觉效果 |
|---|---|---|
| 0.3x | 80fps | 极慢 / 死亡感 |
| 0.5x | 48fps | 戏剧感 / 情绪定格 |
| 1.0x | 24fps | 实时 |
| 1.5x | 36fps | 微慢 / 仪式感 |
| 2x | 48fps | 慢 / 标准动作慢 |
| 3x | 72fps | 极慢 / 物理细节 |
| 5x | 120fps | 超慢 / 子弹时间 |

> 注：本表是"叙事感受"的倍率，不是"视频生成 API 的播放速度参数"。Seedance 实际写法用「1.5x 慢动作」即可。

## 3. 微表情题材变体词典

### 3.1 真人情绪戏（默认）

身体部位 + 动词 + 原文出处。

```
- 林晚的手在抖（原文"手在抖"）
- 嘴唇紧闭后开口（原文"声音平稳"暗示）
- 眼神涣散不聚焦（原文"强撑"的视觉外化）
- 喉结滚动一下（原文"难以启齿"暗示）
- 眉头几不可察地皱了一下（原文"心头一紧"暗示）
```

### 3.2 机甲 / 装甲 / 逆光剪影戏

**改为光学描述**，因为机甲没有面部微表情。

#### 光比常用值语义

| 光比 | 视觉效果 | 适用场景 |
|---|---|---|
| 1:1 | 全平光 / 无层次 | 证件照 / 平淡叙事 |
| 1:2 | 轻明暗 / 自然 | 室内对话 |
| 1:4 | 戏剧光 / 经典电影感 | 大部分剧情戏 |
| 1:6 | 强对比 / 黑色电影 | 悬疑 / 噩梦 |
| 1:8 | 极强对比 / 主体被剪走一半 | 反派出场 / 心理压迫 |
| 1:12 | 剪影感 / 主体只剩轮廓 | 海报帧 / 仪式蒙太奇 |
| 1:16 | 极致剪影 / 完全黑色轮廓 | 神祇出场 / 名场面定格 |
| 1:32 | 纯剪影 / 几乎丢失细节 | 招贴画风 |

#### 光向词汇

| 光向 | 视觉效果 |
|---|---|
| 顶光 | 鼻底阴影 / 神圣或恐怖 |
| 侧光（45°） | 经典布光 / 立体感 |
| 平光（正面 0°） | 平面感 / 平淡 |
| 逆光 | 主体剪影 / 轮廓光勾边 |
| 底光（向上） | 恐怖 / 邪典 |
| 边缘光 / 轮廓光 | 主体与背景分离 |
| 硬光（点光源） | 阴影锐利 / 戏剧 |
| 漫射光（柔光） | 阴影柔和 / 日常 |

#### 机甲反光质感词典

| 词 | 含义 |
|---|---|
| 哑光 | 不反光 / 战损 |
| 半哑 | 略反光 / 标准装甲 |
| 镜面 | 强反光 / 仪式 / 礼装 |
| 划痕磨损 | 战损肌理 / 历经战斗 |
| 油污 | 长期使用 / 维修不及时 |
| 水膜 | 涉水后表面膜 |
| 碳化烧蚀 | 高温战斗后 |
| 锈蚀 | 长期未启用 / 古战甲 |
| 装甲缝隙渗水 / 渗光 | 涉水 / 内部能量泄漏 |

### 3.3 武侠 / 仙侠

真人版微表情 **+ 法术能量层**：

```
能量层描述格式: <颜色 / 强度 / 形态 / 位置>
  - 法力光纹强度: 微弱 / 稳定 / 强盛 / 暴走 (4 级)
  - 流光速度: 静止 / 缓流 / 流动 / 急射 (m/s 可选)
  - 颜色: 通常一色一流派 (青木 / 赤火 / 玄水 / 金阳 / 白雷 / 紫电)
  - 形态: 雾气 / 光纹 / 火焰 / 流光 / 闪电 / 法阵
  - 位置: 主体本体 / 法器 / 周身 / 脚底 / 头顶
```

## 4. 轴线类型词典

### 4.1 标准轴线

| 轴线类型 | 适用场景 | 定义 | 越轴判定 |
|---|---|---|---|
| **对话轴** | 2 人对话 | 两人视线连线 | 机位禁止跨这条线 |
| **运动轴** | 单人或群体单向移动 | 移动方向延长线 | 跨线 = 角色突然反向 |
| **交战轴** | 武戏对峙 | 攻守双方连线 | 跨线 = 攻守左右瞬间反转 |
| **注视轴** | 单人凝视目标 | 主体到目标的视线 | 跨线 = 目标位置漂移 |
| **运动+注视复合轴** | 边走边看 | 运动方向 ⊕ 注视方向 | 取主导方向 |

### 4.2 多人站位特殊规则

| 站位类型 | 规则 |
|---|---|
| **三角站位（3 人）** | 三人构成三角形，机位限于三角外侧弧 |
| **环形站位（≥4 人）** | 选一个核心角色为锚点，机位限于其后半场 |
| **L 形站位** | 取转角处为锚点，机位走 L 的对角线 |
| **同向并行（2 人同向走）** | 用运动轴，相机走平行轨道 |

### 4.3 越轴的"合法借口"

正常情况禁越轴，但以下情形允许：

- ✅ 镜头内连续推过中线（观众看见过程，不会迷失）
- ✅ 主体明显回头（视线变了，轴线也变了）
- ✅ 中性方向插入镜（垂直于轴线的过肩 / 主体正脸 / 俯拍）后再切到对侧
- ✅ 角色物理位置重新洗牌（一人离开 / 第三人加入）

### 4.4 轴线声明的标准写法

```
轴线: <轴线类型>; <方向>; <不越轴声明 或 越轴借口>

示例:
  轴线: 对话轴; A 在画左 / B 在画右; 全程不越轴
  轴线: 运动轴; 角色1 入海方向（画左→画右）; 全程不越轴
  轴线: 交战轴; 老K 在画左 / 林晚在画右; 第 4 拍随老K回头自然换向
```

## 5. 构图原则速查

| 构图 | 用途 |
|---|---|
| 三分法（rule of thirds） | 通用 / 自然 |
| 中央构图 | 海报帧 / 仪式 / 对称感 |
| 黄金分割 | 经典美感 |
| 对角线构图 | 动态 / 不稳定 |
| 框中框（frame within frame） | 隔离主体 / 偷窥感 |
| 引导线（leading lines） | 视线导向主体 |
| 负空间 | 孤独 / 留白 |
| 对称构图 | 仪式 / 命运感 |
| 三角构图 | 稳定 / 群像 |
