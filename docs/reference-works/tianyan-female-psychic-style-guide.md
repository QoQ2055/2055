## 8 大章节填充速读

### 一、整体调性
现代都市玄学捉鬼爽文，弹幕吐槽风金句频出，顺叙单线悬疑解密式推进。

### 二、开篇规范（前三章）
- **悬疑钩开场**（直接以诡异感知/危机切入）
- **第 1 章 5 句公式示例**："这井里有东西。"沈念卿盯着那口枯井，天眼已经看见了——井底那团扭曲的黑影，正在往上爬。
- **5 必备**：核心冲突 / 主角性格 / 天眼初显 / 父母线索 / 章节钩子
- **6 禁忌**：不以环境开篇 / 不时间跳跃 / ≤ 3 设定 / ≤ 3 新角色 / 前 300 字 ≤ 4 对话 / ≤ 2 内心独白

### 三、节奏体系（300 章五阶段细分）

| 阶段 | 章节 | 任务 | 爽点密度 |
|---|---|---|---|
| 开篇立势 | 1-30 | 命理馆亮相 + 捉鬼副本 + 男主登场 | 每章 1 爽点 |
| 悬念铺陈 | 31-90 | 彼岸深入 + 父母线索 + 感情起航 | 每 5 章 1 爽点 |
| 高潮密集 | 91-180 | 真相分层 + 终极对决 + 复仇完成 | 每 3 章 1 爽点 |
| 余韵收束 | 181-250 | 残余清剿 + 千年恩怨 + 角色结局铺垫 | 每 5-10 章 1 爽点 |
| 终章余波 | 251-300 | 最终命运 + 情感余韵 | 纯情感收束 |

**单章 5 段比例**（3000 字章节）：开篇 200-300 / 蓄力 800-1000 / 爆发 1000-1200 / 反应 300-500 / 钩 200-300

### 四、爽点设计

| 优先级 | 类型 | 实例 |
|---|---|---|
| 核心 | **天眼碾压** | 别人看不到的，沈念卿一眼看穿 |
| 核心 | **毒舌打脸** | "就这？" / "画符之前建议先查查字典" |
| 二级 | 悬疑揭示 | 关键线索揭露 |
| 二级 | 命定冤家互动 | 暧昧拉扯 |
| 三级 | 路人不识货 | 嘲讽 → 打脸 |
| 三级 | 配角高光 | 配角独立闪光时刻 |

### 五、人物描写
- **沈念卿**（女主）：毒舌三连 + 行动驱动 + 不解释玄学
- **顾沉渊**（男主）：清冷高冷 + 沉默金贵 + 对女主软化
- **配角**：每个 1 核心记忆点，不超过 3 相似配角
- **反派**：小（1-2 章解决）/ 中（彼岸成员有动机）/ 大（彼岸幕后必须有理由）

### 六、对话基准
| 场景 | 密度 | 字数 |
|---|---|---|
| 捉鬼/打脸 | 高（4-6 句/段） | ≤ 20 字 |
| 悬疑/紧张 | 极低（1-2 句/段） | ≤ 15 字 |
| 日常/感情 | 低（2-3 句/段） | ≤ 25 字 |
| 揭秘/高潮 | 极低（1-2 句/段） | ≤ 15 字 |

### 七、语言禁区（11 条）
1. AI 词汇（此外/然而/值得注意的是）
2. 连续 3 个"的"字结构
3. 环境描写 > 200 字/段
4. 同场景 > 3 句环境描写
5. 以恐怖/恶心为目的（诡异 ≠ 恐怖）
6. 鬼魂有完整人类情感
7. 配角反应雷同
8. 重复打脸套路
9. 玄学说教
10. 女主圣母/软弱/恋爱脑
11. 任何一方舔狗

### 八、章节收尾
4 类钩子（悬念/冲突/反转/情感）+ 4 禁忌（不写完/不感叹号/不旁白/不"本章完"）

## 本实例的教学价值

### 1 · 标志性句式确立得早
女主三大金句："就这？" / "画符之前建议先查查字典" / "饿了吧？要不先吃点？" —— 第 1 章必须确立 1-2 句，建立读者对主角语言的"指纹识别"。

### 2 · 爽点 4 步公式落地示范
**天眼碾压爽点的 4 步**：
- ① 触发：鬼怪出场 / 邪修施法 / 关键线索被掩盖
- ② 蓄力：旁人一脸茫然 / 自信满满
- ③ 爆发：天眼一开，事实摆在眼前，对方当场吓傻
- ④ 延伸：天眼透视 → 引出更深线索 → 指向父母之死 / 彼岸

每个爽点都不孤立，必须延伸到主线。这是爽文不变水文的关键。

### 3 · 男女主张扬度反差
女主**张嘴就来**毒舌 vs 男主**沉默金贵**。这种"语言密度反差"比"性格反差"更易被读者捕捉到。

### 4 · 五阶段对应不同爽点密度
开篇立势每章爽点 → 悬念铺陈每 5 章 → 高潮密集每 3 章 → 余韵收束每 5-10 章 → 终章纯情感。**密度递进而非平铺**，前期密集留住读者，中期蓄势，高潮爆发，尾章温情。

### 5 · "诡异 ≠ 恐怖"边界精确
玄学捉鬼但禁止真正恐怖：诡异感 = "好刺激"；恐怖感 = "好害怕"。爽文读者要的是前者。

## 可参考的题材

本实例特别适合参考的题材：
- **玄学 / 捉鬼 / 都市灵异**（直接借节奏 + 爽点设计）
- **女主异能 / 女主复仇**（借 5 阶段宏观节奏）
- **命定冤家 / 双门对立**（借男女主张扬度反差）
- **悬疑解密 + 爽文**（借单章 5 段式 + 钩子设计）

不太适合直接借用：
- 男频玄幻 / 修真（爽点重点不同：男频更看重升级而非打脸）
- 严肃文学 / 校园日常（节奏完全冲突）
- 短篇（5 段式 + 5 阶段开销过大）
