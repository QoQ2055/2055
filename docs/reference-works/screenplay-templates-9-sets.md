## 未吸收的 3 套 · 保留供未来扩展参考

### 丹尼尔八序列（Frank Daniel）

- **价值**：解决"第二幕拖沓"的终极方案
- **核心**：8 个 12% 序列，每序列都是微型三幕式
- **未吸收原因**：Save the Cat 15 节拍已经解决了节拍切分问题，八序列与之定位重叠
- **可能扩展场景**：若未来做**超长篇分卷**流程（≥ 100 万字），八序列每卷对应一个序列的映射值得启用

### 麦基价值反转（Robert McKee）

- **价值**：场景级理论——每个场景必须完成一次价值正负反转
- **核心**：故事 → 幕 → 序列 → 场景 → 节拍五层结构
- **未吸收原因**：价值反转是**底层理论**而非可执行模板，理论性过强，LLM 直接套用困难
- **可能扩展场景**：若做**场景级润色 / 重写**节点，场景反转公式可作为评分标准

### 埃格里冲突三要素（Lajos Egri）

- **价值**：三维角色模型（生理/社会/心理）+ 冲突升级路径
- **核心**：前提→角色→冲突的因果链
- **未吸收原因**：三维角色模型已被 MBTI 模块覆盖，冲突升级与 truby-22-steps 重合
- **可能扩展场景**：戏剧 / 话剧类项目若有独立流程，可参考

## 万能搭配公式（原文精华）

### 五步搭配流程

```
① 定大框架 → 三幕式 / 故事圈
② 控节奏节拍 → 救猫咪 15 节拍表
③ 填情节模块 → ATU 301 十大功能簇
④ 做人物成长 → 特鲁比 22 步
⑤ 造戏剧张力 → 麦基价值反转
⑥ 适配题材 → 选择对应细分模板
```

**cineforge-web 映射**：
- ①② 合并 = structure 类（9 选 1 互斥）
- ③ = `atu-301-rescue-quest` / `supernatural-webfiction-pack`
- ④ = `truby-22-steps`（但本身已是完整结构骨架）
- ⑤ = 未来可做 **scene-value-reversal** 工艺层模块
- ⑥ = character / craft 层的正交模块

## 新手推荐路径（用户教学）

```
第一阶段（最快上手）：救猫咪 15 节拍
  → 3 天学会主流商业电影的节奏

第二阶段（理解底层）：悉德·菲尔德三幕式
  → 不被 15 节拍束缚，理解背后原理

第三阶段（掌握闭环）：哈蒙故事圈
  → 学会写连载 / 单元剧的起承转合

第四阶段（按需深入）：
  ├─ 深度人物 → 特鲁比 22 步 + 埃格里三要素
  ├─ 悬疑类型 → 三宅隆太 12 步
  ├─ 情感类型 → 林赛·多兰七要点
  └─ 极致节奏 → 丹尼尔八序列
```
