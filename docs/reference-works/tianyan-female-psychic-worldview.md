## 9 柱填充速读

### 柱 1 · 类型与基调
现代都市 + 玄学捉鬼，300 章长篇，女主天眼开挂题材。

### 柱 2 · 顶层设计
- **表世界**：命理馆馆主（算命看相）
- **里世界**：玄门沈家唯一传人，天师级修为，鬼谷门门主
- **核心设定**：天眼（视鬼 + 因果线 + 破妄 + 回溯）
- **三条硬规则**：
  1. 玄门中人不得随意对普通人使用玄术（违背 = 逐出师门 + 追杀）
  2. 玄门恩怨不得牵连无辜（违背 = 废去修为）
  3. 泄露身份者，逐出师门（违背 = 成为众矢之的）

### 柱 3 · 势力格局
- 玄门沈家（女主出身，正道捉鬼）
- 道门顾家（男主出身，正道修道，千年隔阂但最终合作）
- 彼岸（邪道以鬼养术，死敌）
- 散修联盟（中立工具变数）
- 医仙谷（女主隐藏身份来历）

### 柱 4 · 阶层结构
- **表层**：五大家族 → 金领名医 → 普通职员 → 沈念卿表面身份（最底层）
- **里层**：入门 → 小成 → 大成 → 宗师 → **天师（主角）** → 陆地神仙（传说）

### 柱 5 · 能力体系
- 6 级等级：入门 / 小成 / 大成 / 宗师 / **天师（主角位置）** / 陆地神仙
- 核心：天眼（4 种能力 + 3 种限制）
- 辅助：符箓术（镇魂 / 破煞 / 追踪 / 护身 / 天眼符）

### 柱 6 · 揭示节奏
- 前 10 章：天眼 + 命理馆 + 捉鬼
- 10–30 章：顾家 / 彼岸 / 玄道两门对立
- 30–60 章：彼岸详情 / 沈家历史
- 60+ 章：千年恩怨 / 天眼全部能力

### 柱 7 · 未解悬念（5 条）
| 悬念 | 埋入 | 揭示 |
|---|---|---|
| A 父母之死真相 | 第 1 章 | 60–80 章 |
| B 顾沉渊真实身份 | 前 3 章 | 40–50 章 |
| C 玄道两门千年恩怨 | 第 5–10 章 | 第 100 章 |
| D 彼岸幕后黑手 | 第 3 章 | 80–100 章 |
| E 天眼最终来源 | 第 1 章 | **大结局** |

### 柱 8 · 金手指
- **天眼**（沈家血脉 + 十万分之一概率天生觉醒）
- 4 种核心能力 + 3 种限制 + 成长方式（单眼→双眼→完全掌控）

### 柱 9 · 禁忌（7 条）
1. 天眼终极秘密不揭（大结局前）
2. 天眼表现有统一限制规则
3. 彼岸设定大纲阶段确定
4. 女主医仙谷身份仅读者知道
5. 女主绝不圣母 / 被动
6. 不写真正恐怖（诡异刺激替代吓人恶心）
7. 鬼魂不做复杂情感演绎

## 本实例的教学价值（可抄之处）

### 1 · "表里二分"做得精细
表世界身份（命理馆馆主 = 最底层）与里世界身份（天师级 + 门主 + 医仙谷传人）**三重反差**，爽感来源明确。

### 2 · 硬规则与剧情绑定
三条硬规则不是装饰——
- 铁律一（不得对普通人用玄术）→ 引出"被迫破规救人"的冲突点
- 铁律三（身份泄露）→ 引出"几乎泄露"的悬疑张力

### 3 · 多势力三角对抗
5 势力形成**2 正 + 1 邪 + 1 中立 + 1 隐藏**结构，任何章节都能找到可推进的冲突源。

### 4 · 悬念 A–E 的时间错开
5 条悬念的揭示时机精准错开（40 → 50 → 60 → 80 → 100 → 大结局），**每 20 章必有一次大揭秘**，这是长篇留住读者的核心技法。

### 5 · 金手指限制具体到体感
"追溯过往 = 头疼欲裂" / "阴气重地负担极大" —— 用**身体感受**而非抽象数值做限制，读者可共情。
