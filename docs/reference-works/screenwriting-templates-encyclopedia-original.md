# 著名编剧模板大全

> 本文档收录全球影视工业中最经典的编剧结构模板，涵盖好莱坞、日韩、欧洲及独立影坛常用格式。

---

## 一、三幕结构 (Three-Act Structure)

**类型：** 经典叙事结构  
**适用范围：** 几乎所有商业电影、电视剧

### 核心框架

| 幕 | 比例 | 内容 |
|----|------|------|
| 第一幕（建置） | 25% | 建立世界、人物、冲突 |
| 第二幕（对抗） | 50% | 主角面对阻碍，逐步升级 |
| 第三幕（解决） | 25% | 高潮对决，结局收束 |

### 经典公式

```
第一幕：建置（Page 1-30）
  ↓ 第一次转折点（Page 25-27）
第二幕：对抗（Page 30-90）
  ↓ 第二次转折点（Page 85-90）
第三幕：解决（Page 90-120）
```

### 经典台词示例

> *"In the first act, you put your character up a tree. In the second act, you set the tree on fire. In the third act, you throw him off."*  
> — 经典好莱坞编剧法则

### 使用此模板的经典电影

- 《阿甘正传》(1994)
- 《泰坦尼克号》(1997)
- 《黑客帝国》(1999)
- 《盗梦空间》(2010)

## 二、"救命解猫"模板 (Save the Cat)

**类型：** 节拍器结构  
**创始人：** Blake Snyder  
**适用范围：** 商业电影、类型片

### 15个节拍（Beats）

| # | 节拍名称 | 位置 | 说明 |
|----|----------|------|------|
| 1 | Opening Image | 0% | 定调画面，确立情绪基色 |
| 2 | Theme Stated | 5% | 主题揭示（通常被忽视） |
| 3 | Setup | 1-10% | 展示日常生活与世界 |
| 4 | Catalyst | 12% | 催化事件，打破平衡 |
| 5 | Debate | 12-25% | 犹豫、思考、是否行动 |
| 6 | Break into Two | 25% | 进入"第二幕"，接受挑战 |
| 7 | B Story | 22% | 副线故事（通常是爱情线） |
| 8 | Fun and Games | 25-50% | 展示卖点与核心场景 |
| 9 | Midpoint | 50% | 虚假胜利或虚假失败 |
| 10 | Bad Guys Close In | 50-75% | 反派逼近，内外交困 |
| 11 | All Is Lost | 75% | "黑心时刻"，最低点 |
| 12 | Dark Night of the Soul | 75-80% | 绝望、崩溃、反思 |
| 13 | Break into Three | 80% | 顿悟，获得新方案 |
| 14 | Finale | 80-99% | 最后一搏，组合拳对决 |
| 15 | Final Image | 99-100% | 与开头呼应，终幕画面 |

### Save the Cat 完整示例：《阿甘正传》

| 节拍 | 内容 |
|------|------|
| Opening Image | 羽毛飘落，阿甘坐在长椅上 |
| Theme Stated | "Life is like a box of chocolates" |
| Setup | 童年阿甘与母亲、珍妮的生活 |
| Catalyst | 珍妮离开，阿甘开始奔跑 |
| Debate | 越战前夕的困惑 |
| Break into Two | 应征入伍，决定去越南 |
| B Story | 与丹中尉的故事线 |
| Fun and Games | 乒乓外交、捕虾船 |
| Midpoint | 飓风袭击，珍妮归来 |
| Bad Guys Close In | 丹中尉的绝望、阿甘的孤独 |
| All Is Lost | 珍妮再次离去 |
| Dark Night | 阿甘独自守着捕虾船 |
| Break into Three | 收到国会荣誉勋章 |
| Finale | 珍妮归来，儿子出生 |
| Final Image | 羽毛再次飘向天空 |

### 使用此模板的经典电影

- 《怪物史莱克》(2001) — Blake Snyder亲自指导
- 《钢铁侠》(2008)
- 《盗梦空间》(2010)
- 《星际穿越》(2014)
- 《寄生虫》(2019)

## 三、英雄之旅 (Hero's Journey / Monomyth)

**类型：** 神话结构  
**创始人：** Joseph Campbell（神话学），Christopher Vogler（改编影视）  
**适用范围：** 史诗片、奇幻片、冒险片、超级英雄片

### 12阶段框架

```
┌─────────────────────────────────────────────────────────┐
│                    英雄之旅完整地图                       │
├─────────────────────────────────────────────────────────┤
│  第一章：分离                                           │
│                                                         │
│  ① 普通世界（Ordinary World）                           │
│     → 展示主角的日常与平凡生活                           │
│                                                         │
│  ② 冒险召唤（Call to Adventure）                         │
│     → 挑战出现，打破现状                                 │
│                                                         │
│  ③ 拒绝召唤（Refusal of the Call）                       │
│     → 主角犹豫或抗拒                                     │
│                                                         │
│  ④ 遇见导师（Meeting the Mentor）                        │
│     → 获得指引、训练或关键道具                           │
│                                                         │
│  第二章：入门                                           │
│                                                         │
│  ⑤ 跨越门槛（Crossing the Threshold）                    │
│     → 正式进入"特殊世界"，不可回头                        │
│                                                         │
│  ⑥ 试炼盟友（Tests, Allies, Enemies）                    │
│     → 遭遇挑战，结识伙伴，识别敌人                       │
│                                                         │
│  ⑦ 接近深渊（Approaching the Inner Cave）                │
│     → 为高潮做准备的阶段                                 │
│                                                         │
│  ⑧ 严峻考验（The Ordeal）                                │
│     → 最大挑战，面临死亡或重大牺牲                       │
│                                                         │
│  第三章：归来                                           │
│                                                         │
│  ⑨ 获得奖赏（Reward）                                    │
│     → 战胜敌人，获得宝藏或能力                           │
│                                                         │
│  ⑩ 归来之路（The Road Back）                            │
│     → 带着收获踏上归途                                   │
│                                                         │
│  ⑪ 浴火重生（Resurrection）                              │
│     → 最终考验，彻底蜕变                                 │
│                                                         │
│  ⑫ 凯旋而归（Return with the Elixir）                    │
│     → 带回改变世界的力量                                 │
└─────────────────────────────────────────────────────────┘
```

### 英雄vs反派双线对照

| 阶段 | 英雄之旅 | 对应反派弧线 |
|------|----------|--------------|
| 普通世界 | 平凡生活 | 表面秩序 |
| 召唤 | 被选中 | 阴谋浮现 |
| 跨越 | 迈出第一步 | 暴露野心 |
| 试炼 | 遭遇困难 | 扩大势力 |
| 严峻考验 | 面临死亡 | 看似胜利 |
| 获得奖赏 | 获得力量 | 获得权力 |
| 浴火重生 | 蜕变 | 覆灭 |
| 凯旋而归 | 归来 | 消亡 |

## 四、Freytag金字塔 (Freytag's Pyramid)

**类型：** 戏剧结构  
**创始人：** Gustav Freytag（德国戏剧理论家，1863年）  
**适用范围：** 舞台剧、古典叙事、剧情片

### 五要素

```
           ▲
          /│\
         / │ \        ← Climax（高潮）
        /  │  \
       /────│────\     ← Falling Action（下降行动）
      /     │     \
     /      │      \
────/───────┼───────\── ← Falling Action 延续
   /        │        \
──/─────────┼─────────\── ← Resolution（结局）
            │
      Catastrophe
      （灾难/逆转）
```

### 各阶段详解

| 阶段 | 比例 | 内容 |
|------|------|------|
| Exposition（铺陈） | 0-10% | 背景、人物、环境介绍 |
| Rising Action（上升） | 10-35% | 冲突积累，问题升级 |
| Climax（高潮） | 35-50% | 转折点，最高潮时刻 |
| Falling Action（下落） | 50-85% | 高潮后的连锁反应 |
| Dénouement/Catastrophe（结局） | 85-100% | 一切收束/悲剧性结局 |

### 使用此模板的经典作品

- 《罗密欧与朱丽叶》(威廉·莎士比亚)
- 《公民凯恩》(1941)
- 《惊魂记》(1960)
- 《老无所依》(2007)

## 五、八序列结构 (The Sequence Approach)

**类型：** 序列结构  
**创始人：** Dan Carlson  
**适用范围：** 长篇剧集、120分钟以上电影

### 八序列框架

```
┌────────────────────────────────────────────────────────┐
│  第一卷（Sequences 1-2）：建立世界                      │
│    Sequence 1：建置 + 第一次困境                        │
│    Sequence 2：扩张 + 反击                              │
├────────────────────────────────────────────────────────┤
│  第二卷（Sequences 3-4）：主角成长                       │
│    Sequence 3：成长 + 合作                              │
│    Sequence 4：理解 + 和解                              │
├────────────────────────────────────────────────────────┤
│  第三卷（Sequences 5-6）：危机加剧                       │
│    Sequence 5：危机 + 失去                              │
│    Sequence 6：真相揭露                                 │
├────────────────────────────────────────────────────────┤
│  第四卷（Sequences 7-8）：终局                          │
│    Sequence 7：最后机会                                │
│    Sequence 8：终局对决                                 │
└────────────────────────────────────────────────────────┘
```

### 序列内部结构

每个序列内部也是一个完整的三幕结构：
- Sequence有自己的建置、冲突、解决
- 每个序列以"转折点"结束
- 8个转折点串联成整部电影的戏剧弧线

### 使用此模板的经典电影

- 《教父》 (1972)
- 《现代启示录》 (1979)
- 《英国病人》 (1996)

## 六、七点结构 (Seven-Point Story Structure)

**类型：** 精炼结构  
**创始人：** Dan Wells  
**适用范围：** 悬疑、惊悚、恐怖、科幻小说/剧本

### 七点框架

```
         ⑥ Hook（钩子）
            ↑
     ③ Plot Point 2（转折点2）
            ↑
         ⑤ Pinch Point 2（捏点2）
            ↑
     ② Midpoint（中点）
            ↑
         ④ Pinch Point 1（捏点1）
            ↑
     ① Plot Point 1（转折点1）
            ↑
         ⑦ Resolution（结局）
```

### 各点详解

| # | 点 | 说明 | 常见问题 |
|----|-----|------|----------|
| 1 | Plot Point 1 | 主角决定行动的关键节点 | 触发太晚 |
| 2 | Midpoint | 主角开始主动出击，而非被动反应 | 太平淡 |
| 3 | Plot Point 2 | 计划崩溃，需要全新方案 | 转折太轻 |
| 4 | Pinch Point 1 | 反派压力第一次显著加强 | 压力不够 |
| 5 | Pinch Point 2 | 反派压力最大化，主角最低谷 | 压力不够 |
| 6 | Hook | 结局前的最后一个悬念/转折 | 太显而易见 |
| 7 | Resolution | 解决方案与最终对决 | 太仓促/太拖沓 |

### 使用此模板的经典作品

- 《消失的爱人》 (2014)
- 《釜山行》 (2016)
- 《招魂》 (2013)
- 《疯狂的麦克斯：狂暴之路》 (2015)

## 七、故事圆圈 (The Story Circle)

**类型：** 环形结构  
**创始人：** Dan Harmon（美剧《Community》《瑞克与莫蒂》编剧）  
**适用范围：** 现代叙事、角色驱动型故事、剧集

### 八步圆圈

```
            A（主角在熟悉世界）
           ╱ ╲
          ╱   ╲
    D（角色     B（角色
    选择)       离开)
    ↓           ↗
C（遇见        C（遇见
新世界)        新世界)
          ↙     ↘
         ↓       ↘
        E（获得      F（付出代价）
       新力量)      
              ↘     ↙
                G（回归
                起点）
```

### 八步详解

| # | 步骤 | 内容 |
|----|------|------|
| 1 | A区：舒适区 | 主角在日常世界 |
| 2 | B区：需要 | 主角感到某种缺失 |
| 3 | C区：出发 | 进入新世界/情境 |
| 4 | D区：适应 | 学会新规则 |
| 5 | E区：获得 | 获得新力量或答案 |
| 6 | F区：付出 | 为之付出重大代价 |
| 7 | G区：回归 | 回到原点，但已改变 |
| 8 | A区：新平衡 | 问题解决，但世界不同了 |

### 使用此模板的经典作品

- 《星球大战：新希望》 (1977)
- 《狮子王》 (1994)
- 《功夫熊猫》 (2008)
- 美剧《Stranger Things》

## 八、雪球法 (The Snowflake Method)

**类型：** 迭代扩展法  
**创始人：** Randy Ingermanson  
**适用范围：** 长篇小说、复杂剧情、长篇剧集开发

### 十步迭代流程

```
Step 1: 一句话概括（9词内）
   ↓ 扩展
Step 2: 一段式概括（5句话）
   ↓ 扩展
Step 3: 人物概况（每个角色一句话）
   ↓ 扩展
Step 4: 四页概要（每幕一页）
   ↓ 扩展
Step 5: 人物表（角色详细信息）
   ↓ 扩展
Step 6: 四页概要（详细版）
   ↓ 扩展
Step 7: 人物弧线（每个角色完整弧线）
   ↓ 扩展
Step 8: 场景清单（所有场景列表）
   ↓ 扩展
Step 9: 场景描述（每个场景一句话）
   ↓ 扩展
Step 10: 完整剧本
```

### 迭代示例

**Step 1 → Step 2 示例：**

```
Step 1（一句话）：
"一个年轻的图书馆员必须解开她祖母死亡的秘密，
  同时发现她自己的能力是被一个古老组织所压抑。"

Step 2（五句话）：
1. 一个年轻女子在祖母葬礼后收到神秘遗物
2. 她开始调查祖母的过去，发现一个秘密组织
3. 她自己的能力开始觉醒，但每次使用都有代价
4. 她发现祖母曾是该组织的叛逃者
5. 她必须面对组织的领导者，同时接受自己的身份
```

### 使用此模板的经典作品

- 适用于复杂世界观的作品，如《盗墓笔记》剧集开发

## 九、坎泰atsu (起承转結) — Kishotenketsu

**类型：** 四幕结构  
**起源：** 中国古典诗词结构 → 日本传统叙事  
**适用范围：** 东亚叙事、文艺片、黑色喜剧、心理剧

### 四阶段框架

| 阶段 | 含义 | 内容 |
|------|------|------|
| 起 (Ki) | 设定 | 建立情境、人物、背景 |
| 承 (Sho) | 发展 | 延续设定，加深理解 |
| 转 (Ten) | 转折 | 引入意外、新元素 |
| 结 (Ketsu) | 解决 | 融合前后，揭示意义 |

### 与三幕结构的本质区别

> **三幕结构需要"冲突"**  
> **坎泰atsu不需要"对立冲突"** → 重在"意外惊喜"

```
三幕结构：问题 → 升级冲突 → 解决
坎泰atsu：设定 → 延续 → 意外转折 → 融合升华
```

### 使用此模板的经典电影

- 《东京物语》 (1953) — 小津安二郎
- 《无人知晓》 (2004) — 是枝裕和
- 《重庆森林》 (1994) — 王家卫
- 《刺客聂隐娘》 (2015) — 侯孝贤
- 《燃烧》 (2018) — 李沧东

## 十、米兰达法 (The Miranda Method)

**类型：** 角色驱动结构  
**创始人：** John Truby（《故事的解剖》作者）  
**适用范围：** 复杂角色、剧情片、惊悚片

### 22步结构（精要版）

| 层级 | 要素 |
|------|------|
| **第一层：前提** | 一句话故事 |
| **第二层：主题** | 故事的核心观点 |
| **第三层：设定** | 世界、时代、社会 |
| **第四层：主角** | 欲望+道德问题 |
| **第五层：盟友** | 主角的对照角色 |
| **第六层：对手** | 主角的对立力量 |
| **第七层：影响** | 对手对主角的改变 |
| **第八层：价值** | 故事结束时的主题表达 |

### 角色弧线对照表

| 角色 | 开始状态 | 结束状态 | 关键转折 |
|------|----------|----------|----------|
| 主角 | 缺陷状态 | 成长后状态 | 中点顿悟 |
| 盟友 | 支持观点 | 部分认同主角 | 背叛/牺牲 |
| 对手 | 压制观点 | 被击败/反醒 | 终极对决 |

## 十一、极限节拍器 (The Extreme Beat Sheet)

**类型：** 高密度节拍器  
**创始人：** Terry Izumi  
**适用范围：** 快节奏类型片、惊悚片、喜剧

```
开场（0-1%）

├─ Vantage Point [0%]
└─ Pre-Title [1%]

第一幕：钩子（1-10%）
├─ Title Sequence [1%]
├─ Setup [2%]
├─ Theme Setup [3%]
├─ Catalyst [5%]
├─ Debate [5-8%]
└─ Break Into Two [8-10%]

第二幕前半（10-25%）
├─ B Story [10%]
├─ Fun and Games [12%]
├─ Promise of Premise [15%]
├─ Debate Continued [18%]
├─ Midpoint Setup [22%]
└─ Midpoint [25%]

第二幕后半（25-50%）
├─ Bad Guys Close In [27%]
├─ Promise of Premise Delivered [30%]
├─ All Is Lost Setup [33%]
├─ All Is Lost [37%]
├─ Dark Night of Soul [40%]
└─ Break Into Three [42%]

第三幕（50-75%）
├─ Finals Approach [45%]
├─ Finale Setup [47%]

```

## 十二、电视剧结构模板

### 剧集（Episode）结构

| 类型 | 时长 | 幕数 | 结构 |
|------|------|------|------|
| 半小时喜剧 | 22min | 两幕 | 建置/对抗 |
| 一小时Drama | 42-45min | 五幕 | 标准TV三幕+广告切分 |
| 限时剧(Miniseries) | 4-8集 | 电影三幕 | 压缩电影结构 |

### 美剧主流格式：TEAM结构

```
Teaser（开场钩子）：0-5min
├─ Cold Open：吸引眼球的场景
└─ 主题曲前的小钩子
```
