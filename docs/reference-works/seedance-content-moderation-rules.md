## 二、⚠ 与 cineforge 现有模块的潜在冲突

### 2.1 高优先级冲突：`supernatural-webfiction-pack`

`@public/methods/supernatural-webfiction-pack` 模块支持**灵异/超自然/民俗惊悚**题材，但 Seedance 审核规则**明确禁止封建迷信**：

> "禁止生成封建迷信相关内容（如招魂、驱鬼、算命等）"

**影响**：用 `supernatural-webfiction-pack` 生成的小说章节直接送去 Seedance 视频导出 → **会触发审核驳回**。

**应对建议**（未来开发"分镜导出"功能时）：
- 在导出前增加"目标平台合规检查"层
- 检测到 supernatural-webfiction-pack 启用时，提示用户改写为"现代刑侦 / 心理悬疑"等合规变体
- 或在 `methodModuleRecommend.ts` 增加 `outputPlatformCompat` 字段标注每个模块的导出兼容性

### 2.2 与 `anti-ai-flavor` 的呼应（非冲突）

Seedance 审核中"无明显 AI 生成痕迹（人物面部扭曲、肢体畸形、物体穿帮）"与 cineforge 现有 `anti-ai-flavor` 的反 AI 文风思想**异曲同工**——一个是视觉层，一个是文本层。

### 2.3 与 `storyboard-template-spec` 的对接（兼容）

Seedance 要求的提示词结构"**主体 + 动作 + 环境 + 风格 + 特效**"与 `@docs/internal-notes/storyboard-template-spec.md` 的 17 字段 schema **完全兼容**：

| Seedance 要求 | storyboard-template-spec 字段 |
|---|---|
| 主体 | 角色挂载 + 角色朝向 + 构图锚点 |
| 动作 | 节奏 / 起幅 / 落幅 |
| 环境 | 场景挂载 / 相机几何 |
| 风格 | 画质路线 / 成像个性 |
| 特效 | S+质量描述 / 目标物 Must-Show |

## 三、规则速查（提炼版）

### 3.1 绝对禁止（直接驳回）

| 类别 | 关键禁止项 |
|---|---|
| 政治敏感 | 敏感人物/事件/组织、国家象征恶搞、领导人/军警负面 |
| 色情低俗 | 性行为/暗示、敏感部位裸露、低俗挑逗语言 |
| 暴力血腥 | 断肢 / 喷血 / 内脏外露、虐待 / 酷刑 / 谋杀细节 |
| 宗教迷信 | 极端主义 / 邪教、宗教符号恶搞、招魂驱鬼算命 |
| 知识产权 | 未授权肖像 / 商标 / 版权（如漫威 DC 角色） |
| 违法活动 | 赌博 / 毒品 / 邪教、武器制造 / 黑客行为 |
| 深度伪造 | 伪造名人演讲 / 虚假新闻场景 |
| 歧视 | 种族 / 性别 / 年龄 / 残疾歧视性语言 |
| 危害生命 | 自杀 / 自残 / 虐待动物 |
| 技术异常 | 特殊字符 / 乱码 / 模型崩溃诱导 |

### 3.2 限制使用（需调整后通过）

| 类别 | 限制要求 |
|---|---|
| 战争 / 灾难 / 恐怖袭击 | 避免过度渲染暴力血腥；重表现人性光辉 |
| 历史事件 / 名人 | 尊重事实，禁止歪曲恶搞 |
| 宗教内容 | 中立客观，禁止宣扬极端 |
| 武侠 / 动作题材 | 控制暴力程度（"剑客挥剑击中"而非"斩断手臂鲜血四溅"） |
| 模糊抽象描述 | 必须明确主体/动作/环境/风格/特效 |
| 与素材无关请求 | 提示词与上传素材必须相关 |
| 模型能力外 | 避免复杂 3D / 高精度机械 / 真人写实级面部 |

### 3.3 通过标准

- 内容积极健康 / 符合法规公序良俗
- 描述清晰具体 / 可执行
- 不侵权
- 不含敏感或限制类内容

## 四、技术质量审核（视频侧）

### 4.1 画面

- 分辨率 720P（Seedance 2.0 当前上限）
- 无明显模糊 / 噪点 / 失真
- 色彩自然，无偏色 / 过曝 / 欠曝
- 构图合理，无明显抖动 / 变形 / 裁剪不当
- **无明显 AI 痕迹**（面部扭曲 / 肢体畸形 / 物体穿帮）

### 4.2 动态

- 动作流畅自然，符合物理规律
- 特效与画面融合，无边缘生硬 / 颜色不匹配
- 镜头运动符合提示词，无随意切换 / 混乱抖动

### 4.3 音频

- 音频与画面同步，无延迟错位
- 音效符合场景（武侠用金属碰撞 / 风声，避免现代音效）
- 背景音乐风格匹配画面（武侠用古风，避免摇滚电子）

## 五、违规案例 → 修正对照表

| 违规类型 | 违规示例 | 修正建议 |
|---|---|---|
| 政治敏感 | "XX 领导人在街头打架" | 改为"古代官员在街头处理纠纷" |
| 色情低俗 | "穿着暴露的女性在跳舞" | 改为"穿着古装的女性在跳古典舞" |

## 六、提示词技术规范（Seedance 2.0 适配）

### 6.1 推荐结构

```
主体 + 动作 + 环境 + 风格 + 特效
```

**示例**（来自原档）：
> "白衣剑客@图片1 在雨夜古寺前与黑衣刀客@图片2 激战，剑光碰撞产生金色火花，冷蓝色调搭配闪电光影"

### 6.2 格式规则

- 引用素材：`@图片1` / `@视频1`
- 单条提示词 ≤ 200 字
- 禁止特殊字符 / 乱码
- 特效用模型易理解的词汇（"剑光带有淡蓝色拖尾"）

### 6.3 模型能力边界

避免要求生成：
- 复杂 3D 动画
- 高精度机械结构
- 真人写实级面部细节

## 七、审核流程

```
用户提交提示词
    ↓
机器初审（关键词 / 图像 / 音频识别）
    ↓ 通过
视频生成（实时监控，发现违规即终止）
    ↓ 完成
人工复核（隐性违规 / 细节问题）
    ↓ 通过
交付用户

【任一阶段不通过】→ 反馈原因 + 修改建议
                   → 用户可申诉重审
```

**结果分类**：
1. **通过**：可正常交付
2. **修改后重审**：轻微问题，调整提示词重生成
3. **驳回**：严重违规，重新构思

## 八、未来"分镜导出"功能的合规接入点

参考 `@docs/internal-notes/storyboard-template-spec.md` 第六节的开发蓝图，**新增合规层**：

```
小说章节
   ↓
[novel.4 分镜导出层]
   ↓
StoryboardShot[] (17 字段)
   ↓
【合规检查层】← 本档规则在此生效
   ├─ 检测违禁内容（10 大类禁止）
   ├─ 检测限制内容（需调整警告）
   ├─ 模块兼容性（如 supernatural-webfiction-pack vs Seedance）
   └─ 提示词技术规范（结构 / 长度 / 字符）
   ↓
平台适配器（Seedance / 即梦 / Sora / Pika）
   ↓
导出提示词
```

**关键设计**：
- 合规规则**按平台维护**（每个目标平台一份规则文件）
- 推荐使用 LLM 做"违规检测 + 自动改写建议"（V4 Flash + temperature 0.3）
- 用户可看到检测报告 + 一键应用改写建议
