# 参考作品 · `reference-works/`

本目录存放**优质参考作品的索引卡**（电影剧本 / 小说选段 / 游戏脚本等）。

## 与其他文档目录的区别

| 目录 | 内容类型 | 运行时可见 | 定位 |
|---|---|---|---|
| `public/prompts/` | 节点原生 prompt | ✅ | 流程节点主 prompt |
| `public/methods/` | 方法论模块 | ✅ | 项目级可叠加方法论 |
| `docs/prompt-archives/` | 待集成的 prompt 模板 | ❌ | 等未来流程升级时挪进 `public/prompts/` |
| `docs/architecture-refs/` | 外部 AI 系统架构蓝本 | ❌ | 架构级对标参考 |
| **`docs/reference-works/`**（本目录） | **优质参考作品索引卡** | ❌ | 研究 / 学习 / 未来集成原材料 |

## 判别规则：什么归本目录？

**同时满足**：

1. 它是一份**完整作品本体**（剧本 / 小说 / 脚本 / 游戏剧本等），不是方法论或素材
2. 具有特殊的**叙事 / 技法价值**，值得作为参考对照或未来集成原材料
3. 直接塞进用户 KB 的 6 种类型都不合适（sample / trend / antiPattern / styleGuide / worldHardSchema / voiceCard）
4. 原文已有稳定存储路径（本地 / 网络），无需在 repo 中复制全文

## 文件命名约定

`<作品类型>-<作品名 slug>.md`，例如：
- `the-man-from-earth.md`（电影剧本）
- `novella-the-old-man-and-the-sea.md`（小说中篇）
- `game-script-disco-elysium.md`（游戏剧本）

## 每张索引卡必含字段

- **作品基本信息**（作者 / 年份 / 类型 / 原文路径）
- **叙事结构分析**（场景 / 人物 / 时间跨度 / 核心技法）
- **独特技法提炼**（3–5 条，对创作有参考价值的具体技法）
- **未来可用场景**（明确列出哪些工作流可引用它作为原材料）
- **原文路径指向**（绝不复制全文，避免 git 仓库臃肿）

## 使用方式

当要做以下工作时，先扫本目录：
- 改编流程升级（找对标范本）
- 声纹卡 / 风格卡提取（找声音独特的角色做原材料）
- 对话 / 结构 / 节奏研究（找同类作品对照）
- 写特殊题材起笔时（找已有成功样本）
