# fili-web · 受众心理画像与梦境订单

> 写给 dogfooders / 项目立项时参考。本文档**不写代码** · 只写**用户研究**。
> 配套资产：`public/methods/dream-safety-method.md` / `dream-reality-anchor.md` / `dream-pacing-cycle.md` + 3 driver modules。

---

## §0 核心命题

**用户消费内容 ≠ 购买故事，而是购买一场"梦"（情绪体验）**。

不是因为我们文笔优美，也不是因为故事结构精巧。用户真正在消费的，是一种在现实世界中稀缺、但在虚拟世界里可以被精准满足的**情感需求**。

→ fili-web 的产品定位：不是"AI 写作工具"，是"梦境定制服务平台"。

---

## §1 现实世界的 3 大压力源（用户画像背景）

网络内容重度消费者的现实生活，往往被 3 种核心压力笼罩：

### 压力 A1 · 生存压力 + 价值焦虑

| 维度 | 表现 |
|---|---|
| **现实表象** | 工作繁重 / 收入微薄 / 职场竞争激烈 / 怀才不遇 / 被随时替换的螺丝钉感 |
| **心理诉求** | **掌控感** + 价值确认（"我能行 / 世界因我而不同"）|
| **典型用户** | 996 程序员 / 加班白领 / 应届毕业生 / 怀才不遇的中年男性 |

### 压力 A2 · 人际压力 + 情感缺失

| 维度 | 表现 |
|---|---|
| **现实表象** | 社交圈子狭窄 / 害怕冲突又渴望真诚 / 孤独 / 缺无条件爱 / 遭遇背叛误解 |
| **心理诉求** | **高质量情感连接**（被偏爱 / 被理解 / 被保护 / 快意恩仇）|
| **典型用户** | 大城市单身女性 / 中年男性 / 社恐青年 / 离婚人群 |

### 压力 A3 · 信息过载 + 决策疲劳

| 维度 | 表现 |
|---|---|
| **现实表象** | 信息爆炸 / 高耗能大脑 / 工作决策疲劳 / 厌倦思考 |
| **心理诉求** | **精神放松解压**（不动脑 / 即时刺激 / 情绪释放）|
| **典型用户** | 通勤族 / 下班疲惫人群 / 短视频重度用户 |

## §2 3 类用户原型 · 梦境订单

### B1 · 掌控者型观众

```
现实写照：在会议上不敢发言 / 被上司随意批评 / 价值被低估 / 内心压抑最深
梦境核心：力量与颠覆 · 不是与世界和解，而是让世界臣服
关键词：  逆袭 / 打脸 / 秒杀 / 权力 / 财富 / 装逼
情绪轨迹：被压抑（憋）→ 终极爆发（爽）→ 反派磕头 / 围观崇拜
```

| 题材偏好 | fili-web 字段 |
|---|---|
| 都市爽文 | `genres: ['urban_super', 'rebirth']` |
| 赘婿逆袭 | `genres: ['urban_revenge']` |
| 玄幻升级 | `genres: ['xuanhuan', 'system']` |
| 战神归来 | `genres: ['urban_super', 'rebirth']` |
| `novelTone` | `'fast_pleasure'` |
| `novelAudience` | `'male'` |
| **推荐 driver** | **emotion-driven**（情绪驱动）|
| **推荐启用 module** | dream-safety-method（必启）/ dream-pacing-cycle（必启）/ webfiction-pacing-pack |

### B2 · 关系者型观众

```
现实写照：物质生活尚可，精神世界渴望高质量情感连接 / 现实关系功利让人疲惫
梦境核心：纯粹关系 + 情感确定性 · 安全岛感
关键词：  独宠 / 团宠 / 守护 / 救赎 / 忠诚 / 双向奔赴
情绪轨迹：等待 / 误解（憋）→ 真心揭示（爽）→ 永恒承诺
```

| 题材偏好 | fili-web 字段 |
|---|---|
| 甜宠言情 | `genres: ['sweet', 'ceo']` |
| 大女主 | `genres: ['palace', 'intrigue', 'history']` |
| 耽美 | `genres: ['danmei']` |
| 战神文（侧重兄弟情）| `genres: ['urban_super', 'mil']` |
| `novelTone` | `'literary'` 或 `'healing'` |
| `novelAudience` | `'female'` 或 `'general'` |
| **推荐 driver** | **character-driven**（人物驱动）|
| **推荐启用 module** | character-driven-method / mbti-5step / character-three-elements-method / seven-points-romance（言情）|

### B3 · 逃避者型观众

```
现实写照：心累人群 · 大脑不堪重负 · 碎片化时间 · 抗拒深度思考
梦境核心：简单与直接 · 即插即用情绪充电宝
关键词：  搞笑 / 沙雕 / 无脑爽 / 解压 / 反套路
情绪轨迹：日常状态 → 突发反差 / 反套路爆梗 → 哈哈哈 → 重置进入下一个
```

| 题材偏好 | fili-web 字段 |
|---|---|
| 沙雕吐槽文 | `genres: ['urban_super', 'system']` |
| 无敌流 | `genres: ['system', 'infinite']` |
| 直播 / 问答流 | `genres: ['system', 'urban_super']` |
| 系统流 | `genres: ['system']` |
| `novelTone` | `'humor'` 或 `'fast_pleasure'` |
| `novelAudience` | `'male'` 或 `'general'` |
| **推荐 driver** | **emotion-driven**（情绪驱动）|
| **推荐启用 module** | dream-safety-method（轻度）/ webfiction-pacing-pack / anti-ai-flavor |

## §3 立项决策树（项目设置阶段参考）

```
[第一步] 你的目标用户最痛的现实压力是什么？
   ├─ 价值焦虑（A1）→ B1 掌控者型
   ├─ 情感缺失（A2）→ B2 关系者型
   └─ 决策疲劳（A3）→ B3 逃避者型

[第二步] 你的项目体量是？
   ├─ 长篇 ≥ 30 万字 → 用户深度陪伴 → 适合 B2 关系者 / B1 掌控者升级流
   ├─ 中篇 5-30 万字 → 适合三类皆可 · B1 / B2 偏多
   └─ 短篇 < 5 万字 → 适合 B3 逃避者 · 即时满足

[第三步] 你的发布平台决定写作风格
   ├─ 起点 / 番茄 / 七猫（男频爽文）→ B1
   ├─ 晋江 / 七猫 / 番茄（女频）→ B2
   └─ 短剧 / 抖音 → B3 + B1

[第四步] 选 driver
   ├─ B1 → emotion-driven
   ├─ B2 → character-driven
   └─ B3 → emotion-driven（更轻松版）

[第五步] 启用 dream-* 系列 module
   └─ 见各类型推荐 module 列表（§2）
```

## §4 题材融合 · 心理诉求兼容性

成功的题材融合 = **同一批用户内心需求的叠加**，而非冲突。

### ✅ 安全融合（兼容心理诉求）

| 融合 | 兼容性 | 解释 |
|---|:---:|---|
| 仙侠 + 大女主 | 🟢 兼容 | B2 关系者 + B1 掌控者部分重叠 · 都渴望"自我价值确认 + 力量" |
| 玄幻 + 系统流 | 🟢 兼容 | B1 掌控者 + B3 逃避者 · 升级爽 + 不动脑 |
| 都市 + 异能 | 🟢 兼容 | B1 掌控者强化 |
| 言情 + 重生 | 🟢 兼容 | B2 关系者 + 重启可能 · 都是情感确定性诉求 |

### ❌ 危险融合（冲突心理诉求）

| 融合 | 冲突性 | 解释 |
|---|:---:|---|
| 硬核权谋 + 无脑爽 | 🔴 冲突 | 权谋目标用户 = 享受思考的"理性脑活跃"型；爽文目标用户 = 抗拒思考的"理性脑休眠"型。一个梦满足两批人 = 同时让两批人惊醒 |
| 慢热成长 + 短剧节奏 | 🔴 冲突 | 长篇陪伴 vs 即时满足 = 时间维度根本冲突 |
| 严肃文学 + 大量爽点 | 🔴 冲突 | 文学品味 vs 多巴胺刺激 = 美学定位冲突 |
| 推理悬疑 + 反派降智 | 🔴 冲突 | 推理观众期待"反派智商 ≥ 主角"的猫鼠博弈 · 降智 = 出戏 |

→ **fili-web 实现**：`genreCompat.incompatible` 字段已支持 · 项目设置时**显示红色警告**。

## §5 媒介护梦优势（fili-web 平台对照）

| 媒介 | 护梦优势 | 付费逻辑 | fili-web 支持 |
|---|---|---|---|
| **长篇小说** | 极致安全感 + 情感强化 · 长期陪伴 | 高质量虚拟陪伴 | ✅ `novelScale: 'long' / 'mega'` · gap-b CharacterBible 强化 |
| **短剧 / 动态漫** | 极致效率 · 速效情绪救心丸 | 即时情绪救济 | ⚠ 部分（`novelScale: 'short'`）· 暂无短剧专用 prompt |
| **真人剧** | 极致反馈强化 · 表演百倍放大 | 高保真情感共鸣 | ❌ 不做（剧本媒介，未来 v4 候选）|

## §6 守护梦境的 3 大支柱

每一个写作决策都应回答："这个选择是否守护了梦境？"

```
1. 守护道德焦虑（让用户敢做梦）→ dream-safety-method
2. 守护决策疲劳（让用户沉迷做梦）→ dream-pacing-cycle + webfiction-pacing-pack
3. 守护理性大脑（让用户相信梦）→ dream-reality-anchor
```

**三者缺一**：
- 缺 1 → 用户产生道德负罪 → 弃书
- 缺 2 → 用户大脑疲劳无法持续 → 弃书
- 缺 3 → 用户被理性脑唤醒"这不真实"→ 出戏弃书
