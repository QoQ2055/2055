## 一、6 大润色工具集总览

天命平台将"章节润色"拆为 **6 个独立工具**，用户按需触发，每个工具单一职责：

| # | 工具 | 单一职责 | 保留不变项 |
|---|---|---|---|
| 1 | **场景渲染** | 增强环境氛围 / 多感官描写 | 原文情节 |
| 2 | **对话打磨** | 角色语言风格鲜明 / 潜台词 | 非对话部分 |
| 3 | **情感深化** | 心理刻画 / 情感层次 | 情节和人物关系 |
| 4 | **文字精炼** | 删除冗余 / 凝练有力 | 情节、人物和关键细节 |
| 5 | **文笔润色** | 流畅优美 / 文学感染力 | 叙事结构 / 人物关系 / 情节 |
| 6 | **节奏调整** | 长短句疏密变化 / 张弛有度 | 原文情节 |

### 共同设计原则

- **直接输出修改后的文本，不附加任何解释**（避免 LLM 过渡语污染）
- 每个工具**只动一件事**，其他维度严格保留
- 输入输出都是纯文本（不是 JSON）

## 二、6 大工具核心原则速查

### 2.1 场景渲染

**人格定位**：擅长环境氛围营造的小说场景大师，精通多感官描写。

**核心原则**：
- 通过视觉/听觉/嗅觉/触觉等多感官细节，营造沉浸式体验
- 注重光影变化、空间层次、环境氛围与情节情绪呼应
- 场景描写**为叙事服务**而非喧宾夺主

### 2.2 对话打磨

**人格定位**：精通角色塑造的对话写作专家，"闻声识人"。

**核心原则**：
- 让每个角色语言风格鲜明、符合人设、节奏自然
- 注重**潜台词**运用，避免说教式表达
- 对话推动情节同时展现人物性格

### 2.3 情感深化

**人格定位**：擅长人物心理刻画的润色专家，通过微妙文字传递深层情感。

**核心原则**：
- 通过细腻心理描写、微表情、肢体语言暗示
- 让情绪层次丰富饱满
- **避免过度煽情**
- 情感强化**自然融入叙事**，不破坏原文节奏

### 2.4 文字精炼

**人格定位**：崇尚简洁之美的资深文字编辑，"好文章是删出来的"。

**核心原则**：
- 去除不必要的心理独白、过度修饰、无效过渡
- 保留核心内容，让文字凝练有力、节奏紧凑
- **不增加新内容**

### 2.5 文笔润色

**人格定位**：深谙中文文学表达的资深编辑，保持原作灵魂前提下增强文学感染力。

**核心原则**：
- 不增删情节内容
- 优化遣词造句精准度、句式多样性、修辞自然运用
- **避免过度华丽导致风格偏移**，润色程度应与原文气质匹配

### 2.6 节奏调整

**人格定位**：精通叙事节奏控制的小说结构专家，通过文字疏密引导读者情绪起伏。

**核心原则**：
- 紧张情节加快节奏（短句 + 快速切换）
- 舒缓场景放慢节奏（适当展开描写）
- 长短句交替、段落疏密变化控制阅读呼吸感
- **保持原文情节不变**

## 三、与 fili-web 现有 `anti-ai-flavor` 的关系

### 3.1 范围对比

| 维度 | `anti-ai-flavor`（现有） | 6 大润色工具集 |
|---|---|---|
| 定位 | **总括式**反 AI 文风 | **单一职责**细分工具 |
| 触发 | 章节生成时注入 prompt | 用户按需触发（章节后处理） |
| 范围 | 9 大 AI 痕迹 + 8 大反 AI 技巧 | 6 个独立维度 |
| 输出 | 影响生成阶段 | 改造已有文本 |

### 3.2 互补关系

**前置层（`anti-ai-flavor`）+ 后置层（6 大润色工具集）= 双层防御**：

```
用户触发章节生成
    ↓
[anti-ai-flavor 注入 system prompt]
    ↓
LLM 生成章节正文
    ↓
[用户按需触发 6 大润色工具]
    ↓ (任意组合 / 顺序)
最终交付章节
```

### 3.3 各工具与 `anti-ai-flavor` 的覆盖度

| 6 大工具 | anti-ai-flavor 已覆盖 | 增量价值 |
|---|---|---|
| 场景渲染 | ⚠ 部分（视觉脱水反方向） | ⭐⭐ 提供"加描写"工具 |
| 对话打磨 | ⚠ 部分（人物声音差异化） | ⭐⭐ 单独触发的对话专项 |
| 情感深化 | ✗ 几乎未覆盖 | ⭐⭐⭐ 独立增量 |
| 文字精炼 | ⚠ 部分（信息密度） | ⭐ 独立工具更便利 |
| 文笔润色 | ✗ anti-ai 是"反 AI"不是"加文学" | ⭐⭐ 独立增量 |
| 节奏调整 | ⚠ 部分（节奏波动） | ⭐⭐ 单独触发的节奏专项 |

## 四、fili-web 落地蓝图

### 4.1 新增 `RefinementToolPanel` 组件

在章节正文阅读视图中，提供 6 个工具按钮：

```
┌────────────────────────────────────────┐
│ 第 X 章 章节正文                          │
│                                        │
│ [章节正文内容...]                         │
│                                        │
│─── 润色工具 ──────────────────────────  │
│ 🌅 场景渲染   🗣 对话打磨   💖 情感深化   │
│ ✂️ 文字精炼   ✨ 文笔润色   ⏱ 节奏调整   │
│                                        │
│ [选区润色]  [全章润色]  [对比预览]        │
└────────────────────────────────────────┘
```

### 4.2 数据结构

```ts
interface RefinementSession {
  id: string;
  chapterId: string;
  toolType: 'scene' | 'dialogue' | 'emotion' | 'condense' | 'polish' | 'pacing';
  scope: 'selection' | 'paragraph' | 'chapter';
  inputText: string;
  outputText?: string;
  status: 'pending' | 'streaming' | 'done' | 'rejected';
  appliedAt?: Date;
  createdAt: Date;
}
```

### 4.3 LLM 调用配置

按 `@docs/internal-notes/deepseek-v4-tuning-guide.md` 一·1.2 选型决策：

| 工具 | 推荐配置 |
|---|---|
| 场景渲染 / 文笔润色 | V4 Flash + Thinking 禁用 + temperature 0.85 |
| 对话打磨 / 情感深化 | V4 Flash + Thinking 禁用 + temperature 0.8 |
| 文字精炼 / 节奏调整 | V4 Flash + Thinking 禁用 + temperature 0.6 |

> 全部场景适合 Flash + 非 Thinking 模式（创意写作 / 风格控制场景）。

### 4.4 关键交互设计

- **选区润色优先**：用户选中段落 → 触发工具 → 仅替换选中部分
- **对比预览**：原文 vs 润色后并排，diff 高亮
- **可拒绝**：润色结果不满意可一键回退
- **链式触发**：用户可先文字精炼 → 再文笔润色（顺序触发，每步都可独立确认）
- **历史记录**：每次润色记入 `RefinementSession`，支持 N 步撤销

### 4.5 与现有 `ChapterFeedback` 的关系

`ChapterFeedback` 是用户**对章节质量打标**（哪里不好），可以**自动建议润色工具**：

| 反馈标签 | 建议工具 |
|---|---|
| 「场景描写不足」 | 场景渲染 |
| 「对话太死板」 | 对话打磨 |
| 「情感不到位」 | 情感深化 |
| 「啰嗦水字数」 | 文字精炼 |
| 「文笔粗糙」 | 文笔润色 |
| 「节奏拖沓」 | 节奏调整 |

形成**反馈 → 润色 → 验证**闭环。

## 五、扩展：其他可能的润色维度

天命的 6 大工具集已经相当完整，但 fili-web 可考虑额外补充：

| 工具 | 用途 | 价值 |
|---|---|---|
| **题材锚点合规润色** | 自动改写违反"必须避免"清单的内容 | ⭐⭐ 与题材锚点系统配套 |
| **平台合规润色** | 自动改写违反 Seedance/即梦审核规则的内容 | ⭐ 视频导出场景需要 |
| **去 AI 检测润色** | 针对朱雀检测的对抗性润色 | ⭐ 见 `@docs/reference-works/zhuque-ai-detection-methodology.md` |
| **风格统一润色** | 多章节生成后跨章节风格统一 | ⭐⭐ 长篇创作必需 |
