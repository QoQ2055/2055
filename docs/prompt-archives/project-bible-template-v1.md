### 4. 角色体系（Character Bible · ATU_301 系统分析）

**4.1 主角**
- 基础档案
- ATU_301 深度分析
  - **动机图谱**：表层（别人以为他要）/ 中层（他自以为要）/ 深层（原始驱动力，往往是童年空缺）
  - **性格维度**：外向 ↔ 内向 / 理性 ↔ 感性 / 冒险 ↔ 保守 / 利己 ↔ 利他 / 怀疑 ↔ 信任
  - **成长弧线**：起始缺陷 → 催化事件 → 中间挣扎 → 最终状态
- MBTI / 九型人格（可选）
- 角色原型（ATU_301 母题分类）：主角原型 + 阴影面 + 导师原型
- 关键关系网
- 台词风格：口头禅 / 语速 / 沉默时的表达

**4.2 主要配角**（同结构简化）
**4.3 反派**：信条 + 能力威胁 + 与主角的镜像关系 + 败北条件

### 5. 场景与道具系统

**5.1 核心场景清单**：场景 / 出现章数 / 频率 / 情感色调 / 叙事意义
- 设计要点：每个核心场景必须有一个独特的"感官锚点"
- 场景的情感色调要随剧情变化（同一场景在开头和结尾色调应不同）

**5.2 重要道具清单**：道具 / 类型 / 关键能力 / 限制 / 归属 / 出现章数 / 最终命运
- 道具规则三条：
  1. 每个重要道具必须在首次出现前就有"暗示"
  2. 道具的限制比能力更重要（无限制 = 剧情漏洞）
  3. 道具的最终命运必须服务于角色弧线
