## 国际方法论溯源

**作者**：Randy Ingermanson（美国物理学家 + 小说家）
**英文名**：Snowflake Method
**首次发布**：1998 年个人博客
**完整步骤**：原始版有 **10 步**（本档抽取版精简为 7 步）：

| 步骤 | 原始内容 |
|---|---|
| 1 | 写一句话故事概要（15 词） |
| 2 | 扩展为一段（5 句话） |
| 3 | 写主要角色一页摘要 |
| 4 | 把一段扩展为一页 |
| 5 | 为每个角色写一页详细介绍 |
| 6 | 把一页扩展为四页 |
| 7 | 为每个角色写完整角色档案 |
| 8 | 制作场景列表（Excel） |
| 9 | 把场景列表扩展为多段叙事 |
| 10 | 写第一稿 |

中文实战版做了精简：合并步骤 1+2、3+5+7、6+8+9，强调"层层放大"哲学，更适合中文网文场景。

| 优点 | 说明 |

## 原始核心金句

> "雪花写作法其实干的事情很简单：把一个故事，从小到大慢慢长出来。就像雪花一样，一层一层展开。"

> "写大纲，写得特别细，细到自己都头疼。要么完全反过来，凭感觉写，想到哪写到哪。结果伏笔一堆，最后全填不上。雪花写作法解决的就是这个问题。"

> "人物弧光一旦有了，剧情会自然长出来。"
