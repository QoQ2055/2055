## 一、抽象框架（未来做武侠专用模块时可参考）

本资料的核心方法论价值不在具体招式，而在其**结构化分类体系**：

### 武学体系设计法（4 维度）

```
武器类别 × 功能分类 × 核心发力部位 × 攻击范围
```

### 通用 8 类功能（所有武器共用）

| 类 | 功能定位 | 发力部位 | 攻击范围 |
|---|---|---|---|
| **基础直打类** | 核心起势（劈/砍/戳/推/冲） | 肩/臂（主导） | 中距 |
| **横扫斜打类** | 范围控场 | 腰/肩 | 中远距 |
| **撩挑挂带类** | 近身衔接、攻防转换 | 腕/胯 | 近距 |
| **点崩截击类** | 精准短打 / 破招反击 | 腕 | 近距 |
| **旋绕扫摆类** | 大范围控场 / 借力发力 | 整身带械 | 远距 |
| **格挡架卸类** | 防反 / 卸力变招 | 械身 + 巧劲 | 防御 |
| **组合衔接类** | 连招流畅 / 攻防切换 | 综合 | 综合 |
| **身法舞花类** | 身法融合 / 迷惑破防 | 整身旋转 | 远近兼顾 |

### 本资料覆盖的 6 类武器 / 徒手

| 武器 | 独有功能分类 |
|---|---|
| **剑** | 7 类（缺身法舞花类） |
| **刀** | 8 类（齐全） |
| **掌** | 8 类（无器械，用掌面/掌根/掌尖代替） |
| **棍** | 9 类（多出"砸压杵捣"和"舞花转棍"） |
| **拳** | 8 类（"劈掌冲拳结合"是拳法独有） |
| **枪** | 8 类（"舞花转枪"最华丽） |

### 未来集成路径

若未来 fili-web 开发武侠专用流程节点（如 `novel.1.1.martial-system` 武学体系子节点），可：
1. 以本档的 **武学体系设计法 4 维度** 为 prompt 骨架
2. 以本档的 **通用 8 类功能** 为武学体系分类依据
3. 具体招式词库从下方按武器选择性注入

## 二、完整招式词库（按武器分类）

### 2.1 剑法（7 类）

**基础直刺 / 突刺类**（核心戳击，主打快准狠）
→ 直刺、点刺、崩刺、挑刺、钻刺、连环刺、旋身突刺、跨步直刺、提膝点刺

**横斩 / 纵劈类**（大开大合，主打劈砍力度）
→ 纵劈、斜斩、横扫、平劈、撩劈、抡斩、旋身横斩、翻身纵劈、跨步横扫、回身斜斩

**回撩 / 带划类**（衔接反击，主打收势变招）
→ 回撩、反撩、带划、抹斩、扫撩、旋撩、回身反撩、收剑回带、侧腰抹斩、提剑扫撩

**挑格 / 架挡类**（攻防兼备，主打格挡变招）
→ 剑挑、格剑、架劈、撩挑、横格、提格、望月挑剑、横剑格挡、提剑架劈、旋腕撩挑

**旋斩 / 扫划类**（大范围攻击，主打控场）
→ 旋斩、扫剑、云斩、轮劈、旋撩斩、翻身扫剑、云剑横划、旋身轮劈、跨步旋斩

**点崩 / 截击类**（精准短打，主打破招）
→ 剑点、崩剑、截刺、点崩、抹点、截斩、探剑点刺、横剑截击、腕抖崩剑、回身截斩

**组合衔接类**（招招相连，主打连招流畅）
→ 刺后回撩、劈后横斩、格后突刺、挑后点刺、斩后旋撩、刺后崩剑、劈后反撩、扫后挑剑

---

### 2.2 刀法（8 类）

**基础劈砍类**（大开大合，主打刚猛力度，刀法核心基础）
→ 竖劈、斜劈、横劈、平砍、抡劈、重劈、跨步竖劈、旋身斜劈、回身横劈、沉肩重砍

**直刺突扎类**（刀尖发力，主打快准戳击，补劈砍短板）
→ 直刺、点刺、突扎、崩刺、挑刺、连环刺、提膝点刺、旋身突扎、跨步直刺、沉腕崩刺

**横扫撩挂类**（横向控场，主打范围攻击，衔接攻防）
→ 横扫、平扫、撩刀、反撩、挂刀、扫撩、旋身横扫、低扫撩刀、回身反撩、侧腰挂扫

**斩切抹剁类**（近身短打，主打精准破防，细节发力）
→ 横斩、斜斩、抹刀、剁砍、切斩、旋斩、收刀抹斩、提刀剁砍、贴身高切、回身斜斩

**格挡架磕类**（攻防兼备，主打卸力变招，刀身硬抗）
→ 格刀、架劈、磕挡、横格、提格、挡劈、横刀格挡、提刀架劈、沉刀磕挡、格后反劈

**旋扫轮劈类**（大范围控场，主打动态压制，借力发力）
→ 旋扫、轮劈、云斩、旋砍、扫劈、翻身旋扫、跨步轮劈、云刀横划、旋身扫劈、跳步旋砍

**点崩截击类**（精准短打，主打破招反击，腕部发力）
→ 刀点、崩刀、截刺、截斩、点崩、抹点、探刀点刺、横刀截击、腕抖崩刀、回身截斩

**组合衔接类**（招招相连，主打连招流畅，攻防衔接）
→ 劈后横扫、刺后撩刀、格后突扎、斩后抹刀、扫后点刺、劈后反撩、挡后横斩、扎后崩刀

---

### 2.3 掌法（8 类）

**基础直打类**（掌面直推硬击，主打刚劲正面发力，掌法核心基础）
→ 直推掌、平击掌、正打掌、跨步推掌、冲心掌、穿云掌、提膝平击、旋身直推、探步冲掌、沉肩正打

**横劈斜砍类**（掌缘 / 掌侧发力，仿刀劈剑斩，主打横向范围攻击）
→ 横劈掌、斜砍掌、侧劈掌、横扫掌、云劈掌、回身横劈、旋身斜砍、跨步侧劈、低扫掌、翻腕云劈

**撩挑切挂类**（掌底 / 掌尖发力，主打近身巧打、衔接攻防）
→ 撩阴掌、挑掌、切掌、挂掌、反撩掌、提掌撩击、旋腕挑掌、贴身高切、回身反撩、侧腰挂掌

**拍按压劈类**（掌心 / 掌根沉劲，主打卸力压制、刚柔并济）
→ 拍掌、按掌、压掌、劈山掌、沉按掌、合掌拍击、叠掌下按、弓步压掌、沉肩劈山、探掌轻拍

**穿插点戳类**（掌尖 / 指节发力，主打精准透劲、专攻要害）
→ 穿掌、插掌、点掌、戳掌、透心掌、连环穿插、旋身点掌、探步戳掌、提腕穿掌、屈指点击

**旋绕扫摆类**（整掌带身发力，主打大范围控场、借力旋打）
→ 旋掌、绕掌、扫摆掌、云掌、旋身扫掌、跨步绕掌、翻身云掌、低摆掌、旋腕扫摆、跳步旋掌

**格挡架卸类**（掌侧 / 掌根巧劲，主打防反衔接、卸力变招）
→ 格掌、架掌、卸掌、拦掌、截掌、横掌格挡、提掌上架、顺劲卸掌、侧掌拦击、探掌截打

**组合衔接类**（招招相连，主打攻防流畅、刚柔切换）
→ 推掌后横劈、拍掌后穿插、格掌后点戳、按掌后撩击、劈掌后旋扫、穿掌后按压、拦掌后直推、挑掌后戳击

---

### 2.4 棍法（9 类）

**基础劈扫类**（棍身横纵发力，大开大合，棍法核心基础）
→ 竖劈棍、横扫棍、斜劈棍、平扫棍、抡劈棍、重劈棍、跨步横扫、旋身斜劈、回身竖劈、沉肩重扫

**直戳点打类**（棍尖硬顶发力，快准透劲，补劈扫短板）
→ 直戳棍、点棍、崩棍、探戳棍、连环点戳、提膝点棍、旋身直戳、跨步探戳、沉腕崩棍、跳步点打

**撩挂挑架类**（棍身中段 / 梢段巧劲，近身衔接，攻防兼备）
→ 撩棍、反撩棍、挂棍、挑棍、架棍、扫撩棍、低撩棍、回身反撩、侧腰挂棍、提棍上架

**抡绕云旋类**（整棍带身借力，大范围控场，动态压制）
→ 抡棍、绕棍、云棍、旋棍、轮扫棍、翻身抡棍、跨步绕棍、云棍横划、旋身轮扫、跳步旋棍

**磕格挡卸类**（棍身硬抗 / 巧卸，主打防反，卸力变招）
→ 磕棍、格棍、挡棍、卸棍、截棍、横棍格挡、沉棍磕挡、顺劲卸棍、侧棍截击、格后反劈

**戳扫衔接类**（棍尖 + 棍身联动，远近结合，刚柔切换）
→ 戳后横扫、点后撩棍、格后直戳、劈后绕棍、扫后点戳、崩后挂棍、挡后旋扫、探戳后重劈

**舞花转棍类**（棍身花式旋绕，主打身法衔接，迷惑破防）
→ 单头舞花、双头舞花、腰缠棍、腕转棍、旋身舞花、提膝转棍、跨步舞花、低姿腰缠、翻腕舞花

**砸压杵捣类**（棍根沉劲发力，主打刚猛压制，专攻下盘 / 硬防）
→ 砸棍、压棍、杵棍、捣棍、沉棍下砸、叠棍下压、弓步杵棍、探步捣棍、回身重砸

---

### 2.5 拳法（8 类）

**基础直拳类**（拳面硬击，直线发力，拳法核心基础，主打快准刚劲）
→ 直拳、冲拳、钻拳、贯拳、跨步直拳、旋身冲拳、提膝钻拳、探步贯拳、沉肩直拳、连环直拳

**摆拳横打类**（拳背 / 拳面横向发力，大开大合，主打中远距离范围攻击）
→ 摆拳、横拳、扫拳、抡拳、回身摆拳、旋身横拳、跨步扫拳、沉腰抡拳、低扫拳、翻臂摆拳

**勾拳挑打类**（拳面由下向上发力，主打近身短打，专攻中下盘 / 近身要害）
→ 勾拳、挑拳、抄拳、撩拳、上勾拳、侧勾拳、提膝挑拳、贴身穿抄、回身撩拳、沉胯上勾

**砸捶压打类**（拳面 / 拳背沉劲下砸，主打刚猛压制，卸力破防，专攻上盘 / 硬架）
→ 砸拳、捶拳、压拳、崩拳、沉肩砸拳、叠拳下捶、弓步压拳、腕抖崩拳、回身重捶、探步轻砸

**劈掌冲拳结合类**（拳掌联动，刚柔切换，主打攻防衔接，补拳法近身短板）
→ 劈拳、切拳、掌拳、劈后冲拳、拍拳后直刺、格掌后摆拳、按掌后勾拳、劈拳后横打

**格挡架拦类**（拳臂 / 掌侧巧劲防御，主打防反衔接，卸力变招，兼顾近身防护）
→ 格拳、架拳、拦拳、截拳、横臂格挡、提拳上架、侧拳拦击、探拳截打、格后反冲、架后挑拳

**连环组合类**（招招相连，远近结合，主打实战连招，节奏多变）
→ 直拳接摆拳、摆拳接勾拳、钻拳接贯拳、挑拳接砸拳、格拳接冲拳、拦拳接抄拳、连环直摆勾、劈拳接横拳

**身法巧打类**（拳随身动，借力发力，主打身法与拳法融合，迷惑破防）
→ 旋身拳、跳步冲拳、垫步摆拳、俯身勾拳、翻身劈拳、探步钻拳、旋腕崩拳、扭腰横拳

### 2.6 枪法（8 类）

**基础直刺类**（枪尖核心发力，直线突刺，枪法核心快准劲，主打中远距破防）
→ 直刺、平刺、突刺、钻刺、崩刺、连环刺、跨步直刺、旋身突刺、提膝平刺、探步钻刺

**劈扫横打类**（枪身 / 枪杆发力，仿棍法大开大合，主打范围控场，补刺击短板）
→ 竖劈枪、横扫枪、斜劈枪、平扫枪、抡劈枪、回身横扫、旋身斜劈、跨步竖劈、沉肩重扫、低扫枪杆

**撩挂挑架类**（枪尖 / 枪缨段巧劲，主打近身衔接、攻防转换，防反兼备）
→ 撩枪、反撩枪、挂枪、挑枪、架枪、扫撩枪、提枪撩击、回身反撩、侧腰挂枪、提枪上架

**点崩截击类**（枪尖轻颤发力，精准短打，主打破招反击，专攻要害 / 卸力）
→ 点枪、崩枪、截枪、点崩、抹点枪、探枪点刺、横枪截击、腕抖崩枪、回身截刺、跳步点枪

**抡绕云旋类**（整枪带身借力，大范围旋打，主打动态压制，兼顾身法衔接）
→ 抡枪、绕枪、云枪、旋枪、轮扫枪、翻身抡枪、跨步绕枪、云枪横划、旋身轮扫、旋腕绕枪

**砸压杵捣类**（枪根 / 枪杆沉劲发力，主打刚猛压制，专攻下盘 / 硬架，近身反制）
→ 砸枪、压枪、杵枪、捣枪、沉枪下砸、叠杆下压、弓步杵枪、探步捣枪、回身重砸、沉肩压枪

**舞花转枪类**（枪身花式旋绕，主打身法迷惑、招势衔接，枪花破防 + 控场）
→ 单头舞花、双头舞花、腰缠枪、腕转枪、旋身舞花、提膝转枪、跨步舞花、低姿腰缠、翻腕舞花

**组合衔接类**（枪尖 + 枪杆联动，远近结合，主打连招流畅，攻防无缝切换）
→ 刺后横扫、点后撩枪、格后直刺、劈后绕枪、扫后点刺、崩后挂枪、挡后旋扫、探刺后重劈

## 三、未来可用场景

### 场景 A · 武侠 / 古风 / 修真项目的用户 KB styleGuide 导入

用户在以下题材项目中可手动将本档内容复制到项目 KB 的 `styleGuide` 文档：
- 传统武侠（金古温梁风）
- 修真 / 仙侠（辅助法术体系）
- 古风言情（打斗场景需要真实感）
- 武侠改编 / 穿越武侠

**导入建议**：按主角使用的武器，只导入相关的 1–2 类（如主角用剑，只导入剑法 + 可能的掌法），减小 styleGuide 体量。

### 场景 B · 未来武学体系专用方法论模块

若 fili-web 未来开发 `novel.1.1.martial-system`（武学体系子节点）或武侠专用 craft 模块，可：
1. 以本档**武学体系设计法 4 维度**为 prompt 骨架
2. 以**通用 8 类功能**为体系设计依据
3. 让 LLM 按"每个武器 × 每类功能 × 核心发力部位 × 攻击范围"的结构设计**原创武学体系**
4. 具体招式词库作为参考而非直接抄录

### 场景 C · AI 视频分镜流程的武打戏素材

未来 `storyboard.ai-video.*` 流程上线时，武打戏分镜可参考本档招式名 + 动作描述作为视觉 prompt 原材料。

### 场景 D · 角色武学设定的初始化

写角色 bible 时，主角 / 反派武学招数的"代表性招式"可从本档选 3–5 招作为标志性动作（如反派用的是**沉棍重砸 + 腕抖崩棍**的两段式打法），形成角色战斗风格标识。
