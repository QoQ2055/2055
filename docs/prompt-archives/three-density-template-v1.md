## 使用场景建议

| 工作模式 | 推荐方式 |
|---|---|
| **自动化生成**（cineforge-web 主流程） | 启用 `three-density-review` 方法论模块即可，三密度硬律自动注入每章生成节点 |
| **半自动 · 手动章纲 + AI 生成** | 参考本归档的模块一 + 模块三模板填表，喂给 LLM |
| **人物前置设定** | 参考模块四模板，在 `novel.1.2` 节点产物基础上补充三密度属性 |
| **定期伏笔同步** | 本归档模块五可替代 / 补充 `plot-coherence-scaffold` 的伏笔追踪 |
